# 인물 읽어보기 5인 시범 이력

> 완료된 시범 기록이다. 현재 작성·검토·배치 규칙은
> `docs/project/celeb/person-reading.md`만 따른다.

2026-08-04에 `웅녀`, `이순신`, `칭기즈 칸`, `피터 틸`, `아킬레우스` 다섯 명으로
`celeb_explanations` 구조를 검증했다. 당시에는 별도 출처 테이블도 함께 만들었다. 두 글의 초판 이름은
`풀어쓰기`와 `인물 읽기`였으며, 서비스 적용 때 상위 구획을 `읽어보기`, 탭을 `인물 안내`와
`인물 탐구`로 확정했다.

출처 테이블은 서비스 요건이 아니어서 2026-08-04 폐기하고, 본문 행에
`NULL / ai_reviewed / human_reviewed` 검수 상태를 두었다. 현재 규칙은 전량을 먼저 읽어 좋은
글은 유지하고, 부실한 글만 조사해 한영으로 다시 쓰는 방식이다.
