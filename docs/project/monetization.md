# 수익화 방안

Feelandnote 서비스의 수익화 전략을 탐색·정리하는 문서.

## 탐색 소스

- **Google AdSense 한국어 공식 블로그**: https://adsense-ko.googleblog.com/

## 수익 모델 평가

| # | 모델 | 적합도 | 근거 |
|---|------|--------|------|
| 1 | **알라딘 TTB** (도서 제휴 링크) | 높음 | 구매액 3% 적립금. 개인 가입 즉시 사용 가능. DB에 affiliate_url 인프라 완비 |
| 2 | **AdSense 디스플레이 광고** | 높음 | 스크립트 이미 삽입됨. 셀럽 1,073명 등 원본 콘텐츠 풍부 → 승인 가능성 높음 |
| 3 | **쿠팡파트너스** | 중간 | 링크 통해 총매출 15만원 달성해야 최종 승인. 도서 특화는 아님 |
| 4 | **프리미엄 구독** | 중간(장기) | 사용자 기반 성장 후 고급 기능 차별화 |
| ~~5~~ | ~~텐핑/애드픽~~ | 부적합 | CPA 마케터용 플랫폼. 서비스 내 구매 버튼 방식과 맞지 않음 |

## 도서 제휴 프로그램 조사 결과 (26.03.09)

| 서점 | 제휴 방식 | 가입 조건 | 판정 |
|------|----------|----------|------|
| **알라딘 TTB** | 직접 어필리에이트 | 개인 무료 가입, 사이트 URL 등록 후 1~3일 승인 | **유일한 선택지** — 로그인 이슈로 보류 중 |
| **교보문고** | 출판사/저자용 파트너시스템 | eBook/POD 유통용. 어필리에이트 아님 | 부적합 (제휴 제안은 가능하나 소규모 서비스에 비현실적) |
| **YES24** | 자체 어필리에이트 없음 | 텐핑 경유만 가능 | 부적합 (2025년 해킹+서비스 마비 사태로 불안정) |
| **인터파크 도서** | — | 2025년 12월 파산 | 제외 |
| **링크프라이스** | 제휴 네트워크 (중개) | 실명인증만으로 무료 가입 | 도서 서점 광고주 유무 확인 필요 |
| **아마존 Associates** | 글로벌 어필리에이트 | 한국에서 가입 가능. 도서 4.5% | 영문 콘텐츠용으로 검토 가능 |

**결론:** 국내 도서 직접 제휴는 알라딘 TTB가 사실상 유일. 나머지는 자체 어필리에이트 프로그램이 없거나 부적합.

## 현재 인프라 상태

### 제휴 링크 (완비)
- `content_locales.affiliate_url` JSONB 컬럼 존재
- `ContentInfoSection.tsx` 290~318줄: 플랫폼별 구매 버튼 UI 렌더링
- `affiliatePlatforms.ts`: 쿠팡/알라딘/YES24/교보문고 4개 플랫폼 정의
- 백오피스 콘텐츠 상세에서 제휴 URL 입력/편집 UI 존재
- **남은 일: 제휴 프로그램 가입 → 실제 URL을 DB에 채우는 것**

### AdSense (승인 재신청 준비)
- `layout.tsx`에 AdSense 스크립트 삽입됨 (`ca-pub-3751045783335791`)
- Google Analytics 활성 상태
- 승인 필수 페이지 전부 완비: About, Privacy, Terms, Contact, Sitemap, Robots.txt
- 푸터에 모든 정책 페이지 링크됨
- **1차 승인 신청 (26.03.09)** — 거절됨
- **26.03.26 개선 사항:**
  - 개인정보처리방침에 광고 조항 추가 (Google AdSense, 쿠키, 행동 타겟팅, opt-out 안내)
  - 개인정보 보호 책임자 조항 추가 (7조)
  - About 페이지에 운영자 정보 (서비스 설명, 팀, 이메일, 소재지) 추가
  - 정책 페이지(Privacy, Terms, Contact) `robots noindex` 제거 → Google 크롤링 허용
  - 정책 페이지에 `description`, `hreflang alternates` 메타 추가
  - Privacy/Terms 영문 페이지의 "koreanOnly" 배너 제거 (영문 번역 완료 상태와 모순)
  - 쿠팡 제휴 링크 전면 비활성 (홈, 탐색, 서고, 콘텐츠 상세 — 주석처리)
- **남은 일: 승인 후 광고 단위(Ad Unit) 페이지 배치 + 쿠팡 제휴 재활성**
