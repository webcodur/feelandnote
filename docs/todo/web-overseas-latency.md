# 해외 접속 지연 점검 결과와 개선 후보

26.09.21 check-host.net 58노드로 실측했다. 요청 경로는
브라우저 → Cloudflare 엣지 → 춘천 웹 VM → 춘천 DB VM이며 캐시 정책은
`docs/project/platform/external-services.md` 「Cloudflare 앞단 캐시」가 쥔다.

## 실측

| 대상 | 결과 |
|---|---|
| 인물·작품 상세 — 엣지 HIT | 0.03~0.3초. 방문자 근처 엣지가 응답해 해외에서도 빠르다 |
| 인물·작품 상세 — 엣지 MISS | 2.8~4.2초. 그 엣지의 최초 요청만 춘천까지 간다 |
| 홈·탐색·검색·광장·API (캐시 제외) | 총 3~4.7초. 매 요청 춘천 왕복 |
| `robots.txt` (순수 왕복 하한) | 아시아 0.16~0.19s · 북미 0.4~0.6s · 유럽 0.7~1.3s |
| 정적 자산·R2(`assets.feelandnote.com`)·외부 CDN 이미지 | `immutable`+엣지 HIT, R2는 글로벌 — 전역 빠름 |

다이내믹 화면은 왕복 하한 위에 서버 렌더(로컬 기준 홈 TTFB 0.49s·탐색 0.83s)와
큰 HTML(홈 449KB·탐색 517KB)이 얹힌다.

로그인 사용자는 헤더가 브라우저에서 `db.feelandnote.com`(Cloudflare Tunnel→춘천 DB)으로
`auth.getUser`+알림 조회를 직접 날려(`sw/web/src/components/layout/header/useHeaderNotifications.ts`)
한국 왕복이 한 번 더 붙는다. `realtime` 컨테이너는 올라 있지 않아 채널 구독은 조용히 실패한다.

별개 관찰: 무료 플랜이라 한국 사용자도 엣지가 ICN이 아니라 HKG·NRT로 배정될 수 있다(실측 CF-RAY=HKG).

## 개선 후보

- [ ] 비개인화 화면(탐색·명부 등)의 익명 응답도 엣지 캐시에 넣는다. 무효화는 기존
  DB 트리거 → `/api/revalidate` 경로를 재사용한다.
- [ ] 홈·탐색 HTML의 RSC 페이로드를 다이어트한다 — 국내외 모두에 이득.
- [ ] 헤더 알림 초기 조회를 서버 렌더에 합쳐 브라우저→터널 왕복을 없앤다.

## 비용

위 세 후보는 캐시 규칙(무료 플랜 기능)과 코드 작업이라 **추가 요금이 없다**. 퍼지 호출도 무료다.
돈이 드는 것은 그 다음 단계 선택지다 — 해외 트래픽 비중이 실제로 커졌다고 확인된 뒤에 판단한다.

- **Argo Smart Routing** — $5/월 + 비캐시 전송량 $0.10/GB(첫 1GB 무료). 엣지→춘천 오리진 구간을
  CF 백본 최적 경로로 태워 다이내믹 화면의 해외 왕복을 줄이는 사실상 유일한 스위치다.
  캐시 안 타는 요청이 많아질수록 변동비가 커진다.
- **Pro 플랜** — $20/월(연간 결제)·$25/월(월간). 한국 사용자의 ICN 엣지 배정이 나아진다는
  보고가 있으나 보장은 아니며, 해외→춘천 왕복 자체는 줄지 않는다.
- **제2 리전 오리진·로드밸런싱** — VM 실비+운영 공수. 현 규모에는 과하다.
