# 글 부드러움 규칙

에피소드 텍스트가 TTS 음성으로 읽혔을 때 자연스럽고 부드럽게 들리도록 하는 기준.

---

## 에피소드 파일 경로

```
sw/remotion/public/episodes/{stage}/{person}/{locale}.json
```

- `{stage}`: `pre-todo` | `todo` | `live` | `done`
- `{locale}`: `ko` | `en`

### 검토 대상 필드

summary, contextMain, quotePairs[].after, philosophy, celebIntro, outro, shorts 세그먼트

---

## 1. 주어 규칙 *(강력 권장)*

### 모든 문장에 주어를 넣는다

- celebIntro 제외, 모든 텍스트 필드에서 주어 필수.
- 주어가 앞 문장과 동일해도 대명사("그는", "그녀는")라도 넣는다.
- 리듬상 생략이 자연스러운 경우만 예외. 기본값은 주어 삽입.

### 주어는 문장 앞에 둔다

- 한국어 기본 어순: **주어 → 부사어/목적어 → 서술어**
- 주어가 뒤로 밀리면 "누가"를 문장 끝까지 가야 알 수 있다.
- 강조·반전 등 의도적 도치는 허용하되, 기본값은 주어 선행.

**나쁜 예:**
> 전장에서 돌아왔다. 곧바로 개혁에 착수했다.

**좋은 예:**
> 그는 전장에서 돌아왔다. 그리고 곧바로 개혁에 착수했다.

---

## 2. 연결어 규칙

### 문장 시작에 연결어 필수

- 새 문장이 앞 문장과 어떤 관계인지(순접·역접·인과·전환) 문두에서 즉시 알려줘야 한다.
- 연결어 없이 문장을 나열하면 번역체처럼 들린다.

### 같은 연결어 반복 금지

- "결국 ~했습니다. 결국 ~했습니다." — 반복 금지.
- 연결어를 다양하게 교체한다.

| 관계 | 연결어 |
|------|--------|
| 순접 | 그리고, 또한, 게다가, 더불어, 나아가 |
| 역접 | 하지만, 그러나, 반면, 그럼에도, 다만 |
| 인과 | 그래서, 따라서, 그 덕분에, 이 때문에, 결국 |
| 전환 | 한편, 그런데, 반면에, 다른 한편으로 |
| 부연 | 즉, 다시 말해, 특히, 예컨대, 사실 |
| 시간 | 이후, 그 뒤로, 이윽고, 얼마 지나지 않아 |

---

## 3. 문장 리듬

### 장단 교차

- 짧은 문장(15자 이하)과 긴 문장(25~35자)을 교차한다.
- 같은 길이의 문장이 3개 이상 연속되면 단조롭다.

**단조로운 예:**
> 그는 책을 읽었습니다. 그는 감동을 받았습니다. 그는 결심을 했습니다.

**리듬 있는 예:**
> 그는 책을 읽었습니다. 한 줄 한 줄, 밤새 손에서 놓지 못했습니다. 그래서 결심했습니다.

### 문장 끝 변화

- "~했습니다"가 3회 이상 연속되지 않도록 한다.
- "~입니다", "~했습니다", "~이었습니다", "~되었습니다"를 번갈아 사용.

---

## 4. TTS 친화성

### 쉼표 규칙

- 한 문장에 쉼표 2개 이하.
- 쉼표 3개 이상이면 문장 분리를 고려한다.

### 읽기 어려운 패턴

| 패턴 | 문제 | 교정 |
|------|------|------|
| 관형절 중첩 | "~한 ~를 ~한 ~의" | 두 문장으로 분리 |
| 접속사 연쇄 | "~하고 ~하며 ~하면서" | 각각 독립 문장으로 |
| 한자어 밀집 | "혁명적 사상적 변혁" | 순우리말 혼용 |

---

## 5. 필드별 말투 규칙

| 필드 | 말투 | 예시 |
|------|------|------|
| summary | 정중체 (~입니다) | "이 책은 ~를 다룬 작품입니다." |
| contextMain | 정중체 (~했습니다) | "그는 ~했습니다." |
| quotePairs[].after | 정중체 | "하지만 놀라운 건 ~였습니다." |
| philosophy | 1인칭 + speech_tone | "나는 ~이다." 또는 "저는 ~입니다." |
| celebIntro | 서술체 (~이다, ~했다) | "~은 ~의 왕이다." |
| outro | 정중체 | "~의 N권의 책이었습니다." |
| shorts | 각 segment 역할에 따름 | narrator=정중체, celeb=1인칭 |

---

## 6. 인용부호 규칙

- **AI가 작성한 텍스트에 큰따옴표(`""`)를 사용하지 않는다.** 인용부호는 검증된 실제 발언(quotePairs[].quote)에만 허용.
- 강조가 필요하면 인용부호 대신 문맥으로 전달한다.

---

## 7. 리라이트 시 보호 필드

텍스트를 수정할 때 아래 필드는 절대 건드리지 않는다:

- `thumbnail_url`, `stats`, `source` — 데이터 필드
- `duration`, `*Duration` — TTS 파이프라인이 관리
- `quotePairs[].quote` — 실제 발언 원문

텍스트를 변경하면 `tts` 오버라이드(tts.replace, tts.titles)도 갱신 필요 여부를 확인한다.

---

## 자기 검증 체크리스트

수정 후 각 텍스트 필드에 대해 확인:

- [ ] 주어 없는 문장이 없는가 (celebIntro 제외)
- [ ] 연결어 없이 시작하는 문장이 없는가
- [ ] 같은 연결어가 2문장 이내에 반복되지 않는가
- [ ] 같은 문장 끝이 3회 이상 연속되지 않는가
- [ ] 소리 내어 읽었을 때 호흡이 자연스러운가
- [ ] AI 작성 텍스트에 큰따옴표가 없는가
- [ ] tts 오버라이드 갱신이 필요하지 않은가

---

## 행동 원칙

- 문제 문장을 발견하면 **즉시 리라이트**한다. 보고서만 남기지 않는다.
- 사료·구성·논리 문제가 보이면 함께 지적하고 수정한다.

---

## 보고 형식

```
## [인물명] 문장 다듬기 완료

### 수정 사항
- summary Book 1: 주어 삽입 2건, 연결어 추가 1건
- context Book 3: 장문 분리 1건 (42자→두 문장)
- philosophy: 도치 교정 1건

### 미수정 (의도적 허용)
- context Book 5: 도치 유지 (반전 강조)
```

- 단어를 삭제하지 않고 **수려하게 재작문**한다.
- contextQuote는 수정하지 않는다.
- 새로운 정보를 추가하지 않는다.
