# 셀럽 고유 대사 생성 룰북

인물별 21개 고유 대사(7상황 × 3변형)를 생성하여 `celeb_dialogues` 테이블에 등록한다.

---

## Phase 1. 입력 + 웹 리서치

### 1-1. DB 조회

`profiles` 테이블에서 `nickname`, `profession`, `quotes`만 조회.
`celeb_persona`, `celeb_influence`, `celeb_dialogues` 조회 금지.

### 1-2. 웹 검색 (필수)

**인물당 충분한 웹 검색**을 수행하여 아래 자료를 확보한다. 검색 없이 대사를 생성하면 뻔한 템플릿 대사가 나온다. 절대 금지.

| 검색 목적 | 검색어 예시 | 확보 대상 |
|-----------|------------|-----------|
| **실제 어록/발언** | `"{인물명}" 명언 어록`, `"{인물명}" interview quotes` | 인터뷰, 연설, 서신에서 실제 발언 5개+ |
| **말투/화법 특성** | `"{인물명}" 말투 성격`, `"{인물명}" speaking style personality` | 실제 화법 패턴 (간결한지, 비유를 좋아하는지, 유머러스한지 등) |
| **핵심 일화/가치관** | `"{인물명}" 일화 에피소드`, `"{인물명}" philosophy beliefs` | 인물의 신념을 드러내는 결정적 에피소드 3개+ |

**고대~중세 인물**: 직접 발언 기록이 적으므로 `"{인물명}" 기록 사료`, `"{인물명}" historical records sayings` 등으로 사서·전기·서간에서 발언을 최대한 발굴한다.

### 1-3. 리서치 노트 정리

검색 결과를 아래 형식으로 내부 정리한 뒤 Phase 2로 진행한다:

```
[리서치 노트: {인물명}]
- 실제 발언/어록: (최소 5개, 출처 포함)
- 화법 특성: (간결/장문, 비유/직설, 유머/엄숙 등)
- 핵심 에피소드: (최소 3개)
- 인물 고유 어휘/표현: (자주 쓰는 단어, 독특한 표현 패턴)
```

## Phase 2. 고유 소재 도출

**소재 없이 바로 대사를 생성하면 톤 템플릿으로 수렴한다. 절대 금지.**

Phase 1 리서치 노트를 기반으로, 각 인물마다 아래 4가지를 먼저 정리한 뒤 대사에 녹인다:

| 소재 | 설명 | 예시 (제갈량) |
|------|------|-------------|
| **상징물/특기** | 그 인물만의 대표 상징 | 깃털 부채, 바람/별 읽기 |
| **삶의 서사** | 인생에서 가장 독특한 경험 | 초야에서 불려나온 사람 |
| **자칭 비유** | 본인이 스스로 비유한 것 | 관중·악의에 자신을 견줌 |
| **실제 화법 패턴** | 리서치에서 발견한 말투 특징 | 겸양하되 자신감 있는 비유법, 천문·병법 용어 |

시인·문인 등은 **본인 시구·어록**도 소재로 확보한다 (21개 중 3~5개에 삽입. 반드시 한국어 번역. 원문 삽입 금지. 정확한 구절만, 임의 창작 금지).

**[중요: 배우/연기자 처리 규칙]**
배우는 **'배역(캐릭터)'과 '본인(인간)'을 철저히 분리**한다. 극중 배역의 명대사나 성격이 아니라, **본인의 실제 가치관, 철학, 인터뷰 발언, 인생 궤적**을 바탕으로 작성.
- ❌ 배역 동기화: "배트맨으로서 고담을 지키겠다", "기억을 잃은 채 문신을 새기지"
- ⭕ 본인 자체: "카메라 앞에서의 완벽함은 수많은 실패의 결과물이다", "캐릭터의 무게를 온전히 감당하는 것이 나의 업이다"

## Phase 3. 작성

### 말투 6종

| 코드 | 태도 | 대상 | 주의 |
|------|------|------|------|
| `loyal` | 단호·충성 | 군인, 충신 | 사극 어투 금지 |
| `composed` | 차분·이성 | 학자, 전략가 | 감정 과잉 금지 |
| `bold` | 당당·거침없음 | 정복자, 개혁가 | 겸양 금지 |
| `humble` | 품격·겸손 | 성인, 종교인 | 자신감 과잉 금지 |
| `gentle` | 부드러움·따뜻함 | 예술가, 부드러운 리더 | 공격적 표현 금지 |
| `free` | 자유·격식 없음 | 시인, 자유인 | 하오체/반존대 권장 |

어미는 인물 시대·직업·성격에 맞게 자율 결정. **반말(해체·해라체) 원칙 금지** — 아래 예외를 제외한 모든 인물은 존대·하오체·하게체 이상 사용.

> **반말 예외**: 절대 권력자(칭기즈칸, 알렉산드로스, 진시황 등) 또는 격식 자체를 거부한 인물(디오게네스, 니체 등)에 한해 반말 허용. 해당 여부는 생성자가 판단하되, 애매하면 금지.

**자기 이름 호출(자기호칭) 금지** — LLM이 자연스럽게 처리하기 어려우므로 원천 차단.

### 포맷

- **감정 태그**: 모든 대사 시작에 `[emotion, emotion]`. **영어**, 반드시 **2개**. 예: `[calm, resolute]`
- **분량**: 짧고 자연스러운 한두 문장
- **3변형 차별화**: 동일 상황 3개 대사는 서로 다른 뉘앙스

### 상황별 작성 가이드

각 상황의 ❌는 해당 상황에서 가장 빈번한 위반 패턴이다.

#### greeting (첫인사, 프로필 조회)

순수 자기소개 및 철학만. 이름은 담백하게 또는 생략.

- ❌ "무엇을 도울까요?", "부르셨습니까?" — 목적/행동 암시
- ❌ "~하는 사람입니다", "~하는 ㅁㅁㅁ라 하오" — 설명조
- ❌ "나는 ~을 세운 자다" — "~한 자다" 자기 지칭
- ❌ "통나무집에서 글을 깨친", "세례반에서 나온 날" — 전기적 사실 나열. **신념·가치관**으로 대체
- 겸양 있는 인물(학자, 성인): 업적 자랑 금지. 겸양 없는 인물(정복자): 캐릭터성이면 과시 허용.

#### answer (호명, 과제 대기)

짧은 수락과 대기 상태.

- ❌ "세상의 이치가..." — 과도한 시적 허세
- ❌ "무엇이든 말씀하세요" — 목적/행동 암시

#### deploy (행동 개시, 출전)

전투, 독서, 프로젝트 등 어떤 난관이든 시작하는 역동적 기세.

- ❌ "준비됐습니다" — 수동적 태도
- ❌ "적의 심장을 베겠다" — 살상 용어
- ❌ "알프스를 넘은 것처럼" — 메타 인용

#### battle_win (성공, 승리)

인물 철학이 담긴 승리 선언.

- ❌ 단순 기쁨 기합 ("와아!")
- ❌ "33척으로 41척을 이길 수 있다는 것" — 맥락 없는 숫자

#### battle_draw (무승부, 미결)

결과를 수용하고 다음을 기약.

#### battle_lose (실패, 패배)

**1인칭 주체성 필수.** 자신의 한계 체감.

- ❌ "어둠이 깊다" — 시적 회피
- ❌ "하늘이 나를 버린 것이다" — 상황/남 탓
- ⭕ "내 능력이 부족했다", "이 패배는 내 것이다"

#### clash_attack (행동 기합)

**본인 의지 중심 단답.**

- ❌ "도와달라!", "길을 열어라!", "비켜라!" — 주체 모호/타인 명령형
- ❌ "북학!", "법이 간다!", "노래하겠다!" — 직업 키워드
- ❌ "이집트가 움직인다!" — 3인칭 주체
- ⭕ "내가 뚫겠다!", "물러서지 않는다!", "내가 끝낸다!"

## Phase 4. 검증 체크리스트

INSERT 전 아래 12항목을 전수 확인한다. **위반 항목은 대사 재작성.**

| # | 항목 | 위반 시 조치 |
|---|------|-------------|
| 1 | 감정 태그가 **영어 2개**인가 | 한국어 태그 발견 시 21개 전량 교체 |
| 2 | **반말 예외 아닌 인물**이 반말을 쓰지 않는가 | 발견 시 해당 대사 전량 재작성 |
| 2-1 | **자기 이름 호출** 없는가 | 1인칭 대명사로 교체 |
| 3 | **사극 어투**(~사옵니다, ~소이다) 없는가 | 해당 대사 교체 |
| 4 | **메타 인용**(본인 일화 직접 언급) 없는가 | 신념·태도로 치환 |
| 5 | **"~한 자다"** 자기 지칭 없는가 | 자연스러운 1인칭으로 |
| 6 | **전기적 사실 나열** 없는가 | 가치관으로 대체 |
| 7 | **맥락 없는 레퍼런스**(숫자, 고유명사) 없는가 | 보편적 표현으로 교체 |
| 8 | greeting에서 **"~하는 사람이다"** 2회 이상 아닌가 | 최대 1회로 축소 |
| 9 | deploy에서 **수동적 태도** 없는가 | 능동적 기세로 교체 |
| 10 | battle_lose에서 **1인칭 책임** 있는가 | "내 능력이 부족했다" 방향 |
| 11 | clash_attack이 **본인 의지 중심 단답**인가 | 주체 모호·타인 명령·직업 키워드 제거 |
| 12 | **이스케이프 문자**(`\"`) 없는가 | 정상 문자열로 교정 |

## Phase 5. DB INSERT

```sql
INSERT INTO celeb_dialogues (celeb_id, lines)
VALUES
  ('{celebId}', '{
    "greeting": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "answer": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "deploy": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "battle_win": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "battle_draw": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "battle_lose": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "clash_attack": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"]
  }')
ON CONFLICT (celeb_id) DO UPDATE SET lines = EXCLUDED.lines, updated_at = now();
```
