# 인물 상세 화면

사용자 웹 인물 상세(`(main)/celeb/[slug]/`)의 구획, 감상 목록 펼침, 작품 소개 표시 규격이다. 인물 데이터의 작성·검수는 [`../celeb/`](../celeb/README.md), 세계 결정·배너는 celeb 08 문서가 쥔다.

책장은 등장·집필·직군·소속 네 분류를 한 줄로 표시하고, 책이 없는 분류는 비활성화한다. 본인의 감상 목록은 위쪽 리뷰 구획에서 제공한다. 책장 인물 목록 모달은 공용 `FigurePersonRows`를 사용하며 얼굴은 확대, 이름은 대사, 오른쪽 조작은 `CelebDetailModal`을 연다. 책장 본문의 다른 인물 이름도 같은 상세 모달로 열고 선택한 책을 유지한다. 해당 인물의 공개 감상 기록이 있으면 그 책의 감상 배경과 출처를 함께 표시하고, 스포일러는 해제하기 전까지 가린다. 감상자 목록에서 인물을 열었다 닫으면 검색 상태를 유지한 목록으로 돌아온다.

책장 관계 목록은 작품에 등록된 실제 등장·집필 관계와 공개 감상 기록을 유지한다. 개인 책장의 등장 목록에서는 본인만 제외한다. 직군 추천의 근거 인물과 신화·세력 구성원은 정렬 우선순위에만 반영하며 전체 감상자를 줄이지 않는다. 본문에는 전체 인원수와 공통 기준의 일부 이름을 표시하고, 감상 기록이 있으면 인원수와 무관하게 전체 감상자 목록을 열 수 있다.

책장의 좌우 이동 버튼은 책을 바꾼 뒤 제목이 고정 헤더 아래에 보이도록 책 시작 위치로 부드럽게 이동한다. 동작 줄이기 설정에서는 즉시 이동한다. 현재 책의 바로 다음 책까지 표지·판본·소개·관계 자료를 미리 불러오며, 감상 분류에서는 다음 책의 작품 소개와 공개 감상 전문도 준비한다. 마지막 책의 다음은 첫 책이다.

## 구획과 티어

프로필과 본문 구획은 메인 화면과 같은 `HubSection`의 번호·가운데 제목·구분선을 사용한다. 본문을 둘러싼 별도 외곽 패널과 좌우 패딩을 두지 않아 콘텐츠가 페이지 본문 폭을 그대로 쓴다. 구획 이동은 아틀라스 목차가 맡는다.

셀럽 상세의 02번 구획은 티어에 따라 갈린다. `full`은 감상·창작 기록물을 표시하고,
`fiction`은 `figure_book_contents`에 지정된 대표 콘텐츠를 「원전·등장 작품」으로 표시한다.
대표 콘텐츠 상세에서는 같은 관계를 역으로 읽어 「이 작품의 인물」을 보여준다.
이 등장 관계는 감상 관계인 `celeb_contents`와 분리되어 있다.
인물 상세 히어로 구획은 `celeb_reality`가 `BOTH`이면 「복합」 버튼, `FICTION`이면 「가상」 칩을 표시한다. 「복합」을 누르면 역사 속 인물과 전설이나 문학 속 모습을 함께 지닌 분류라는 설명을 모달로 읽는다. 인물 카드와 세력도감 소개도 `CelebRealityLabel`을 공유한다. 인물 선택 버튼 안의 표식은 중첩 버튼을 만들지 않고 이름만 표시한다. `REAL`은 칩을 표시하지 않는다.

검색 제목과 화면 공유 제목의 티어별 규칙은 [SEO](../operations/ops-02-seo.md) 「인물 상세 메타데이터」가 쥔다. `fiction`은 서사 배경 연도로 현실 인물의 동시대를 계산하지 않고, 영향력·스펙트럼 자리에는 미등록 표시 대신 현실 인물용 평가를 적용하지 않는다는 해석 안내를 보여준다.

소개 카드의 「채널과 자료」는 검증된 `wikidata_qid`에서 공식 웹사이트·SNS·Wikipedia·
권위 레코드를 읽어 실제로 존재하는 링크만 표시한다. 현대인은 공식 채널을 우선하고,
고대·신화 인물은 백과·철학사전·도서관 자료가 중심이 된다. QID가 없는 인물은 이름 검색
결과를 공식 링크처럼 추정해 보여주지 않으며, fiction의 원전 연결은 기존 「원전·등장 작품」
구획이 맡는다. 같은 링크들은 Person JSON-LD의 `sameAs`에도 반영한다.

인물 안내와 가상독백은 각각 독립 구획으로 표시한다. 인물 안내는 전문을 바로 보여준다. 상세페이지 가상독백은 PC에서 높이 제한과 끝 흐림 없이 전문을 표시하고, 모바일에서는 적정 높이에서 자른 미리보기를 눌러 전문 모달로 읽는다. 감상배경·독백 등에 쓰는 공용 미리보기 모듈 `ReviewScrollBox`는 기본적으로 마지막으로 보이는 글줄을 흐리며, 아래쪽 빈 개행은 흐림의 기준에서 제외한다. 감상 목록은 글이 실제로 잘릴 때만 흐리고, 짧은 글은 선명하게 모두 표시한다. 셀럽 상세의 PC 감상 본문은 화면이 넓어져도 읽기 폭을 제한해 가운데 배치한다. 음원 메타데이터에서 재생 가능 여부를 확인한 경우에만 낭독 조작을 표시하며, 제목·목차에 초록색 존재 표시는 두지 않는다.
타임라인은 본문 구획과 목차에서 제외한다. 프로필의 타임라인 버튼을 누른 방문자만 전체 연표 모달을 열어 본다.
게임용 고유 대사는 상세 본문과 목차에 별도 구획으로 표시하지 않는다.
관계에는 인물 관계망을 표시하며, 자료가 없으면 목차와 본문에서 제외한다. 소속 신화·세력 이동은 프로필 조작부의 조직 아이콘으로 모은다. 누르면 소속 목록 모달을 열고 각 항목에서 해당 신화·세력도감으로 이동한다. 프로필 조작부는 기본정보 아래에서 줄바꿈 가능한 가로 줄을 쓰며, 모바일 버튼은 최소 44px로 표시한다. 프로필 이미지 확대와 직군 설명은 공용 `Modal`을 쓰며, 바깥 화면에 기본 모달의 어두운 배경·블러를 적용한다. 이미지의 투명 영역은 별도 배경판 없이 이 바깥 화면을 비춘다. 직군 설명은 화면 중앙에서 연다.
모바일 관계 섹션은 연결선과 중심 인물 없이 얼굴·이름을 3열 목록으로 보여준다. 전체 관계에서는 여러 갈래에 속한 인물도 한 번만 표시하며, 관계 갈래로 범위를 좁힐 수 있다. 한 번에 최대 여섯 인물을 표시하고 좌우 버튼이나 밀기로 나머지를 본다. 얼굴을 누르면 아래의 선택 인물 설명을 교체한다. 설명 카드는 공용 `FigurePersonRows`를 사용하며 얼굴·이름·관계 표기를 헤더에 묶고 본문은 그 아래 전체 폭으로 읽는다. 카드의 얼굴은 확대, 이름은 대사 재생, 우측은 인물 상세 또는 미등록 인물의 외부 안내로 이동한다. PC에서는 기존 관계망을 유지한다.
평가 구획은 영향력·능력·성향·덕목의 수치를 함께 표시한다. 네 영역은 제목과 간격으로 구분하고 같은 행 높이·숫자 글꼴을 사용하고, 개별 수치는 막대 안에 표시한다. 종합 영향력은 `RANK C` 형식의 등급 표기, `영향력 48점` 형식의 점수, 순위·상위 비율, 유형을 네 줄로 가운데 정렬하며 점수 막대는 두지 않는다. 등급 아래에만 짧고 양끝이 흐려지는 선을 두며, 등급을 누르면 등급·점수 기준을 보여준다. 별도 외곽 패널은 두지 않으며 덕목 내부의 윤곽·구분선·점수 박스는 유지한다. 넓은 화면에서는 영향력 항목을 두 줄로 모으고, 능력·성향·덕목의 제목과 목록을 세 열로 나란히 배치한다. 좁은 화면에서는 네 영역을 차례로 쌓는다. 성향의 수치는 막대 중앙에 고정하며 실제 위치는 얇은 표시선으로 구분한다. 영향력·능력·성향·덕목의 개별 수치를 누르면 같은 모달에서 값과 평가 근거를 보여준다. 본문 아래로 펼치지 않으며, 닫으면 선택 표시를 해제하고 누른 수치로 포커스를 돌려준다. 영향력 점수와 능력·성향·덕목 제목을 누르면 설명 모달을 열며, 스펙트럼 설명은 누른 모드가 선택된 상태로 열고 안에서 세 모드를 전환한다. 시대초월성은 목록에서 `시대`로 줄여 쓰며, 누르면 전체 이름과 인물의 평가 근거·척도 기준을 하나의 모달에서 보여준다. 영향력 전체 설명에서는 여섯 영역만 보여준다. 영향력 비교 두 버튼과 유사 스펙트럼 네 버튼은 스펙트럼 수치 아래에서 한 묶음으로 배치하고, 별도 구획 제목 없이 같은 높이·테두리·간격을 사용한다. 여섯 비교 버튼은 넓은 화면에서는 한 줄, 좁은 화면에서는 `영향력 순위 | 영향력 선두`, `유사 능력 | 유사 덕목`, `유사 성향 | 유사 인물` 순서로 2×3 배치한다. 버튼의 화살표는 텍스트 중앙 정렬에 영향을 주지 않는다.

영향력 항목 목록에는 일반 점수 합계를 표시하지 않고, 덕목 수치 표에는 내적·외적 덕목의 별도 제목을 표시하지 않는다.

실존 인물의 영향력 순위는 공개 중인 `full`·`light` 인물을 하나의 모집단으로 삼는다. 영향력 비교 구획의 `영향력 순위`·`영향력 선두` 버튼은 해당 모드가 선택된 모달을 연다. 두 목록은 좌우 버튼과 밀기로 탐색하며, 더보기는 종합 또는 선택 분야의 영향력 순위 화면으로 연결한다. 종합
순위 레일은 동점자를 연달아 나열하지 않고 현재 점수보다 바로 높은 인물과 바로 낮은
인물을 현재 인물 양옆에 두며, 공동 순위와 동점 인원도 함께 밝힌다. 분야별 선두는
정치·전략·기술·사회·경제·문화·시대초월성 탭마다 상위 인물 5명을 보여준다. 분야
점수가 같은 인물은 임의로 순위를 가르지 않고 `공동 N위`로 표시한다.
목록에서 다른 인물을 누르면 기본정보만 담은 가벼운 인물 미리보기를 열고,
그 안에서 앞뒤 인물 또는 정본 상세 페이지로 이동한다.

인물 상세의 감상 목록은 화면 폭과 무관하게 **펼침** 하나로만 연다. 목록형 열람은 「전체 기록」 페이지가 맡고,
회원 서가만 **목록 ↔ 펼침** 두 보기를 오간다. 서버는 첫 4건을 주어 색인이 오기 전까지 첫 카드와 이전·다음 상태를 그린다. 펼침은 목록에서 고른 한 건을
넓게 보여주는 형태로, `작품 소개 → 감상배경 → 기타 메타데이터` 순서로 읽는다. PC의 작품 소개와 감상배경은 표지 오른쪽의 같은 본문 열에 두어 가로폭과 시작 위치를 맞춘다. 화면이 넓어져도 읽기 폭을 제한하고,
내부 스크롤 없이 미리보기에서 자르고, 눌러 전문을 모달로 읽는다. PC·모바일 모두 잘린 본문의 끝을 흐린다. 책장의 책 소개도 감상 목록과 같은 `ContentIntro` 모듈을 사용한다.
낭독이 있는 미리보기와 전문은 하나의 음원에서 재생 위치·일시정지·배속·문장 강조를 공유한다. 현재 문장이 미리보기 밖에 가려져도 접힘과 동기화를 유지하며, 모달을 열면 일시정지한 경우에도 그 문장이 보이도록 위치를 맞춘다.
본문은 공용 `FormattedText`의 일반 글자·금색 인용·흰색 작품명·용어의 색과 굵기 구분을 유지한다. 낭독 중에는 현재 구간에만 옅은 초록 배경과 밑줄을 더하며, 기존 글자색과 굵기를 덮어쓰지 않는다. 모달과 미리보기 모두 같은 규칙을 따른다.
소개·감상배경은 아이콘과 아바타 없이 「작품 소개:」「감상 배경:」를 본문 앞에 표시한다. 개인 영어 화면의 감상배경 라벨에는 인물 이름을 넣어 미리보기와 전문 모달을 일치시킨다. 출처 링크는 바깥 미리보기에서 빼고 각각의 상세 모달 오른쪽 아래에 고정하며, 본문을 스크롤해도 제자리를 유지한다. 제목 목록이나 이전·다음 버튼으로 작품을 고르면 상세를 즉시 교체한다. PC는 본문 양옆의 좁은 화살표 열을 쓰고, 모바일은 제목 헤더와 본문 아래에 이전·다음 버튼을 둔다. 처음과 끝은 순환한다.
리뷰와 책장의 분류 칩은 모드만 변경한다. 바깥 칩을 누르면 제목·저자가 있는 헤더 면 전체가 잠깐 천천히 밝아졌다 사라져 목록을 여는 위치를 알린다. 강조 테두리는 두지 않고 양옆 이동 버튼은 효과에서 제외한다. 제목 헤더를 누르면 화면 폭과 무관하게 중앙 목록 모달을 열며, 검색은 모달 안에서 한다. 제목과 저자는 가운데 정렬하고 목록 아이콘은 정렬에 영향을 주지 않게 오른쪽에 고정한다.
리뷰·책장·판본 선택 목록은 `LibraryIndexModal`·`LibraryIndexList`·`LibraryIndexItem`을 공유한다. 각 행에는 순번·작은 표지·제목·저자·현재 선택을 표시하고, 검색 후에도 원래 순번을 유지한다. 분류와 검색은 위에 고정하고 목록만 스크롤한다. 항목 수가 바뀌면 모달 높이를 부드럽게 전환하며, 동작 줄이기 설정에서는 높이 전환과 펄스를 생략한다. 책장 판본은 별도 「판본」 설명 없이 가로 제목 칩으로 나열한다.
초기 일부 목록이 전량 목록으로 바뀌어도 이미 선택한 작품이 남아 있으면 작품 ID로 선택을 보존한다. 리뷰 구획에는 정렬 조작을 두지 않으며, 「전체 기록」 버튼은 도서·영상·게임·음악 칩 아래에 둔다. 아이콘 조작의 접근성 이름과 툴팁에는 전체 이름을 남긴다.
펼침은 쪽을 나누지 않고 최대 500건의 얇은 색인을 한 번에 받는다. 색인에는 기록·작품 ID, 유형, 제목, 제작자, 표지와 정렬 시각만 담고 감상배경·출처·저장 메타데이터는 싣지 않는다.
첫 작품의 완성 기록은 서버 응답에 포함하며, 다른 작품의 완성 기록과 작품 소개는 선택할 때 한 건씩 병렬로 받고 작품 ID별 페이지 캐시에 누적한다. 따라서 전체 탐색 순서와 좌우 순환은 유지하면서 아직 열지 않은 작품의 본문은 전송하지 않는다.

작품 소개·정보는 선택한 한 건만 `getContentBrief`가 바깥(카카오·TMDB·IGDB·iTunes)에서 받는다.
작품을 선택하면 제목·표지와 `OO의 감상배경`·`책 소개`·`게임 소개` 같은 구획명을 즉시 바꾼다. 아직 도착하지 않은 감상배경·출처·작품 소개·메타데이터 자리는 로딩 상태로 남기며, 이전 작품의 본문을 대신 보여 주지 않는다. 인접 작품은 미리 요청하지 않는다. 음악은 저장된 iTunes metadata가 있으면 외부를 다시 조회하지 않는다. 소개에는 `책 소개` 또는 `작품 소개` 라벨을 붙이고, 문자열로 넘어온 HTML 엔티티를
일반 텍스트로 복원하며 연속된 빈 줄은 문단 사이 한 줄로 줄인다. 소개 제목과 감상배경 제목은 같은 글꼴·크기·굵기의
섹션 위계를 쓴다. 긴 소개의 전문은 모달에서 읽으며, 책 기본 정보는 넓은 화면에서
2×2로 배치하고 좁은 화면에서는 한 줄씩 쌓는다. 메타데이터 패널에 별도 외곽 박스를 덧씌우지 않으며, 각 항목은 `라벨 | 값` 2열 셀이며 출판사·출판일·ISBN 누락은
`미확인`으로 남긴다. 책 표지를 누르면 이미지만 확대하고, 내부 작품 상세는 `모든 감상`, 외부 자료는
`도서 정보`로 구분하며 모바일에서도 두 버튼을 한 행에 둔다. 표지 전환은 `BlurDissolve`만 사용하며 별도의 pulse 배경이나 이미지 placeholder를 겹치지 않는다.
게임 스크린샷은 격자의 한 장을 누르면 공용 전체화면 갤러리를 열고, 좌우 버튼·방향키·하단 썸네일로 최대 6장을 순환한다. 닫으면 누른 스크린샷으로 포커스를 돌려준다.
셀럽 감상 목록은 서비스 등록일을 감상 시점처럼 월별로 나누지 않으며, 월 구획과
접기·펼치기 UI는 회원 기록에만 제공한다. `contents.metadata`는 책·영상 기준 열에 여덟이 비어 있고 같은 값이
출처마다 다른 이름(`publishDate`/`pubdate`/`publishedDate`)으로 들어 있어, 이 함수가 이름을 하나로
모은 뒤 화면에 넘긴다. 음악은 iTunes 출처가 다수라 전용 칸에 부른 사람·갈래·맛보기·듣기 링크를 모은다.
BOOK 소개는 저장된 번역문을 그대로 표시하거나, 소개값에 지정된 외부 출처에서 선택 ISBN의 본문을 조회·캐시한다. 출처 선정과 기존 소개 전환은 [콘텐츠 등록 규칙](../celeb/celeb-02-02-content-registration.md#locale)이 쥔다.
그 외 콘텐츠의 소개 본문은 요청 locale의 `content_locales` 값만 우선하며, 값이 없을 때도 같은 언어를 돌려주는 외부 출처만 쓴다.
다른 언어의 소개를 대체 노출하지 않고 소개 없음 상태로 남긴다.

**인물 서가의 클라이언트 재조회는 `getPublicCelebContents`를 쓴다.** `getPublicViewerContents`는
회원 서재(`member_contents`)만 읽으므로, 인물 화면이 그쪽을 부르면 쪽을 넘기거나 조건을 바꾸는
순간 목록이 사라진다. `ContentLibrary`의 `ownerKind` prop이 두 경로를 가른다.

인물 상세의 세계 결정·화면 구성·대표 사진 fallback은 [`../celeb/celeb-08-03-detail-themes.md`](../celeb/celeb-08-03-detail-themes.md), 세계 배너의 자산 계약과 장면 기준은 [`../celeb/celeb-08-04-world-banners.md`](../celeb/celeb-08-04-world-banners.md)가 쥔다. 이 문서에는 세계 수·자산 보유 수·회차별 UI 변경을 복제하지 않는다.
