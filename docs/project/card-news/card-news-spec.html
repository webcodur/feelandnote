요약 — 제작 전략:
· 거의 자동(G·A·B·D·K): 컴포지션 1개 만들면 인물/책 전체를 코드로 양산. 여기부터 시작하면 즉시 대량 생산.
· 발췌만 자동화하면 양산(F·H·J): 긴 contextMain을 LLM으로 "한 줄 계기/라벨"로 압축하는 단계만 한 번 만들면 전권 적용.
· 장당 손이 필요(C·E·I·L): 큐레이션·카피라이팅이 핵심. 양산 말고 엄선 소수 장으로.
· 신규 이미지 생성: 사실상 없음. 전부 영상용 에셋 재활용 + CSS 가공.
