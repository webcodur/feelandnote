# 대표사진 자세 아이디어

주머니손·반복된 공수를 교정하거나 새로운 자세가 필요할 때 고르는 선택용 참고표다. 좋은 본인 레퍼런스가 있으면 그 자세를 살린다. 생성·검수 기준과 오브젝트 사용 금지는 [대표사진 룰북](celeb-08-02-hero-photo.md)을 따른다.

손의 높이, 좌우 반전, 옷의 종류, 미소·긴장 정도만 다른 것은 같은 기본형의 변형으로 묶었다. 몸의 각도·체중 이동은 아래 기본형에 조합하는 조정이며 별도 아이디어로 세지 않는다. 손을 모두 담으려고 허리샷을 넓히지 않는다.

## 직업·활동에서 자세 고르기

본인의 실제 화보·훈련·공연·연설 사진에서 그 사람다운 자세를 먼저 찾는다. 아래 일반 초상 기본형은 출발점이며, 그 목록 안에서만 고를 필요는 없다. 직업과 활동에 맞는 자세가 더 잘 어울리면 사용한다. 아래 예시는 선택 방향이며 모든 종사자에게 일괄 배정하는 자세가 아니다.

| 인물의 활동 | 활용할 수 있는 자세 | 적용할 때 볼 부분 |
|---|---|---|
| 무술가·격투 선수 | 본인 종목의 대전 준비 자세나 가드. 몸을 살짝 비스듬히 두고 실제로 쓰는 손·팔 배치를 살린다. | 권투·태권도·쿵후 등을 같은 주먹 자세로 섞지 않고 본인의 실제 자료를 본다. 얼굴을 가리지 않는 가드와 렌즈 응시를 유지하고 주먹을 렌즈 앞으로 내밀어 크게 만들지 않는다. |
| 무용가·댄서 | 본인 장르의 팔 선·손 모양·어깨와 흉곽의 방향을 살린 정지 자세. | 모든 무용을 발레 팔 동작으로 만들지 않는다. 얼굴·목·몸이 자연스럽게 이어지고, 다리 동작을 담으려고 허리샷을 넓히지 않는다. |
| 지휘자 | 지휘봉 없이 양손으로 준비 박자나 작은 지휘 동작을 잡은 자세. | 본인의 실제 손 배치에서 고른다. 양손을 구분되게 두고 얼굴을 가리지 않으며, 존재하지 않는 지휘봉이나 악기를 쥔 흉내로 만들지 않는다. |
| 연설가·정치인·교육자 | 본인의 실제 연설에서 쓰는 설명 손짓이나 청중에게 건네는 인사. | 인물에게 익숙한 태도와 손짓을 고른다. 모두 같은 손인사나 검지 지적으로 통일하지 않는다. |
| 가수·배우·코미디언 | 본인의 프로모션 화보나 무대 인사에서 확인되는 개성 있는 몸짓·표정. | 직업을 보여주려고 마이크·소품을 추가하지 않는다. 본인다운 태도를 살리되 과장된 희화화나 다른 배역의 얼굴로 바꾸지 않는다. |

이는 카메라 앞에서 취하는 직업·활동 기반의 초상 자세다. 종목·동작을 확인할 자료가 없으면 구체적인 기술 자세를 추정하지 않고 본인에게 어울리는 일반 초상 자세를 고른다.

## 기본형과 변형

| 기본형 | 몸·팔·손의 배치 | 같은 기본형 안에서 고를 변형·적용점 |
|---|---|---|
| 양팔 내림 | 양팔을 몸 옆으로 편하게 내린다. | 한쪽 팔꿈치를 조금 굽히기, 팔과 몸 사이 간격, 몸을 살짝 비스듬히 두기는 이 안의 조정이다. 어깨를 편다는 설명이나 미소만 바꿔 새 자세로 세지 않는다. |
| 등 뒤에 손 | 한 손 또는 양손을 몸 뒤 낮은 곳에 둔다. | 뒤 허리선의 높이를 조정한다. 어깨를 들거나 허리를 젖혀 손을 숨기지 않는다. |
| 허리에 손 | 한 손 또는 양손을 허리 옆에 가볍게 둔다. | 골반 옆으로 낮추거나 반대 팔을 내린다. 손 높이·손 개수를 달리한 변형이며 인물에게 어울리는 자신감일 때 고른다. |
| 팔 교차 | 팔을 몸통 앞에서 교차한다. | 낮은 팔짱과 양손으로 반대쪽 어깨를 감싸는 높은 교차를 이 안의 변형으로 묶는다. 어깨·가슴·몸통의 부피를 유지하며, 웅크린 인상이나 누구에게나 쓰는 기본값으로 만들지 않는다. |
| 반대팔에 접촉 | 한 손으로 반대쪽 팔을 가볍게 짚거나 받친다. | 아래팔·윗팔·팔꿈치 위치를 고른다. 몸을 꽉 감싸거나 배 앞 공수로 바뀌지 않게 한다. |
| 낮은 손 접촉 | 몸 앞 낮은 곳에서 손가락이나 손등을 가볍게 맞댄다. | 손을 꽉 쥐거나 깍지 끼는 대신 힘을 뺀다. 차분한 인물의 실제 레퍼런스에 어울릴 때만 선택한다. |
| 열린 손짓·인사 | 한 손 또는 양손을 몸 옆에서 펼친다. | 손바닥 방향·높이·좌우 높이 차이를 고른다. 렌즈 쪽으로 손바닥을 보이는 인사도 이 안의 변형이다. 설명·안내·대답 같은 상황 이름만 바꿔 별도 자세로 세지 않는다. |
| 가슴·쇄골에 손 | 한 손을 가슴 또는 쇄골 가까이에 가볍게 댄다. | 높이를 조정하되 목을 움켜쥐거나 과한 맹세 동작으로 만들지 않는다. |
| 입은 옷 정리 | 현재 입은 옷의 앞섶·칼라·여밈을 한 손 또는 양손으로 가볍게 정리한다. | 재킷·코트·가디건·스카프 등 복식 이름이 달라도 같은 계열이다. 자세를 만들려고 옷이나 장신구를 추가하지 않는다. |
| 소매 정리 | 한 손으로 반대쪽 소매나 커프스를 정리한다. | 걷은 소매 끝과 손목 커프스는 이 안의 변형이다. 팔·손의 실제 접촉을 유지한다. |
| 머리·목 뒤에 손 | 한 손 또는 양손을 머리 옆·뒤나 목덜미에 둔다. | 머리 넘기기와 손의 좌우·개수는 이 안의 변형이다. 얼굴을 가리거나 목을 비틀지 않고, 들린 팔을 담으려고 인물을 작게 만들지 않는다. |
| 얼굴 곁에 손 | 한 손을 관자놀이·볼·턱 곁에 편하게 둔다. | 손가락을 놓는 위치와 반대팔의 지지 여부를 고른다. 눈·코·입을 가리거나 얼굴을 손에 묻지 않는다. |

기본형을 고를 때는 인물의 실제 태도·복식·체구와 최근 제작한 이미지의 반복을 함께 본다. 양팔 내림을 전부 팔짱으로, 공수를 전부 허리손으로 바꾸는 식으로 한 자세에 몰지 않는다. 숫자를 채우려고 미세한 차이나 분위기 문장을 독립 항목으로 늘리지 않는다.
