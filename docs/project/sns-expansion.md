## 3. 핵심 레버 (두 개의 지렛대)

**레버 1 — 카드 생성기** (인스타·쓰레드·틱톡·네이버·X 캐러셀)
- **무엇:** 기존 책·인물 데이터로 정지 이미지 카드(여러 장 넘기는 카드뉴스)를 자동으로 찍어낸다.
- **왜:** 비율(1:1·4:5·9:16·16:9)만 바꾸면 다섯 채널을 **한 코드로 전부 먹인다.**
- **현황(26.07.29 실측): 만들어졌다.** 카드 렌더러(`sw/remotion/src/compositions/BookCard/` 7종, `FactionCard/` 5종), 미리보기·편성 화면(서재 탐방은 web-bo `/book-recommend/<인물>/cards`, 팩션은 web-bo `/factions` 카드 화면), 출고 배치(`pnpm render:cards`)가 전부 있다. 남은 건 전권 양산·배포. 구현 SSoT: `sw/remotion/docs/project/card-news/IMPLEMENTATION.md`.
- **남은 제약:** 비율별 레이아웃(1:1·9:16)에서 책 많은 목차·긴 감상경위가 넘치는지 미점검. 세로 인물 사진을 가로/정사각에 맞추는 초점 정보가 대부분 미지정.

**레버 2 — 감상 배경 스토리화** (텍스트 채널 무기)
- **무엇:** 인물이 그 책을 왜·어떻게 읽었는가(감상 배경)를 텍스트로 뽑는다. 데이터에 이미 있어 제작비 0.
- **왜:** 이게 우리만 가진 것이다. 명언은 아무나 퍼올릴 수 있어 차별점이 없다 → **명언은 미끼(후크)로만 쓰고 본론은 맥락으로 간다.** (§8 2026-06-30 "콘텐츠 정의 교정"에서 "명언 텍스트 추출"을 이 항목으로 교체 확정)
- 카드를 뽑기 전에도 **오늘 당장** X를 채울 수 있다는 성질은 그대로다.

## 4. 플랫폼 보드

### 우선순위 요약

| 플랫폼 | 순위 | 계정 | 한 줄 판단 |
|---|---|---|---|
| 유튜브 쇼츠 | 🟢 높음 | 보유 | 자동화 다 깔림, 제작비 0. 가장 먼저 가동 |
| 인스타그램 | 🟢 높음 | 신규 | 책 커뮤니티 두텁고 한국 거대. 릴스+카드 병행 |
| 네이버 블로그 | 🟢 높음 | 신규 | 한국 책 검색 본진. 장기 검색 자산 |
| 쓰레드 | 🟢 높음 | 신규 | 텍스트·리스트형 적합, 인스타 연동 교차성장 |
| X (트위터) | 🟢 높음(명언·카드 한정) | 신규 | 명언 텍스트가 X 토착 포맷과 정확히 겹침. **영상 레인은 약함** |
| 틱톡 | 🟡 높음(조건부) | 신규 | 책 발견 1위지만 영어권 우선 전제 |
| 페이스북 | 🔴 비추 | 신규 | 한국 사용자 급감·고령화. 인스타 결과물 동승만 |
| 카카오스토리 | 🔴 비추 | 신규 | 이용자 급감·자동화 불가. 본격 투자 안 함 |

### 플랫폼별 카드

**🟢 유튜브 쇼츠**
- 적합도: 거의 손질 없이 직행. 가로 롱폼이 환영받는 유일한 곳.
- 다음 액션: 이미 렌더된 쇼츠 공개 전환 → 인지도 높은 인물부터 매일~격일. 제목·설명에 인물명+책명 검색어. 30~45초 타이트 편집 우선. 같은 채널 가로 롱폼 주 1편으로 깔때기.

**🟢 인스타그램**
- 적합도: 세로 영상 즉시 재활용, 카드뉴스 ROI 최고.
- 다음 액션: 세로 쇼츠를 7~15초 후크 컷 릴스로(첫 3초에 인물+책). 프로필에 깔아둘 대표 카드 묶음 5~8개 선제작. 릴스 주 4~5회·카드 주 2~3회. KPI는 조회수 아닌 저장·공유.

**🟢 네이버 블로그**
- 적합도: 영상 자체는 약하나 텍스트·이미지 재료는 완성형.
- 다음 액션: 주제를 "유명인 독서·책 추천" 한 갈래로 단일화. 인물 1명=정리 글 1편(1,500자+) + 표지·인물·카드 이미지 + 세로 영상 한 개 삽입. 경쟁 낮은 인물부터. 기계 문체 금지(저품질 필터), 관점·맥락 가미. 글 하단에 feelandnote.com 링크.

**🟢 쓰레드**
- 적합도: 4:5 카드가 핵심, 영상 보조. 본문 링크는 도달 깎임.
- 다음 액션: 인스타 연동 → 첫 줄 텍스트 후크 글 + 4:5 카드 묶음. 링크는 바이오·답글에. 하루 1~2회 + 매일 책 토픽 답글(답글이 확산 엔진). 게시 직후 30~60분 응대.

**🟢 X (트위터) — 비대칭 우선순위**
- **명언 텍스트·카드 레인은 높음, 영상 레인은 낮음.** 다른 플랫폼과 반대 성격이다.
- 적합도: 명언·인용 텍스트는 가공 0으로 그대로 직행(X 최적 자산). 카드 1:1·4:5·16:9는 X 이미지 포맷(한 게시물 최대 4장 격자)에 정확히 대응. 세로 쇼츠는 타임라인에서 윗부분만 보여 1:1/16:9 크롭 필요. 롱폼은 부적합(무료 140초 한도).
- 콘텐츠 적합성: "유명인이 읽은 책"은 **영어권 X의 토착 장르**다(창업자·지식인 독서 리스트, 머스크·나발 등이 직접 활동). 한국 X 책 커뮤니티는 얇음.
- 도달: 추천 피드 중심. 답글·대화가 좋아요보다 압도적 가중, 게시 후 첫 30분 반응이 분기점. 인용·리트윗 확산이 명언과 잘 맞음. 팔로워 0도 반응 비율 좋으면 도달.
- 다음 액션(첫 30일): 프로필·고정 게시물(베스트 명언 카드)부터. 매일 명언 텍스트 1~2개 + 주 2~3회 카드 묶음 + 주 1회 인물 독서 스레드(8~12개) + 매일 책·테크 스레드에 답글 진입. **링크는 항상 첫 답글에.**
- 레인: 영어 우선 권고(다른 플랫폼과 반대), 한국어는 같은 카드 미러링.

**🟡 틱톡 (조건부)**
- 적합도: 세로 쇼츠·사진 카드 직행. 가로 롱폼만 부적합.
- 조건: 영어권·셀럽 북클럽 레인 전제일 때 높음. 국내 단독이면 중간으로 내려감.
- 다음 액션: 언어 레인 먼저 결정. 워터마크 없는 클린본만. 계정 정체성을 "셀럽·역사인물이 읽은 책"으로 좁게 고정(첫 5~10개가 분류 결정). 인물·책·저자명을 캡션·화면·음성 세 곳에.
- 주의: 지정학 리스크로 단일 의존 금물.

**🔴 페이스북 (비추)**
- 사유: 한국 사용자 5년간 35% 감소, 50대 이상 고령화, 책 독자층은 인스타로 이동.
- 처리: 전용 투자 안 함. 페이지만 만들어 **인스타 결과물 자동 전달**로 무료 동승. 한계비용 0이라 끄지는 않음.

**🔴 카카오스토리 (비추)**
- 사유: 이용자 급감, 외부 연동 종료(2023.11)로 자동화 불가, 추천 알고리즘 없음.
- 처리: 본격 투자 안 함. 필요 시 인스타용 1:1 카드를 수동 교차 게시(선택).

## 5. 한 소재 → 다채널 파생 맵

영상 한 편(예: "일론 머스크가 읽은 책")을 만들면 한 번에 퍼진다.

| 채널 | 나가는 것 | 가공 |
|---|---|---|
| 유튜브 | 세로 쇼츠 + 가로 롱폼(여기서만 가치) | 그대로 |
| 인스타 | 후크 컷 릴스 + 4:5 카드 7~10장 | 카드 자동 생성 |
| 쓰레드 | 4:5 카드 + 첫 줄 후크 글 | 카드 재사용 |
| X | 명언 텍스트 트윗 + 1:1/16:9 카드 + 인물 독서 스레드 | 명언은 그대로, 카드 비율만 변경 |
| 틱톡 | 쇼츠 클린본 + 세로 카드 | 비율만 변경 |
| 네이버 | 정리 글 + 표지·카드 이미지 + 영상 삽입 | 글만 작성 |
| 페북·카스 | 인스타 결과물 동승 | 무료 |

**카드 생성기 하나가 다섯 채널 이미지를 먹이고, 명언 데이터가 X 텍스트를 따로 먹인다.**
