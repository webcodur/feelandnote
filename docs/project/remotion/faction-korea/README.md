# 한국형 팩션 아이디어 뱅크

세력도(faction) 영상의 **한국 소재 전용** 에피소드 후보 풀. 글로벌 뱅크(`../faction-ideas.md`)와 분리 관리한다.

- 선정 기준·평가축은 스킬 `faction-series-concept` 참조. 두 축: **〔효〕** 효용·투자 / **〔재〕** 순수 재미.
- 형식: **인물형**(얼굴 카리스마+라이벌) / **장비형**(제품이 주인공) / **팀형**(얼굴 비공개 → 실루엣·엠블럼).
- 팩션 포맷 = 무대사·무자막 시네마틱 세로영상(9:16). 이미지 한 장 + 짧은 설명 2줄로 카리스마가 서는 대상만 산다.
- **대중 인지선(한국판)**: 한국 대중 누구나 아는 얼굴/이름까지만. 매니아 전용은 배제.
- 모든 명단은 초안. 채택 시 현직·고증·초상권 웹 재검증 필수.

### 두 가지 편성 유형

- **화보형** (기본): 한 진영을 인물·장비 화보로 나열. 대부분 후보가 여기 속한다.
- **대결·대외항쟁형** (유저 발원): 우리 세력 vs 적 세력을 양 진영으로 세워 색온도·군기 대비로 충돌시킨다. 규모가 큰 전쟁편은 **국가·상대별 쇼츠 여러 편 + 통합 롱폼 1편**으로 편성. 임진왜란(조선·명·일본 3국)·고구려 700년 대륙전쟁·고려 대외항쟁이 여기 속한다. 얼굴(초상) 없는 고대 인물의 약점을 "명확한 적 세력 + 갑주·군기 대비"로 가장 잘 덮는 유형.

### 전체 최우선 트랙 (실패 확률 최저 → 각인 효과 최대)

1. **한국 스포츠 명예의 전당** — 유저 발원 아이디어이자 안전빵 최강. 얼굴 소스 풍부·진영(종목) 명확·대중 인지선 최상·화보 궁합. 첫 편으로 시리즈 문법을 세우기 가장 안전.
2. **K-방산** (지상군단) — 요즘 수출붐으로 뉴스 인지선 확보 + 강철·발사 화염 비주얼이 badass 톤과 최상 궁합. 장비형이라 초상권 리스크 0.
3. **한국 우주로켓** — 누리호 전 국민 생중계로 인지선·비주얼·효용 세 축 모두 통과. 과학기술 대표.
4. **임진왜란** — 역사 카테고리 최광폭 인지선, 정치 민감도 낮음.

### 비주얼 위험 신호 (설계 선검증 필요)

- **흑백 원본만 있는 대상**(기업 1세대, 독립운동가, 6·25 영웅): 세피아 다큐톤 or 컬러 복원 연출을 한 편 먼저 검증.
- **초상 전무 고대 인물**(삼국·고려 명장): 실루엣·갑주·환경 비주얼로 얼굴 부재 상쇄.
- **생존 인물 다수**(문화예술 스타, 현직 경영인, 스포츠 현역): 초상권 최민감 → 전원 시네마틱 가공 전제.

### 정치·윤리 민감 관리 대상

- 독립운동가·6·25 영웅: 서훈·이념·친일 논란(백선엽 등) → 헌사 톤, 인선 보수화, 미화·단죄 양쪽 금지.
- 문화예술 논란 인물(김기덕·고은): 명단 제외 처리 완료. 이문열: 신중 판단 표기.
