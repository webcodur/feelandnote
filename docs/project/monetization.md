## 도서 제휴 프로그램 조사 결과 (26.03.09)

| 서점 | 제휴 방식 | 가입 조건 | 판정 |
|------|----------|----------|------|
| **알라딘 TTB** | 직접 어필리에이트 | 개인 무료 가입, 사이트 URL 등록 후 1~3일 승인 | **유일한 선택지** — 로그인 이슈로 보류 중 |
| **교보문고** | 출판사/저자용 파트너시스템 | eBook/POD 유통용. 어필리에이트 아님 | 부적합 (제휴 제안은 가능하나 소규모 서비스에 비현실적) |
| **YES24** | 자체 어필리에이트 없음 | 텐핑 경유만 가능 | 부적합 (2025년 해킹+서비스 마비 사태로 불안정) |
| **인터파크 도서** | — | 2025년 12월 파산 | 제외 |
| **링크프라이스** | 제휴 네트워크 (중개) | 실명인증만으로 무료 가입 | 도서 서점 광고주 유무 확인 필요 |
| **아마존 Associates** | 글로벌 어필리에이트 | 한국에서 가입 가능. 도서 4.5% | 영문 콘텐츠용으로 검토 가능 |

**결론:** 국내 도서 직접 제휴는 알라딘 TTB가 사실상 유일. 나머지는 자체 어필리에이트 프로그램이 없거나 부적합.

### AdSense (26.07.15 전방위 감사 → 근본 원인 교정 완료. 재신청 대기)

**상세: `docs/project/adsense-audit-2026-07-15.md` 참조 (원인 규명·조치 내역·재신청 절차의 SSoT)**

- pub ID `ca-pub-3751045783335791`. GA4 활성. ads.txt 정상.
- **1차 승인 신청 (26.03.09)** — 거절. 이후 26.03.26 개선 후 재신청도 반복 거절.
- **26.07.15 감사 결론**: 거절 원인은 정책 페이지·필수 요건이 아니라 **색인 붕괴**였다. 사이트맵 2,196 URL 제출 대비 3개월간 검색 노출된 고유 페이지 45개(색인률 ~2%), 클릭 11회. 심사관과 크롤러가 보는 사이트는 사실상 빈 사이트였다.
- **확정된 근본 원인 4종** (전부 적대적 재검증 통과):
  1. `robots.ts`의 `Disallow: /*?` 가 쿼리 URL 전면 차단 → 콘텐츠 상세 링크(전부 `?category=` 부착)가 크롤 불가. 사이트맵에도 미등재라 contents 7,568건 전체가 구글 비가시.
  2. 셀럽 페이지(사이트 표면적 96%)의 책 목록·리뷰·감상 여정이 클라이언트 fetch → 서버 HTML에 책 0권. 제목은 "추천 책 58권"을 약속하는데 본문 0권.
  3. `[locale]/layout.tsx`가 canonical=홈을 레이아웃 레벨 선언 → 자체 alternates 없는 탐색·서가 허브 20 URL이 "내 정본은 홈"으로 신고.
  4. AdSense 스크립트가 `afterInteractive`로 body에 삽입 → 초기 HTML에 태그 부재(정적 코드 검출기 미인식 위험).
- **26.07.15 조치 (전부 완료·타입체크 통과)**: robots 쿼리 차단 해제·crawlDelay 10→1·locale 접두 변형 추가 / 셀럽 페이지 서가·리뷰·감상 여정 SSR 전환 / AdSense 스크립트 head 원시 태그 이전 + `google-adsense-account` 메타 / canonical 상속 결함 해소 / About 페이지 복원(메시지 키 17개 신설 — 기존 파일은 키 부재로 렌더 시 깨지는 상태였음) / 사이트맵에 리뷰 보유 콘텐츠 6,665건 등재·리다이렉트 스텁 6종 제거·lastmod 정리·full 티어만 등재 / 얇은 셀럽·리뷰 0건 콘텐츠·아고라 noindex.
- **남은 일**:
  1. 배포 → 라이브 실측(초기 HTML에 책 목록 텍스트 존재 확인) → 사이트맵 재제출
  2. 색인 회복 확인(2~4주) 후 AdSense 사이트 화면에서 **검토 요청** (사이트 삭제 후 재추가는 공식 비권장)
  3. 승인 후 광고 단위(Ad Unit) 배치 + 쿠팡 제휴 재활성
