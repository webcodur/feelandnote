# 팩션 「소셜 네트워크 / 스트리밍」 통합 재설계

기존 보류 에피소드 3종(`not-using/social-network`, `not-using/streaming`, `not-using/streaming-media`)을 전수 조사 기반으로 재편한 기획 원자료. 주제 선정·진영 규칙은 스킬 `faction-series-concept`, 이미지 발주는 스킬 `faction-image` 참조. 여기는 **진영 구획 + 출연 명단 + 큐레이션 근거**까지.

작성: 2026-06-29. 조사: 서구 SNS / 글로벌 메신저 / 스트리밍 / 중국 / 일본 5개 갈래 + 한국 추억 서비스 개별 조사. 플랫폼 150종+.

---

## 1. 배경 — 왜 재설계인가

| 에피소드 | 제목 | 현재 출연 | 문제 |
|----------|------|-----------|------|
| social-network | 소셜 네트워크 제국 | 저커버그·세버린·숀파커·샌드버그 / 잭 도시 / 시스트롬·스피겔 | 미국 SNS만. 메신저·아시아·추억 전무 |
| streaming | 눈동자 전쟁 | 테드 서랜도스(넷플) / 밥 아이거(디즈니) / 닐 모한(유튜브) | streaming-media와 **거의 동일 주제** |
| streaming-media | 플랫폼 혁명가들 | 리드 헤이스팅스(넷플) / 수잔 워치스키(유튜브) / 다니엘 에크(스포티파이) | streaming과 **넷플·유튜브 중복**, 인물만 다름 |

**streaming과 streaming-media는 같은 기획이다.** 같은 회사에 한쪽은 현 CEO, 한쪽은 창업자를 박았을 뿐. 하나로 통합한다.

→ **3에피소드 → 2시리즈로 정리.**
- **시리즈 ① 소셜 네트워크 제국** — 사람을 연결한 자들 (SNS·메신저·커뮤니티)
- **시리즈 ② 스트리밍 제국** — 시간을 훔치는 자들 (영상·음악·라이브)

**경계 규칙**: "사람을 잇느냐(소셜)" vs "콘텐츠를 보여주느냐(스트리밍)". 유튜브·트위치=스트리밍. 틱톡=숏폼 소셜 피드라 소셜(장이밍은 ②에 카메오 가능). 디스코드=커뮤니티 소셜.

유저 지시: **회사(Meta)가 아니라 개별 서비스(Facebook·Instagram·Threads·WhatsApp) 단위로 진영을 나눈다.**

## 2. 핵심 통찰 — 무대사 인물형의 벽

팩션은 **대사·자막 없이 인물 사진 한 장 + 소개 2줄**로 굴러간다. 조사된 창업자 150여 명 중 한국 시청자가 얼굴/이름을 아는 사람은 극소수다.

| 인지도 | 인물 |
|--------|------|
| **상** (즉시 인지) | 저커버그, 일론 머스크, 트럼프, 김범수, 빌 게이츠(MSN), 제프 베이조스, 팀 쿡, 제이지(Tidal), 닥터 드레(Beats) |
| **중** (이름은 앎) | 잭 도시, 에반 스피겔(미란다 커 남편), 파벨 두로프, 이해진, 다니엘 에크, 밥 아이거, 리드 헤이스팅스, 히로유키(2ch), 장이밍 |
| **하** (무명) | 나머지 전부 — 인스타·스냅·핀터레스트·레딧·디스코드·위챗·라인 개발자·중국 전체·일본 대부분·한국 추억 서비스 창업자 |

**결론: 100% 인물형으로는 못 간다. 두 길을 섞는다.**

1. **인물형 + 서사 보강** — 얼굴 무명이라도 강한 일화가 있으면 인물 컷 + 자막 서사로 산다. (두로프 체포 / 애런 슈워츠 요절 / 아이러브스쿨 "500억을 놓친 사나이" / 냅스터 / 브라이언 액튼 #deletefacebook)
2. **서비스 비주얼형** — 인물 대신 그 시절 로고·UI·시대 무드로. 추억 진영(싸이월드 미니홈피·버디버디 손발 이모티콘)은 인물보다 UI·무드가 훨씬 강렬. **팩션 포맷에 장비형 변종을 처음 도입하는 셈** — 검증 필요.

각 진영에 **아는 얼굴 또는 강한 서사를 최소 1개씩 앵커로** 박는다.

## 5. 자기비판

1. **비대하다.** 두 시리즈 합 12진영·40명+. 한 영상에 다 못 넣는다. → 각 시리즈를 **롱폼 1편(핵심 4진영) + 쇼츠 분할**로 가거나 진영 압축.
2. **인물 무명 문제.** 진영 절반이 얼굴 무명(추억·중국·일본). → 서비스 비주얼형으로 처리. **이건 팩션이 안 해본 방식** — 1개 진영 시범 제작으로 검증 후 확대.
3. **틱톡·유튜브 경계.** 양다리 서비스는 한 기준으로 못 박으면 두 시리즈에 중복 노출. 유튜브=②, 틱톡=① 고정.
4. **추억 진영의 양날.** 한국 추억 SNS는 후킹 최강이나 인물 사진을 못 구한다. 옛 UI 스크린샷·시대 무드로 가야 하는데, 팩션의 영웅 화보 톤과 충돌할 수 있다.

## 6. 1픽 추천

- **먼저 만들 1픽: 시리즈 ② 스트리밍 제국.** 인물 인지도가 소셜보다 높고(헤이스팅스·베이조스·쿡·아이거·제이지·닥터 드레), 기존 중복 2에피소드를 통합하는 실익이 즉시 있다. 진영 명확·비주얼 화려.
- **시그니처 한 방: 시리즈 ① "추억의 토종 SNS" 진영.** 한국 시청자에겐 싸이월드·버디버디·아이러브스쿨이 인물 인지를 초월하는 노스탤지어 폭격. 단 서비스 비주얼형 연출 검증이 선행.
