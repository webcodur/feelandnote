# 신화 인물 남은 작업

그리스·로마 신 계보를 정비하며 남긴 후속 과제다. 관계 규칙은
[`../project/celeb/celeb-07-01-relations.md`](../project/celeb/celeb-07-01-relations.md),
신화 목록 화면은 `sw/web/src/actions/home/getMythAtlas.ts`가 쥔다.

## 표기와 안내

- 로마 신 다섯은 익숙한 이름을 앞에 세우고 라틴어 이름을 `title` 괄호로 안내한다
  (주피터(유피테르)·주노(유노)·넵튠(넵투누스)·비너스(베누스)·머큐리(메르쿠리우스)).
  나머지 일곱은 한국어 표기가 이미 익숙한 형태와 같아 그대로 둔다.
  `title`은 역할을 적는 자리이므로 이 괄호는 임시 방편이다. 별칭 전용 자리를 만들 때
  옮긴다 — 새 컬럼은 사용자가 지시할 때만 만든다.

- 대응 신격(counterpart)은 「같은 신을 문화권마다 다르게 부른 것」이라 가족도 사회도 아니다.
  관계망에서는 기타 갈래에 두고, 프로필 하단 이어지는 인물 목록이 이름을 밝힌다.
  이름 옆에 「그리스식 이름: 제우스」 같은 이름표를 세우는 안은 미착수다.

- 인물 검색은 `nickname`·`nickname_en`만 본다(`sw/web/src/actions/search/searchCelebs.ts`).
  「유피테르」처럼 괄호 안의 라틴어 이름으로는 찾을 수 없다. `title`까지 매칭 대상에 넣으면
  관련도 순위가 없어 「여신」·「왕」 같은 역할 단어로 결과가 쏟아진다. 고치려면 이름 매칭을
  먼저 보이는 두 단 검색이 필요하다. 우선순위는 낮다.

- 아이네이스 팩션 영상 대본(`sw/remotion/public/factions/virgil-aeneid/`)은 「유피테르」를
  쓴다. 이미 렌더·발행한 영상이라 손대지 않았고, 웹 표기와 다르다.

## 데이터 공백

- 헤스티아는 프로필이 있으나 `publication_status='inactive'`이고 신화 목록 배정도 `hidden`이다.
  형제인 제우스·헤라·포세이돈·하데스·데메테르는 모두 공개 상태라, 관계망에서 헤스티아만
  이동할 수 없는 노드로 뜬다. 공개할지 판단한다.

- 사투르누스의 여섯 남매 가운데 관계 행이 없는 쌍이 넷이다 — 넵튠·케레스, 넵튠·베스타,
  베스타·플루토, 주노·케레스. 나머지 쌍은 각자 다른 내용으로 채워져 있으므로, 채울 때도
  같은 문장을 되풀이하지 않는다.

- 디오니소스의 로마 대응(바쿠스·리베르) 프로필이 없다. 아폴론은 로마도 같은 이름을 써서
  대응 행이 없는 것이 맞다.

## 실화면 확인

- 관계망의 기타 갈래를 실제 화면에서 보지 못했다. 탭 셋이 한 줄에 서는지, 기타 탭에서
  거르는 줄이 사라졌는지, 갈래 이름표가 「대응 신격」으로 뜨는지 확인한다.
  진입 경로는 `/celeb/jupiter` 관계망이다.
