# 인물 (`/explore`)

인물(`/explore`)과 작품(`/explore/works`)은 각각 주요 메뉴로 직접 연다. 작품 화면은 [service-02-library.md](service-02-library.md)가 설명한다.

주요 메뉴와 홈·프로필의 입구 배치는 [서비스 화면 지도](README.md)가 쥔다. 메뉴와 링크의 원천은 `sw/web/src/constants/navigation.tsx`다.

인물 모드에서는 원하는 사람을 찾고, 별도 페이지에서 분야·성향·신화·세력을 탐색한다. 인물 주소와 상세(`/celeb/[slug]`·`/content/[id]`)는 유지한다.

상단 배너는 각각 「인물」·「작품」 제목이며 PC에서는 별자리 판(`ConstellationBanner` compact)을 쓴다. 하위 화면에서는 배너가 현재 위치를 알린다 — 상위 단계는 제목 위 작은 경로 줄(「인물 › 세력도감 ›」), 지금 화면은 큰 제목(`BannerHeading`). 위로 가는 길은 이 경로 줄이 쥐므로 본문 위에 따로 「← 인물」 링크를 두지 않는다. 인물·작품 첫 목록은 큰 모드 탭·번호·중복 목록 제목을 두지 않는다. 공용 아틀라스 목차로 첫 목록과 「주제별 탐색」 구획을 오간다. 인물은 검색·정렬·필터·결과 줄·얼굴 카드가 이어지고, 작품은 작은 베스트셀러 제목·분야 칩·출처 안내·표지 카드가 이어진다. 「주제별 탐색」은 공용 목차로 이동하며 아래 안내 카드를 유지한다. 구획 제목에는 설명 문장(부제)을 두지 않는다 — 배너·검색창·결과 수가 이미 말하는 것을 되풀이했다. 조작은 인물이 공용 검색 + 선택 단추 셋(`ExploreSearchControls`), 작품이 분야 칩(도서·영상·게임·음악)이고, 결과 줄 자리에 인물은 결과 수를, 작품은 출처 안내(「국내 도서 · 일별 판매 순위」)를 둔다. 머리부터 카드 전까지 모두 가운데 정렬이다. 두 모드의 첫 화면에는 곧바로 대상 자체가 보여야 한다 — 인물은 얼굴 격자, 작품은 베스트셀러 표지 순위([서가](service-02-library.md)). 기관 선정을 작품 첫 화면에 두었을 때는 기관 로고·선정 목록이 먼저 나와 작품까지 두 번 더 눌러야 해서 「주제별 탐색」로 내렸다(26.09.28 유저 지시). 이미지 안내 카드는 `ExploreFeatureCard`를 공유한다. 카드 배경은 공통 단색(`bg-bg-card`)을 쓰고, 그림과 글 영역은 CSS 마스크로 부드럽게 잇는다.

조작 요소는 역할마다 모양이 다르다. 인물·작품 이동은 주요 메뉴가 맡고, 작품의 분야·매체 범주는 [작품 화면의 공통 카테고리 칩](service-02-library.md#인기-작품-갱신)을 쓴다. 선택 단추(인물: 리뷰 유무·정렬·필터, 기관 선정: 국가·주제·기관)는 ▾가 붙은 네모 단추다. 선택 단추는 기본값에서 벗어나면 글자·선만 금색으로 바뀐다. 검색·선택 단추를 바깥 상자로 한 번 더 감싸지 않는다. 검색창은 한 줄을 다 쓰고, 선택 단추 셋은 모든 폭에서 그 아래 줄을 같은 폭으로 나눈다 — 넓은 화면에서 검색창 옆에 붙이면 단추 글자 길이에 따라 검색창 폭이 모드마다 달라진다. 결과 수(「전체 N명 중 M명」·기관 선정의 「선정 목록 M개 · 기관 N곳」)는 조작 아래 한 줄에 두고, 인물 모드는 검색 급증 안내를 그 옆에 붙인다. 패널 폭과 조작 요소 스타일은 `ExploreSearchControls.tsx`가 쥔다. 두 모드 모두 페이지 번호를 바꿀 때 현재 스크롤 위치를 유지한다. 인물 카드와 선정 목록 카드는 hover의 금빛 테두리·그림자를 `ExploreCard.styles.ts`로 공유한다(인물 카드는 이미지 하단 빛·이름 칸 강조·이미지 확대를, 목록 카드는 표지 부채꼴이 조금 더 벌어지는 연출을 더한다). 인물 카드의 오른쪽 위 숫자는 서가 아이콘과 함께 보유 작품 수를 뜻한다. 선정 목록의 검색·조건·카드·로고 표시는 [기관 선정](service-03-curated-lists.md#31-사용자-웹)이 쥔다.

다른 탐색 화면은 목록 아래 「주제별 탐색」에서 안내한다. 국가별 연대기와 디렉토리는 카드 아래 같은 크기의 텍스트 링크 한 줄로 둔다. 목차 항목과 구획 제목은 같은 문구를 쓰고(`quickNav` 등 — 「다른 방식으로 인물 탐색하기」처럼 풀어 쓴 설명은 늘어져서 짧은 이름으로 줄였다, 26.09.28 유저 지시), 목차는 이 화면 안 구획 앵커(`hub-explore-figures-N`·`hub-explore-works-N`, `EXPLORE_HUB_GROUP`)로만 굴러간다. 목차 말고 모드 탭과 목록 사이에 다른 화면으로 가는 입구 줄을 따로 세우지 않는다 — 지금 보는 목록과 다른 화면이 한 층에 섞이고, 알약 모양이 매체 칩과 겹쳐 무엇이 거르기이고 무엇이 이동인지 흐려진다(26.09.28 유저 지적으로 철거). 그림·묶음·순서는 `constants/exploreLenses.ts` 한 곳이 쥐고 주소·이름은 `navigation.tsx`를 따른다. 카드 크기는 큰 카드와 낮은 줄 카드 두 단계뿐이며, 휴대폰에서 큰 카드는 그림이 위에 오는 두 열 타일이 된다. 안내 카드는 같은 사이트 안의 입구라 제목 옆에 →를 쓴다(↗는 바깥 사이트 표시로 읽힌다). 아직 재편 중인 화면은 완성된 입구와 같은 크기로 앞세우지 않고 낮은 줄 카드(`ExploreFeatureCard compact`)로 둔다.

## 탐색 첫 화면

`/explore`는 필터·검색·정렬·페이지네이션을 갖춘 인물 그리드다. 첫 진입은 「감상 있음」 필터와 「오늘의 추천」 정렬을 사용한다. 사용자가 감상 조건이나 정렬을 직접 바꾸면 그 선택을 따른다. 「오늘의 추천」은 영향력·감상 작품 수·날짜별 변화·생존·기업가 속성으로 정렬하는 `daily_recommend` 조회를 사용한다. 생존한 현대 인물의 가산점을 높이고 오래된 역사 인물에는 소폭 감점을 적용해 현재 활동하는 인물이 더 자주 보이게 한다. 역사 인물도 추천 대상에 남으며 생년·직군·검색 조건은 그대로 따른다. 점수는 기존 SQL 조회에서 계산하며 과거 추천 조회·자정 배치·저장 데이터 갱신을 하지 않는다. 여기에 국가별 트렌드 매칭 인물이 일일 시드 추첨으로 첫 페이지 칸을 얹는다 — 당첨 확률과 상한은 `lib/celeb/dailyRecommendTrend.ts`가 쥐고, 그려진 인물은 이름 아래 금색 「검색 N위」 칩과 조작 아래 안내 줄로 드러난다. 카드 테두리는 다른 인물과 같게 둔다 — 색을 바꾸면 선택된 카드처럼 읽힌다. 기본값과 허용값은 `constants/celebProfessions.ts`, `celebContentPresence.ts`, `celebSort.ts`, URL 해석은 `explore/figures/filterParams.ts`가 쥔다.

필터는 모달로 열며 제목을 가운데에 locale에 맞춰 표시한다. 직군·국적·콘텐츠·성별·생년·실존 여부를 고르고, 모달 아래 「적용하기」 바로 위에서 선택한 조건을 확인·해제한다. 체크 아이콘이나 탭의 점 표식은 쓰지 않고 선택한 항목의 배경·글자색으로 상태를 보여 준다. 선택과 해제는 모달의 임시 값만 바꾸며, 「적용하기」를 누르면 모든 조건을 한 번에 조회하고 URL에 반영한다. 적용하지 않고 닫으면 기존 조건을 유지한다. 목록과 모달의 조건 표시·해제 동작은 `useCelebDetailConditions`를 공유한다. 리뷰 유무는 상단 「리뷰 전체/있음/없음」 선택 하나로 거른다. 이전 `tier` 주소는 같은 리뷰 조건으로 읽으며 상세 필터에 중복 노출하지 않는다. 실존 여부의 「복합」은 실존과 전승·가상 설정을 함께 갖는 `BOTH`만 거르며, 「전체」는 세 분류를 모두 포함한다. 미확인 작품 수는 음수 배지로 노출하지 않는다. 탐색 인물 카드는 상세 주소를 가진 링크이며 일반 클릭은 인물 미리보기를 연다(`CelebCarousel`의 `onSelect`). 미리보기에서 앞뒤 인물을 살펴보거나 상세로 이동한다. 대사 재생은 별도 버튼이다(`components/shared/CelebCard.tsx`).

그리드 아래 주제별 탐색은 세력도감·신화를 「관계로 보기」 큰 카드로, 영향력·스펙트럼을 「영향과 성향으로 보기」 큰 카드로 배치한다. 그 아래 가상독백·분야별 챔피언은 같은 크기의 낮은 카드로 나란히 두고, 국가별 연대기·디렉토리는 같은 크기의 작은 텍스트 링크로 한 줄에 둔다. 카드의 묶음·크기·순서는 `constants/exploreLenses.ts`, 주소·메뉴와 푸터 링크는 `constants/navigation.tsx`가 쥔다. 인물 피드·오늘의 인물은 탐색 메뉴에서 제외하고 기존 주소는 유지한다. 가상독백 페이지는 가상독백이 있는 공개 인물 전체를 대상으로 한국어·영문 이름과 수식어를 검색하고 직군·국적·낭독 여부로 좁힌다. 얼굴·이름은 16명씩 페이지로 나누고 낭독 인물을 먼저 보여준다. 검색·페이지 변경 중에도 선택한 인물은 유지한다. 명부에는 짧은 탐색 정보만 담으며 인물을 고르면 소개·본문·책장을 읽는다. 목록 아래에는 선택한 인물의 수식어·한 줄 소개·직군·국적·생몰연도·bio와 낭독 조작·독백 전문·책장을 표시한다. 음원이 없는 인물도 독백을 읽을 수 있다. 독백은 셀럽 상세의 공용 `ReadingPlayer`를 사용하며 높이 제한 없이 펼친다. 다른 인물을 고르면 이전 낭독을 멈추고 선택한 인물의 자료만 불러온다. 책장은 셀럽 상세의 공용 `CelebBookShelf`를 사용하며 등장·집필·직군·소속 분류에 감상을 추가해 등장·감상·집필·직군·소속 다섯 분류를 한 책장에서 표시한다. 중복 작품은 각 분류 안에서만 제거해 실제 감상·집필 등 여러 관계를 보존한다. 감상 분류는 셀럽 상세 리뷰와 같은 공용 `ExpandCard`를 사용해 작품 소개 아래 감상배경을 바로 표시하고, 전문과 출처는 눌러 모달로 읽는다. 리뷰 전문은 선택한 책만 불러온다. 음악·게임·영상은 포함하지 않는다.

목록은 `FiguresFilterResult`에서 서버 조회하고 `Lane`으로 감싼다. 봇·미확인 UA에는 완성 HTML을 주며, 사람 브라우저에는 대기 UI 뒤 목록을 제공한다. 수집 가능한 링크와 렌더링 규칙은 [코드 규칙](../platform/platform-02-code-rules.md), 검색 검증은 [SEO](../operations/ops-02-seo.md)를 따른다.

## 국가별 트렌드

접속 국가는 `lib/visitorCountryServer.ts`가 요청 헤더에서 읽고 `lib/visitorCountry.ts`가 실제 국가 코드인지 검증한다. 화면 언어로 국가를 추정하지 않는다. 오늘의 추천은 기존 조건을 통과한 자국 인물을 첫 페이지 일부에 섞으며, 추천 인원 제한과 트렌드 합성은 `lib/celeb/dailyRecommendTrend.ts`가 쥔다. 추천 캐시는 국가·날짜별로 나뉘고 다음 페이지에서 승격 인물이 중복되지 않는다. 국적 선택지는 전체 선택을 유지하면서 자국을 앞에 둔다. 연대기는 URL에 국가가 없을 때만 접속 국가로 시작하고, 명부는 공유 HTML 색인을 유지한 채 `VisitorDirectory`가 자국 인물 구획을 위에 더한다.

트렌드는 Google Trends 공개 페이지의 검색 급상승어와 등록 인물의 국문·영문 이름을 띄어쓰기를 무시하고 대조한다. 급상승어의 제목에 이름이 일치한 인물만 인정하며, 연관 검색어에만 등장한 인물은 포함하지 않는다. 옛 인물은 동명의 현대 뉴스 검색어를 가로채므로(연암 박지원, 삼국지 법정) 기준 연도 이전 출생자는 대조하지 않는다. 기준 연도는 `lib/trends/trendMatching.ts`가 쥔다. 최근에 시작했고 아직 종료되지 않은 급상승어만 사용한다. 종료 시각이 있는 검색어는 검색량이 많아도 제외하고, 조회 기간을 벗어나면 후보에서 빠진다. 서버가 읽어 국가별로 캐시하며, 같은 서버 프로세스의 동시 요청은 국가별로 진행 중인 조회를 공유한다. 방문할 때마다 실시간 API를 호출하는 방식은 아니다. 지원 국가는 Google Trends 급상승 페이지가 받는 국가 전체다. 목록과 재확인 방법, 출처 기간은 `constants/trendCountries.ts`, 조회·캐시는 `lib/trends/countryTrending.ts`, 파싱·이름 매칭은 `lib/trends/trendMatching.ts`가 쥔다. 인물 이름이 국문·영문뿐이라 일본어·중국어·태국어처럼 다른 문자로 검색하는 나라는 일치 인물이 드물다.

국가는 URL 선택·마지막 직접 선택·접속 국가 헤더(`CF-IPCountry`)·한국 순으로 연다. 직접 고른 국가는 브라우저 쿠키에 기억하며 공유 주소를 여는 것만으로 저장값을 바꾸지 않는다. 화면에는 현재 국가 선택 단추 하나만 두고, 국가 목록은 그 단추를 눌렀을 때 검색 가능한 창에서 연다. 쿠키 이름·보존 기간·국가 선택 순서는 `constants/trendCountries.ts`가 쥔다. 이는 인물의 국적 필터와 별개다. `actions/home/getCelebs.ts`가 현재 필터에 맞는 트렌드 인물을 검색량 순으로 앞에 놓고 나머지를 작품 수 순으로 채운 뒤 페이지를 나눈다. 일치 인물이 없거나 조회에 실패하면 작품 수 순으로 보여주며, 화면에서 일치 여부와 조회 상태를 구분한다. 홈의 「검색이 급증한 인물」도 같은 매칭과 저장 국가를 사용하며, 기록이 있는 급상승 인물을 보여준다. 홈 표시 수에 못 미치면 미국 급상승 인물을 뒤에 추가하고 같은 인물은 한 번만 보여준다. 선택한 국가와 국적이 다른 인물은 카드에 실제 국적을 함께 표시한다. 양쪽 모두 표시할 인물이 없으면 안내 문구를 보여준다. 표시 수는 `HomeFigureLinks.tsx`가 쥔다.

`/explore/figures`·`celebs`는 검색 조건을 보존해 `/explore`로 영구 이동한다. `persona`는 `/explore/spectrum`으로 308 이전한다. 옛 주소의 목적지는 `sw/web/next.config.ts`가 쥐며 중복 리다이렉트 페이지는 두지 않는다. `youtube`는 영상관 재개를 고려해 임시 이전을 유지한다. 새 링크와 워밍 점검에는 현재 정본 주소를 쓴다.

영향력·분야별 챔피언·스펙트럼은 같은 부모 화면 **인물 순위판(Figure Ranking Board, `components/features/user/explore/figureRankingBoard/`)** 위에 선다. 선택기 → 무대(머리·시상대·순위) → 선택적인 함께 감상한 작품 서가의 배치와 대기 화면을 순위판이 전부 쥐고, 각 화면은 자기 자료를 순위판의 입력으로 바꿔 넘기기만 한다. 갈리는 조건은 머리 앞 표식(글자 칩 | 아이콘), 순위 형식(시상대 | 양극 매치업), 서가 유무·묶음 수 셋뿐이다. 머리는 각 화면 모두 「표식·제목·Top N」 한 줄에 설명 한 줄이고, 각 화면 모두 Top 10이다. 선택기 칩 모양(네모), 머리의 「Top N」(인원 수에서 만든다), 서가의 제목·부제(문구 `explore.rankingBoard`)는 순위판이 정하고 화면은 넘기지 못한다 — 화면이 고르게 두면 각 화면이 다시 갈린다. 서가의 작품 낱장은 사이트 공통 작품 카드(`ContentCard`)를 그대로 쓴다 — 감상 인원은 카드 기본 표시(표지 왼쪽 아래, 누르면 감상 인물 창)에 맡기고 순번 칩만 얹는다. 각 화면의 모양을 바꿀 때는 각 화면이 아니라 순위판을 고친다.

영향력·스펙트럼과 신화·세력 화면은 인물 | 작품 탭 아래에 각각 「영향력 | 스펙트럼」·「신화의 세계 | 세력도감」 전환 메뉴를 둔다. 공통 레이아웃(`ExploreLayoutFrame`)의 같은 모듈을 쓰며 현재 화면을 금색으로 표시하고 로딩 중에도 유지한다. 신화·세력의 본문 선택 상자에는 세계 전환을 중복 표시하지 않는다.

영향력 분야 칩은 PC·모바일 모두 「종합·시대초월성 / 정치·전략·기술 / 사회·경제·문화」 세 줄로 배치하며, 순서는 `constants/influenceRanking.ts`가 쥔다. 순위 아래에는 해당 분야의 상위 인물들이 공개 감상한 작품을 `getSharedContents`로 모아 감상 인원이 많은 순으로 표시한다. 책장은 화면 언어에 맞는 제목·표지를 사용하고, 감상 작품이 없으면 빈 안내를 표시한다.

랭킹의 매체 선택·주소는 `explore/ranking/constants.ts`, 연대기의 대륙 분류·페이지 분할은 `components/features/user/explore/sections/TimelineSection/continents.ts`와 `pagination.ts`가 쥔다. 디렉토리는 이름별 인물 링크를 HTML에 싣고 직군별 명부에도 연결한다.

## 도감 용어

「신화의 세계」(`/explore/myth`)와 「세력도감」(`/explore/faction`)은 같은 뼈대의 화면 둘이다. 계층은 세 층이고 층 이름이 곧 스키마 이름이다 — 따로 대응표를 유지하지 않는다.

- **lv1 테마** — 세력도감의 분야(인공지능·산업·권력…), 신화의 지역(한국·그리스·로마…). 화면 첫 칩 줄.
- **lv2 세력** — 카드 한 장. 신화 화면에서는 신화(일리아스·서유기), 세력도감에서는 팩션(OpenAI·삼국지). 「신화/팩션」은 같은 층의 화면 표기이고, `is_myth`로 가른다.
- **lv3 그룹** — 세력 안의 인물 묶음(올림포스 신·기초를 놓은 세대).
- **인물** — 세력에 배정된 `celebs` 행. 일반 팩션은 `celeb_reality`를 명단과 인물 소개 모달의 사실·가상 표식으로 보여 준다(`CelebRealityLabel`).
- **숨김**은 인물 배정 단위, **잠금**(`published`)은 세력 단위, **차례**(`sort_order`)는 각 층의 나열 순서다.
- `is_fiction`은 「이야기 속 인물 세력」 표시로 이 계층과 무관하다 — 역사창작 세력도 참이라 화면 소속을 가르는 값으로 쓰지 않는다.
- `신화와 이야기` 뿌리 행은 `is_myth`가 대신하므로 두지 않는다.

스키마는 `faction_lv1`(테마) → `faction_lv2`(세력·신화) → `faction_lv3`(그룹), 인물 연결은 `faction_members`, 읽기는 뷰 `faction_member_rows`다. 이관에서 남은 불변사항은 [`data-03-celeb.md`](../data/data-03-celeb.md)가 쥔다.

### 한 줄 정의 (`faction_lv2.headline`·`headline_en`)

신화·세력 카드마다 이름 뒤에 붙여 「오디세이아, 트로이 전쟁 영웅 오디세우스의 10년 귀향길」로 읽히는 명사구 한 줄을 둔다. 화면에서는 이름 바로 아래에 보이고, 검색 설명은 「이름, 한 줄 정의.」로 연다. 소개글(`description`)은 이야기 도입부로 시작해 「이게 무엇인지」를 말하지 않으므로 그 몫을 이 줄이 맡는다(26.09.29 유저 지시).

- **무엇을 쓰나** — 신화는 누가 무엇을 하는 이야기인지(주인공·핵심 사건·결말 중 가장 강한 장면 하나), 건국 신화는 누가 어떤 나라를 어떻게 세웠는지, 한 지역 전체를 담은 신화(일본 신화·그리스 신화)는 대표 신과 큰 줄기다. 세력은 무엇으로 묶인 사람들인지(함께 한 일·공통점), 기업·조직이면 그 조직이 한 대표적인 일, 이야기 속 세력(홍길동전)은 작품 줄거리다.
- **규격** — 한국어 12~28자, 30자를 넘기지 않는다. 명사구로 끝내고 마침표를 넣지 않는다. 이름을 되풀이하지 않는다. 검증 가능한 구체 사실(인물·사건·장소·작품·방식)이 하나 이상 들어간다 — 평가어만으로 된 줄(「시대를 바꾼」「전설적인」)은 정의가 아니다. 수치·연도로 시작하지 않고, 1~2년 안에 낡을 현재 시점 사실(현 대표·올해 순위)에 기대지 않는다. 독자가 모르는 조연·지명을 넣지 않는다. 금지 표현은 인물 한 줄 정의와 같다(`sw/web-bo/scripts/celeb/headline-rewrite/rules.mjs`).
- **영어** — 한국어를 직역하지 않고 따로 쓴다. 90자 이하, 문장식 대소문자(첫 글자와 고유명사만 대문자), 마침표 없음.
- **정하는 법** — 인물 한 줄 정의와 같은 무기명 경쟁전이다([celeb-01-02-profile-intro.md](../celeb/celeb-01-02-profile-intro.md) 「한 줄 정의」). 생성자는 서로 다른 사실로 10안을 내고 고르지 않으며, 다른 심사자가 출처를 모른 채 1위를 고른다.
- **고치는 곳** — 백오피스 도감 행 편집(`/factions/[entry]`)의 「한 줄 정의」 칸이다. 신화도 같은 화면에서 연다. 세력(L2)에만 있고 분류(L1)에는 없다.

## 신화 (`/explore/myth`)

개요·구성원·책장·전체 목록의 폭과 좌우 여백은 공용 `PageContainer`·`LayoutMain`을 따르며 구획별로 추가 여백이나 최대 폭을 두지 않는다. 구성원 격자의 열 수와 가로 간격은 탐색 인물 목록과 `components/shared/celebGridLayout.ts`를 공유하고, 이름·타이틀의 글자 크기도 탐색 카드에 맞춘다.

**신화 탐색판**은 `/explore/myth`에서 표시한다. 신화·일반 팩션은 `세 단계 선택·대표 이미지 → 인물 격자 → 작품 선반` 순서로 같은 화면을 쓴다. PC는 왼쪽 L1·L2·L3와 개요·선택기 조작만 윤곽선 안에 묶고, 오른쪽 대표 이미지는 별도 바깥 상자나 패딩 없이 열 너비를 채운다. 선택 영역의 실제 높이에 이미지 열을 맞춰 위아래 끝을 일치시킨다. 모바일은 선택 영역 아래에 대표 이미지를 별도 행으로 놓고 전체 구도를 보여 준다. PC는 종류 이름(지역·신화·그룹 등)을 선택 버튼의 왼쪽 별도 칸에 두고 선택값은 한 행을 기본으로 표시한다. 긴 이름은 줄바꿈하여 전부 보여 주며 줄 수 제한으로 자르지 않는다. 모바일은 종류 이름을 생략하고 선택값 옆에 개수를 표시한다. 지역·테마 수는 전체에서, 신화·팩션 수는 선택한 지역·테마에서, 그룹 수는 선택한 신화·팩션에서 현재 고를 수 있는 항목만 센다. 「전체 구성원」은 그룹 수에서 제외한다. 전체 수는 중성색, 하위 수는 금색으로 구분한다. 이름은 중앙 정렬하고 양옆 화살표로 같은 단계의 이전·다음 항목을 고른다. 각 행의 이름을 누르면 「선택기」 창(`AtlasPicker`)이 그 단계의 탭을 연 채 열린다. 세계 전환은 분할 버튼, 단계 선택은 번호와 단계 이름을 한 행에 두고 화살표로 연결한 표시로 구분한다. 선택한 신화·팩션과 그룹은 창 제목에서 보여 주고 단계 아래에 작은 경로 줄로 반복하지 않는다. 지역·테마에서 신화·팩션을 거쳐 그룹으로 내려가는 위계를 보여 주며, 현재 단계는 채운 번호와 이동하는 밑줄로 강조한다. 단계와 안내문 사이에는 여백을 두며, 화면 높이가 짧으면 안내문을 시각적으로 숨겨 목록 공간을 확보한다. 탭은 지역·신화·그룹(세력도감은 테마·팩션·그룹) 셋이며 방향키·Home·End로 이동한다. 창 안의 신화·세력 전환은 목록만 바꾸고 본문과 주소는 유지한다. 두 세계의 임시 선택을 각각 보관하며, 맨 아래 전체 너비의 「선택 완료」 버튼 또는 선택된 그룹 칩 재클릭으로 최종 세계·항목·그룹을 적용한다. X·ESC·바깥 클릭은 적용 없이 닫는다. 제목에는 임시 선택한 신화·팩션 이름과 그룹을 표시하며, 긴 제목은 한 줄로 줄여 창 높이를 흔들지 않는다. 세계 전환과 검색창은 제목 아래 한 행에 두며, 모바일에서는 검색 영역에 포커스가 있는 동안 전환 버튼을 숨기고 검색창이 행 전체를 채운다. 검색창이나 지우기 버튼에서 포커스가 빠지면 원래 배치로 돌아온다. 검색은 선택한 세계의 모든 지역·테마에서 신화·팩션을 찾는다. 검색 중에는 단계 탭 대신 결과 수와 「목록 보기」를 표시하고, 세계를 전환해도 검색어를 유지한다. 입력마다 목록을 재마운트하지 않는다. 지우기 뒤에는 입력 포커스를 유지하며, ESC는 검색어가 있으면 먼저 검색어를 지운다. ↓는 첫 선택 가능한 결과로 이동하고, Enter는 선택 가능한 결과가 하나일 때 그 항목을 임시 선택한다. 결과를 고르면 그 항목의 지역·테마도 함께 선택한다. 목록은 같은 폭의 격자 대신 이름 길이에 맞는 칩으로 줄바꿈한다. 모바일 칩 영역은 화면 높이에 맞춰 보통 4~6행을 보여 주도록 크기를 조절하고, PC는 기본 5행 높이를 확보한다. 항목이 적을 때도 칩 묶음을 가로·세로 중앙에 배치한다. 목록이 영역보다 길어지면 스크롤하고, 창을 열거나 화면 크기가 바뀔 때 선택된 칩이 보이도록 필요한 만큼만 이동한다. 화면 높이가 작아지면 검색·전환·확정 영역을 유지하고 칩 목록만 줄여 스크롤하며, 확정 버튼이 목록을 덮지 않는다. 단계 전환은 밑줄 이동과 목록의 짧은 페이드·이동으로 표시하고, 검색어를 입력할 때는 목록 애니메이션을 다시 시작하지 않는다. 로딩·오류 표시도 같은 목록 영역 안에 넣어 세계 전환 시 창이 접혔다 펼쳐지지 않게 한다. 실제 내용 높이가 바뀔 때만 바깥 모달이 높이 전환을 한 번 담당한다. 칩 선택 조명은 짧게 켜지고 꺼지며, hover와 키보드 포커스는 즉시 반응한다. 체크 아이콘은 두지 않는다. 지역·테마를 고르면 그 첫 신화·팩션을 임시 선택한다. 지역·테마와 신화·팩션의 첫 클릭은 선택과 펄스를 표시하고, 같은 칩을 다시 누르면 각각 신화·팩션과 그룹 단계로 이동한다. 처음부터 선택돼 있던 칩도 첫 클릭에는 펄스만 표시한다. 다른 칩·단계·세계로 바꾸면 펄스 대상을 초기화한다. 그룹에는 펄스를 붙이지 않는다. 그룹 칩을 누르면 임시 선택하고, 선택된 같은 칩을 다시 누르면 클릭 간격과 관계없이 확정하고 닫는다. 「전체 구성원」도 같은 방식으로 선택·확정하며, 이미 선택된 그룹을 다시 눌러 선택을 해제하지 않는다. 「주요 장면」 자료가 있는 신화 칩은 장면 아이콘을 이름 앞에, 항목 수를 이름 뒤에 표시한다. 각 목록은 휠·터치와 마우스 드래그로 스크롤한다. 세로 드래그도 공용 `useMouseDragScroll("y")`를 쓰며, 끈 직후 클릭은 차단한다. 모양과 주소 키는 `atlasNavigationData.ts`, 선택 패널의 배치는 `mythLayout.ts`가 쥔다. 신화·세력의 공용 선택 목록은 `lib/atlas-navigation.ts`에서 만들며, 다른 세계의 목록은 `getAtlasNavigation`으로 읽는다.

대표 이미지의 미리보기는 PC에서 선택 영역과 같은 높이를 채우고, 모바일에서는 독립된 이미지 영역을 쓴다. 확대 창에서는 원본 전체 구도를 보여 준다. 이미지 주위에 별도 패딩을 두지 않는다. 기본 화면과 이미지 확대 창에서 원본 우하단의 비워 둔 영역에 선택한 세력·신화 이름을 큰 글씨로 오른쪽 정렬해 표시한다. 이미지는 어두운 덮개 없이 표시하고 호버 시 안쪽 그림이 확대된다. 이미지를 누르면 확대 창을 연다. 세 줄 선택 영역 아래 「선택기」 옆의 별도 「팩션 개요」(신화 화면은 「신화 개요」) 버튼에는 창 모양 아이콘을 붙이고 설명 모달을 연다.

그룹은 `faction_lv3`가 쥐고 뷰 `faction_member_rows.group_name`으로 읽는다. 구성원 구획의 제목은 「그룹명 (인원수)」로 표시하고, 바로 아래에 「‹ | 그룹 개요 | ›」를 한 줄로 둔다. 좌우 버튼은 상단 그룹 선택과 같은 순서로 이동하며, 가운데 버튼은 현재 그룹의 개요를 연다. 구성원 목록 끝과 다음 구획의 가로선 사이는 작게 띄우고, 가로선 아래 책장 구획 머리까지는 더 넉넉한 여백을 둔다. 그룹이 둘 미만이면 세 번째 줄은 「전체 구성원」으로 두고 화살표를 끈다. 그룹이 없는 인물은 맨 끝 「그 외」로 모인다. 구성원은 모두 펼치고 얼굴 아래에 이름과 인물의 정식 타이틀(`celebs.title`·`title_en`)을 중앙 정렬한다. 카드 타이틀의 줄 수 제한은 `MythPersonPicker`가 쥐며, 빈 타이틀을 등장 설명·bio로 대체하지 않는다. 실존 인물의 「사실」 배지는 생략하고 허구·복합 구분은 유지한다. 전체 타이틀과 테마별 긴 소개, 관련 작품, 소개·읽어보기는 인물 소개 모달에서 읽는다. 모달은 아바타·이름·상세 버튼을 머리말로 묶고 설명은 아래 전체 폭에 둔다. 신화 인물의 본문은 읽기 안내를 우선하고 없으면 bio를 쓴다. 인물 모달의 참고도서는 인물 상세와 같은 조회와 화면을 쓰며, 탭·책장 노출 규칙은 [인물 도서](../celeb/celeb-02-05-figure-books.md)가 쥔다. 작품·판본 선택기와 감상 선반을 그대로 공유하며, 감상 도서는 같은 첫 묶음과 더 보기로 이어 받는다. 관계 정보는 조회하거나 렌더하지 않는다.

개요 전문은 PC·모바일 모두 공용 읽기 모달에서 연다. `faction_lv2.description`·`description_en`의 문단과 작품명·인용 강조를 보존하고, 모달 안에 인원·작품 수와 낭독 조작·재생 문장 강조·문장부터 재생·자동 스크롤을 둔다. 낭독 자료는 선택된 팩션에서 미리 확인하고, 음원이 있으면 개요 버튼 옆에 재생·정지 단추를 둔다. 바깥 단추와 모달은 같은 재생기를 공유하므로 모달을 열고 닫아도 재생 위치를 유지한다. 속도·탐색 등 상세 조작은 모달에 두며, 다른 팩션으로 이동하면 음원을 해제한다. 대표 그림이 여러 장이면 별도 이미지 확대 창에서 넘겨 볼 수 있다. 타이틀 원본 PNG는 R2에 보존하고 `MythTitleImage`가 실제 이미지 칸의 폭·배율에 맞는 WebP를 `/api/myth-title/`에서 요청한다. 서버는 R2 원본에서 필요한 크기를 만들고 캐시한다. 크기·품질은 공유 `responsive-artwork.ts`가 쥔다. 확대 창에서 그림 설명이 있으면 이미지 아래에 가로 중앙 정렬로 표시한다. 그림 안 우하단의 제목과 설명은 겹치지 않는다. 확대 창은 원본을 자르지 않고 보여 주며, 그림 비율에 맞춰 이미지 칸의 높이도 줄여 모바일의 위아래 빈 공간을 없앤다. 그림은 블러·페이드 없이 전환한다.

검수한 장면이 있으면 개요 옆에 「주요 장면」 버튼과 장면 수를 표시한다. 신화·일반 팩션 모두 장면 전용 캐러셀을 열 수 있고, 대표 이미지 확대 창에서도 장면으로 이어진다. 장면 캐러셀의 첫 슬라이드는 대표 이미지다 — 장면이 있는 신화도 표지로 돌아갈 수 있고, 표지를 보는 동작은 읽던 장면 번호를 바꾸지 않는다(26.09.30). 좌우 버튼·방향키는 전체 자막 모드에서 장면을, 개별 자막 모드에서 문장을 넘긴다. PC 화살표는 이미지 비율·로딩과 관계없이 화면 양끝의 같은 위치에 고정하고, 클릭·호버 영역은 그림 옆의 빈 여백 전체로 둔다. 호버 시 색은 즉시 반응하고 배경 강조는 부드럽게 켜진다. 문장·장면은 전환 애니메이션 없이 즉시 교체한다. 스와이프 중에는 그림·자막을 움직이지 않고, 손을 놓을 때 전환한다. 하단의 한 칸 이동 버튼은 모바일에만 표시하고 자막 옆에는 별도 좌우 버튼을 두지 않는다. 자막은 하단 조작 바에서 여유를 두고 크게 표시한다. 상단의 장면 번호와 제목은 한 덩어리로 화면 중앙에 놓는다. 「장면 바로가기」 창에서 이미지 번호를 입력하거나 제목을 검색해 이동할 수 있다. 장면 해설과 엔딩 글은 가운데 정렬하고 원문에 작성된 개행만 유지한다. PC에서는 줄 길이를 균등하게 배분하며, 그림을 크게 보여 주고 모달 폭도 그림에 맞춘다. 설명 영역은 간결한 고정 높이로 두어 장면마다 이미지 위치가 흔들리지 않게 하며, 긴 설명은 영역 안에서 스크롤한다. 주요 장면의 그림을 누르면 창을 닫지 않고 그 자리에서 확대한다. 확대 후에는 끌어서 이동하고, 다시 누르거나 Esc로 확대만 해제한다. 다른 장면으로 이동하면 기본 배율로 돌아간다. 큰따옴표로 둘러싼 대사 행은 초록색으로 표시하고 바깥 큰따옴표만 화면에서 숨긴다. 앞에 인물 이름이 있으면 금색으로 표시한다. 원문의 따옴표와 대사 안의 작은따옴표는 보존하며, 서술의 작품명·인용·용어는 공용 텍스트 강조를 따른다. 그림은 원본 비율로 전체를 보여 준다. 장면 묶음이 아닌 이미지 한 장만 확대해서 보는 창은 그림을 다시 누르면 닫히며, 드래그 뒤의 클릭으로는 닫히지 않는다. 후속 이야기가 등록되어 있으면 마지막 이미지 다음에 별도 ENDING 카드를 보여 주며, 이미지 수에는 포함하지 않는다. 선정·작성·저장 규칙은 [신화 이미지 설명문](../production/prod-02-myth-image-captions.md)이 쥔다.

주요 장면 뷰어는 처음 열릴 때 모든 장면의 제목·해설·엔딩 텍스트를 문서에 넣는다. 현재 읽지 않는 글은 화면 밖에 두고, 문장·장면 이동이나 전체 자막·텍스트 선택 전환에서도 같은 텍스트 노드를 유지해 브라우저 페이지 번역 결과를 이어 표시한다.

이미지 창은 현재 그림이 로드된 뒤 이어지는 그림만 미리 받고, 받은 파일은 브라우저 캐시로 재사용한다. 미리 읽는 범위는 `FactionArtworkViewer`가 정하며, `usePreloadImages`는 그 범위의 이미지 객체만 보유한다. 마지막 이미지·엔딩에서 처음으로 돌아가며 미리 받거나 모든 신화의 장면을 한꺼번에 받지 않는다.

**신화 편성 기준** — L1은 탐색할 지역·문화권, L2는 고유한 소개와 대표 그림이 성립하는 전승·서사, L3는 그 전승 안의 인물 집단이다. 같은 대륙에 있다는 이유로 별개 전승을 한 L2에 합치지 않는다. 인물이 적은 전승은 L3 없이 보여 주며, 각 층의 개수를 맞추려고 전승을 섞거나 한 사람씩 그룹을 만들지 않는다. 전승을 분리할 때 기존 그림은 그 장면이 속한 전승에만 남기고, 맞는 그림이 없는 전승에는 다른 문화의 그림을 복사하지 않는다.

**신화 그룹 기준** — 인물이 크게 늘어도 같은 기준으로 넣을 수 있게 전승마다 축 하나로 가른다. 이름은 짧고 익숙하게 짓되 작품·서사의 기존 명칭은 보존한다. 순수 신화에는 ‘신화’를 쓰고, ‘건국 신화’는 ‘건국’으로 줄인다. 지역별 이야기 묶음은 ‘베트남 전승·하와이 전승’처럼 맞춘다. ‘왕통’ 같은 낯선 말과 설명식 수식을 걷되 ‘삼장 일행·박씨 왕가’처럼 이해를 돕는 말은 살린다. 영상 시절의 문학적 이름(「천 척의 배를 이끈」 따위)은 쓰지 않는다(`docs/project/platform/platform-02-code-rules.md` 「명칭 규칙」). 명단에는 그 작품에 실제로 나오는 인물만 둔다 — 영상 편에 함께 나왔어도 다른 작품 인물은 뺀다(시논은 『아이네이스』, 펜테실레이아·멤논은 『아이티오피스』). 그룹을 사용하는 전승은 아바타를 기다리며 숨긴 인물에게도 그룹을 미리 준다. 그룹 이름과 구성원은 DB가 원천이라 여기 옮겨 적지 않는다.

**그룹 개요** — 처음에는 「전체 구성원」을 보이고, 그룹을 고르면 인물·작품만 해당 그룹으로 좁힌다. 선택 창에서 고른 그룹을 다시 누르거나 「전체 구성원」을 고르면 선택이 풀린다. 별도 × 표시는 두지 않는다. 그룹 선택은 주소의 `group` 값으로 복원한다. 대표 이미지와 전체 개요는 그룹을 골라도 그대로 남는다. 그룹 설명이 있으면 인물 목록 머리의 「그룹 개요」 버튼으로 읽기 모달을 연다. 그룹 설명은 `faction_lv3.description`·`description_en`이 원천이고 백오피스 「신화 편집」(`/myths`)의 그룹 칸에서 고친다. 이 무리가 누구이고 작품에서 무슨 일을 하는지 원전에 근거해 두세 문장으로 쓰고, 명단에 있는 인물을 되도록 설명 안에서 부른다. 숨긴 인물만 있는 그룹은 인물이 공개될 때 쓴다.

**인물 상세 이미지** — 신화·일반 팩션 모두 `FactionPersonHeader`의 아바타 중심 머리말을 쓴다. 기본 이미지는 목록보다 조금 큰 아바타이며 얼굴 본체와 확대 아이콘을 누르면 원본 아바타를 연다. 인사 음성은 별도 음성 버튼으로 재생한다. 별도 화보가 있을 때만 가상독백·인물 상세 버튼 옆에 「상세 이미지」를 둔다. 화보는 해당 세력·전승의 개인샷(`faction_members.image_url`)을 먼저 쓰고, 없으면 인물 대표 사진(`celebs.portrait_url`)을 쓴다. 선택 규칙은 `mythLeadImage.ts`, 이미지 확대 창은 `FactionArtworkViewer`가 쥐며 그림을 다시 누르면 닫힌다. 세 가지 상세 조작은 어두운 배경·밝은 글자로 표시한다. 같은 인물도 전승별 개인샷이 있으면 각 전승에 맞는 사진을 연다.

**신화 주소** — 신화마다 `/explore/myth/<slug>`가 정본 주소이고 사이트맵에 오른다. 공개되지 않았거나 없는 신화는 404다. 화면에서 다른 신화를 고르면 페이지를 새로 받지 않고 주소만 그 신화로 바꾼다(`history.replaceState`). 신화 자료는 첫 화면에서 한 번에 받아 두므로 세력도감처럼 서버를 다시 부르지 않는다. 첫 화면 `/explore/myth`는 들어올 때 주소를 바꾸지 않는다. 옛 바로가기 `/explore/myth?myth=<slug>`는 미들웨어가 `group` 같은 나머지 조건을 실은 채 308로 옮긴다. 신화·세력 한 편의 주소에서는 그 이름(개요 머리)이 h1이고 탐색 배너는 제목 요소를 내려놓는다. 첫 화면은 배너의 「신화의 세계」「세력도감」이 h1이고 선택한 이름은 h2다(`mythHref.ts`의 `atlasPageOwnsTitle`). 검색 제목·설명은 [SEO](../operations/ops-02-seo.md) 「신화·세력도감」이 쥔다.

**전체 목록** — 신화의 세계·세력도감의 첫 화면과 한 편 주소 모두 화면 맨 아래에 공개된 신화·세력 전체를 지역·분야별로 늘 펼친 링크 목록(`AtlasIndex`)으로 둔다. 세력 목록은 분야명을 별도 행에 두고 그 아래 항목을 나열하며, 이 영역의 텍스트는 모두 중앙 정렬한다. 선택기 창은 누른 뒤에만 그려져 크롤러에게 막다른 길이라 이 목록이 한 편 주소로 가는 통로다. 목록 전용 페이지와 지역 페이지는 두지 않는다 — 지역 페이지는 「일본 신화」「그리스 신화」 같은 기존 신화 한 편과 겹친다(26.09.29 결정).

**처음 여는 신화** — 신화 주소(`/explore/myth/<slug>`)는 늘 그 신화를 연다. 첫 화면은 마지막으로 보던 신화, 기본 신화, 첫 공개 신화 순으로 연다. 닫혔거나 없는 신화는 건너뛴다. 첫 방문은 오디세이아로 열고 이 첫 감상도 쿠키에 남긴다. 이후에는 마지막 선택을 이어 연다. 접속 국가에 관련된 지역은 선택창과 전체 목록의 앞에 두되, 이 정렬이 처음 열리는 작품을 바꾸지 않는다. 국가와 지역 대응은 `lib/visitorCountry.ts`, 기본 신화·쿠키 이름·보존 기간은 `mythHref.ts`가 쥔다. 그룹은 기억하지 않고 「전체 구성원」으로 연다. 세력도감은 이 차례를 쓰지 않는다.

**공개 범위** — 로컬과 운영 모두 `faction_lv2.published`가 참인 전승만 연다. 하나라도 열린 전승이 있는 지역만 지역 줄에 나타나고, 그 지역의 닫힌 전승은 「작업 예정」 칩으로 남는다. `getMythClientData`는 닫힌 전승의 인물·그룹·작품 상세를 클라이언트에 넘기지 않는다. 제목 이미지와 아바타는 DB에 등록된 R2 URL을 읽는다.

| 전승 | 가르는 축 |
|---|---|
| 일리아스 | 진영과 역할. 신은 20권 신들의 전투에서 편을 가른 대로 그리스 편·트로이 편으로 나누고, 제우스와 전령은 따로 둔다 |
| 그리스 신화 | 존재의 종류와 세대(태초·티탄·올림포스·저승·그 밖의 신·영웅) |
| 그리스 건국 | 인간 시조와 후손을 도시·민족별로 가른다 |
| 오디세이아 | 오디세우스와의 관계(동료·가족·충직한 사람·구혼자·신과 요정·여정에서 만난 이·망령·파이아케스·필로스와 스파르타) |

나머지 전승도 같은 방식으로 축을 먼저 정하고 그룹을 짠다.

## 세력도감 (`/explore/faction`, `/explore/faction/[slug]`)

신화의 선택기·인물 격자·개요·그룹 개요를 함께 쓴다. FactionScreen이 주소와 자료를 준비하고 `lib/faction-theme.ts`가 공용 MythScreen의 입력으로 바꾼다. 신화의 기존 이미지와 탐색 흐름은 유지한다. 명단은 getFeaturedFactions(신화 갈래·숨긴 배정 제외), 섹션·진영 구성은 `lib/faction-sections.ts`가 쥔다.

팩션 선택·개요 조작 아래에 비로그인 좋아요·누적 조회수·공유를 표시한다. 좋아요 정책과 공용 버튼은 [인물 상세](service-04-celeb-detail.md)의 규칙을 함께 쓴다. 조회수의 브라우저별 재방문 중복 방지는 `sw/web/src/lib/celeb/viewDedup.ts`를 공유한다.

- 배치와 개요·그룹 모달은 위 「신화 탐색판」의 공용 규칙을 따른다. 화살표로 테마를 이동하면 그룹을 초기화하고, 선택기 창에서 함께 고른 그룹은 이동 후에도 유지한다.
- 세 줄 선택기는 `AtlasNavigation`, 선택기 창은 `AtlasPicker`를 공유한다. `FactionScreen`은 전체 선택 계층의 이름·인원만 넘기고, 다른 팩션의 인물·작품은 적용 후 `/explore/faction/<slug>`에서 받는다. `/explore/faction?section=<묶음 slug>` 진입과 기존 리다이렉트는 유지하며, 없거나 닫힌 테마는 notFound다.
- **테마 이미지**는 DB `faction_lv2.team_images`에서 `kind: 'cover'`로 지정한 표지를 읽는다. 신화의 기존 `/myth/title-art/` 이미지는 호환하며, 주요 장면은 `kind: 'scene'`으로 구분한다. 기존 단체화보를 자동으로 대표 이미지로 쓰지 않는다. 이미지가 없거나 로드에 실패해도 별도의 개요 버튼으로 설명 모달을 열 수 있다. 로딩 화면도 같은 배치와 이미지 유무를 따른다.
- 인물을 고르면 소개 모달을 연다(FactionMemberModal). 아바타 확대·인사 음성, 테마·진영, 이름·직함, 「{테마}에서의 {이름}」 제목 아래 긴 소개(getFactionLongDescs), 인물 페이지 링크와 관련 도서를 표시한다. 실존·복합 인물은 관련 도서 위의 「감상 기록」에서 인물 상세와 같은 도서·영상·게임·음악 분류, 감상 목록과 리뷰를 모달 안에서 펼쳐 읽는다. 공개 기록이 없으면 빈 상태를 안내한다. PC·모바일 모두 모달을 열고 닫을 때 배경 목록·책장과 스크롤 위치를 유지하며, 닫으면 선택했던 카드로 키보드 포커스를 돌려준다. 신화도 같은 동작을 쓴다. 인물 페이지의 소속 세력에서는 같은 소개를 여전히 모달로 연다. 요약 모달의 소속 목록은 「인물도감 / {이름}의 소속」 머리말과 「{테마}에서의 {이름}」 제목 아래 긴 소개만 표시한다.
- 책은 공용 AffiliateBookList로 표시하고, 영문 화면은 판매 주소가 걸린 책만 싣는다. 인물 목록 아래에는 현재 인물 범위에 해당하는 작품을 보여 준다. 인물 자료는 getCelebs 조회 후 공개 명단에 든 사람만 남긴다(`lib/faction-celebs.ts`).
- 팩션 주소의 검색 제목·설명은 [SEO](../operations/ops-02-seo.md) 「신화·세력도감」을 따르고, 구조화 데이터(JSON-LD CollectionPage·ItemList)에 구성원 이름·역할·인물 주소를 싣는다.
- 인물 상세의 「소속 신화·세력」 줄은 공개된 신화·팩션 주소를 실제 링크로 서버 HTML에 싣는다(`RelatedFigureLinks.tsx`). 소속 세력 모달에서 신화는 신화 주소로 보낸다.

**테마·그룹의 운영 규격은 여기서 복제하지 않는다.** 계층의 단일원천(`faction_lv2.lv1_id`)과 편집 규격은 `docs/project/apps/apps-01-web-bo.md` 「세력도감」이 쥔다.

## 영상관 — 내려 둠

서재 탐방 형태를 바꾸는 동안 웹의 영상 노출(홈 영상관 배너, `/explore/youtube`, 인물 상세 미디어의 영상 탭)을 걷었다. `/explore/youtube`는 탐색으로 임시 리다이렉트한다(`next.config.ts`). 되살릴 때는 이 리다이렉트를 지우고 코드를 커밋 이력에서 꺼낸다. `celebs.youtube_videos` 값과 유튜브 채널 링크(푸터·구조화 데이터)는 그대로 둔다.
