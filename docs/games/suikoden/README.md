# 천도 — 셀럽 전략 시뮬레이션

공개 인물 중 주군을 골라 방랑하고, 동료와 거병해 영토를 경영하며 천하를 통일하는 게임이다. 수호전 천도 108성에서 영감을 받았다.

쉼터의 개발자 모드에서 천도 카드를 누르거나 `/rest?dev=1#suikoden`으로 연다. 공개 여부는 [`rest-games.ts`](../../../sw/web/src/constants/rest-games.ts)가 정한다.
