# 셀럽 후보 목록

고대~근대 인물 중 Feelandnote 등록 대상을 시대별로 관리한다.

## 파일 구조

| 파일 | 시대 | 대략적 범위 |
|------|------|------------|
| `ancient.md` | 고대 | ~5세기 (서로마 멸망) |
| `medieval.md` | 중세 | 5~15세기 |
| `early-modern.md` | 근세·근대 | 15~19세기 |

## 티어 기준

- **full**: 1차 사료에서 특정 작품명·구절 인용이 확인됨 → 콘텐츠 수집(엄격 증거) 포함
- **light**: 문화 활동(시, 음악, 독서, 관극 등)을 즐긴 기록은 있으나 엄격한 1차 사료 인용은 없음 → 콘텐츠 수집 없이 철학·영향력·페르소나만

### 등록 최소 조건

인물이 최소한 하나의 문화적 감상 활동(시문학, 음악, 독서, 관극, 예술 향유 등)을 즐긴 기록이 있어야 한다. "감상을 거부했다"는 감상 철학이 아니다.

## 상태

| 값 | 의미 |
|----|------|
| `pending` | 대기 중 |
| `in_progress` | 작업 중 |
| `done` | DB 등록 완료 |
| `skip` | 철학조차 작성 불가 |

## 운영 규칙

- 이미 DB에 등록된 인물은 이 목록에 넣지 않는다
- 등록 전 중복 확인: `SELECT nickname FROM profiles WHERE profile_type = 'CELEB' AND nickname LIKE '%{검색어}%'`
- 작업 완료 시 상태를 `done`으로 변경
- 룰북: `.claude/rules/celeb-6-queue.md`
