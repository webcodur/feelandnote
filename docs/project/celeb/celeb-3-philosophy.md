# 셀럽 감상 철학 생성 룰북

인물의 콘텐츠 감상 철학을 작성하는 가이드.

---

## 작성 기준

**그 사람의 인생을 감상철학과 함께 자연스럽게 풀어쓴다.**

분석 보고서가 아니다. 이 사람이 무엇을 읽고/보고/들었는지, 그것이 삶에 어떻게 녹아들었는지를 하나의 이야기로 쓴다.

---

## 핵심 원칙

### 1. 장면으로 보여준다

추상적 분석("감상을 도구로 활용한다") 대신 구체적 장면("베개 밑에 두고 잤다")으로 쓴다.

| 나쁜 예 | 좋은 예 |
|---------|---------|
| 텍스트를 자기 정체성을 규정하는 거울로 사용한다 | 단검과 함께 『일리아스』를 베개 밑에 두고 잤다 |
| 감상을 현실과 단절된 행위로 두지 않는다 | 아킬레우스의 무덤 앞을 달리며 말했다 |
| 영웅 서사의 문법을 현실에 적용한다 | 쐐기대형의 선봉에 섰다 |

### 2. 인생과 감상을 분리하지 않는다

"감상 분석" 파트와 "업적 설명" 파트를 나누지 않는다. 이 사람의 삶 자체를 쓰되, 그 안에서 감상 경험이 자연스럽게 등장하게 한다.

### 3. 부연하지 않는다

장면이나 인용문이 스스로 말하게 둔다. "~라는 뜻이다", "~라는 선언이었다" 같은 해설을 붙이지 않는다.

## 금지 패턴

### 문체 금지

| 패턴 | 예시 | 이유 |
|------|------|------|
| **부정-긍정 대구 시작** | "X는 ~하지 않는다. 그는 ~한다." | 전 인물이 같은 톤으로 시작하게 된다 |
| **"~이 아니라 ~이다" 반복** | "오락이 아니라 훈련이다" | 한 글에 1회 이하 |
| **도구론 프레임** | "감상을 ~의 도구로 활용한다" | 모든 인물이 같은 결론에 수렴한다 |
| **메타 해설** | "이 태도는 ~을 보여준다" | 보여주지 말고 직접 쓴다 |

### 내용 금지

| 금지 | 설명 |
|------|------|
| ❌ **추측성 어미** | "~로 보인다", "~짐작할 수 있다" 금지. 단정("~다.")으로 끝낸다 |
| ❌ **추상적 나열** | "다양한 장르를 좋아했다" → 구체적 작품명으로 |
| ❌ **'컨텐츠'/'콘텐츠' 단어** | 구체적 장르명(책, 영화, 음악)이나 '작품' 등으로 표현 |
| ❌ **뻔한 칭찬** | 모순된 취향이나 비판적 시각이 있다면 그대로 서술 |

## 기호 규칙

| 용도 | 기호 | 예시 |
|------|------|------|
| **작품명** (책/영화/앨범/게임) | `『』` 겹낫표 | 『일리아스』, 『다크 나이트』 |
| **하위 작품** (곡명/에피소드/기사) | `「」` 홑낫표 | 「Bohemian Rhapsody」, 「1화」 |
| **직접 인용** (셀럽 발언) | `""` 큰따옴표 | "나를 바꾼 책이다"라고 말했다 |
| **강조/개념어** | `''` 작은따옴표 | '독서법'은 전장으로도 이어졌다 |

### 금지

- 스마트 따옴표(`""`, `''`) 사용 금지. 일반 따옴표(`""`, `''`)만 사용
- 작품명에 `''`, `""`, `「」` 사용 금지. 반드시 `『』`
- 곡명/에피소드에 `『』` 사용 금지. 반드시 `「」`

---

## 분량 규칙

- **500자 이하 권장, 600자 미만 필수**. 짧고 밀도 있게 쓴다.
- 자료가 부족한 인물도 **최소 3문단** 이상 작성
- 자료 부족 시 해당 인물의 직업적 특성, 시대적 맥락, 유추 가능한 감상 태도로 보완

---

## 모범 답안

**아래 예시의 문체, 밀도, 호흡을 그대로 따른다.**

```
알렉산더 대왕은 단검과 함께 『일리아스』를 베개 밑에 두고 잤다. 그에게 호메로스의 서사시는 단순한 문학이 아닌 삶의 대본이었다. 그는 아킬레우스를 감상하는 데 그치지 않고, 스스로 그 자리에 자신을 투영했다.

트로이 유적지에 당도했을 때는 아킬레우스의 무덤 앞을 달리며 말했다. "그대는 행복한 자다. 살아서는 목숨을 바칠 벗이 있었고, 죽어서는 호메로스가 너를 노래했으니."

이러한 그의 '독서법'은 전장으로도 이어졌다. 알렉산더는 후방 지휘를 거부하고, 서사시 속 영웅처럼 쐐기대형의 선봉에 섰다. 폐에 화살이 관통하는 등 숱한 중상을 입고도 결코 전선 뒤로 물러서지 않았다.

몸을 돌보지 않은 대가로 서른둘에 요절하고 제국은 분열되었으나, 그의 이름은 2,300년이 지난 지금도 살아 숨 쉰다. 아킬레우스처럼 기억되길 바랐던 소년은, 결국 아킬레우스보다 더 위대한 이름이 되었다.
```

**이 예시가 잘 된 이유:**
- 첫 문장이 구체적 장면("베개 밑에 두고 잤다")으로 시작한다
- 인용문("그대는 행복한 자다~")이 부연 없이 문단을 닫는다
- 감상(일리아스)과 인생(전투, 요절)이 분리되지 않고 하나의 흐름이다
- 마지막 문장에 임팩트가 있다

## 자료 수집

### full 셀럽 (celeb_tier = 'full')

**1단계: DB 콘텐츠 활용**

```sql
SELECT c.title, c.creator, c.type, uc.review
FROM user_contents uc
JOIN contents c ON c.id = uc.content_id
WHERE uc.user_id = '{셀럽ID}'
ORDER BY c.type;
```

- **review 필드**: 셀럽이 해당 작품을 언급한 맥락·발언이 담겨 있다. 철학 작성의 핵심 소스로 활용한다.
- **작품 목록**: 장르별 분포, 반복 등장 주제 등을 파악하여 감상 패턴 분석에 활용한다.

**2단계: 웹 검색 (보충)**

| DB 콘텐츠 | 검색 전략 |
|-----------|----------|
| **10건 이상** | 검색 1~2회. 감상 태도·에피소드·명언 중심으로 보충 |
| **10건 미만** | 최소 2~3개 검색어로 다각도 조사 |

### light 셀럽 (celeb_tier = 'light')

DB 콘텐츠가 없으므로 **웹 리서치가 유일한 소스**다.

**검색 전략**: 최소 3개 검색어로 다각도 조사

- 감상 기록이 있는 인물: 독서·감상 기록 중심 검색
- 감상을 거부/경시한 인물: 그 태도 자체를 철학으로 서술 (예: 항우의 "글은 이름만 쓰면 족하다")
- 교육 배경만 확인되는 인물: 시대·교육·문화적 맥락에서 감상 태도 추론

### 공통 검색 키워드

- "{셀럽명} 독서 책 추천 인터뷰"
- "{셀럽명} 영화 음악 취미"
- "{셀럽명} 명언 철학"
- "{셀럽명} education influences reading" (고대~근대 인물)

## 업데이트 가드 (필수)

**반드시 `docs/project/celeb/celeb-common-update-guard.md`를 읽고 따른다.**

핵심 요약:
- 기존 감상철학을 읽지 않는다. 매번 백지에서 새로 리서치하고 새로 쓴다.
- UPDATE 직전에 기존 텍스트를 SELECT하여 비교한다.
- 완전히 동일하면 SKIPPED 처리, 한 글자라도 다르면 UPDATE 실행.
- 배치 완료 시 [UPDATED/SKIPPED/FAILED] 카운트 보고 필수.
