# 편성표

유튜브 배포 순서 및 제작 진행 현황.

## 편성 원칙

1. 고대 → 근세 → 근현대 → 현대 → … 시대를 교차하며 편성
2. 직군(무장/정치/예술/과학 등)과 동서양을 겹치지 않게 배치
3. 음성(has_voice) 보유 인물을 우선 제작
4. **라이벌 묶음**: 대립 관계 인물은 연속 2~3회로 묶어 공정하게 다룸
5. **정치 인물**: 좌↔우, 동↔서 왔다갔다 교차 편성

## 제작 규칙

### 분량

- **최대 20권, 최대 2편**. 모든 인물에 동일 적용.
- **10권 이하**: 단일 JSON.
- **11~20권**: 2편 분할. `Math.ceil(N/2)` 기준. Part 2에 `series` 필드 + `returnIntro` + `prevRecap`.
- **20권 초과**: 20권으로 선별 후 2편 분할 (10+10). 나머지는 서비스 내 프로필에서 확인 유도.

### 20권 초과 인물 선별 기준 (우선순위 순)

1. **review 충실도**: DB review가 충분히 작성된 콘텐츠 우선. 빈 review는 제외.
2. **contextQuote 보유**: 검증된 인용문이 있는 콘텐츠 우선.
3. **celebCount**: 다른 셀럽도 추천한 책(celebCount 높은 순) 우선. 영상 시청자의 관심 유도.
4. **다양성**: 같은 저자·장르가 편중되지 않도록 분산. 시대·주제 교차.
5. **스토리**: 인물의 인생 서사와 연결이 강한 책 우선 (전환점, 위기, 성장).

### 보이스

- **해설**: 롱폼·쇼츠·SOLO 모두 Gemini `Charon` 고정.
- **실제 인물**: 진행 인물과 조연 모두 ElevenLabs ID 필수. DB `profiles.voice_id_ko`를 우선하고, 없으면 청음된 ELE 후보를 새로 캐스팅한다. Gemini로 임시 대체하지 않는다.

### 품질

- **글솜씨 리뷰**: JSON 생성 후 반드시 텍스트 리뷰 (주어 규칙, 진부 표현, 반복 어휘).
