# 타입캐스트 음성 저장

스튜디오 안에서 생성하고 재생하는 데에는 크레딧이 들지 않는다. 크레딧은 다운로드할 때 든다. 재생하면 브라우저가 줄마다 `cdn.typecast.ai`에서 wav를 받아 오므로, 그 주소를 모아 받으면 다운로드 단추 없이 음원이 저장된다. 시험 단계용 도구다. 대량 처리는 나중에 공식 API로 한다(사용자 방침, 26.11.22).

## 처음 쓰는 컴퓨터·계정

로그인과 시험용 프로젝트는 컴퓨터·계정마다 다르다. 처음 한 번 맞춘다.

1. ego lite 기본 프로필에 타입캐스트 회원 계정과 같은 구글 계정으로 로그인해 둔다. 타입캐스트 로그인이 풀리면 스크립트가 「구글로 계속하기」와 계정 고르기(하나일 때)로 다시 들어간다. 비밀번호·2단계 인증·구글 정보 제공 동의·타입캐스트 회원가입 화면이 뜨면 멈추고 알린다(사람이 처리한다). 26.11.23 확인: ego 프로필의 구글 계정으로 들어가면 회원가입 화면이 뜬다. 즉 그 계정은 타입캐스트 회원이 아니다.
2. 시험용 프로젝트를 찾거나 만든다. 이름이 같은 프로젝트가 있으면 찾기만 하고, 없으면 「새 프로젝트」(한국어 하나의 언어)로 만든다.

```bash
node .agents/skills/typecast-voice-save/scripts/setup-projects.mjs \
  --out D:/feelandnote/video/shorts/typecast-projects.json [--names test,test2,test3]
```

- 목록 파일은 그 컴퓨터 것이다. 저장소에 올리지 않는다(영상 저장소 `.gitignore`). 목록이 없으면 쇼츠 조립기가 이 명령을 알려 주고 멈춘다.
- 이름 수가 병렬 일꾼 수다. 두 컴퓨터가 같은 계정으로 동시에 돌리면 이름을 달리한다(예: 다른 컴퓨터는 `--names pc2-a,pc2-b`). 같은 프로젝트를 동시에 쓰면 대본이 섞인다.
- feelandnote 저장소가 `C:/project/feelandnote` 가 아니면 환경변수 `FEELANDNOTE_ROOT` 로 알려 준다(쇼츠 조립기가 이 스킬을 찾는 경로).
- 목소리는 이름으로 찾는다. 요금제에 따라 쓸 수 없는 목소리는 「목소리를 찾지 못했다」로 알린다.

## 줄 목록으로 생성해 받기

```bash
node .agents/skills/typecast-voice-save/scripts/generate-voices.mjs \
  --url https://studio.typecast.ai/text-to-speech/<프로젝트 id> \
  --job <줄 목록.json> --out D:/feelandnote/video/tmp/<작업명>
```

줄 목록(JSON 배열):

```json
[
  { "voice": "진우", "text": "애덤 스미스는 국부론에서 시장을 이렇게 설명합니다." },
  { "voice": "진우", "text": "정말요?", "emotion": "기쁨", "intensity": 150, "speed": 1.2, "pitch": 2, "name": "jinwoo-joy" }
]
```

| 항목 | 값 | 생략하면 |
|---|---|---|
| `voice` | 스튜디오 목소리 이름. 아래 「목소리 후보」에서 고른다. 보이스 찾기에서 이름이 정확히 같은 것을 고른다 | 필수 |
| `text` | 읽을 문장. 줄바꿈은 공백으로 바뀐다 | 필수 |
| `emotion` | 감정 이름(일반·기쁨·슬픔·화남·높은 톤·낮은 톤·속삭임 등, 목소리마다 다르다) | `일반` |
| `intensity` | 감정 강도 0~200(%). `일반`에는 강도 칸이 없어 무시된다 | 100 |
| `speed` | 속도 0.5~2.0배 | 1 |
| `pitch` | 피치 -5~+5 | 0 |
| `name` | 저장 파일 이름(확장자 제외) | `01-진우`처럼 순번-목소리 |

- 한 줄마다 편집기 문장을 바꾸고 목소리·감정·강도·속도·피치를 고른 뒤, 화면 값이 요청과 같은지 확인하고 재생해 받는다. 긴 문장이 여러 조각으로 생성되면 이어 붙인다.
- 실패한 줄(없는 목소리·감정, 화면 값 불일치)은 사유를 출력하고 다음 줄로 넘어간다. 없는 감정이면 고를 수 있는 감정 목록을 함께 출력한다. 실패가 하나라도 있으면 종료 코드 1이다.
- 실측 속도(26.11.22): 4줄에 약 47초(브라우저 열기 약 10초 + 줄당 음성 길이 + 6~8초).
- **이 스크립트는 지정한 프로젝트의 대본을 덮어쓴다(자동 저장).** 시험용 프로젝트에만 쓴다(위 「처음 쓰는 컴퓨터·계정」의 목록 파일에 있는 것).

## 쇼츠에서 쓰기 (「한 사람, 한 권」)

쇼츠 조립기가 이 스킬을 부른다. 줄 목록을 손으로 만들지 않는다.

```bash
cd D:/feelandnote/video
node shorts/build.mjs <편> --voice                    # 기본(타입캐스트) → shorts/view/<편>.html, 굽기·업로드도 이 음성
node shorts/build.mjs <편> --voice --tc-female 미소    # 여성 목소리만 바꿔 시험
node shorts/build.mjs <편> --voice --edge             # 예전 Edge 음성(비교용) → shorts/view/<편>.edge.html
node shorts/voice-all.mjs [편…] [--workers N]         # 여러 편을 병렬로(바뀐 줄만 받음, 기록 tmp/typecast/voice-all.log)
```

- 배정(26.11.24): 해설은 진우 고정. 인물은 여성이면 선영, 남성이면 편 데이터 `typecast.person`(기본 철훈). 그 전에 녹음한 편은 편 데이터에 녹음된 목소리가 적혀 있다. 다른 사람은 기본값이 없고 말하는 사람에 맞춰 편 데이터 `typecast { "other": 목소리 }` 로 정한다(고전 인용 명일, 노년 창배·명일(권일은 발음이 약해 뺐다), 젊은이 셰인·현준, 여성은 나이에 맞춰 승연·인선·미소(주하·엠마는 뺐다) / 예: 메이플스 편 보비 클라인 창배). 정하지 않으면 조립기가 멈춘다. 필재·엠마·주하는 후보에서 뺐다(26.11.22~23).
- 빠르기·쉼: 인물·다른 사람 1.1배, 문장 앞뒤 쉼 0.14·0.38초(`shorts/build.mjs` 상단). 해설·인물 배속은 목소리마다 다르며 `shorts/typecast-speed.json`(역할별 표)이 쥔다.
- 바뀐 줄만 받는다: 줄마다 목소리·속도·문장을 `voice-typecast/<id>.meta.json` 에 적고, 바뀐 줄만 다시 받는다. 원음은 조건별로 `tmp/typecast/<편>/cache/` 에 남아 되돌릴 때 다시 받지 않는다. 손으로 음성 파일을 지우지 않는다.
- 해설 빠르기는 스스로 맞춘다: 받은 뒤 해설이 기준(진우 1.2배 초당 7.3자)과 7% 넘게 다르면 맞는 배속을 셈해 `typecast-speed.json` 에 적고 해설 줄만 다시 받는다. 처음 쓰는 목소리도 손댈 것이 없다.
- 글자 수에 비해 지나치게 긴 원음(초당 4자 미만)은 앞 음원이 섞인 것으로 보고 한 번 더 받는다. 구현은 `D:/feelandnote/video/tools/typecast-lines.mjs`.
- 병렬: 스튜디오 프로젝트 하나를 일꾼 하나가 맡는다(같은 프로젝트를 동시에 쓰면 대본이 섞인다). 프로젝트 목록은 `shorts/typecast-projects.json`(`setup-projects.mjs` 가 쓴다), 일꾼 수 기본값은 1이다. 타입캐스트 생성 한도(「일정 시간 내 생성 한도를 초과했습니다」)가 계정 단위라 일꾼을 늘려도 크게 빨라지지 않고 한도에 일찍 닿는다(26.11.22 일꾼 셋 → 20분 만에 한도). 한도에 걸리면 스킬이 1·2·4·8분 기다렸다 같은 줄을 다시 받고, 15분 넘게 안 풀리면 실행기가 멈춘다.

## 이미 만든 프로젝트를 받기

```bash
node .agents/skills/typecast-voice-save/scripts/save-voices.mjs \
  --url https://studio.typecast.ai/text-to-speech/<프로젝트 id> --out <저장 폴더> [--prefix line]
```

프로젝트를 끝까지 재생해 `<prefix>-01.wav`부터 줄 순서대로 저장한다. 대본 줄 수와 받은 파일 수가 다르면 경고한다. 프로젝트를 고치지 않는다.

## 구성과 함정

- `scripts/ego-lib.mjs`: ego 안에서 도는 스튜디오 조작(목소리·감정·숫자 설정, 재생·수집, wav 이어 붙이기). 화면이 바뀌어 깨지면 여기만 고친다.
- `scripts/ego-run.mjs`: 일반 Node에서 ego 실행·결과 받기·서명값 가리기.
- ego 브라우저 기본 프로필의 로그인을 쓴다. 로그인이 풀려 있으면 ego 안에서 다시 로그인한다. 비밀번호를 물으면 사용자에게 넘긴다. ego 사용법은 `ego-browser skill`과 [`res-06-ego-browser.md`](../../../docs/resource/res-06-ego-browser.md)를 따른다.
- 재생 중에는 하단 단추 이름이 `Stop`, 끝나면 `Play`다. 고정 시간 대신 이 변화를 기다린다.
- 브라우저 요청 기록은 기본 250개가 한도라 광고·통계 요청에 금방 찬다. 차면 음원 요청이 기록되지 않아 「새 음원 요청이 없었다」가 난다. 재생마다 기록을 비운다.
- 같은 페이지에서 바로 앞과 같은 문장·설정을 다시 재생하면 받아 둔 음원을 재사용해 새 요청이 없다.

## 지킬 것

- **다운로드 단추를 누르지 않는다.** 크레딧이 든다.
- **음성 재생성 단추 등 크레딧이 드는 조작은 사용자 지시 없이 누르지 않는다.**
- **로그인 토큰을 꺼내 쓰지 않는다.** 스튜디오 내부 API(`typecast.ai/api/speak/batch/post` 등)는 로그인 토큰이 있어야 하고, 토큰을 꺼내려 하면 자동 권한 검사가 막는다. 사용자도 화면 조작 방식을 골랐다(26.11.22).
- **서명값(`Signature`·`Key-Pair-Id`)을 로그·문서·보고에 남기지 않는다.** 서명 주소에는 만료가 있으니 저장해 두고 다시 쓰지 않는다.

## 음질

받은 음원은 16kHz 모노 wav다(26.11.22 실측). 미리 듣기용 음질일 가능성이 있다. 다운로드 파일이나 API 출력은 더 높을 수 있으나 확인하지 않았다. 음질이 중요한 곳에 쓰기 전에 사용자에게 알린다.
