# 얼굴 씨앗 배정 — 468명

아바타와 대표 사진이 둘 다 없는 468명에게 얼굴 씨앗을 하나씩 붙였다. **468명 전원 배정이 끝났고, 계통과 배역 적합성을 agy로 전수 대조했다**(26.09.07).

씨앗은 그 인물의 초상이 아니다. 남의 사진이고, 골격만 가져오고 나머지는 발주서가 덮어쓴다. 방식과 근거는 [`image-generation.md` §6.6~6.7](../../../docs/project/production/image-generation.md)이 쥔다.

## 어디에 무엇이 있나

| 것 | 자리 |
|---|---|
| 배정된 얼굴 469장 | `D:\image\_재료\지정\<인물명>.png` — 파일명이 곧 배정이다 |
| 남은 재료 398장 | `D:\image\_재료\<male\|female>\<버킷>\` |
| 생성 배치 468건 | `sw/web-bo/.tmp/hero-batch.json` (발주서 + 얼굴 경로 + 성별·나이·체구·계통) |
| 발주서 원문 | `sw/web-bo/.tmp/briefs.jsonl` |
| 배정 원장 | `sw/web-bo/.tmp/face-assign-ledger.json` |
| 배정표(브라우저) | `sw/web-bo/.tmp/face-cast/face-table.html` |

`지정`에 469장인데 배치가 468건인 것은 욥이 대상 목록에서 빠졌기 때문이다. 그 한 장은 잔여물이다.

## 규칙

- **한 얼굴은 한 인물에게만 간다.** 배정하면 원본을 풀에서 지운다. 복사만 하고 두었더니 다음 회차에 같은 얼굴이 또 뽑혀 15장이 37명에게 물렸다(26.09.06).
- **관문은 셋이다 — 계통, 성별, 나이 두 칸(스무 살).** 발주서가 나이를 되돌리지만 스무 살이 한계다. 극단 AI형은 버리지 않고 뒤로 민다.
- **회차 끝에 해시로 훑는다.** 지정 폴더 안의 중복, 풀에 남은 배정본, 풀 안의 같은 그림 셋을 본다. 셋 다 실제로 생겼다.
- 아이 얼굴은 어느 인물에게도 가지 않는다. **나이 라벨이 없는 얼굴도 배정하지 않는다.**
- **배정을 풀면 그 얼굴의 나이 라벨을 지운다.** 나이가 안 맞아 풀린 얼굴은 라벨이 틀린 것이라, 그대로 두면 같은 얼굴이 같은 자리로 돌아온다.
- 씨앗은 **정면 사진**이어야 한다. 옆얼굴·그림·뭉갠 것은 골격을 못 준다.
- 알아볼 수 있는 배우·모델은 폐기한다. 검수에서 임달화·유덕화·고천락·타이슨 베크포드·프리다 핀토·에릭 데인·트리플 H·알 파치노·아드리아나 리마가 나왔다.

## 계통 버킷

| 버킷 | 담는 것 |
|---|---|
| `EastAsian` | 한·중·일·몽골·티베트·중앙아시아 튀르크 |
| `SEAsian` | 대륙부·도서부 동남아와 오세아니아(마오리·통가·사모아·하와이·피지) |
| `Amerind` | 콜럼버스 이전 아메리카. 히말라야·티베트 얼굴이 실제로 통한다 |
| `Indian` | 인도 아대륙 |
| `MiddleEastern` | 레반트·메소포타미아·페르시아·아나톨리아·아라비아·베르베르, 그리고 캅카스 |
| `Black` | 사하라 이남 아프리카 |
| `white-etc` / `-blonde` / `-red` | 유럽 |
| `Latino` | 현대 라틴아메리카. **건국 인물에는 쓰지 않는다** |

국적→버킷 표와 예외는 `sw/web-bo/scripts/photo/assign-faces.mjs`가 쥔다. 국적으로 못 가르는 경우가 있다 — 모리타니는 무어인 기준이라 중동에 묶여 있지만 와가두 건국자는 소닌케족이고, 미국은 이로쿼이와 하와이가 섞여 있어 슬러그로 가른다.

## 도구

전부 `sw/web-bo/.tmp/face-cast/`에 있다. 배정기 본체만 `scripts/photo/assign-faces.mjs`다.

| 도구 | 하는 일 |
|---|---|
| `sheet.mjs <폴더> <태그> [칸px]` | 컨택트 시트로 묶는다. **검수는 450px로 한다** — 300px로는 측면·그림·뭉갬이 안 보인다 |
| `fix/stage-all.mjs` | 배정된 얼굴 전부를 시트용으로 깐다. 파일명에 이름·성별·나이가 들어간다 |
| `fix/age-relabel.mjs` | 나이 라벨이 비어 있는 얼굴을 모아 시트로 깔고, 판정을 받아 채운다 |
| `table.mjs` | `face-table.html` 배정표를 만든다 |
| `fix/relabel.mjs` | 폴더 실물을 훑어 `pool-labels.json`을 다시 만든다 |
| `fix/lineage-check.mjs` | agy로 계통을 전수 대조한다 |
| `fix/cast-check.mjs` | agy로 배역 적합성(성별·나이·계통·인상)을 본다 |
| `fix/uncast.mjs <판정.json>` | 배정을 풀어 얼굴을 제 계통으로 돌려보낸다 |
| `fix/pin.mjs <계획.json>` | 특정 인물에게 특정 얼굴을 손으로 못 박는다 |
| `fix/dedupe.mjs` | 같은 얼굴이 여럿에게 간 것을 푼다 |
| `fix/stage.mjs <권역>` | 권역별로 얼굴을 모아 시트용으로 깐다 |
| `fix/resort.mjs <태그> <폴더> <이동표>` | 시트를 보고 판정한 대로 풀 안에서 계통을 옮긴다 |
| `harvest/get.mjs` · `install.mjs` | 핀터레스트 수집본을 내려받아 풀에 넣는다 |
| `harvest/get.mjs`·`install.mjs` | 핀터레스트 수집본을 내려받아 풀에 넣는다 |

**원장(`face-assign-ledger.json`)은 배정기가 쓴 것만 기록한다.** `pin.mjs`로 손수 바꾼 칸은 해당 항목을 지워 「기록 없음」으로 만든다 — 그대로 두면 이미 고친 칸을 나중에 결함으로 읽는다(26.09.07에 실제로 그랬다). 원장의 `spread`로 감사할 때는 이 점을 안다.

DB 반영 전 작업 자료다. 생성과 등록이 끝나면 지운다.
