# 랭킹 — 순위 나레이션 시리즈

한 축의 순위를 나레이터가 읽고, 인물마다 화보 위에 설명이 한 컷으로 붙는다. 인물 대사는 없다.

## 데이터

```
sw/remotion/public/rankings/
  _episodes.json              # 스튜디오·렌더 노출 목록
  <편>/ranking-data.json      # 제목·축·인물(순위·설명·이미지)
  <편>/images/                # 개인샷. 경로만 적어도 된다
```

`_episodes.json`에 없는 편은 폴더가 있어도 컴포지션으로 안 뜬다. 백오피스 목록은 폴더를 전부 보여 주고, 스튜디오에 올릴 편만 이 목록에 넣는다. 백오피스에서 새 편을 만들면 이 목록에도 붙는다.

한 편은 축 하나다. 그리스 로마 신화는 무력·지력·통솔력·매력이 각 편이다. 편 JSON의 `themeSlug`가 세력도감 테마(`celeb_tags.slug`)를 가리킨다. 인물 풀과 개인화보는 그 테마를 쓰고, 랭킹은 축·순위·설명만 쥔다. 새 테이블은 없다.

사진은 백오피스 편 화면의 사진 목록(Ctrl+Q)에서 올리거나 고른다. 인물 칸에 끌어다 놓으면 `image`에 경로가 붙는다. 창구는 `/api/ranking/media`.

영상은 셀럽 주소를 그대로 읽는다. 설명 컷은 아바타, 이미지 컷은 테마 개인화보가 있으면 그것, 없으면 대표 사진이다. 백오피스 편 화면의 「인물 사진」에서 아바타·대표 사진을 등록하면 셀럽 프로필에 바로 저장되고, 편을 저장하면 영상에 붙는다. 테마에 없는 이름은 그 칸에서 테마 사람이나 셀럽을 찾아 연결한다.

## 스튜디오

- 폴더: `Ranking` → `<편>`
- 본편: `Ranking-<편>-KO-LV` — 세로 1080×1920, 60fps
- 썸네일: `Ranking-<편>-KO-LV-TH` — 첫 프레임 1장
- 그리스 로마: `Ranking-greece-might-KO-LV` · `greece-wit` · `greece-command` · `greece-charm`

렌더는 사용자가 스튜디오 또는 `pnpm render Ranking-greece-might-KO-LV`로 실행한다.

## 편집

백오피스 `/rankings`. 원천은 위 JSON이다. 새 테이블은 없다.
