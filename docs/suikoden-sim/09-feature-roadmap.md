# 09. 기능 로드맵

> 기획서(01~08) 대비 현재 구현 상태 분석 및 우선순위별 구현 계획.

## 현재 구현 상태 (2026-07-16 코드 실측)

### 완료

| 시스템 | 구현 내용 |
|--------|----------|
| **턴제 엔진** | `advanceTurn()` — 시간 진행(+10일/턴), 건설/자원/급여/식량/훈련/체력/민심/인구 처리 |
| **2단계 셋업** | 시나리오 5종 중 택1 → `previewScenario()` → AI 세력 미리보기 + 시나리오 지정 후보 중 주군 선택 → `finalizeGame()` |
| **시나리오** | 삼국쟁패/십자군/전국시대/나폴레옹/대몽골 5종, 시나리오별 활성 거점·지역 제한 |
| **페르소나 Grade** | `celeb_persona` 4능력 가중평균 우선, 없으면 `total_score` 폴백 |
| **방랑 페이즈** | 지역 이동, 동료 모집(최대 5명), 랜덤 이벤트(객장/도적/풍경/소문), 거병 |
| **건설** | 15종 건물, 건설→시공→완성, 카드 UI + 드래그앤드롭 배치 |
| **자원 생산** | 건물별 생산, 담당관 배치 보너스, 무기고 무기 생산 |
| **식량 소비** | 병력 기반 소모, 부족 시 사기/충성 하락 |
| **근무 배치** | 캐릭터를 건물에 배치 → 생산 보너스 |
| **순찰** | 위협 출몰 → 캐릭터 배정 → 해결 판정 |
| **인재 영입** | 선술집 방문자 등용, 명성 기반 영입 제한(`GRADE_FAME_REQ`) |
| **자동 내정** | idle 캐릭터 자동 배치 |
| **전투** | **3×5 그리드 개별 유닛 턴제.** 배치 → 속도순 행동 → 공격/스킬(14종)/방어/후퇴, 최대 30턴, 성벽 효과, SVG 애니메이션 |
| **포로 처분** | 전투 승리 시 등용/석방/처형 |
| **AI** | 세력별 성향(정복/책략/경제/인덕/문화), 내정·전투·침공 판단, 전투 중 행동 선택 |
| **세계맵** | 10지역 22영토, d3 + topojson 지구본 + 텍스트맵 |
| **UI** | GameHUD, GameToolbar, 건물 카드 그리드, 캐릭터 정보 패널, 대사 스낵바 |
| **장비** | 수량제 4종(무기/군마/조선/부적), `commandEquip()` 배분, AI 자동 분배, 전투 보정 |
| **인사** | 훈련(연병장), 포상/처벌, 체력 소모/회복 |
| **외교** | 동맹/정전/조공/항복 권유, 관계도 |
| **경영** | 세율 조정, 건물 철거, 민심, 인구 변동 |
| **이벤트** | 계절 이벤트 7종, 랜덤 이벤트 4종, 위협 4종 (로그 표시만) |
| **명성** | 0~1000, 등급별 영입 요구치, 건설/점령/영입/외교 트리거 |
| **급여** | 등급별 자동 지불 |
| **대사** | DB 개인화 대사(`celeb_dialogues`) + 톤별 기본 대사 6톤 × 11상황 |
| **i18n** | 게임 전용 ko/en 텍스트 테이블 + 전투 로그 후번역 |
| **오디오** | 페이즈별 BGM 2트랙 |

| 카테고리 | 미구현 항목 | 근거 |

## 구현 우선순위 (잔여)

### Phase 0: 정합성 복구

| 항목 | 설명 |
|------|------|
| **죽은 링크** | `navigation.tsx`의 `/rest/suikoden`이 404. 페이지 신설 또는 `/rest#suikoden`으로 교정 |
| **누락 에셋** | 거점 배경 3장 추가, 또는 배경 URL을 `imageUrl` 필드 기반으로 교정 |
| **죽은 코드** | 미사용 전술 상수(`TACTIC_MATCHUP`/`TACTIC_INFO`/`CLASS_TACTIC_BONUS`), 미호출 `previewWorld`/`initGame` 처리 방침 결정 |

### Phase A: 이벤트 팝업 + UI 개선

| 항목 | 설명 |
|------|------|
| **이벤트 팝업** | 이벤트 발생 시 화면 중앙 팝업, 확인 버튼 |
| **영토 비교** | 세력별 영토/자원/병력 비교 테이블 |

### Phase B: 인사/경영 확장

| 항목 | 설명 |
|------|------|
| **학당 학습** | 학당에 배치 → intellect/virtue 성장 |
| **징병** | 병영에서 인구→병력 전환, 민심 -5 |
| **민심 세분화** | 폭동(0-19) 시 건물 파괴/인재 이탈 이벤트 |

### Phase C: 승리 조건 + 전투 확장

| 항목 | 설명 |
|------|------|
| **일기토** | martial ≥ 50 장수끼리 1:1 대결 |
| **문화 승리** | 극장/사원 문화 영향력 → 전체 60% 이상 |
| **외교 승리** | 2/3 이상 세력과 동맹 체결 |
| **턴 초과 패배** | `DIFFICULTY_CONFIG.maxTurns` 연결 |

### Phase D: 장비 + 세이브

| 항목 | 설명 |
|------|------|
| **장비 구매 UI** | 비용 상수 정의 후 무기고에서 금/자재로 구매 |
| **수상전** | `ships` 전투 보정 설계·구현 |
| **세이브/로드** | localStorage 기반 세이브 슬롯 3개 |
