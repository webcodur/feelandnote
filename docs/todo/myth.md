# 신화 인물 남은 작업

그리스·로마 신 계보를 정비하며 남긴 후속 과제다. 관계 규칙과 이름 치환 주의는
[`../project/celeb/celeb-07-01-relations.md`](../project/celeb/celeb-07-01-relations.md),
신화 목록 화면은 `sw/web/src/actions/home/getMythData.ts`가 쥔다.

## 표기와 안내

- 대응 신격(counterpart)은 「같은 신을 문화권마다 다르게 부른 것」이라 가족도 사회도 아니다.
  관계는 `rel_group=counterpart`로 들어가 있다(주피터→제우스, 26.09.29 확인). 관계망에서는 기타 갈래에 두고,
  프로필 하단 이어지는 인물 목록이 이름을 밝힌다. 이름 옆에 「그리스식 이름: 제우스」 같은 이름표를 세우는 안은 미착수다.

## 데이터 공백

- 디오니소스의 로마 대응(바쿠스·리베르) 프로필이 없다(26.09.29 확인 — `bacchus`·`liber` slug 없음). 아폴론은 로마도 같은 이름을 써서 대응 행이 없는 것이 맞다.

## 실화면 확인

- 관계망의 기타 갈래를 실제 화면에서 보지 못했다. 탭 셋이 한 줄에 서는지, 기타 탭에서
  거르는 줄이 사라졌는지, 갈래 이름표가 「대응 신격」으로 뜨는지 확인한다.
  진입 경로는 `/celeb/jupiter` 관계망이다.
