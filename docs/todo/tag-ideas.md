# 태그 아이디어 후보

> **최종 실측 체크: 26.07.16** — 실 DB로 `celeb_tags` 전량(40행)·배정 인원·`profiles` 직군 분포 대조. 기준선(13개 태그·1,086명)이 낡아 전면 교정하고, 이미 등록된 후보 6종을 소진 표시. 후보의 기획적 타당성(콘셉트·색상·매력)은 판단 사항이라 손대지 않았다.

작성 당시 DB 1,086명 / 태그 13개 기준으로 뽑은 후보 풀이다. **기준선은 아래 "현재 태그 현황"으로 갱신됐다.** 후보 본문(A~D)은 백로그로 유지하되, 이미 등록된 것은 소진 표시했다.

**옛 기준선과의 차이**:
- `AI의 지도를 그리다`(`mapping-ai`) **삭제됨**. AI 계열은 「AI」그룹 + 자식 11종으로 대체됐고, 인물사 태그는 `AI 선구자들`(14명)이다.
- `워커홀릭`·`코펜하겐 학파` 부재(현 DB에 없음).
- 계획서에 없던 태그가 다수 신설: 삼국지·초한지·빈의 세기말·잃어버린 세대·브리티시 인베이전.
