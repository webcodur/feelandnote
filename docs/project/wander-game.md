# 유랑 게임 개발 규격

> **최종 실측 체크: 26.07.30** — 본서비스 코드·쉼터 진입·인물 조회·게임 엔진 대조


유랑은 추방된 가상 주인공이 한 시대를 여행하며 실제 역사 인물들과 인연을 맺고, 고향을 장악한 가상의 섭정을 끌어내리는 짧은 선택형 게임이다.

## 핵심 원칙

- 여행 자체가 목적이 아니다. 최종 목표는 **고향 탈환**이다.
- 플레이어와 섭정은 허구다. 실제 인물을 악역이나 찬탈자로 만들지 않는다.
- 실제 인물은 전우·참모·후원자로만 등장한다.
- 무작위는 만남의 순서만 바꾼다. 최종 승패는 플레이어가 모은 힘과 귀환 방식으로 확정한다.
- 한 판은 시대 선택, 여덟 번의 만남, 귀환 작전, 결산까지 10분 안팎을 목표로 한다.

## 완주 흐름

1. 고대·중세·근세·혁명의 시대·현대 중 하나를 고른다.
2. 선택 시대에 실제로 생존 기간이 겹치는 인물 여덟 명을 만난다.
3. 각 사건에서 군세·책략·민심 중 한 방향으로 관계를 맺는다. 행동명은 사건마다 달라진다.
4. 인물의 강점에 따라 7~17을 얻고, 사건에 맞는 접근이면 4를 더 얻는다. 대신 다른 힘 하나가 2 줄어든다.
5. 여행 중에는 현재 가장 강한 귀환 방식과 예상 결정력을 계속 보여준다.
6. 여덟 만남 뒤 봉기·폭로·민중 중 하나의 귀환 방식을 고르고, 별도 확인을 거쳐 작전을 시작한다.
7. 주력 힘, 나머지 두 힘의 25%, 인연 보너스를 합친 결정력이 85 이상이면 고향을 되찾는다.

## 사건

여덟 만남에는 닫힌 국경, 비밀 살롱, 불타는 기록관, 시장 광장의 소요, 폭풍 속의 항구, 광장의 재판, 한밤의 추격, 마지막 연회가 차례로 배치된다. 각 사건은 세 행동명을 따로 가지며 군세·책략·민심 중 하나에 유리한 보너스를 준다. 선택 전에는 정확한 증가량 대신 인물의 적합도·사건 유리 여부·잃는 힘을 보여주고, 선택 후 실제 증감을 공개한다. 사건은 역사적 사실을 날조하지 않는 가상 상황이며, 실제 인물의 이름·시대·초상·검수된 인용문만 서비스 데이터에서 가져온다.

## 인물 데이터

| 원천 | 사용 값 |
|---|---|
| `profiles` | 이름, 영문 이름, 수식어, 국적, 초상, 생몰년 |
| `celeb_influence` | 시대 안에서 우선 만날 인물의 정렬 |
| `celeb_persona` | 군세(command+martial), 책략(intellect), 민심(charm) |
| `celeb_dialogues` | 한국어·영어 인용문 |

PostgREST 1,000행 상한을 피하기 위해 `selectAllPages`를 쓰고, 선택된 인물의 대사는 `selectInChunks`로 나눠 받는다. 시대별 후보는 영향력 순으로 정렬한 뒤 지역을 번갈아 뽑아 특정 문화권에 쏠리지 않게 한다.

## 시대 판정

인물의 생존 기간이 시대 구간과 하루라도 겹치면 후보가 된다.

| 시대 | 범위 |
|---|---:|
| 고대 | 기원전 3000년~500년 |
| 중세 | 501~1499년 |
| 근세 | 1500~1788년 |
| 혁명의 시대 | 1789~1913년 |
| 현대 | 1914년~현재 |

## 코드 경로

| 구분 | 경로 |
|---|---|
| 게임 규칙 | `sw/web/src/lib/game/wander/` |
| 인물 조회 | `sw/web/src/actions/game/wander.ts` |
| 화면 | `sw/web/src/components/features/game/wander/` |
| 쉼터 등록 | `sw/web/src/components/features/rest/RestGameGrid.tsx` |
| 서버 진입 | `sw/web/src/app/[locale]/(main)/rest/page.tsx` |
| 문구 | `sw/web/messages/{ko,en}/rest.json` |

전용 페이지는 만들지 않는다. `/rest#wander` 앵커로 진입한다.

## 현재 검증 상태

- 웹 전체 TypeScript 검사 통과
- 유랑 변경 범위 ESLint와 `git diff --check` 통과
- 한국어·영어 유랑 문구 각 130키 일치, 사건별 행동명 24개 누락 없음
- 순수 엔진 임시 컴파일과 8회 완주 실행 통과: 사건 유리 보너스 +4, 집중 성장 최고 결정력 151, 균형 성장 최고 결정력 88, 인연 8명 확인
- 전체 프로덕션 빌드 통과: 129개 화면 생성, `/[locale]/rest` 동적 화면 포함
- 독립 UX 회귀 검수 통과: 반복 선택·자명한 최적해·여행 중 예측·모바일 초상·귀환 오조작·결말 개인화 6개 항목 모두 PASS, 신규 심각 결함 없음

로컬 프로덕션 서버는 시작됐으나 현재 셸에 Supabase 공개 URL·키가 없어 미들웨어가 500을 반환했다. 따라서 실 DB 후보 수와 브라우저 시각 검수는 환경변수가 있는 실행 환경에서 한 번 더 확인한다. 빌드·타입·순수 완주 흐름은 위와 같이 확인됐다.
