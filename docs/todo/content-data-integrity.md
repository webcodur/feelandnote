## 전체 BOOK 미확인 검수

결론: 기존 작업의 확인 범위를 대조하고 남은 미확인 항목을 끝낸다. 실제 근거와 현재 데이터가 일치하는 확정 교정은 유지한다. 기계 대조·소개 보완·작품 귀속 확인을 종합 선정 완료로 확대하지 않는다. 완료 흔적이 없거나 현재 데이터와 충돌하는 항목에만 추가 조사한다.

## 하나의 작업순서

**전체 등록분 확보 → 작품별 검수 묶음 구성 → 묶음의 근거 수집 → LLM이 최종 작품·판본·연결을 함께 확정 → 확정 변경 반영·검증 → 다음 묶음 → 전체 대조 → 신규 등록 경로 교정·TEMP 폐기**

1. **전체 등록분을 확보한다.** 같은 시점의 BOOK·언어 카드·판본·상품·인물 관계·감상·직군·세력 연결과 이용 기록 참조를 DB에서 읽는다. 전체 원본 ID가 이후 어떤 최종 작품·판본으로 남거나 통합·제외됐는지 대조할 수 있게 세션에서 유지한다.
2. **검수 묶음을 만든다.** 작품마다 모든 언어 카드·판본·연결을 붙이고, 같은 원전·ISBN·시리즈가 의심되는 작품은 한 묶음으로 올린다. 기계는 묶음 후보와 모순을 찾고, LLM이 실제 같은 저작인지 결정한다. 모든 원본 작품은 검수 묶음에 포함한다. 책장 노출이 있으면서 귀속·중복 의심인 묶음을 먼저 처리하고, 이후 나머지 노출작과 비노출작까지 순회한다.
3. **한 묶음의 근거를 한 번 수집한다.** DB의 기존 출처·검수 내용을 먼저 읽고 부족한 ISBN·원전만 조회한다. 출판사 소개·목차·필요한 본문, 원저자·역자·언어·수록 범위, 인물 연결과 상품 정보를 같은 묶음 안에 모은다. HTML과 긴 중복 소개 대신 판단에 필요한 부분만 LLM에 전달하고, 부족하면 해당 출처를 더 읽는다.
4. **LLM이 그 묶음의 최종 상태를 확정한다.** 무엇이 독립 작품인지, 독자에게 안내할 책인지, 어떤 원문·번역을 대표 판본으로 남길지, 어떤 인물 관계가 맞는지 함께 판단한다. 유지할 대표가 정해진 뒤 그 대표의 소개·표지·구매 정보를 완성한다. 원본 행별로 유지·교정·통합·제외와 근거를 정하고, 확인되지 않은 항목은 미확인으로 남긴다. 통합·폐기될 상품에 소개를 먼저 쓰지 않는다. 정상 판정은 [작품·판본 룰북](../project/celeb/celeb-02-05-figure-books.md), 감상 근거는 [콘텐츠 감사](../project/celeb/celeb-02-04-content-audit.md)를 따른다.
5. **확정한 묶음을 반영하고 검증한다.** 기존 CAS·트랜잭션·참조 보존 경로로 실행한다. 저장값·작품 귀속·판본 대표·언어 카드·상품과 이용 기록을 재조회하고, 한영 책장·상세에 전달되는 값과 캐시를 확인한다. 해당 묶음의 판단·반영·검증까지 끝나야 완료로 기록한다. 미확인은 예외로 남기고 다음 묶음의 3번으로 진행한다. 별도로 소개 전수, 판본 전수, 관계 전수를 반복 순회하지 않는다.
6. **전체 원본과 최종 결과를 대조한다.** 첫 조회의 모든 원본 작품·판본에 처리 결과가 있는지 확인한다. 미심사·미확인·반영 실패·검증 실패를 다시 처리한다. 중복 후보 0, 소개 공백 0, `verified=true` 같은 단일 수치는 완료 근거로 쓰지 않는다. 확인된 미번역·실판본 부재는 정상 결손으로 구별한다.
7. **재발 경로를 고치고 작업을 끝낸다.** 기존 검색·대량 등록 경로도 검색 결과를 후보로 받아 같은 작품 심사를 거친 확정분만 책장에 연결하도록 교정한다. 전체 대조와 실제 서비스 경로 검수가 끝나면 이 메모와 작업 중 발생한 TEMP·원장·백업을 폐기한다. 최종 서비스 데이터와 선정 근거는 DB·R2에 남긴다.

## 현재 위치와 비용

현재 전수 대상의 초벌은 끝났고, 17묶음의 작품·판본 통합을 운영 DB에 반영·검증했다. 묶음 전체의 선정·관계·상품 검수와 이후 대상은 남아 있다. 최근 소개를 고친 판본 ID는 `176,399,431,758,1271,5384,6623,6700,7248,8053,8640,9185,30056,37271,37272,37274,37275,37282,37283,37287`다. 이 행의 DB 근거·현재 값을 재사용하되, 소개 교정을 묶음 전체 승인으로 확대하지 않는다. 앞의 기존 미확인 사항도 해당 묶음에 합친다.

전수 초벌에는 중복·시리즈 후보 1,157묶음, 귀속 의심 판본 839건이 남았다. 판본 비교 근거 부족은 KO 12,154 / EN 19,746건이다. 이들은 조사 우선순위를 정하는 신호이며 오류 확정 수가 아니다. 단계별 기록은 전체 분모, 끝낸 묶음·원본 수, 다음 처리 위치, 미확인 예외만 이 메모에 갱신한다. 행별 배정·후보·원장은 세션에서 관리하고 새 DB 상태 테이블·컬럼을 만들지 않는다.

토큰은 **작품 묶음당 한 번의 근거 수집·판단·반영**으로 줄인다. 인물마다 같은 책을 재조사하지 않고, ISBN·원전·출처 응답은 세션에서 공유한다. 기존 검수는 근거가 현재 정체성·판본 범위와 맞는 항목에만 재사용한다. 초벌 신호가 없는 작품도 확인 범위를 대조하며, 근거 없이 정상으로 간주하지 않는다. 기존 LLM 판단의 근거·대상·현재 값이 일치하는 항목은 재조사하지 않고 미확인 부분을 이어서 처리한다.

3번의 API는 한국어 자료 조사에 `KAKAO_RESEARCH_REST_API_KEY`, 영어 메타에 키 없는 OpenLibrary, YES24 조사에 `YES24_AUDIT_API_KEY`(ykj5598) → 일일 소진 확인 시 `YES24_AUDIT_SECONDARY_API_KEY`(webcodur)를 쓴다. 운영 whdmstnv 키는 연구 호출과 분리한다. 10-11 초기화 뒤 ykj5598 조사 키의 정상 응답과 잔량 19,999를 확인해 다시 사용 중이다. 소개 원문은 출판사·공개 원문 우선이며 Google Books는 무료 소개 수집 허용 범위에만 쓴다. 신규 메타와 번역은 [외부 서비스](../project/platform/platform-05-external-services.md)·[소개 출처](../project/celeb/celeb-02-06-content-introduction-sources.md)의 기존 계약을 따른다. 최종 판단은 현재 LLM이 수행한다.
