# 세력도감 영상 중단

새 세력도감 영상을 만들지 않고 세력은 웹 세력도감에만 게시한다. 이 문서는 웹을 영상층에서 떼어 내는 순서와, 떼어 낸 영상층을 걷을지의 판단만 적는다. 운영 화면은 [`web-bo.md`](../project/apps/web-bo.md) 「세력도감」, 현재 데이터 경계는 [`unification.md`](../project/remotion/faction/unification.md) §4-3이 쥔다.

## 정해진 것 (26.09.11)

- 새 영상·음성·유튜브 업로드를 만들지 않는다.
- 새 세력은 web-bo 테마 편집 화면(`/factions/<태그 id 또는 slug>`)에서 만든다. 이름·설명·색·노출, 인물 검색 추가·정렬·소개문, 단체화보·개인화보·숨김이 이미 된다.
- **웹과 영상층을 구분한다.** 웹 세력도감의 원천은 웹 전용 배정(`celeb_tag_assignments`) 하나로 둔다. 대사 자막 덩어리·음성 설정·음성 길이·컷 효과·장면 구성·어록 후보 같은 영상 제작 데이터는 웹으로 가져오지 않는다.
- 이미 올라간 유튜브 영상·테마 음악 링크는 `celeb_tags`에 남아 웹에 계속 뜬다.
- **웹 세력도감도 단체샷 없이 간다(V1).** 세력 화면은 단체화보를 띄우지 않는다. 묶음·세력은 구성원 아바타를 한 무대에 세운 출연진 판으로 보이고, 묶음도 세력도 없는 테마는 맨 앞에 테마 전체 출연진 판을 세운다. 규칙은 [`celeb-08-00-image-map.md`](../project/celeb/celeb-08-00-image-map.md)가 쥔다.

## 할 일 — 웹 V1 남은 화면

1. **세력도감 모음 화면**(`/explore/faction`) — 테마 카드와 대문 표지가 아직 단체화보다. 단체화보가 없는 테마의 구성원 격자(`FactionIntroView/sections/ThemeVisual.tsx`)와 함께 출연진 판 방식으로 통일한다.
2. **탐색 허브 세력 카드** — 단체화보가 있는 테마를 우선 뽑아 표지로 쓴다(`getFactionHubPreviews`). 표지 우선 규칙을 걷고 출연진 판 표지로 바꾼다.
3. **단체화보 묶음을 그룹 표로 흡수** — 세력 화면은 세력이 둘 이상인 테마를 세력으로 묶고, 단체 사진 묶음(`celeb_tags.team_images`의 이름·구성원)은 세력이 하나뿐인 테마(앤트로픽·오픈AI 등)에서만 쓴다. 이 묶음도 `celeb_tag_groups`로 옮기면 웹 그룹 원천이 하나가 되고 사진 칸은 쓸모가 없어진다.
4. **새 인물 누끼 보장** — 출연진 판은 아바타가 배경을 지운 누끼라는 전제에 선다. 배경 제거는 아바타 업로드 때 자동으로 붙지 않고 web-bo 인물 화면의 개별·일괄 nobg 버튼으로 따로 돈다. 테마 편집 화면 명단에 「배경 미제거」 표시와 기존 nobg 대기열로 보내는 일괄 버튼을 붙인다. 이것까지 되면 새 세력은 올리기만 하면 판이 완성된다.

## 지금 구조

웹 세력도감은 뷰 `faction_atlas_members`를 읽는다. 이 뷰가 영상 제작 테이블(`faction_people`·`faction_clusters`·`faction_groups`)과 웹 전용 배정을 합친다(`sw/web/database/migrations/20260803203600_secure_faction_atlas_public_view.sql`). 영상으로 만든 세력은 웹에 뜨는 문구·화보·대사까지 제작 테이블에 산다. 셀럽 공개 정책 세 개도 이 뷰를 보고, 비활성 셀럽이라도 뷰에 있으면 공개한다(`20260809182248_complete_profile_domain_runtime_contract.sql`). 그래서 영상층을 동결하든 걷든 웹부터 떼어 낸다.

## 할 일 — 웹 원천 분리 (먼저)

0. **정했고 만들었다(26.09.11, 신화 탐색 작업 경유 사용자 승인)** — 웹 그룹 표 `celeb_tag_groups`(테마·이름·영문 이름·순서)와 배정의 `group_id`·`quote_media`(대사 음성) 칸. 세력 색·로고·부제는 옮기지 않는다. 표·뷰 수정·이관 스크립트는 신화 탐색 작업이 맡는다. 그룹 이름(뷰의 `group_label`)은 세력 화면의 세력 머리글과 `/explore` 신화 탐색의 그룹 줄이 함께 읽는다.
1. **테마 단위 이관** — 테마 slug를 받는 스크립트 하나로 한다(기본은 모의 실행). 제작 행에서 웹이 지금 보여 주는 값을 뷰 계산 결과 그대로 배정으로 옮기고(한줄·상세 ko/en·대사·개인화보·음성·숨김·순서), 세력을 그룹 표 시작값으로 복사한 뒤 그 테마의 `faction_groups.tag_id`를 끊는다. 끊으면 뷰의 제작 갈래가 그 테마에서 빠지고 배정이 이어받는다. 제작 행을 `web_hidden`으로 가리는 방식은 쓰지 않는다 — 뷰는 같은 테마·인물의 제작 행이 있으면 숨김과 무관하게 배정을 버린다. 먼저 homer-odyssey·homer-iliad·greek-roman-myth, 나머지 테마도 같은 스크립트로 옮긴다.
   - 표·칸·뷰: `sw/web/database/migrations/20260911170000_add_celeb_tag_groups.sql` — 운영 DB에 적용했다(26.09.11).
   - 옮긴 테마: homer-iliad·greek-roman-myth·homer-odyssey(26.09.11). 세 테마는 이관 뒤 「그 외」 인원까지 넣어 그룹을 8개씩 다시 짰다. 이 세 번의 `--apply`는 백업 파싱 버그로 이관 전 명단이 남지 않았고, 되돌리기 대응(끊은 세력 id)만 커밋 직후 DB에서 복원해 `data/celeb/_backup/faction-web-roster/three-traditions-2026-09-11-cut-groups.json`에 두었다. 버그는 고쳤다(백업을 한 줄 jsonb로 뽑고, 파싱이 깨져도 원문을 남긴다).
   - 이관: `cd sw/web-bo && node --env-file=.env scripts/faction/move-tag-roster-to-web.mjs --tag <slug> [--apply]`. 기본은 모의 실행(롤백)이다. 이관 전후 인원·순서·문구·화보·음성·그룹이 어긋나면 트랜잭션째 롤백한다. `--apply`면 되돌리기용 대응(끊은 세력→테마)과 이관 전 명단을 `data/celeb/_backup/faction-web-roster/<slug>-<시각>.json`에 남긴다.
2. **대조** — 이관 전후로 태그별 명단·순서·문구·화보·음성이 같은지 본다.
3. **뷰** — 배정 갈래가 그룹·음성을 새 칸에서 읽게 한다(신화 탐색 작업). 모든 테마를 옮긴 뒤 제작 갈래를 뗀다. 셀럽 공개 정책은 뷰를 그대로 보므로 이관이 끝났으면 영향이 없다.
4. **편집 경로 정리** — 영상 편집기의 「출간」이 웹 칸에 쓰지 않게 막고, 테마 편집기의 제작/수동 출처 구분을 걷는다.
5. **대사 편집** — 테마 편집기에 수동 행 대사(ko/en) 편집을 붙인다. 이관된 대사를 고칠 곳이 이것뿐이다.

## 정할 것 — 떼어 낸 영상층을 걷을지

분리가 끝나면 영상층은 웹과 무관하다. 영상층은 Remotion 세력도감·카드 컴포지션, 음성·자막·렌더·유튜브 스크립트, web-bo 편 편집기·출간·로컬 자산 창구, shared 영상 모듈, 영상 전용 스킬, 제작 5테이블이다. 코드만 300여 파일이다(26.09.11 조사).

| 안 | 비용 | 결과 |
|---|---|---|
| 동결 | 없다. 되돌리기 쉽다 | 코드·문서·스킬이 남아 유지 부담과 오독 여지가 계속된다 |
| 철거 | 중간. 웹 영향 없는 순수 삭제다 | 저장소에서 영상층이 사라진다 |

추천: 분리까지 하고 영상층은 동결한다. 다시 만들 일이 없다고 확정되면 철거한다.

## 철거 순서 (결정 뒤)

1. **헬퍼 이전** — 다른 기능이 쓰는 헬퍼를 영상 폴더 밖으로 옮긴다(web-bo 목록 표·곡 폴더 상수·보이스 캐스팅 기록·자산 열쇠·작업 패널). 테마 편집기를 편 목록에서 떼어 낸다. shared에서는 `faction-team-image`·`faction-quote-media`만 남긴다.
2. **코드 제거** — Remotion 컴포지션·스크립트·테스트, web-bo 편집기·액션·창구·스크립트, shared 영상 모듈, package.json 스크립트, 영상 전용 스킬을 지운다. `faction-celeb-sync`·`faction-image`는 웹 게시용으로 고쳐 남긴다.
3. **DB** — 제작 테이블에 걸린 트리거·RPC·웹 재검증 트리거를 걷고 5테이블을 지운다.
4. **자산·기록** — 유튜브 업로드 기록(`sw/remotion/scripts/youtube/faction-lineup.json`)과 로컬 자산 `sw/remotion/public/factions/`(git 밖)는 지우기 전에 백업한다.
5. **문서** — `docs/project/remotion/faction/`을 지우고 남는 규칙은 `web-bo.md` 「세력도감」으로 흡수한다. 옛 경로 참조가 0건인지 확인한다.
