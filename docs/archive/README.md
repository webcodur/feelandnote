# 아카이브

완료된 일회성 문서와 폐기된 기획을 보관한다. **현역 규칙이 아니며 작업 기준으로 사용하지 않는다.**

여기 있는 서술은 작성 당시 상태다. 현재 코드·데이터와 일치한다고 가정하지 않는다.

## 영역

| 경로 | 보관 범위 |
|---|---|
| [`data/`](data/README.md) | DB 구조·locale 수집·프로필 분리 이력 |
| [`service/`](service/README.md) | 사용자 화면·용어 개편 이력 |
| [`celeb/`](celeb/README.md) | 인물 데이터·이미지·가상 독백 회차 |
| [`remotion/`](remotion/README.md) | 영상 제작 앱·시리즈·이미지·음성 이력 |

## 별도 보존 묶음

| 경로 | 성격 |
|---|---|
| [`db-dumps/`](db-dumps/README.md) | 삭제한 DB 테이블 원본 덤프 |
| `backup/` | 외부 에이전트 스킬 통합 당시의 비정본 백업 자료 |

## 아카이브 기준

- **완료 보고서·회차 스냅샷·1회성 실행 지시서** → 작업 종료 시 이곳의 담당 영역으로 옮긴다.
- **현역 규격·규칙 문서** → 이곳에 두지 않고 `docs/project/` 또는 `docs/games/`에 둔다.
- **다음 작업이 남은 문서** → `docs/todo/`에 둔다.
- 문서를 이동하면 담당 영역 README와 직접 참조하는 스킬·코드 주석의 경로를 함께 갱신한다.
