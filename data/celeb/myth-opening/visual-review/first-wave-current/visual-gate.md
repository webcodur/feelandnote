# 콘텐츠 1차 GO 전승 5종 시각 게이트

2026-09-23 현재 등록 표지 5장, 아바타 시트 5종(아트레우스는 2장), 한영 화면 10장을 직접 열어 대조했다. 초기 캡처와 이후 교체된 캡처는 정리했다. 남긴 비교 화면은 `../../screen-check/`, `live-screen-check-postdb/`, `live-screen-check-settled/`에 있다. **10개 모두 HTTP 200·깨진 이미지 0·브라우저 JS 오류 0**이었다. 중단된 요청은 음악·경로 미리 읽기였고 이미지 실패는 아니었다.

| 전승 | 저장 화면과 등록 이미지 판정 | 현재 공개 판정 |
|---|---|---|
| 고조선 `myth-korea-gojoseon` | 표지·아바타·한영 패널과 《삼국유사》 카드의 5명 연결이 나온다. 웅녀가 단군보다 지나치게 어려 보이고 표지가 건국 사건보다 정적 인물 화보에 가깝다. 기존 영문 캡처에서 흐렸던 책 표지는 CSS의 500ms 흐림 해제 전환 중 찍힌 것이며, 정착 후 정상 표지로 확인했다. | 표시 가능. 연령 표현 권고와 도서·안내문 검수는 별도. |
| 아르고 원정대 `argonauts` | 이아손의 양털을 향한 동작과 메데이아·용의 위치가 읽힌다. 주요 얼굴을 패널이 가리지 않고, 33명 아바타 시트와 현재 한영 명단의 크롭이 안정적이다. | 현재 화면 기준 시각 통과. 전체 도서 관계는 별도 검증 필요. |
| 아서왕과 원탁의 기사들 `arthur-round-table` | 아서·멀린·랜슬롯과 원탁 일부가 보인다. 현재 한국어 제목은 실제로 `아서왕과 / 원탁의 기사들` 두 줄이며 마지막 글자 고립은 없다. 25명 아바타 시트와 한영 배치가 안정적이고, 영문 화면의 《The Legends of King Arthur and His Knights》 카드에는 `Untranslated`가 표시된다. | 현재 화면 기준 시각 통과. |
| 아트레우스 가문 `house-of-atreus` | 대면·문턱 구도, 한영 텍스트 패널, 41명 아바타 크롭이 현재 화면에 표시된다. 다만 표지만으로 특정 사건이나 인물 관계를 알아보긴 어렵다. 기존 승인 표지는 유지한다. | 표시 가능. 서사 식별력은 약하다. |
| 서유기 `myth-china-xiyou` | 손오공과 일행의 진행 방향이 일치하고 주요 얼굴이 패널 밖에 남는다. 28명 아바타 시트와 한영 명단이 표시된다. 영문 카드에서 《Journey to the West》·《Living Korean Myths》는 `Untranslated` 표시가 눈에 보인다. 《Creation of the Gods》 표지는 흐림 전환 완료 후 정상적으로 선명해진다. | 현재 화면 기준 시각 통과. |

등록 표지 파일은 모두 `faction_lv2.team_images[0].url`에 있으며 `getMythData.ts` 연결도 확인했다. 이 검수는 아바타의 독립 신원 출처와 도서 본문 등장 관계의 전수 검증을 대신하지 않는다. 다섯 전승 모두 현재 `published=false`다. 따라서 **콘텐츠 GO를 곧바로 전체 공개 GO로 올릴 근거는 아직 없다.**

공유 작품 《Metamorphoses》의 잘못된 영어판 서지를 정리한 뒤 [아르고 영문 화면](live-screen-check-postdb/en-argonauts.png)과 [아트레우스 영문 화면의 펼친 작품 목록](live-screen-check-postdb/en-house-of-atreus-ovid-visible.png)도 다시 열었다. 두 카드 모두 한국어 표지 위에 `Untranslated`가 보이고, `118 figures linked to the full work`는 작품 관계 수로 따로 표시된다. 영어판 ISBN이 있는 듯한 표시나 깨진 이미지는 없었다.
아트레우스 영문 화면을 빠르게 캡처한 한 번은 Next 개발 오버레이의 `1 Issue` 배지가 보였다. 별도 재접속에서는 콘솔 warning/error와 `pageerror`가 없었고 카드·이미지는 정상이었다. 개발 오버레이의 원인은 이 검수에서 특정하지 못했다.
