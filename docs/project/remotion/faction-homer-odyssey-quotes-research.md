# 호메로스-오디세이아 — 어록 조사 자료

> 2026-07-10 착수. 팩션 「호메로스-오디세이아」(Homer-Odyssey) 출연 26인의 대사화용 어록 조사.
> **진행 상태: 조사 설계 완료, 본 채굴 미완.** 병렬 채굴 에이전트 8기를 발주했으나 세션 한도로 전원 착수 직후 중단(2026-07-10 16:30, 한도 리셋 17:50). 리셋 후 아래 발주 설계를 그대로 재사용해 재발주한다.
> 이 인물들은 실존이 아니므로 어록 출처는 인터뷰·기사가 아니라 **『오디세이아』 원전 본문**이다. 권.행 번호(Murray/Loeb 표준 행수) + 원문 링크를 붙인다.

## 표기 규격

```
- "한국어 대사" — Od. <권>.<행-행> ([원문](링크)) — _주제태그_ (한 줄 맥락)
```

- 링크 소스(권 단위, 안정적): Wikisource Butler 영역 `https://en.wikisource.org/wiki/The_Odyssey_(Butler)/Book_IX` (로마 숫자) 또는 Perseus Murray 영역 `https://www.perseus.tufts.edu/hopper/text?doc=Perseus%3Atext%3A1999.01.0136`
- 행 번호 불확실 시 `[행 미확정]` 표기. 창작·짜깁기 절대 금지.
- 직접 발화가 없는 존재(스킬라·카리브디스·로토스파고스족 등)는 "직접 대사 없음"을 명시하고 원전 묘사 구절을 `[서술]` 표기로 대체 수집.
- 9~12권 전체는 오디세우스가 파이아케스 궁정에서 1인칭으로 회고하는 본인 발화로 취급.

## 인물별 발화 지점 지도 (사전 조사 확정분)

재발주 시 각 에이전트 프롬프트에 그대로 복붙하는 탐색 좌표다.

### 이타카 왕가
- **오디세우스**: 전권 주인공. 9~12권은 전체가 본인 회고 발화. 우선 채굴 주제: 귀향 의지, 정체성 선언("나는 오디세우스다" 9권 서두), 책략(우티스/노바디 9권), 인내("참아라, 마음이여" 20.18-21), 복수 선언, 칼립소의 영생 제안 거절(5권).
- **페넬로페**: 1권(가인 페미오스 제지), 4권(아들 걱정), 17~19권(거지 오디세우스와의 대화, 19권 베 짜기 고백), 18권(구혼자 질타), 21권(활 시합 선언), 23권(재회·침대 시험).
- **텔레마코스**: 1권(구혼자들에 맞선 첫 발언), 2권(민회 연설), 3·4권(네스토르·메넬라오스 방문), 15~17권(귀환), 18~24권(복수 동참).

### 선원·하인
- **에우릴로코스**: 10권(키르케 궁 정찰 보고·재진입 거부), 12권(트리나키아 상륙 강요, 태양신 소 도살 선동 "굶어 죽는 것이 가장 비참한 죽음" — 백미).
- **폴리테스**: 10.226-228 부근 1회("안에서 누가 아름답게 노래한다") — 사실상 유일한 발화.
- **엘페노르**: 11.60-78 장례 간청("울지 않고 묻지 않은 채 떠나지 마시오, 노를 무덤에 꽂아 주시오").
- **에우마이오스**: 14권(거지 환대 "손님은 제우스가 보낸다", 주인 그리움), 15권(자기 출생 내력), 16·17권(구혼자 비판). 발화 풍부.
- **에우뤼클레이아**: 1권(배웅), 2권(항해 만류·비밀 맹세), 4권(페넬로페에게 고백), 19권(흉터 발견 — 백미), 22권(환호 제지당함), 23권(귀환 보고).

### 장애물 진영
- **폴리페모스**: 9권 단일. 심문, "노바디가 나를 죽인다" 절규, 눈먼 뒤 숫양 독백(백미), 포세이돈 저주 기도(9.528-535).
- **스킬라/카리브디스**: 직접 발화 없음. 키르케의 경고 묘사(스킬라 12.85-100, 카리브디스 12.101-110 부근), 오디세우스 목격 회고(12.234-243, 2차 조우 12.426-446)를 [서술]로.
- **라이스트뤼고네스**: 10권. 왕 안티파테스 일가 등장하나 직접 인용 유무는 원문 확인 필요. 학살 장면 10.116-124 부근.
- **키르케**: 10권(변신 마법·대면·저승행 안내), 12권(세이렌·스킬라·카리브디스·태양신 소 항로 경고 — 발화 풍부).
- **세이렌**: 12.184-191 노래가 유일 발화("이리 오라... 우리는 모든 것을 안다").
- **칼립소**: 5권 단일 장면(헤르메스에게 "신들은 질투가 심하다" 항의, "나는 페넬로페보다 못하지 않다", 방면·작별).
- **로토스파고스족**: 9권. 직접 발화 없음 추정 — 원문 확인 후 [서술] 대체.

### 초월자·구원자
- **아테나**: 1권(올림포스 회의·멘테스 변장), 2·3권(멘토르 변장), 5권(재청원), 6권(나우시카아 꿈), 13권(정체 공개 대화, "우리 둘 다 책략에 능하다" — 백미), 15·16·20·22·24권. 변장(멘테스·멘토르) 발언도 채택하되 변장 표기.
- **포세이돈**: 5권(오디세우스 발견·폭풍 독백), 13권(파이아케스 응징 논의). 발화 적음.
- **제우스**: 1.32-34("인간은 제 허물로 파멸하면서 신을 탓한다" — 백미), 5권(헤르메스 파견 명령), 12권(헬리오스 응답), 13권(포세이돈에게), 24권(평화 재가).
- **헤르메스**: 5권(칼립소에게 명 전달), 10권(몰리 약초 조언), 24권(영혼 인도 — 발화 확인 필요).
- **테이레시아스**: 11권 예언 단일(태양신 소 금기, "홀로, 늦게, 남의 배로" 귀향 조건, 노 들고 내륙행 후일 예언, 바다에서 오지 않는 온화한 죽음).
- **나우시카아**: 6권(구조 "그대는 악한 사람으로 보이지 않는다", 시녀 질책, 궁전 안내, 평판 걱정), 8.461-462(작별 "나를 잊지 마세요, 그대는 내게 목숨을 빚졌으니" — 백미).
- **알키노오스**: 7권(환대·사위 제안), 8권(경기·선물), 11.363-376("그대의 이야기는 가인의 노래 같다" — 백미), 13권(귀향선 명령).

## 재발주 방법

- 8기 분할: ①오디세우스 ②아테나 ③텔레마코스+페넬로페 ④제우스·포세이돈·헤르메스·테이레시아스 ⑤키르케·칼립소·세이렌·로토스파고스족 ⑥폴리페모스·스킬라·카리브디스·라이스트뤼고네스 ⑦선원 3인+하인 2인 ⑧나우시카아·알키노오스·구혼자 2인·멜란티오스
