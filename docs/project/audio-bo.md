# Audio BO

유튜브 인터뷰의 일부를 가져와 잡음을 줄이고, 받아쓰기·화자 학습·음성 합성까지 수행하는 로컬 작업실이다. 코드만 저장소에 두며 음원, 학습 자료, 모델과 결과물은 모두 D드라이브에 둔다.

음성 생성 품질 조사와 대체 엔진 결정은 [Audio BO 음성 생성 엔진 조사](./audio-bo-tts-engine-research.md)를 참조한다. 현재 GPT-SoVITS는 실험용으로만 유지하며, 다음 비교 대상은 Fun-CosyVoice 3이다. 동일한 한국어 시험을 통과하지 못하면 ElevenLabs Eleven v3로 전환한다.

## 실행

```bash

```

- 화면: `http://localhost:3005`
- 작업 자료: `D:\audios\interview-cleaner\projects\<작업 번호>`
- 음성 학습 도구: `D:\GPT-SoVITS\GPT-SoVITS-v2pro-20250604`

## 네 가지 작업 단계

화면은 서로 목적이 다른 네 단계로 나뉜다.

네 단계는 헤더 바로 아래에 항상 표시한다. `영상 선택`에서만 새 영상 등록과 저장된 작업 보관함을 보여준다. 작업을 고른 뒤의 세 단계에서는 보관함과 별도 상태판을 숨기고, 현재 작업·실행 상태·영상 변경 버튼만 한 줄로 표시해 본문 전체 폭을 편집에 사용한다. 전체 흐름은 임의의 백분율로 환산하지 않고 `3/4단계 · 목소리 학습 완료`처럼 완료한 단계와 이름으로 표시한다.

`영상 선택`의 `저장된 작업`은 `D:\audios\interview-cleaner\projects` 아래의 작업 폴더를 읽어 만든 보관함이다. 이름·저장 이름·작업 번호로 검색하고 하나를 눌러 불러올 수 있다. `폴더 열기`를 누르면 해당 D드라이브 폴더를 Windows 탐색기로 연다.

1. **영상 선택**: 새 영상 등록, D드라이브로 가져오기, 기존 작업 불러오기
2. **구간 편집**: 발화 구간 선택, 받아쓰기, 화자 A·B·겹침 구분
3. **목소리 학습**: 받아쓰기 결과 교정, 해당 화자의 목소리 학습
4. **새 음성 만들기**: 새로 읽힐 문장 입력, 기본·학습·성우형 결과 비교

학습용 대본과 새로 읽힐 문장은 별도로 저장한다. 새 음성 문장을 바꿔도 학습용 대본과 이미 만든 목소리 모델은 변하지 않는다.

## 사용 순서

1. 작업 이름, 유튜브 주소와 영문 저장 이름을 입력한다.
2. `영상 가져오기`로 최대 720p 영상을 MP4와 WAV로 D드라이브에 저장한다.
3. 음성 파형 위를 좌우로 드래그해 사용할 발화 구간을 만든다. 한 문장씩 3~10초로 골라도 되고, 같은 사람이 이어 말하는 부분을 약 1분간 넓게 골라도 된다. 10초가 넘는 선택은 받아쓰기할 때 말이 끊기는 지점을 기준으로 자동 분리된다. 시작점·끝점 버튼은 보조 방식으로 사용할 수 있다.
   - 긴 영상은 기본 60초 파형으로 확대된다.
   - 30초·60초·120초·전체 보기를 선택하고 이전·다음 또는 현재 재생 위치로 이동할 수 있다.
4. 편집기 상단의 `선택 구간 받아쓰기`를 누르고 각 구간을 화자 A, 화자 B 또는 겹친 음성으로 확인한다. 선택 구간이 없으면 버튼이 `전체 받아쓰기 후 구간 자동 생성`으로 표시된다.
5. 학습할 화자를 고른 뒤 3~10초 발화 구간을 최소 3개 선택하고 저장한다.
6. `목소리 학습`으로 선택한 한 사람의 목소리 모델을 만든다.
7. `새 음성 만들기` 모드로 이동해 실제로 읽힐 문장을 별도 칸에 입력한다.
8. 문장을 저장하고 기본, 학습, 성우형 보정 결과를 만든다.
9. 세 결과를 듣고 자동으로 다시 받아쓴 문장과 원문을 비교한다.

구간·화자·문장을 수정하면 1.2초 뒤 자동 저장된다. 같은 화자의 유효한 3~10초 구간이 3개 이상 준비되어야 다음 단계와 목소리 학습이 활성화된다. 마지막 모드에서는 `저장하고 음성 만들기` 한 번으로 문장 저장과 합성을 연속 실행한다.

목소리 학습 화면에서는 실행 버튼을 먼저 보여주고, 이미 확인한 영상 편집기는 `학습 자료 확인·수정` 안에 접어 둔다. 학습을 누르면 `발언 준비 → 발음 정보 → 음성 특징 → 음색 학습 1/2 → 말투 학습 2/2` 순서가 작업 상태에 표시된다. 화면을 닫아도 학습은 계속되며, 완료된 뒤에만 새 음성 만들기 단계가 활성화된다.

## 보관 구조

```text
<작업 번호>/
  job.json             작업 상태와 파일 위치
  input/source.wav     원본 음원
  input/source.mp4     브라우저 편집용 영상
  output/              잡음 감소본과 합성 결과
  training/            학습용 짧은 음원과 설정
  launcher.log         실행 시작 과정 기록
  worker.log           전체 처리 기록
  worker-error.log     외부 프로그램 오류 기록
```

브라우저를 닫거나 새로고침해도 `job.json`에서 상태를 다시 읽는다. 각 단계는 따로 실행되므로 실패한 단계만 다시 시도할 수 있다. 진행 중에는 다른 단계를 동시에 시작할 수 없다.

새 음성을 만들 때는 파일이 생겼다는 이유만으로 완료 처리하지 않는다. 학습 음성이 비어 있거나 지나치게 짧으면 같은 학습 과정의 이전 저장본을 자동으로 시험하고, 정상적인 말소리가 확인된 결과만 재생 화면에 표시한다. 듣기 보정은 검사를 통과한 학습 음성에만 적용하고 보정 후 다시 확인한다.

음성 생성 전에는 `차분하게`, `단호하게`, `힘차게`, `긴박하게`, `여유 있게`, `부드럽게`, `또렷하게`, `무게감 있게`를 복수 선택할 수 있다. 선택한 느낌은 속도·쉼·강약·선명도를 안전 범위 안에서 겹쳐 적용한다. 이는 감정 연기의 근사 조절이며, 서로 반대되는 선택은 일부 상쇄될 수 있음을 화면에 알린다.

생성 화면 하단의 `이 작업의 결과 파일`에서 현재·이전 생성본을 재생하고 파일명·길이·용량·생성 시각을 확인한다. `결과 폴더 열기`로 윈도우 탐색기를 바로 열 수 있다. 새 생성본은 `output/runs/<생성 시각>/`에 누적 보관하고 문장·말하는 느낌·검사 결과를 함께 기록한다. 새 생성이 실패해도 직전 정상 결과 연결은 유지한다.

## 품질 기준

- 학습에는 한 사람만 말하는 3~9.5초 길이의 완결 문장을 최소 3개 사용한다.
- A와 B가 번갈아 말하면 각 발화를 별도 구간으로 두고 화자 표시만 맞춘다. 음원을 억지로 이어 붙이지 않는다.
- 두 사람이 겹쳐 말하는 구간은 `겹친 음성`으로 표시해 학습에서 제외한다.
- 잡음 감소본이 듣기 편해도 발음이 뭉개질 수 있으므로 학습에는 원본을 사용한다.
- 안내 방송이나 다른 사람 목소리가 겹친 부분은 완전 복원이 어렵다.
- 자동 발음 확인은 누락 여부를 찾는 보조 수단이다. 자연스러움과 감정은 직접 들어서 판단한다.
- 원본과 모든 결과물은 서로 다른 파일로 보관하며 원본을 덮어쓰지 않는다.

## 문제 해결

- 실패하면 해당 작업 폴더의 `worker-error.log`를 먼저 확인한다.
- 한글이 깨지면 작업 실행용 PowerShell 파일의 첫 세 바이트가 `EF BB BF`인지 확인한다.
- 학습이 시작되지 않으면 대본이 문장부호로 끝나는 완결 문장 세 개 이상인지 확인한다.
- 합성 결과에서 문장이 빠지면 대본을 더 짧은 문장으로 나누고 다시 생성한다.
