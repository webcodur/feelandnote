# Feel&Note 문서 지도

저장소 전체 작업 규약은 루트 [`AGENTS.md`](../AGENTS.md)가 쥔다. 제품·데이터·제작의 현역 문서는 [`project/`](project/README.md), 게임 문서는 [`games/`](games/README.md)에서 시작한다.

## 최상위 구조

| 경로 | 성격 | 사용할 때 |
|---|---|---|
| [`project/`](project/README.md) | 현역 프로젝트 규격 | 앱·서비스 화면·DB·인물·영상·운영·제작 규칙을 확인할 때 |
| [`games/`](games/README.md) | 현역·실험 게임 문서 | 쉼터 게임, 천도, 실험 게임을 작업할 때 |
| [`todo/`](todo/README.md) | 진행 중 과제와 재개 문서 | 미완료 작업의 다음 착수 지점을 찾을 때 |
| [`continuous/`](continuous/README.md) | 지속 과제의 현재 도달점 | 끝나지 않고 인물·회차를 바꾸어 반복하는 작업을 이어갈 때 |
| [`resource/`](resource/README.md) | 비정본 메모와 참고자료 | 프로젝트 규격으로 인용하지 않는 개인·실험 메모를 볼 때 |

데이터는 문서 폴더에 두지 않는다. 인물 원고·선정 목록·제휴 자료는 저장소 최상단 [`data/`](../data/README.md)에 있다.

## 배치 원칙

- 현재 동작과 운영 규칙은 `project/` 또는 `games/`에 둔다.
- DB 반영 전 원고·배치·기계 산출물은 저장소 최상단 `data/` 아래 해당 폴더에 둔다.
- 끝이 있는 미완료 작업은 `todo/`, 대상을 바꾸어 계속 반복하는 작업의 현재 도달점은 `continuous/`에 둔다.
- 개인 메모나 비정본 참고자료는 `resource/`에 두며 현역 규칙의 근거로 쓰지 않는다.
- 문서를 이동하거나 이름을 바꾸면 상위 README, 스킬 문서, 코드 주석의 경로를 함께 갱신한다. 루트 `AGENTS.md`는 최상위 허브나 전역 불변사항이 바뀔 때만 수정한다.
- 규칙·상수·임계값은 코드와 해당 SSoT 한 곳만 쥔다. README에는 경로와 책임만 적는다.
