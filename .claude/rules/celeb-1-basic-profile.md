# 셀럽 기본 정보 생성 룰북

셀럽의 기본 프로필 정보를 생성하는 가이드.

---

## JSON 출력 형식

```json
{
  "nickname": "셀럽 이름 (한국어로 작성, 예: 슬라보예 지젝)",
  "profession": "직군 코드",
  "title": "수식어 (2~8자, 대표작명/호칭/업적 중 하나)",
  "nationality": "국가 코드 (ISO 3166-1 alpha-2, 예: US, KR, GB, JP)",
  "gender": "성별 (남성: true, 여성: false, 불명: null)",
  "birth_date": "출생일 (YYYY-MM-DD 또는 -356 같은 기원전 연도)",
  "death_date": "사망일 (생존시 빈 문자열)",
  "bio": "인물 소개글 (2줄 분량, 한국어)",
  "quotes": "대표 명언 (한 문장)",
  "is_verified": false
}
```

## 직군 코드

| 코드 | 한국어 |
|------|--------|
| `leader` | 지도자 |
| `politician` | 정치인 |
| `commander` | 지휘관 |
| `entrepreneur` | 기업가 |
| `investor` | 투자자 |
| `humanities_scholar` | 인문학자 |
| `social_scientist` | 사회과학자 |
| `scientist` | 과학자 |
| `director` | 감독 |
| `musician` | 음악인 |
| `visual_artist` | 미술인 |
| `author` | 작가 |
| `actor` | 배우 |
| `influencer` | 인플루엔서 |
| `athlete` | 스포츠인 |
| `other` | 기타 |

### 직군 분류 주의사항: leader / commander / politician 구분

**leader(지도자)**: 종교 지도자, 사회운동 지도자만 해당한다.
- 예: 예수, 석가모니, 무함마드, 간디, 마틴 루터 킹

**commander(지휘관)**: 군사적 활동이 높거나 직접 전투에 참여한 인물. 왕·황제라도 칼을 잡았으면 지휘관이다.
- 예: 알렉산더 대왕, 칭기즈 칸, 나폴레옹, 이순신, 광개토대왕, 이성계

**politician(정치인)**: 정치 권력을 행사했으나 군사적 활동이 없는 인물. 군주·황제·왕비라도 전투 참여가 없으면 정치인이다.
- 예: 예카테리나 2세, 엘리자베스 2세, 메이지 천황, 제임스 매디슨

**판단 순서**: 군사활동 여부를 먼저 확인 → 있으면 commander, 없으면 politician. 종교·사회운동이면 leader.

## 수식어(title) 작성 가이드

- **용도**: 인물 이름 앞에 붙는 짧은 수식어
  - 예: "군주론의 마키아벨리", "철의 여인 마거릿 대처"
- **길이 제한**: 2~8자 이내로 최대한 짧게

### 우선순위 (위에서부터 적용)

1. **대표작**: 작품명 하나
   - 예: '군주론', '자본론', '코스모스'
2. **실제 호칭/별명**: 역사적 통용 호칭
   - 예: '철의 여인', '가왕', '독안룡'
3. **핵심 업적**: 가장 상징적인 것 하나
   - 예: '테슬라 창립자', '지동설'

### 금지

- 긴 설명형 문장
- 나열식 표현
- "~의 아버지/어머니" 같은 뻔한 표현

---

## 성별(gender) 필드 규칙

`gender` 필드는 **boolean** 타입이다.

| 값 | 의미 |
|-----|------|
| `true` | 남성 |
| `false` | 여성 |
| `null` | 알 수 없음 / 해당 없음 (논바이너리, 그룹, 불명) |

### 판단 기준

- **역사적 인물**: 문헌/기록 기반으로 명확히 판단
- **현대 인물**: 공식 프로필 또는 본인 발언 기반
- **불명확한 경우**: null로 설정

---

## 작성 규칙

1. **nickname**: 정확한 풀네임을 한국어로 작성
   - 예: 슬라보예 지젝, 알베르트 아인슈타인

2. **bio**: 100자 이내
   - 주어 없이 출신/직업을 짧게 서술
   - 마침표로 끊은 뒤 주요 업적 이어감

3. **nationality**: ISO 3166-1 alpha-2 국가 코드
   - 현대인이 아닌 경우 현재 해당 지역의 국가 코드로 재구성
   - 예: 알렉산더 대왕 → GR, 공자 → CN
   - 고대 국가로 특정 불가능한 경우 빈 문자열

4. **birth_date / death_date**
   - 정확한 날짜를 알 수 없으면 연도만 작성
   - 기원전은 음수로 표기 (예: -356)

5. **quotes**: 아래 "명언(quotes) 작성 가이드" 참조

6. **문자열 처리**
   - 큰따옴표는 작은따옴표로 대체

7. **is_verified**
   - **항상 false** (공식 인증은 수동 처리)

## 명언(quotes) 작성 가이드

### 출처 기준 (핵심)

명언은 **해당 인물이 본인으로서 직접 한 말**만 허용한다.

| 허용 | 불허 |
|------|------|
| 인터뷰, 연설, 기자회견 발언 | 출연작 캐릭터 대사 |
| 저서, 서한, 조서에서의 문장 | 타인이 해당 인물에 대해 한 말 |
| 공식 SNS에서의 본인 발언 | 작품 속 인물 대사 (소설·영화·드라마) |
| 역사서에 기록된 직접 발언 | 노래 가사 (작사 본인이라도 캐릭터 발화) |

### 금지 패턴

| 패턴 | 예시 | 대응 |
|------|------|------|
| **캐릭터 대사** | 아놀드 슈왈츠제네거 "I'll be back" (터미네이터 대사) | 본인 인터뷰 발언으로 교체 |
| **타인 명언 오귀속** | 벤저민 그레이엄에게 워렌 버핏 명언 등록 | 정확한 출처 확인 후 교체 |
| **중복 귀속** | 동일 명언이 두 인물에게 등록 | 원발화자에게만 유지 |
| **AI 생성 의심** | "연기는 ~이다" 패턴의 범용적 문장 | 검증 가능한 실제 발언으로 교체, 불가 시 빈 문자열 |
| **복수 명언 합본** | `"명언1" / "명언2" / "명언3"` | 가장 상징적인 1문장만 선택 |
| **따옴표 감싸기** | `'명언 내용'` (작은따옴표로 래핑) | 따옴표 없이 본문만 기록 |
| **원문 미번역** | 한문/외국어 원문 그대로 등록 | 한국어로 번역 (원문 병기 금지) |
| **슬로건/구호** | 정치 캠페인 구호, 브랜드 슬로건 | 인물의 신념/철학이 담긴 발언으로 교체 |

### 배우·감독 특별 규칙

배우·감독은 캐릭터 대사와 본인 발언의 혼동이 가장 잦은 직군이다.

- **허용**: 인터뷰, 수상 소감, 자서전, 공식 발언
- **불허**: 출연작/감독작 속 대사 (아무리 유명해도)
- **예외 없음**: "I'll be back", "나한테 말하는 거야?" 등은 캐릭터 대사이므로 절대 불허
- **확인 방법**: 해당 문장 + 인물명으로 웹 검색 → 인터뷰/연설 출처가 확인되어야 등록

### 검증 의무 (핵심)

**AI 일반 지식만으로 명언을 작성하지 않는다.** 확신이 없으면 반드시 웹 검색으로 확인한다.

- 해당 인물의 대표 명언이 **확실하게** 떠오르는 경우만 검색 없이 작성 가능
  - 예: 데카르트 "나는 생각한다, 고로 존재한다" → 검색 불필요
- 조금이라도 불확실하면 `"{인물명} famous quote"` 또는 `"{인물명} 명언"`으로 검색
- 검색해도 신뢰할 수 있는 출처가 나오지 않으면 **빈 문자열** 처리
- **추측·창작·짐작으로 명언을 지어내는 행위는 절대 금지**

### 분량·포맷

- **50자 이내**, 한 문장
- 한국어로 작성 (외국어 원문 병기 금지)
- 따옴표(`""`, `''`)로 감싸지 않음
- 문자열 내 큰따옴표는 작은따옴표로 대체
- 검증 가능한 명언이 없으면 **빈 문자열**

### 우선순위 (위에서부터 적용)

1. **역사적으로 가장 유명한 발언**: 해당 인물 하면 바로 떠오르는 한마디
   - 예: 데카르트 → "나는 생각한다, 고로 존재한다"
2. **인물의 핵심 철학/신념을 담은 발언**: 인터뷰·연설·저서에서
   - 예: 스티브 잡스 → "항상 갈망하고, 항상 우직하게 나아가라"
3. **빈 문자열**: 1~2에 해당하는 검증 가능한 발언이 없으면
