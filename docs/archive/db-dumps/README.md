# DB 덤프 보관

삭제한 테이블의 내용을 그대로 떠 둔 것이다. **현행 스키마가 아니다.** 복원이 필요할 때만 쓴다.

## `remotion_images.json` (62행)

영상 이미지의 **메타데이터**다. 이미지 파일 자체는 R2에 있고 여기엔 생성 프롬프트·설명·R2 주소가 들어 있다.

| 항목 | 내용 |
|------|------|
| 대상 인물 | 4종 (알렉산더·마르쿠스 아우렐리우스 등) |
| 생성 시점 | 2026-03-27 하루. 이후 추가 없음 |
| 생성 출처 | `fal-pro` |
| 보유 | 62행 전부 `prompt`·`r2_url` 보유 |
| 컬럼 | id, type, width, height, desc_ko, desc_en, prompt, tags, source, r2_key, r2_url, created_at |

**삭제 사유**: 읽거나 쓰는 코드가 없었다. 유일한 참조가 DB에서 자동 생성된 타입 정의(`sw/web/src/types/supabase.ts`)뿐이라 사용처로 볼 수 없다. 실제 영상 이미지는 파일로 관리한다. 26.03 이미지 관리를 DB로 시도했다 접은 잔재로 판단했다. RLS가 꺼져 있어 외부 노출 상태이기도 했다.

**프롬프트 62건은 자산이다.** 같은 인물 이미지를 다시 뽑을 때 이 파일을 참조한다.

## `celeb_dialogues_bak_20260714.json` (18행)

셀럽 대사 교정 전 백업본이다. 현역 대사표(`celeb_dialogues`, 1577행)와 별개.

| 항목 | 내용 |
|------|------|
| 인물 | 18명 (앨리스 먼로·이청준·칼 융·박노해 등) |
| 현역 잔존 | 18명 전원 현역 표에 존재 |
| 교정됨 | 13명 — 백업 이후 대사가 실제로 바뀜 |
| 동일 | 5명 |
| 보유 | 18행 전부 `lines`·`lines_en` 보유 |
| 대사 상황 | deploy, greeting, roll_call, battle_win, battle_draw, battle_lose, clash_attack |

**삭제 사유**: 백업 목적을 다했고 RLS가 꺼져 외부 노출 상태였다. 다만 **13명분은 교정 전 원본**이라 되돌릴 근거가 되므로 이 덤프로 보존한다.

## 복원 방법

두 파일 모두 `row_to_json` 결과 배열이라 컬럼명이 그대로다. 테이블을 다시 만든 뒤 JSON을 INSERT하면 복원된다. 스키마는 위 컬럼 목록 참조.
