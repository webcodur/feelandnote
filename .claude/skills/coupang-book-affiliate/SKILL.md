# 쿠팡 도서 제휴 링크

상품 URL 확보가 아니라 **살 만한 상품 선정**이 이 작업의 핵심이다.

## 먼저 읽기

- 상품 판정은 `docs/project/operations/monetization.md`의 「쿠팡 파트너스」를 따른다.
- 후보 수집·확정 명령과 입력 형식은 `sw/web-bo/scripts/coupang/README.md`를 따른다.

## 실행

1. 기존 콘텐츠는 한국어판 ISBN을 확정한다. 신규 픽션 원전은 쿠팡에서 판매 상태가 좋은 판본을 먼저 고른 뒤 그 ISBN으로 콘텐츠를 등록한다.
   - 기존 원전의 판본도 고정값으로 보지 않는다. 현재 판본에 믿을 만한 상품이 없거나 축약·분권·현대 재화가 원전처럼 잡혀 있으면, 같은 작품의 완역·완질 판본 중 쿠팡 판매 상태가 나은 판본으로 서지를 교체한다.
   - 같은 작품이 권별 행이나 중복 번역본으로 흩어졌다면 등장 관계를 대표 판본 하나로 합친다. 원전 지정만 해제하고 기존 콘텐츠·이용 기록은 지우지 않는다. 서로 다른 원전이나 실제로 다른 이본은 겹치는 인물이 많다는 이유만으로 합치지 않는다.
2. `candidates.mjs`로 후보를 모으고, 같은 ISBN 후보의 상품 화면을 직접 연다. 로켓배송·도착 보장 같은 배송 배지가 실제 선택 상품에 붙어 있는 후보만 남긴 뒤 구매 또는 상품평 신호·판매자·재고·가격을 비교한다. 배송 배지가 없으면 판매량이나 평점이 높아도 링크를 비워 둔다.
3. 선택 자료에는 후보의 `productId`와 `productUrl`, 파트너스 `affiliateUrl`, 화면에서 확인한 `qualityEvidence`를 보존한다. `qualityEvidence`에는 실제 배송 배지 문구가 반드시 들어가야 하며 검색 순번은 상품 식별자가 아니다.
4. `pick.mjs`가 검토한 상품 ID·판매 항목과 현재 검색 결과가 일치할 때만 파트너스 링크를 만든다.
5. 반영 뒤 DB의 최종 URL이 `https://link.coupang.com/a/...`인지, 그 링크가 선택한 상품으로 가는지 다시 확인한다. 같은 상품 안의 도착 보장 판매자를 골랐더라도 단축 링크가 판매자를 고정하지 못해 무배지 기본 판매자로 열리면 탈락시킨다. 바뀐 콘텐츠 ID만 캐시 무효화한다.
6. 픽션 원전 BOOK은 작품 소개도 확인한다. 카카오 검색 요약이 문장 중간에서 끊겼다면 `fiction:source:descriptions`를 dry-run한 뒤 반영한다. 이 도구는 같은 ISBN의 전체 소개와 현재 앞부분이 일치할 때만 늘리고, 관련 작품·인물 캐시까지 갱신한다.

## 탈락

- 같은 작품의 다른 판본을 기존 ISBN 상품인 것처럼 연결하지 않는다.
- 해설서·현대 재화·일부 발췌본을 원전 전체처럼 지정하지 않는다. 더 적절한 대표 원전이 이미 같은 인물을 모두 포괄하면 그 행의 원전 지정을 해제한다.
- 로켓배송·도착 보장 같은 배송 배지가 실제 선택 상품에 없으면 비워 둔다. 공식 판매자·상품평·판매량은 배송 배지를 대신하지 못한다.
- 묶음·분권·중고·해설서·해외판이 콘텐츠 범위와 다르면 탈락시킨다.
- 일반 `www.coupang.com/vp/products/...` 주소는 후보 근거로만 쓴다. DB에는 파트너스 단축 주소만 저장한다.

## 감사 완료 조건

링크가 열리는지만 세지 않는다. 원전 자체의 대표성까지 다시 보고, 각 연결에 대해 판본, 선택 상품 ID, 배송·판매 근거, 최종 파트너스 링크가 서로 맞아야 통과다. 현재 상품 정보를 복원할 근거가 없으면 미확인이지 통과가 아니다.
