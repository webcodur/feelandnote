# 세력도감 주요 장면 제작 인계

2026-11-12 인계. **이미 발주한 마지막 묶음까지 서비스에 반영하고 제작을 멈췄다. Dots에 남은 발주·진행 작업은 없다.** 다음 컴퓨터에서 사용자의 재개 지시를 받으면 이 문서부터 읽는다. 이 대화나 이전 컴퓨터의 임시파일은 필요하지 않다. 아래 수치는 인계 당시이며, 수정 전에는 DB를 다시 읽는다.

## 사용자가 정한 작업 방식

조회수가 높은 세력부터 주요 장면을 보완한다. 작업자가 시나리오·사진/공식 영상 프레임 조사·해설·검수·서비스 반영을 맡고 **같은 feelandnote 계정의 ChatGPT Dots에는 이미지 재합성만 시킨다.** 사용자 목적은 Codex 토큰 절약이다. Codex 서브에이전트로 제작을 분산하지 않는다. Dots 본체와 내부 워커를 합쳐 최대 6개로 나누라고 요청했으며, 실제 6개 동시 실행 여부를 계측한 것은 아니다. 긴 상황 설명·계획 토론을 Dots에 보내지 않는다.

실제 사진을 참조로 보내 **1:1·풀컬러·최대 원본 해상도**로 다시 만든다. 백지 생성, 단순 크롭·확대, 참조 사진 자체 등록으로 끝내지 않는다. 원본의 시선·동작·앞/뒤 방향을 보존한다. 사용자는 별도 저작권 조사 절차를 요구하지 않았으며, 그 절차를 추가해 제작을 멈추지 않는다. WW2의 ‘2천 장’ 발언은 처음 10장으로 전쟁을 다뤘다는 지적이다. 10장·34장을 완료 목표나 상한으로 삼지 않는다.

제작 기준은 [faction-image 스킬](../../.agents/skills/faction-image/SKILL.md)과 [주요 장면 룰북 — 실사 자료 기반 주요 장면](../project/production/prod-02-myth-image-captions.md#실사-자료-기반-주요-장면), 브라우저 테크닉은 [ChatGPT Dots 이미지 재합성](../resource/res-04-browser-chat-automation.md#chatgpt-dots-이미지-재합성)이 SSoT다. 자료 조사는 해당 환경의 `web-search` 스킬을 읽고 wigolo 우선으로 한다.

## 실제 Dots 연결

- 계정: **feelandnote@gmail.com**, 이전 컴퓨터에서 Pro와 실제 계정을 확인했다.
- [작업한 Dot ‘내 dot’](https://chatgpt.com/dots/35cd51f2-5b3c-4202-9099-635d6a05e3f9~6acf4a8b540081a28e947b1fbed94b17). 참조 ZIP과 생성 이미지·교정 대화가 여기에 남아 있다.
- [Aside 스킬](../../.agents/skills/aside-browser/SKILL.md)의 `aside account list`로 해당 컴퓨터의 프로필부터 찾는다. 이전 컴퓨터의 `u1`·탭 ID·`pwd`를 복사해 쓰지 않는다. 실제 ChatGPT 로그인 계정과 Dot 제목/주소를 확인한다. Chrome 확장으로 같은 계정에 접근해도 된다.
- 유지 연결은 저장소의 [AsideClient](../../.agents/skills/aside-browser/scripts/aside-client.mjs)를 import해 `new AsideClient({account: 확인한프로필})`, `await client.ready`, `client.callRepl(...)` 순서로 사용한다. 생성자가 초기화하므로 `initialize()`를 다시 부르지 않는다. 호스트 경로는 옮긴 저장소 위치에 맞춘다.
- `listBrowserTabs()`로 기존 탭을 확인하고 자신의 작업 탭 Page 핸들을 고정한다. 사용자가 이미지를 보고 있는 탭이나 다른 작업의 탭을 닫지 않는다. 다운로드 허용은 한 번 거절된 적이 있으나 현재 원본은 canvas 경로로 모두 회수했다. 다운로드 오류를 재생성으로 해결하지 않는다.
- 이전에 ‘무료 Dots API’라고 부른 것은 Kilo의 무료 **텍스트 모델**이었다. 네이티브 Dots가 아니었다. 그 경로·LLM7·유료 이미지 API로 대체하지 않는다.

짧은 발주 예: `첨부 3장 각각 1:1 풀컬러 최대 해상도로 재합성. 여백을 늘리지 말고 인물 중심으로 프레이밍. 원본의 얼굴·시선·몸 방향·손동작 유지. 뒤를 보고 있는 사람은 뒷모습 그대로. 주변 로고·자막만 정리. 입력명 뒤 -square를 붙인 PNG로 첨부.` 여러 장은 ZIP으로 보내고 네이티브 워커 분담을 짧게 요청한다. 회수는 정확한 `img.alt` 파일명과 로드된 원본 크기로 확인한다. 이번 실제 반환값은 **1254×1254 PNG**였다.

마지막으로 WW2의 됭케르크·엘알라메인·여성 항공기 공장·아이젠하워의 공수부대 방문·파리 해방·레마겐을 추가했고, 파리는 v2를 채택했다. AI는 AlexNet 저자 사진, K-pop은 2NE1 《Fire》와 NewJeans의 Lollapalooza를 추가했다. 이 묶음을 다시 발주할 필요는 없다.

인계 직전 DB와 대조하여 **72장 모두 로컬 원본을 찾았고, R2 원본 PNG 72개·표시 파일 72개가 HTTP 200 및 바이트 크기까지 일치**했다. 마지막 추가·교정 9장에 대해 한국어 데스크톱 1280×900과 영어 모바일 390×844에서 실제 모달의 정확한 이미지 URL·1254×1254·한영 해설 두 페이지·넘침 없음·실행 오류 없음을 확인했다. WW2 전체 34장의 순서와 마지막 일본 항복 엔딩도 두 언어에서 확인했다. 서비스 캐시 갱신 완료 후 검사했다. 이 검수는 사용자 최종 승인을 대신하지 않는다.

저품질 이전 장면 **66개는 서비스 연결에서 철회했으며 R2 파일 자체를 일괄 삭제한 것은 아니다.** 대상은 AI·장길산·K-pop 두 세력·MCU·한국미술·xAI·한국영화·PayPal이었다. 한때 재합성 전 WW2 원자료 31장을 잘못 올린 상태도 철회하고 기존 이미지를 복구한 뒤 검수한 재합성으로 교체했다. **과거 철회 스크립트나 DB 복사본을 재실행하면 지금의 정상 교체본을 잃는다.**

## 남은 장면과 다음 판단

WW2의 기존 그림은 **「1945 · 아우슈비츠 생존자들이 구호를 받다」** 한 장이다. 참조 재합성 요청이 생성 제한으로 거절되어 기존 이미지를 유지했다. 표현을 바꿔 제한을 우회하지 않는다. WW2 자체는 지역·민간인·산업·전후까지 필요한 사건을 계속 조사해 넓힐 수 있다.

영화의 기존 10장은 다음 제목으로 현재 DB에서 다시 찾아 처리한다. 과거 배열 인덱스를 그대로 사용하지 않는다.

- 할리우드 블랙리스트 — 도입 / 1947 — 답변을 거부한 작가 / 1951–1952 — 동료의 이름을 밝히다 / 1960 — 본명으로 돌아온 각본가
- 누벨바그 — 도입 / 1954 — 부족한 예산을 편집으로 풀다 / 1950년대 말 — 비평가가 감독이 되다
- 도그마 95 — 도입 / 1995 — 스스로 만든 금지 목록 / 1999년 이후 — 규칙이 퍼지고 흔들리다

보류 후보를 완성본으로 착각하지 않는다. 모스크바 v1은 1941년 6월 사진에 눈을 만들었고 v2는 전차 포탑·차체 무장 형태가 틀려 **둘 다 미반영**이다. 크레타 AWM C63738, 퍼스 C256439도 손·크롭 문제로 보류했다. Nobody는 커튼과 인물 배치를 고친 **v3**, 파리는 원본에 없는 개선문 지붕 위 군중을 없앤 **v2**가 최종이다. NewJeans는 관객을 향한 다섯 명의 **뒷모습·옆모습**을 유지한 것이 맞다.

다음 세력은 `faction_lv2`의 현재 `is_featured`·`view_count`와 `team_images`를 다시 읽어 정한다. 이전 우선순위는 WW2 → cinema → AI → 걸그룹 → 장길산 → K-pop 제작자 순이었다. **`published=true`로만 필터링하지 않는다.** 현재 실제로 열리는 도감 중 `published=false`인 행도 있어 이 조건을 넣으면 대상을 누락한다. 이번 작업을 이유로 그 플래그를 바꾸지 않는다.

장길산(`jang-gilsan`, `e66450e7-569e-432b-9896-68ab102634aa`)은 현재 주요 장면 0개이며 새 제작은 발주하지 않았다. 현재 도감은 **황석영 소설** 기준이다. 기존 설명의 세부 조직·역할은 검증되지 않았으므로 그 문장만 믿고 장면을 만들지 않는다. SBS 2004 각색의 [최종 50회](https://programs.sbs.co.kr/drama/janggilsan/vod/68810/22000026376)는 체포 결말로 소설과 차이가 있다. 먼저 소설 원문·출판사 자료로 사건을 확인하고, 드라마는 일치하는 장면에 한해 시각 참조로 쓴다. 사용자 원고를 임의로 고치지 않는다.

## 다른 컴퓨터에서 반영할 때

현행 데이터 원천은 **DB `faction_lv2.team_images`와 R2**다. 일회성 발행·검수 스크립트와 로컬 이미지·ZIP·DB 복사본은 인계 자료가 아니다. 최종 원격 자산 검증 후 이번 작업의 임시 폴더 20개, Aside 회수 파일 104개, 다운로드 ZIP 9개를 정리했다. 합계 1,383파일을 삭제했고 지정 대상의 잔여 0개를 확인했다. 서비스 DB·R2와 Dot의 첨부는 유지했다. 참조 재확인은 위 Dot 첨부와 원출처를 사용한다. 원본 PNG와 표시 WebP의 해시는 서로 다르며, 원본 재탐색 방법은 제작 룰북에 있다.

기존 백오피스 `/faction-scenes` 또는 `/factions/<slug>`와 [장면 편집 액션](../../sw/web-bo/src/actions/admin/faction-scenes.ts)을 우선 사용한다. 배치가 필요해도 기존 검증·변환·경합 방지 규칙을 그대로 쓴다. 환경변수는 해당 컴퓨터의 기존 안전한 환경 구성을 사용하며 비밀값을 문서나 터미널 출력에 남기지 않는다. 캐시 갱신에는 사용자 웹 `/api/revalidate`의 기존 factions 경로를 사용하고 전체 완료·Cloudflare 성공을 확인한다.

**다른 컴퓨터에서는 최신 `main`을 받은 뒤 이 문서부터 읽는다.** 이 문서, 위에서 연결한 faction-image 스킬·주요 장면 룰북·브라우저 채팅 테크닉, 진입 링크를 갱신한 [TODO 목차](README.md)·[세력도감 웹 TODO](faction-web.md)의 6개를 함께 Git으로 전달한다. 받은 쪽은 위 링크 파일들이 있는지 확인한 뒤 현재 DB를 다시 읽고 이어간다. 이번 인계 변경은 문서·스킬뿐이며, 이미지·해설은 이미 운영 DB·R2와 사용자 웹 캐시에 반영되어 별도 웹 코드 배포는 필요하지 않다.
