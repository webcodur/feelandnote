# Faction Character Info 생성 규칙

이 스킬은 팩션(세력도, factions/) 영상에 등장하는 인물들의 얼굴, 생김새, 스타일 등을 안내하는 외모 가이드 문서(`_refs/info.md`)를 자동 생성할 때 적용됩니다. "팩션 인물 외모 문서 작성해줘", "info.md 채워줘", "어떤 인물이 어떻게 생겼다라는 가이드 작성해" 등의 호출에 발동합니다.

## 1. 목적 (Purpose)
이미지 발주나 캐릭터 레퍼런스를 지정할 때 참고할 수 있도록, `faction-data.json`의 내용을 바탕으로 해당 팩션 내 모든 인물의 **간단 스토리**와 **외모 가이드(어떻게 생겨야 하는지)** 를 정리하여 하나의 마크다운 문서로 만듭니다.

## 2. 작업 순서 (Workflow)
1. 타겟 팩션 디렉토리(예: `sw/remotion/public/factions/<팩션명>`)에 접근합니다.
2. `faction-data.json` 파일을 열어 `groups` 배열 내부의 `clusters` 배열 속 `people` 목록을 순회합니다.
3. 각 인물(`people` 객체)의 다음 필드를 파악합니다:
   - `name`: 인물 이름
   - `lines` / `epithet`: 인물을 묘사하는 키워드 및 한 줄 설명
   - 인물이 역사적, 신화적 인물인지 혹은 현대 인물인지에 대한 컨텍스트
4. 위 정보를 바탕으로, 다음 두 가지를 유추/작성합니다.
   - **간단 스토리**: json의 `epithet`과 `lines`를 기반으로 한두 줄의 요약 스토리.
   - **외모 가이드**: 인물의 행적, 성향, 세력 내 위치를 근거로 연령대, 체형·실루엣, 얼굴형, 눈·코·턱의 비례, 머리·수염, 피부, 표정의 긴장, 복식을 구체적으로 묘사한다.
   - **집단 내 대비**: 같은 클러스터 인물과 최소 세 가지 시각 축에서 어떻게 달라야 하는지 적는다.
   - 원전·자료의 고정 단서와 작품을 위한 창작 결정을 구분한다. 근거가 적다는 이유로 평균적인 미남·미녀나 수염 난 중년 얼굴로 자동 보충하지 않는다.
5. `_refs/info.md` (혹은 `_refs/` 폴더가 없다면 생성한 뒤) 파일에 마크다운 포맷으로 저장합니다.

## 3. 출력 포맷 (Output Format)
마크다운 문서는 다음과 같은 구조를 가져야 합니다:

```markdown
# [팩션명] 인물 정보 및 외모 가이드 (Reference)

이 문서는 `[팩션명]` 팩션에 등장하는 주요 인물들의 간단한 스토리와 외모(어떻게 생겨야 하는지)를 안내하기 위한 기준 문서입니다.

## [그룹 번호]. [그룹/클러스터 명]

### [인물 이름] ([영문 이름 또는 slug])
- **간단 스토리**: [인물의 역할 및 주요 서사 1~2줄]
- **고정 단서**: [원전 또는 프로젝트 데이터가 명시한 시각·관계·지위 정보]
- **외모 가이드**: [이번 작품의 구체적인 캐스팅 설계. 얼굴 골격, 눈매, 표정, 체형, 머리, 옷차림 등]
- **집단 내 대비**: [같은 클러스터 인물과 구별되는 시각 축 최소 3개]

... (반복)
```

## 4. 제약 사항 및 원칙
- 이 문서의 외모 설계는 이미지 발주를 위한 기록일 뿐, AI가 새 얼굴 REF를 생성하거나 교체할 권한이 아니다. REF 창조는 사용자가 특정 인물에 대해 먼저 직접 권유한 특별 상황에서만 별도 절차로 진행한다.
- **존재하는 모든 인물 누락 금지**: `faction-data.json`에 기재된 `people`은 단 한 명도 빠짐없이 문서에 포함되어야 합니다.
- **창의적이고 구체적인 외모 묘사**: `영웅적`, `신성한 아우라`, `고대 복식`처럼 여러 인물에게 복사할 수 있는 문장은 외모 가이드로 인정하지 않는다. 이름을 가렸을 때도 누구의 설계인지 구분될 정도로 구체화한다.
- **평균 얼굴 방지**: `평균 체격의 수염 난 중년 남성`, `무난하게 잘생긴 왕`, `근육질 전사`로 요약되면 실패다. 얼굴 골격·체형·표정 에너지·머리 중 최소 세 축을 같은 클러스터의 다른 인물과 다르게 설계한다.
- **`_refs/` 폴더 사용**: 생성되는 문서는 반드시 해당 팩션 폴더 내의 `_refs/info.md`에 위치해야 합니다.
