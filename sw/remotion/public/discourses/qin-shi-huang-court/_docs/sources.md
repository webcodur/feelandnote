# 진시황과 세 사람 — 대본 근거

이 편에 쓴 인용의 출처와 등급. **대본을 고칠 때 이 문서를 먼저 본다.**

## 명단을 이렇게 짠 이유

논제는 「제국은 무엇으로 무너졌는가」다. 진시황·이사·조고·부소 넷이 센 조합인 까닭은 **진시황의 법이 그의 맏아들과 그의 승상과 그의 왕조를 죽였고, 그것도 그가 만든 문서 체계를 그대로 흉내 낸 가짜 명령서로 죽였다**는 데 있다. 넷 다 자기가 남긴 말이 자기를 겨눈다.

- **이사**: 「쥐가 어디 있느냐가 그 쥐를 정한다」고 말하고 곳간에 올랐다가, 「고라니와 사슴이 조정에서 뛰노는 것을 보리라」로 끝난다. 그리고 **황제에게 귀를 막고 눈을 가리라고 쓴 문서를 자기가 썼고, 몇 달 뒤 자기 상소가 막혀 죽는다.**
- **부소**: 조서가 씌운 죄목이 **불효**였기에, 조서를 의심하는 순간 조서가 옳음을 증명하게 된다. 그래서 묻지 않았다. 조고의 설계가 완결되는 지점이다.
- **조고**: 「지록위마」의 본질은 사슴이 말이냐가 아니라 **「先設驗」(먼저 시험을 마련했다)** — 누가 복종하는지를 계량한 것이다. 사마천이 직접 못 박았다.
- **진시황**: 「만세에 전하라」고 명하고 이세에서 끝났다.

**형가(荊軻)는 뺐다.** 통일 이전 인물이라 사구지변 축과 시간이 어긋나고, 셀럽 DB 미등록이다. 암살 축으로 별도 편이 가능하다(자객열전 확보).

## 채택 원칙

1. **제3자 평가는 대사로 쓰지 않는다.** 가의 「과진론」의 「仁義不施而攻守之勢異也」, 사마천의 태사공왈(「知六藝之歸」 — 이사는 옳은 길을 알면서 하지 않았다)은 강력하나 **넷 중 누구의 말도 아니다.** 이 편은 네 사람의 자기 말만으로 선다.
2. **큰따옴표 = 사료에 실제로 있는 말.** `origin`에 한문 원문, `originRef`에 편명과 상황을 싣는다. 재구성 대사에는 따옴표를 쓰지 않는다.
3. **확인 불가는 단정하지 않는다.** 아래 「배제」 참조.

## 마지막 장 표지 — 『조정서(趙正書)』

북경대 소장 서한 죽서. 조화성은 성서 연대를 **『사기』보다 이르다**고 본다. 사구지변을 정면으로 뒤집는다.

> 丞相臣**斯**、御史臣**去疾**昧死頓首言曰：「今道遠而詔期羣臣，恐大臣之有謀，**請立子胡亥為代後。**」**王曰：「可。」**

위조가 아니라 **이사가 정식으로 청했고 시황이 「可」로 재가했다**는 기록이다. 조고는 거의 등장하지 않는다.

**이 편은 『조정서』가 참이라고 주장하지 않는다.** 마지막 장 표지로 한 줄만 던진다. 학계도 갈린다 — 신더융은 「소설이며 진대 정치사에 쓸 수 없다」, 이예는 「신빙성 있다」. 절충적 정리는 **"『조정서』를 믿고 『사기』를 버릴 수는 없으나, 『사기』만 믿는 경향은 교정할 수 있다"**다. 『조정서』가 이세 정권의 관방 발표를 채록한 것이라는 해석이 유력하지만, **뒤집으면 『사기』야말로 한 왕조가 진의 정통성을 부정하려 채택한 서사일 수 있다.**

## 배제 — 사료 밖이거나 확인 불가

| 항목 | 이유 |
|------|------|
| **조고 = 환관** | **1차 사료 안에 반증이 있다.** 근거는 「隱宮」(몽염열전)과 이세의 「故宦人也」 두 곳뿐인데, 마비백이 수호지 진묘 죽간으로 「隱宮」=「隱官」(형기 마친 자를 수용한 관영 작소) 오사임을 논증했고, 「宦」은 궁중 근시를 뜻하지 거세가 아니다(장가산 한간). **결정타: 조고에게 사위 염락이 있다**(이사열전). 이 편은 조고를 **법률 실무 관료**로 그린다 — 원문이 보장하는 것은 「諸趙疏遠屬」·「世世卑賤」·「通於獄法」·「刀筆之文進入秦宮」까지다. 오히려 더 센 인물이 된다 |
| **조고의 동기 = 조나라 복수** | 「諸趙疏遠屬也」에서 후대가 추론한 것. **『사기』는 조고의 동기를 몽의에 대한 사원과 권력욕으로만 서술한다** |
| **분서갱유 / 갱유** | 『사기』 원문은 「阬之咸陽」·「諸生」뿐. **「坑儒」도 「焚書坑儒」도 없다.** 유생 매장 서사는 후한 위굉의 글에서 확장되며 사건과 250년 격차. 학계에서 사실로 인정되지 않는다. 시황의 분노가 겨눈 것은 명백히 **달아난 방사(노생·후생)**다 |
| **"모든 책을 태웠다"** | 원문이 박사관 소장본 존치·의약복서종수 제외·진 사관 기록 보존을 명시한다 |
| **부소 = 유가** | 원문은 「諸生皆誦法孔子」로 **제생을 변호했을 뿐**. 사마천이 준 성격 규정은 「扶蘇為人仁」 넉 자뿐 |
| **부소 = 태자** | 몽염이 「未立太子」라 명시. **시황은 끝내 태자를 세우지 않았다.** 그래서 유조 아홉 자가 후계 지명이냐가 해석의 문제로 남는다 — 조고가 이 구멍을 정확히 짚는다(「無詔封王諸子而獨賜長子書」) |
| **부소 좌천** | 처벌이 아니라 **북방 30만 군 감독**으로 보냈다. 좌천인지 후계 수업인지 『사기』는 판정하지 않는다 |
| **여불위 친자설** | 여불위열전에 있으나 본기(「莊襄王子也」)와 충돌. 한대 서사 의심 |
| **이사 사망 연도** | **이사열전 「二世二年七月」 vs 진시황본기 「二世三年冬」 — 같은 책이 다르다.** 대본에서 연도를 말하지 않는다 |
| **조고의 죽음** | 이사열전(한담이 자살), 본기 태사공왈(자영이 거열), 조정서(장한) — **셋 다 다르다.** 이 편은 다루지 않는다 |

## 남은 검증 과제

- 분서 조칙 이본: **본기본**(「今皇帝…別黑白」+ 우어기시·이고비금자족 조항 있음) vs **열전본**(「今陛下…別白黑」+ 두 조항 없음). 이 편은 조칙을 직접 인용하지 않아 미해당이나, 확장 시 **본기본을 쓴다**(전문이고 「制曰：可」로 닫힌다).
- 「具五刑」의 정확한 집행 순서는 『한서』 형법지 기준 추정이다. 대본은 「요참」만 말한다.
