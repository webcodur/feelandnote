# 셀럽 사진 즉시 등록 확장

검색용 브라우저에서 사진을 **Alt+클릭**하면 백오피스(`localhost:3001`)의 셀럽 이미지 작업 화면으로 곧바로 넘긴다. 창을 나란히 두고 끌어다 놓을 필요가 없다.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더(`tools/celeb-image-grabber`) 선택

크롬 계열 브라우저(엣지·웨일 등)도 같은 방식이다. 저장소를 옮기면 경로가 바뀌므로 다시 불러와야 한다.

## 사용

1. 백오피스를 띄운다 — `pnpm dev:bo`
2. `http://localhost:3001/celebs/images`를 연다. 사진 없는 인물만 보려면 화면 위 조건에서 걸러낸다.
3. 검색용 브라우저에서 원하는 사진을 Alt+클릭한다. 화면 우측 위에 「보냈습니다」가 뜬다.
4. 백오피스 창으로 건너오면 **받을 자리**의 편집 창이 열려 있다. 마무리해 저장한다.

받을 자리는 사람이 정한다. **행은 화면에 가장 크게 보이는 인물**이고, **자리는 숫자키 1·2·3**이 고른다(아바타·대표 사진·각성 이미지). 목록을 굴리면 받을 행이 따라 움직이고, 그 행은 테두리와 「받을 자리」 표지로 드러난다. 타일을 직접 누르면 그 행에 묶이고, 다시 굴리면 풀린다. 목록 맨 위 안내줄이 지금 누구의 어느 자리인지 알려준다.

이미 사진이 있는 자리도 그대로 받는다 — 편집 창에서 저장을 눌러야 교체된다.

- **끄기**: 사진을 받지 않는다.

## 알아둘 것

- 백오피스가 꺼져 있으면 「백오피스에 연결하지 못했습니다」가 뜬다.
- 자르기 창이 떠 있는 동안 보낸 사진은 서버가 최대 5장까지 들고 있다가 차례로 내보낸다. 5분이 지나면 버린다.
- 이 창구는 `localhost`·`127.0.0.1`로 들어온 요청에만 응답한다. 배포된 백오피스에는 열리지 않는다.
- 서버 쪽 창구는 `sw/web-bo/src/app/api/celebs/quick-image/route.ts`다. 포트를 바꾸면 `background.js`의 `ENDPOINT`도 함께 고친다.
