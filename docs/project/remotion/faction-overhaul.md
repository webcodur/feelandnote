# 팩션 전량 데이터 정비 — 작업 지시서 + 진행 보드 (라이브)

LLM 편(`AI패권전쟁`)을 기준으로 나머지 현역 에피소드 6편과 `not-using/` 66건 전체의 데이터를 정비하고 이미지 발주서를 완성한다. 2026-07-02 착수.

## 기준 (Definition of Done — 항목당)

1. **데이터 파일**: `faction-data.json` 단일 파일 (로더가 `faction-data.json`만 스캔). `data.ko.json`만 있으면 내용 이관 후 `faction-data.json` 생성, 원본은 삭제하지 않고 `data.ko.json.bak`으로 개명.
2. **현행 스키마** (`docs/project/remotion/faction.md`의 데이터 모델 절이 SSoT):
   - 인물은 항상 `groups[].clusters[].people`. 레거시 `group.people` → `clusters: [{ people }]`로 이관.
   - `tagline`/`taglineEn` → `name`/`nameEn` 뒷부분(개행 결합)으로 흡수 후 필드 삭제.
   - `note`/`noteEn` → `label` 뒷부분으로 흡수. `subtitle*` → `title`로 흡수.
   - `titleArt`/`titleArtCrop`/`logo` → `logoImg`/`logoCrop`으로 개명. `group.image`/`imageCrop` 필드 삭제(표지는 logoImg 단일 소스).
   - 폐기 필드 잔존 0.
3. **전역 텍스트**: `title` + `titleEn` + `logline` + `loglineEn` 필수. `heroes`(대표 3~5인) 권장.
4. **세력·묶음**: 세력마다 `name`(앞부분\n뒷부분)·`nameEn`·`color`. 묶음이 2개 이상이면 각 `label`·`labelEn`.
5. **인물 전원**: `name`·`nameEn`·`org`·`lines` 3줄·`linesEn` 3줄. 작성 원칙은 faction.md 「인물 문구(lines) 작성 원칙」 — 1줄=현직 직책 짧게, 2·3줄=이력 명사구, `前` 금지, 칭찬어·부각 수식어·잡신상 금지. **현존 인물·기업은 웹 검색으로 현직 여부 교차 검증**(역사 인물은 사실관계만 확인). 장비형 에피소드(로켓·무기 등)는 장비 스펙·이력을 같은 3줄 규격으로.
6. **이미지 발주서**: `faction-image` 스킬(`.agents/skills/faction-image/SKILL.md`)이 규칙 SSoT. 세력(또는 묶음)당 `00-<slug>.md` 하나 + `00-발주서-인덱스.md`. 각 발주서는 최상단 진행 순서 강제 지시 → 대상·컨셉·핵심 원칙·배치 → STEP 단체샷(완성 영문 프롬프트, 1:1 square, 4인+는 마네킹 단계) → STEP 로고 → STEP 개인샷(단체샷 승인 뒤, 공통 블록+인물 목록) → 데이터 연결 안내 순. 표본: `factions/AI패권전쟁/00-pioneers-neuralorigin.md`, `00-huggingface.md`. 포즈는 `factions/AI패권전쟁/group-pose-bank.md` 풀에서 세력마다 다르게 추출.
7. **REF**: 발주서에 인물별 REF 경로(`_refs/<인물명>.<ext>`)와 보유/미보유 체크리스트를 명시한다. 실제 수집·이미지 생성은 이 정비의 범위 밖(유저 진행 단계).
8. `_status.json` 없으면 `{"status":"todo"}` 생성.

## 보존 원칙 (전 에이전트 공통)

- 기존 필드(음성·컷 효과·part·quote 등)는 **전부 보존** — 모르는 필드 삭제 금지.
- 기존 완성 발주서·이미지·연구 자료는 삭제·덮어쓰기 금지. 규격 미달 부분만 고치고 결손만 채운다.
- 대사(quote) 신규 채굴은 범위 밖(후속 단계). 기존 quote는 보존.
- `slug`는 있는 것만 보존, 신규 발명 금지.
- JSON은 UTF-8(BOM 없음)·`ensure_ascii=False`·기존 들여쓰기 유지. 저장 후 파싱 재검증.
- 유료 생성(이미지·음성) 절대 금지. 발주서 작성까지만.
