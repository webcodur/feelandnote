# 신화 인물 남은 작업

그리스·로마 신 계보를 정비하며 남긴 후속 과제다. 관계 규칙은
[`../project/celeb/celeb-07-01-relations.md`](../project/celeb/celeb-07-01-relations.md),
신화 목록 화면은 `sw/web/src/actions/home/getMythData.ts`가 쥔다.

## 표기와 안내

- 대응 신격(counterpart)은 「같은 신을 문화권마다 다르게 부른 것」이라 가족도 사회도 아니다.
  관계망에서는 기타 갈래에 두고, 프로필 하단 이어지는 인물 목록이 이름을 밝힌다.
  이름 옆에 「그리스식 이름: 제우스」 같은 이름표를 세우는 안은 미착수다.

- 이름을 바꿀 때는 조사와 겹치는 낱말을 함께 본다. 「유노」는 유노윤호(동방신기)·자유노조·
  유노니아 안에도 들어 있어 이름 뒤에 조사가 붙을 때만 바꿔야 하고, 「넵투누스→넵튠」은
  받침이 생겨 「넵투누스가→넵튠이」처럼 조사까지 바뀐다. 표를 훑을 때는 정렬 없이
  `range()`로 넘기면 페이지마다 순서가 흔들려 행이 빠진다 — 키로 정렬해 고정한다.

## 데이터 공백

- 디오니소스의 로마 대응(바쿠스·리베르) 프로필이 없다. 아폴론은 로마도 같은 이름을 써서
  대응 행이 없는 것이 맞다.

## 실화면 확인

- 관계망의 기타 갈래를 실제 화면에서 보지 못했다. 탭 셋이 한 줄에 서는지, 기타 탭에서
  거르는 줄이 사라졌는지, 갈래 이름표가 「대응 신격」으로 뜨는지 확인한다.
  진입 경로는 `/celeb/jupiter` 관계망이다.
