# 인물 특성 다원 표시 검토

단일 `celeb_tier`가 존재 여부와 서사 기능을 한 축에 접어서, 두 특성을 함께 가진 인물을 한쪽에서만 보여준다. 파이프라인 분기(어느 장치로 다루는가)와 특성 표시(무엇으로 보이는가)를 분리할지 검토한다.

## 문제

`celeb_tier`는 실존(`light`·`full`)과 허구(`fiction`) 둘 중 하나를 강제한다. 티어가 곧 사용 가능한 장치(감상 콘텐츠 대 원전·등장 작품, 영향력·스펙트럼 유무)를 정하므로, 경계 인물은 반대쪽 특성을 화면에 드러낼 통로가 없다.

| 인물 | 현행 티어 | 보이는 쪽 | 가려지는 쪽 |
|---|---|---|---|
| 예수 | `full` | 역사적 코어(세례·처형), 종교 지도자 서사 | 동정녀 탄생·기적·부활의 신화층 |
| 주몽 | `fiction` | 건국신화, 원전(삼국사기·삼국유사) 연결 | 역사적 실체 논란 자체 |
| 테세우스 | `fiction` | 미궁 퇴치, 아테네 건국 서사 | 없음(실존 코어 없음) |
| 단군왕검 | `fiction` | 건국신화, 시조 표기 | 고조선 실체와의 관계 논란 |

## 설계안: 2축 분리

티어는 파이프라인 분기로 남기고, 특성은 체크박스식으로 별도 축에 둔다.

- `historicity`: `confirmed` (독립 실존 증거) · `contested` (실체설 대 전승설) · `none` (실존 코어 없음). 미평가는 `NULL`.
- `is_founder`: 건국·개창 서사의 주체이면 `true`. 미평가는 `false`가 아니라 별도 평가 전 상태를 둔다면 `NULL`도 검토한다.

표시 규칙 초안:

- `historicity='contested'`면 상세에 논란 배지와 근거 한 줄을 노출한다(주몽).
- 실존 트랙 + 신화층이 두꺼운 인물(예수)은 전승 서사를 읽어보기·연표에서 감추지 않는다. 현재 full 장치가 이미 허용하므로 규칙 명문화만으로 충분한지 본다.
- `is_founder=true`면 타이틀 시조 표기와 건국 기록 원전 연결을 필수 점검 항목에 넣는다.

## 미결 질문

1. `historicity` 기본값을 티어에서 유도할지(`full`·`light`→`confirmed`, `fiction`→`none`), 전부 `NULL`에서 시작할지. 전자는 현행 편향을 굳히고, 후자는 3,282명 재평가가 숙제다.
2. `contested` 판정의 근거 SSoT(학계 정설 출처를 어디에 남기는가).
3. 건국영웅 외에 다원 표시가 필요한 유형이 있는지(개창 종교인, 신격화 군주 등).
4. 외부 관계(`celeb_relations_external`)의 QID 대조를 신원 확정 절차에 포함할지. 테세우스 5건(아이게우스·파이드라·히폴리토스·페이리토스·아리아드네)은 위키데이터 양방향 클레임으로 확정한 선례다.

## 제약

- `celebs` 컬럼 신설은 사용자 명시 지시 뒤에만 실행한다(`AGENTS.md` 전역 불변사항). 이 문서는 설계 검토용이며 스키마를 바꾸지 않는다.
- 관련 현행 규칙: `docs/project/celeb/celeb-00-01-pipeline.md`의 「존재와 속성을 구분한다」.
