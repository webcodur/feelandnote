# 편성

> 선정 조건: 감상여정(cultural_journey) 보유 + 도서(BOOK) 3권 이상 + celeb_tier=full
> 라이벌 인물은 반드시 묶어서 연속 편성 (한쪽 편 들지 않도록)

## 편성 원칙

1. 고대 → 근세 → 근현대 → 현대 → … 시대를 교차하며 편성
2. 직군(무장/정치/예술/과학 등)과 동서양을 겹치지 않게 배치
3. 음성(has_voice) 보유 인물을 우선 제작
4. **라이벌 묶음**: 대립 관계 인물은 연속 2~3회로 묶어 공정하게 다룸
5. **정치 인물**: 좌↔우, 동↔서 왔다갔다 교차 편성

- 괴테·잔 다르크: 음성은 있으나 책 3권 미만으로 Phase 1 탈락. 콘텐츠 보강 시 편입 가능.
- (?)로 표기한 인물은 DB에 책 수 미확인 또는 조건 미달 가능성 — 보강 필요.
- 라이벌 묶음은 반드시 연속 회차로 편성. A를 먼저 다뤘으면 B를 바로 다음 회차에.
- 현대 = 1945년 이후 출생 (2차대전 종전 기준).
- 한국 정치 인물은 특히 균형 주의 — 진보·보수 교차 필수.
