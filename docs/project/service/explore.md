# 탐색 (`/explore`)

탐색은 인물(`/explore`)과 작품(`/explore/works`) 두 모드로 나뉜다. `navigation.tsx`의 `EXPLORE_MODES`를 공통 모드 탭(`ExploreModeTabs`)이 그리며, 허브와 하위 화면에서 현재 모드를 강조한다. 작품 구획은 [library.md](library.md)가 설명한다.

상위 메뉴는 탐색·광장·쉼터다. 모바일은 홈·탐색·광장·쉼터와 음악 재생기 칸을 두며, 내 기록은 헤더 프로필 메뉴로 들어간다. 푸터는 인물·작품 두 칼럼을 유지한다. 메뉴와 링크의 원천은 `sw/web/src/constants/navigation.tsx`다.

인물 모드에서는 원하는 사람을 찾고, 별도 페이지에서 분야·성향·신화·세력을 탐색한다. 인물 주소와 상세(`/celeb/[slug]`·`/content/[id]`)는 유지한다.

두 모드의 상단 배너는 「탐색 / EXPLORE」이며 PC에서도 같은 별자리(`ConstellationBanner`)를 쓴다. 아래에서 인물·작품 모드를 고르고, 「인물로 탐색하기 / 작품으로 탐색하기」 소개(`ExploreHubIntro`) → 공용 검색·정렬·필터(`ExploreSearchControls`) → 결과 수와 카드 → 다른 탐색 방법 순서로 그린다. 작품의 기관 로고 격자는 인물 격자와 같은 열 구성을 쓰며 이미지 안내 카드는 `ExploreFeatureCard`를 공유한다.

검색·정렬·필터는 최대 폭을 제한한 중앙의 공통 패널로 묶고 PC에서는 한 줄로 배치한다. 좁은 화면에서는 검색창 아래에 선택 버튼을 둔다. 작품의 매체 선택과 인물의 트렌드 안내도 이 패널 안에 두며, 트렌드 안내는 강한 배지 없이 보조 문구로 표시한다. 패널 폭과 조작 요소 스타일은 `ExploreSearchControls.tsx`가 쥔다. 두 모드 모두 페이지 번호를 바꿀 때 현재 스크롤 위치를 유지한다. 인물·기관 카드는 금빛 테두리·그림자·이미지 하단 빛·이름 칸 강조와 내부 이미지 확대를 `ExploreCard.styles.ts`로 공유한다. 기관 검색·필터·미리보기·로고 표시는 [기관 선정](curated-lists.md#31-사용자-웹)이 쥔다.

## 탐색 첫 화면

`/explore`는 필터·검색·정렬·페이지네이션을 갖춘 인물 그리드다. 첫 진입은 「감상 있음」 필터와 「오늘의 추천」 정렬을 사용한다. 사용자가 감상 조건이나 정렬을 직접 바꾸면 그 선택을 따른다. 「오늘의 추천」은 영향력·감상 작품 수·날짜별 변화에 생존·기업가 속성 가산을 얹는 `daily_recommend` 조회를 사용한다. 여기에 국가별 트렌드 매칭 인물이 일일 시드 추첨으로 첫 페이지 칸을 얹는다 — 당첨 확률과 상한은 `lib/celeb/dailyRecommendTrend.ts`가 쥐고, 그려진 인물은 카드의 화염 표지·급상승 칩과 필터 아래 안내 줄로 드러난다. 기본값과 허용값은 `constants/celebProfessions.ts`, `celebContentPresence.ts`, `celebSort.ts`, URL 해석은 `explore/figures/filterParams.ts`가 쥔다.

필터는 모달로 열며 제목을 가운데에 locale에 맞춰 표시한다. 작품 유무는 기존 수록 필터 자리에 둔다. 미확인 작품 수는 음수 배지로 노출하지 않는다. 탐색 인물 카드는 상세 주소를 가진 링크이며 일반 클릭은 인물 미리보기를 연다(`CelebCarousel`의 `onSelect`). 미리보기에서 앞뒤 인물을 살펴보거나 상세로 이동한다. 대사 재생은 별도 버튼이다(`components/shared/CelebCard.tsx`).

그리드 아래 탐색 메뉴는 가상독백을 그림과 설명이 있는 전폭 카드로 먼저 보여주고, 분야별 챔피언·스펙트럼·신화의 세계·세력도감을 같은 그림 카드 형식의 2×2 격자로 배치한다. 연대기·디렉토리는 보조 카드다. 주요 카드 중 네 항목과 푸터의 인물 메뉴는 `EXPLORE_FEATURED_LINKS`를 공유한다. 인물 피드·오늘의 인물은 탐색 메뉴에서 제외하고 기존 주소는 유지한다. 가상독백 페이지는 낭독 인물을 검색 가능한 카드 격자로 보여주고 12명씩 더 펼친다. 독백 전문과 책장은 카드를 고른 인물 것만 불러온다.

목록은 `FiguresFilterResult`에서 서버 조회하고 `Lane`으로 감싼다. 봇·미확인 UA에는 완성 HTML을 주며, 사람 브라우저에는 대기 UI 뒤 목록을 제공한다. 수집 가능한 링크와 렌더링 규칙은 [코드 규칙](../platform/code-rules.md), 검색 검증은 [SEO](../operations/seo.md)를 따른다.

## 국가별 트렌드

트렌드는 Google Trends 공개 페이지의 검색 급상승어와 등록 인물의 국문·영문 이름을 띄어쓰기를 무시하고 대조한다. 급상승어에 딸린 연관 검색어도 대조하되, 한 단어 이름(예명)은 엉뚱한 검색어에 걸리므로 두 단어 이상 이름만 인정한다. 옛 인물은 동명의 현대 뉴스 검색어를 가로채므로(연암 박지원, 삼국지 법정) 기준 연도 이전 출생자는 대조하지 않는다. 기준 연도는 `lib/trends/trendMatching.ts`가 쥔다. 짧은 기간은 등록 인물과 겹치는 검색어가 너무 적어 Google이 제공하는 가장 긴 기간을 쓴다. 서버가 읽어 국가별로 캐시하며, 방문할 때마다 실시간 API를 호출하는 방식은 아니다. 지원 국가는 Google Trends 급상승 페이지가 받는 국가 전체다. 목록과 재확인 방법, 출처 기간은 `constants/trendCountries.ts`, 조회·캐시는 `lib/trends/countryTrending.ts`, 파싱·이름 매칭은 `lib/trends/trendMatching.ts`가 쥔다. 인물 이름이 국문·영문뿐이라 일본어·중국어·태국어처럼 다른 문자로 검색하는 나라는 일치 인물이 드물다.

국가는 URL 선택을 먼저 쓰고, 없으면 접속 국가 헤더(`CF-IPCountry`)를 적용한다. 지원되지 않거나 헤더가 없으면(로컬 개발 서버) 한국으로 시작한다. 국가 단추는 접속 국가·한국·미국에 공유 주소로 들어온 국가를 더해 페이지를 열 때 한 번 정한다. 이는 인물의 국적 필터와 별개다. `actions/home/getCelebs.ts`가 현재 필터에 맞는 트렌드 인물을 검색량 순으로 앞에 놓고 나머지를 작품 수 순으로 채운 뒤 페이지를 나눈다. 일치 인물이 없거나 조회에 실패하면 작품 수 순으로 보여주며, 화면에서 일치 여부와 조회 상태를 구분한다.

## 개별 페이지

| 경로 | 역할 |
|---|---|
| `/explore/ranking` | 상단 매체 메뉴에서 선택한 분야의 인물과 공통 감상작만 조회·표시 |
| `/explore/spectrum` | 성향 축별 극단 인물과 차순위 탐색 |
| `/explore/myth` | 지역·전승·그룹별 신화 인물 탐색 |
| `/explore/faction`, `/explore/faction/[slug]` | 세력도감과 특정 테마 진입 |
| `/explore/timeline` | 대륙을 고른 뒤 나라를 선택하는 연대기. 국가·페이지별 목록을 서버에서 나눔 |
| `/explore/directory`, `/explore/directory/[profession]` | 전체·직군별 인물 주소를 발견하는 명부 |
| `/explore/today`, `/explore/feed` | 기존 주소 유지. 탐색 메뉴에는 노출하지 않음 |

`/explore/figures`·`celebs`는 검색 조건을 보존해 `/explore`로 영구 이동한다. `persona`는 `/explore/spectrum`으로 308 이전한다. 옛 주소의 목적지는 `sw/web/next.config.ts`가 쥐며 중복 리다이렉트 페이지는 두지 않는다. `youtube`는 영상관 재개를 고려해 임시 이전을 유지한다. 새 링크와 워밍 점검에는 현재 정본 주소를 쓴다.

분야별 챔피언과 스펙트럼은 같은 부모 화면 **인물 순위판(Figure Ranking Board, `components/features/user/explore/figureRankingBoard/`)** 위에 선다. 선택기 → 무대(머리·시상대·순위) → 함께 감상한 작품 서가의 배치와 대기 화면을 순위판이 전부 쥐고, 두 화면은 자기 자료를 순위판의 입력으로 바꿔 넘기기만 한다. 갈리는 조건은 머리 앞 표식(글자 칩 | 아이콘), 순위 형식(시상대 | 양극 매치업), 서가 묶음 수(하나 | 둘) 셋뿐이다. 머리는 두 화면 모두 「표식·제목·Top N」 한 줄에 설명 한 줄이고, 두 화면 모두 Top 10이다. 선택기 칩 모양(네모), 머리의 「Top N」(인원 수에서 만든다), 서가의 제목·부제(문구 `explore.rankingBoard`)는 순위판이 정하고 화면은 넘기지 못한다 — 화면이 고르게 두면 두 화면이 다시 갈린다. 서가의 작품 낱장은 사이트 공통 작품 카드(`ContentCard`)를 그대로 쓴다 — 감상 인원은 카드 기본 표시(표지 왼쪽 아래, 누르면 감상 인물 창)에 맡기고 순번 칩만 얹는다. 두 화면의 모양을 바꿀 때는 각 화면이 아니라 순위판을 고친다.

랭킹의 매체 선택·주소는 `explore/ranking/constants.ts`, 연대기의 대륙 분류·페이지 분할은 `components/features/user/explore/sections/TimelineSection/continents.ts`와 `pagination.ts`가 쥔다. 디렉토리는 이름별 인물 링크를 HTML에 싣고 직군별 명부에도 연결한다.

## 도감 용어

「신화의 세계」(`/explore/myth`)와 「세력도감」(`/explore/faction`)은 같은 뼈대의 화면 둘이다. 계층은 세 층이고 층 이름이 곧 스키마 이름이다 — 따로 대응표를 유지하지 않는다.

- **lv1 테마** — 세력도감의 분야(인공지능·산업·권력…), 신화의 지역(한국·그리스·로마…). 화면 첫 칩 줄.
- **lv2 세력** — 카드 한 장. 신화 화면에서는 신화(일리아스·서유기), 세력도감에서는 팩션(OpenAI·삼국지). 「신화/팩션」은 같은 층의 화면 표기이고, `is_myth`로 가른다.
- **lv3 그룹** — 세력 안의 인물 묶음(올림포스 신·기초를 놓은 세대).
- **인물** — 세력에 배정된 `celebs` 행. 일반 팩션은 `celeb_reality`를 명단과 인물 소개 모달의 사실·가상 표식으로 보여 준다(`CelebRealityLabel`).
- **숨김**은 인물 배정 단위, **잠금**(`published`)은 세력 단위, **차례**(`sort_order`)는 각 층의 나열 순서다.
- `is_fiction`은 「이야기 속 인물 세력」 표시로 이 계층과 무관하다 — 역사창작 세력도 참이라 화면 소속을 가르는 값으로 쓰지 않는다.
- `신화와 이야기` 뿌리 행은 `is_myth`가 대신하므로 두지 않는다.

스키마는 `faction_lv1`(테마) → `faction_lv2`(세력·신화) → `faction_lv3`(그룹), 인물 연결은 `faction_members`, 읽기는 뷰 `faction_member_rows`다. 이관 경위와 남은 일은 [`docs/todo/faction-schema-migration.md`](../../todo/faction-schema-migration.md)가 쥔다.

## 신화 (`/explore/myth`)

**신화 탐색판**은 `/explore/myth`에서 표시한다. 신화·일반 팩션은 `세 단계 선택·대표 이미지 → 인물 격자 → 작품 선반` 순서로 같은 화면을 쓴다. PC는 왼쪽 L1·L2·L3와 개요·선택기 조작만 윤곽선 안에 묶고, 오른쪽 대표 이미지는 별도 바깥 상자나 패딩 없이 열 너비를 채운다. 선택 영역의 실제 높이에 이미지 열을 맞춰 위아래 끝을 일치시킨다. 모바일은 선택 영역 아래에 대표 이미지를 별도 행으로 놓고 전체 구도를 보여 준다. PC는 각 줄에서 종류(지역·신화·그룹 등)와 선택값을 두 행으로 표시하고 그 높이에 맞춰 이미지를 넓힌다. 모바일은 종류 이름을 생략하고 선택값 옆에 개수를 표시한다. 지역·테마 수는 전체에서, 신화·팩션 수는 선택한 지역·테마에서, 그룹 수는 선택한 신화·팩션에서 현재 고를 수 있는 항목만 센다. 「전체 구성원」은 그룹 수에서 제외한다. 전체 수는 중성색, 하위 수는 금색으로 구분한다. 이름은 중앙 정렬하고 양옆 화살표로 같은 단계의 이전·다음 항목을 고른다. 각 행의 이름을 누르면 해당 단계의 칩만 담은 창이 열리고 선택 즉시 적용해 닫는다. 「선택기」 버튼은 전체 계층을 담은 창을 연다. PC에서는 세 열을 함께 보고, 모바일에서는 선택한 윗단계의 이름을 남긴 채 다음 목록을 펼친다. 상위 선택을 바꾸면 하위 목록도 바뀐다. 그룹을 누르면 즉시 적용하고 창을 닫으며, 현재 선택을 그대로 적용하려면 「선택 완료」를 누른다. 적용하지 않고 창을 닫으면 기존 선택을 유지한다. 각 목록은 휠·터치와 마우스 드래그로 스크롤한다. 세로 드래그도 공용 `useMouseDragScroll("y")`를 쓰며, 끈 직후 클릭은 차단한다. 모양과 주소 키는 `atlasNavigationData.ts`, 선택 패널의 배치는 `mythLayout.ts`가 쥔다.

대표 이미지의 미리보기는 PC에서 선택 영역과 같은 높이를 채우고, 모바일에서는 독립된 이미지 영역을 쓴다. 확대 창에서는 원본 전체 구도를 보여 준다. 이미지 주위에 별도 패딩을 두지 않는다. 기본 화면과 이미지 확대 창에서 원본 우하단의 비워 둔 영역에 선택한 세력·신화 이름을 큰 글씨로 오른쪽 정렬해 표시한다. 이미지는 어두운 덮개 없이 표시하고 호버 시 안쪽 그림이 확대된다. 이미지를 누르면 확대 창을 연다. 세 줄 선택 영역 아래 「선택기」 옆의 별도 「팩션 개요」(신화 화면은 「신화 개요」) 버튼에는 창 모양 아이콘을 붙이고 설명 모달을 연다.

그룹은 `faction_lv3`가 쥐고 뷰 `faction_member_rows.group_name`으로 읽는다. 그룹이 둘 미만이면 세 번째 줄은 「전체 구성원」으로 두고 화살표를 끈다. 그룹이 없는 인물은 맨 끝 「그 외」로 모인다. 구성원은 모두 펼치고 얼굴 아래에 이름과 인물의 정식 타이틀(`celebs.title`·`title_en`)을 중앙 정렬한다. 카드 타이틀의 줄 수 제한은 `MythPersonPicker`가 쥐며, 빈 타이틀을 등장 설명·bio로 대체하지 않는다. 실존 인물의 「사실」 배지는 생략하고 허구·혼합 구분은 유지한다. 전체 타이틀과 `faction_member_rows.short_desc`의 등장 설명, 관련 작품, 소개·읽어보기는 인물 소개 모달에서 읽는다. 모달은 아바타·이름·상세 버튼을 머리말로 묶고 설명은 아래 전체 폭에 둔다. 신화 인물의 본문은 읽기 안내를 우선하고 없으면 bio를 쓴다. 인물 모달의 참고도서는 인물 상세와 같은 순서인 등장·감상·집필로 나누고, 자료가 있는 갈래만 표시한다. 작품·판본 선택기와 감상 선반을 그대로 공유하며, 감상 도서는 같은 첫 묶음과 더 보기로 이어 받는다. 관계 정보는 조회하거나 렌더하지 않는다.

개요 전문은 PC·모바일 모두 공용 읽기 모달에서 연다. `faction_lv2.description`·`description_en`의 문단과 작품명·인용 강조를 보존하고, 모달 안에 인원·작품 수와 낭독 조작·재생 문장 강조·문장부터 재생·자동 스크롤을 둔다. 낭독 자료는 선택된 팩션에서 미리 확인하고, 음원이 있으면 개요 버튼 옆에 재생·정지 단추를 둔다. 바깥 단추와 모달은 같은 재생기를 공유하므로 모달을 열고 닫아도 재생 위치를 유지한다. 속도·탐색 등 상세 조작은 모달에 두며, 다른 팩션으로 이동하면 음원을 해제한다. 대표 그림이 여러 장이면 별도 이미지 확대 창에서 넘겨 볼 수 있다. 타이틀 원본 PNG는 R2에 보존하고 `MythTitleImage`가 실제 이미지 칸의 폭·배율에 맞는 WebP를 `/api/myth-title/`에서 요청한다. 서버는 R2 원본에서 필요한 크기를 만들고 캐시한다. 크기·품질은 공유 `responsive-artwork.ts`가 쥔다. 확대 창에서 그림 설명이 있으면 이미지 아래에 가로 중앙 정렬로 표시한다. 그림 안 우하단의 제목과 설명은 겹치지 않는다. 확대 창은 원본을 자르지 않고 보여 주며, 공용 BlurDissolve의 animateOnMount로 그림이 준비된 뒤 흐림이 풀리는 효과를 재생한다. 다시 열거나 그림을 넘길 때도 재생하고, 움직임 최소화 설정에서는 생략한다.

**신화 편성 기준** — L1은 탐색할 지역·문화권, L2는 고유한 소개와 대표 그림이 성립하는 전승·서사, L3는 그 전승 안의 인물 집단이다. 같은 대륙에 있다는 이유로 별개 전승을 한 L2에 합치지 않는다. 인물이 적은 전승은 L3 없이 보여 주며, 각 층의 개수를 맞추려고 전승을 섞거나 한 사람씩 그룹을 만들지 않는다. 전승을 분리할 때 기존 그림은 그 장면이 속한 전승에만 남기고, 맞는 그림이 없는 전승에는 다른 문화의 그림을 복사하지 않는다.

**신화 그룹 기준** — 인물이 크게 늘어도 같은 기준으로 넣을 수 있게 전승마다 축 하나로 가른다. 이름은 짧고 익숙하게 짓되 작품·서사의 기존 명칭은 보존한다. 순수 신화에는 ‘신화’를 쓰고, ‘건국 신화’는 ‘건국’으로 줄인다. 지역별 이야기 묶음은 ‘베트남 전승·하와이 전승’처럼 맞춘다. ‘왕통’ 같은 낯선 말과 설명식 수식을 걷되 ‘삼장 일행·박씨 왕가’처럼 이해를 돕는 말은 살린다. 영상 시절의 문학적 이름(「천 척의 배를 이끈」 따위)은 쓰지 않는다(`docs/project/platform/code-rules.md` 「명칭 규칙」). 명단에는 그 작품에 실제로 나오는 인물만 둔다 — 영상 편에 함께 나왔어도 다른 작품 인물은 뺀다(시논은 『아이네이스』, 펜테실레이아·멤논은 『아이티오피스』). 그룹을 사용하는 전승은 아바타를 기다리며 숨긴 인물에게도 그룹을 미리 준다. 그룹 이름과 구성원은 DB가 원천이라 여기 옮겨 적지 않는다.

**그룹 개요** — 처음에는 「전체 구성원」을 보이고, 그룹을 고르면 인물·작품만 해당 그룹으로 좁힌다. 선택 창에서 고른 그룹을 다시 누르거나 「전체 구성원」을 고르면 선택이 풀린다. 별도 × 표시는 두지 않는다. 그룹 선택은 주소의 `group` 값으로 복원한다. 대표 이미지와 전체 개요는 그룹을 골라도 그대로 남는다. 그룹 설명이 있으면 인물 목록 머리의 「그룹 개요」 버튼으로 읽기 모달을 연다. 그룹 설명은 `faction_lv3.description`·`description_en`이 원천이고 백오피스 「신화 편집」(`/myths`)의 그룹 칸에서 고친다. 이 무리가 누구이고 작품에서 무슨 일을 하는지 원전에 근거해 두세 문장으로 쓰고, 명단에 있는 인물을 되도록 설명 안에서 부른다. 숨긴 인물만 있는 그룹은 인물이 공개될 때 쓴다.

**인물 상세 이미지** — 신화·일반 팩션 모두 `FactionPersonHeader`의 아바타 중심 머리말을 쓴다. 기본 이미지는 목록보다 조금 큰 아바타이며 얼굴 본체와 확대 아이콘을 누르면 원본 아바타를 연다. 인사 음성은 별도 음성 버튼으로 재생한다. 별도 화보가 있을 때만 가상독백·인물 상세 버튼 옆에 「상세 이미지」를 둔다. 화보는 해당 세력·전승의 개인샷(`faction_members.image_url`)을 먼저 쓰고, 없으면 인물 대표 사진(`celebs.portrait_url`)을 쓴다. 선택 규칙은 `mythLeadImage.ts`, 이미지 확대 창은 `FactionArtworkViewer`가 쥐며 그림을 다시 누르면 닫힌다. 세 가지 상세 조작은 어두운 배경·밝은 글자로 표시한다. 같은 인물도 전승별 개인샷이 있으면 각 전승에 맞는 사진을 연다.

**공개 범위** — 로컬과 운영 모두 `faction_lv2.published`가 참인 전승만 연다. 하나라도 열린 전승이 있는 지역만 지역 줄에 나타나고, 그 지역의 닫힌 전승은 「작업 예정」 칩으로 남는다. `getMythClientData`는 닫힌 전승의 인물·그룹·작품 상세를 클라이언트에 넘기지 않는다. 제목 이미지와 아바타는 DB에 등록된 R2 URL을 읽는다.

| 전승 | 가르는 축 |
|---|---|
| 일리아스 | 진영과 역할. 신은 20권 신들의 전투에서 편을 가른 대로 그리스 편·트로이 편으로 나누고, 제우스와 전령은 따로 둔다 |
| 그리스 신화 | 존재의 종류와 세대(태초·티탄·올림포스·저승·그 밖의 신·영웅) |
| 그리스 건국 | 인간 시조와 후손을 도시·민족별로 가른다 |
| 오디세이아 | 오디세우스와의 관계(동료·가족·충직한 사람·구혼자·신과 요정·여정에서 만난 이·망령·파이아케스·필로스와 스파르타) |

나머지 전승도 같은 방식으로 축을 먼저 정하고 그룹을 짠다.

## 세력도감 (`/explore/faction`, `/explore/faction/[slug]`)

신화의 선택기·인물 격자·개요·그룹 개요를 함께 쓴다. FactionScreen이 주소와 자료를 준비하고 `lib/faction-theme.ts`가 공용 MythScreen의 입력으로 바꾼다. 신화의 기존 이미지와 탐색 흐름은 유지한다. 명단은 getFeaturedFactions(신화 갈래·숨긴 배정 제외), 섹션·진영 구성은 `lib/faction-sections.ts`가 쥔다.

- 배치와 개요·그룹 모달은 위 「신화 탐색판」의 공용 규칙을 따른다. 화살표로 테마를 이동하면 그룹을 초기화하고, 선택기 창에서 함께 고른 그룹은 이동 후에도 유지한다.
- 세 줄 선택기는 `AtlasNavigation`, 선택기 창은 `AtlasPicker`를 공유한다. `FactionScreen`은 전체 선택 계층의 이름·인원만 넘기고, 다른 팩션의 인물·작품은 적용 후 `/explore/faction/<slug>`에서 받는다. `/explore/faction?section=<묶음 slug>` 진입과 기존 리다이렉트는 유지하며, 없거나 닫힌 테마는 notFound다.
- **테마 이미지**는 `lib/faction-theme.ts`의 slug 대응표와 `public/images/factions/themes/` 파일을 쓴다. 기존 단체화보를 자동으로 대표 이미지로 쓰지 않는다. 이미지가 없거나 로드에 실패해도 별도의 개요 버튼으로 설명 모달을 열 수 있다. 로딩 화면도 같은 배치와 이미지 유무를 따른다. 개별 최종 발주서와 선정 원본은 [`data/faction-theme-art/`](../../../data/faction-theme-art/)에 둔다.
- 인물을 고르면 소개 모달을 연다(FactionMemberModal). 아바타 확대·인사 음성, 테마·진영, 이름·직함, 역할(short_desc), 긴 소개(getFactionLongDescs), 인물 페이지 링크와 인물 상세 기준의 「등장 / 감상 / 집필」 탭을 유지한다. PC·모바일 모두 모달을 열고 닫을 때 배경 목록·책장과 스크롤 위치를 유지하며, 닫으면 선택했던 카드로 키보드 포커스를 돌려준다. 신화도 같은 동작을 쓴다. 인물 페이지의 소속 세력에서는 같은 소개를 여전히 모달로 연다.
- 책은 공용 AffiliateBookList로 표시하고, 영문 화면은 판매 주소가 걸린 책만 싣는다. 인물 목록 아래에는 현재 인물 범위에 해당하는 작품을 보여 준다. 인물 자료는 getCelebs 조회 후 공개 명단에 든 사람만 남긴다(`lib/faction-celebs.ts`).
- 테마 주소는 메타 설명에 테마 소개를, 구조화 데이터(JSON-LD CollectionPage·ItemList)에 구성원 이름·역할·인물 주소를 싣는다.

**테마·그룹의 운영 규격은 여기서 복제하지 않는다.** 계층의 단일원천(`faction_lv2.lv1_id`)과 편집 규격은 `docs/project/apps/web-bo.md` 「세력도감」이 쥔다.

## 영상관 — 내려 둠

서재 탐방 형태를 바꾸는 동안 웹의 영상 노출(홈 영상관 배너, `/explore/youtube`, 인물 상세 미디어의 영상 탭)을 걷었다. `/explore/youtube`는 탐색으로 임시 리다이렉트한다(`next.config.ts`). 되살릴 때는 이 리다이렉트를 지우고 코드를 커밋 이력에서 꺼낸다. `celebs.youtube_videos` 값과 유튜브 채널 링크(푸터·구조화 데이터)는 그대로 둔다.
