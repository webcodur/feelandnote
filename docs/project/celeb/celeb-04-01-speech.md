# Speech

`speech_tone`, 검증된 한마디, 상황 대사의 작성·검수 규칙을 쥔다. 대상 선별부터 반영까지의 명령은 [`celeb-04-02-speech-pipeline.md`](celeb-04-02-speech-pipeline.md), 대사 음원은 `celeb-dialogue-voice-publish` 스킬이 맡는다.

```text
기본 프로필 → 최소 조사 → speech_tone → 한마디 → 상황 대사 → 검증·반영
```

## SSoT와 저장 위치

| 값 | 저장·규약 |
|---|---|
| 말투 허용값·표시명 | `packages/shared/src/constants/celeb-speech.ts`의 `CELEB_SPEECH_TONES`, `CELEB_SPEECH_TONE_LABELS_KO` |
| 한마디 | `celeb_dialogues.lines.quote`, `lines_en.quote` |
| 상황 대사 | `celeb_dialogues.lines`, `lines_en`의 문자열 배열 |
| 상황 키·변형 번호 | `packages/shared/src/constants/celeb-speech.ts`의 `CELEB_DIALOGUE_SITUATIONS`, `CELEB_DIALOGUE_VARIANTS` |
| 길이 상한·자료 희박 표준값 | `sw/web-bo/scripts/lib/celeb-speech-research.ts` |
| 조사 묶음과 반영 계약 | 같은 파일의 `SpeechResearch`, `validateSpeechResearch` |

`celebs.quotes`와 `celebs.quotes_en` 컬럼은 없다. 한마디는 다른 대사 키를 보존하는 `set_celeb_quote` RPC로 한영을 함께 갱신한다. 상황 배열의 원소는 항상 문자열이며 `{ text, quote }` 같은 객체를 넣지 않는다.

기존 한마디를 검수 범위 밖에 둔 채 상황 대사만 `REVISE`할 때는 `quoteOutcome='preserved'`를 사용한다. 패치의 한영 한마디는 현재값과 같아야 하고, 기존 영문 한마디가 없으면 새로 만들지 않는다. 이 값은 한마디가 검증됐다는 판정이 아니다.

## 최소 조사

프로필만 보고 한마디와 대사를 만들지 않는다. 인물마다 다음을 한 묶음으로 확보하고, 코드가 요구하는 최소 개수는 `validateSpeechResearch`를 그대로 따른다.

- 이름·소속·시대·작품 속 역할을 확인한 신원 근거
- 대표 활동·사건·선택·관계와 각 출처
- 원문, 원문 언어, 한영 대응, 직접 출처를 갖춘 실제 발화 표본
- 그 인물의 어휘·판단 습관·갈등 방식을 대사로 옮길 고유 앵커
- 실제 본문을 열어 무엇을 확인했는지 적은 출처 기록과 검색 경로

실존 인물은 공식 인터뷰·연설·저서·서한·본인 계정을 우선한다. 기자의 요약, 타인의 발언, 검색 스니펫, 명언 모음 사이트 단독 근거를 본인 발언으로 쓰지 않는다. 한국어 또는 영어 원문은 해당 언어의 한마디 필드에서 어순·종결·내용을 다듬지 않는다. 허구 인물은 연결된 원전의 직접화법과 위치를 확인하고 후대 각색을 섞지 않는다.

직접 발언을 끝내 찾지 못했을 때만 `quoteOutcome='unavailable'`을 사용한다. 필요한 검색 경로·출처 수와 한영 표준값은 검사 코드가 강제하므로 문구를 새로 만들지 않는다. 이 판정은 조사를 마쳤다는 뜻이지 빈칸을 메우는 수단이 아니다. 대표 정보가 충분하면 한마디가 없어도 상황 대사는 작성할 수 있다.

기존 대사가 있는 인물도 같은 조사를 거친다.

- `KEEP`: 사실·말투·상황·고유성이 모두 맞아 기존 대사를 보존한다.
- `REVISE`: 틀린 사실, 동명이인 혼입, 범용 문구, 상황·말투 불일치가 있어 완성본을 교체한다.
- `CREATE`: 표준 상황 대사가 없어 새로 만든다.

## speech_tone

직군은 후보를 좁히는 보조 근거이고 실제 발화가 우선한다.

| 값 | 중심 호흡 |
|---|---|
| `bold` | 단언·선언·명령 |
| `composed` | 절제·관조 |
| `gentle` | 부드럽고 따뜻한 구어 |
| `free` | 격식에 덜 얽힌 거침없는 구어 |
| `humble` | 겸양 |
| `loyal` | 의무·사명 |

톤은 모든 문장을 같은 종결어미로 찍는 템플릿이 아니다. 발화 표본과 인물의 시대·관계·상황에 맞춰 같은 중심 호흡 안에서 변주한다.

## 한마디

한마디는 그 사람이 실제로 한 검증 가능한 발언 한 문장이다. 표시 길이는 코드 상한을 지키며 따옴표로 감싸지 않는다. 번역은 원뜻과 말투를 보존하고, 원문이 이미 영어라면 한국어를 거쳐 다시 번역하지 않는다.

허용하는 근거는 본인의 인터뷰·연설·기자회견·저서·서한·공식 계정과 신뢰할 수 있는 기록의 직접 발언이다. 출연작 캐릭터 대사, 노래 가사, 타인의 평가를 본인 말로 쓰지 않는다. 문학가의 본인 작품 구절은 작품명과 위치를 확인한 경우에만 사용할 수 있다.

다음은 교체 대상이다.

- 비어 있거나 여러 문장을 이어 붙인 값
- 다른 사람에게서 잘못 귀속된 말
- 출처를 찾을 수 없는 창작형 명언
- 인물과 무관한 슬로건·자기계발 문구
- 원문 의미나 speech_tone을 바꾼 번역

## 상황 대사

모든 인물은 생몰 연대와 무관하게 `SPEECH_SITUATIONS`가 정한 한국어 상황 대사 전체를 가진다. full·light의 영문 대사는 한국어와 같은 상황·의미를 갖추며, fiction 영문 대사는 요청 범위에 포함될 때 작성한다.

| 상황 | 대사의 역할 |
|---|---|
| `greeting` | 인물을 만났을 때의 대표 호흡 |
| `roll_call` | 등장·호명에 대한 짧은 응답 |
| `deploy` | 당장 실행할 결단·지시 |
| `battle_win` | 승리에 대한 반응 |
| `battle_draw` | 무승부에 대한 반응 |
| `battle_lose` | 패배에 대한 반응 |
| `clash_attack` | 돌격·기합·도발처럼 가장 짧은 충돌 발화 |

대사는 평전이 아니라 화면에서 한 번 튀어나오는 반응이다. 조사 사실을 모두 설명하지 말고 그 사실에서 드러난 선택과 호흡만 남긴다.

- 이름과 고유명사를 지우면 같은 직군 누구에게나 붙는 문장은 실패다.
- 상황 라벨을 서로 바꿔도 어색하지 않으면 상황 반응이 아니다.
- 업적·연대·수상 목록을 한 문장에 압축하지 않는다.
- commander 외 인물은 기본적으로 존댓말을 쓰되 `deploy`와 `clash_attack`은 짧은 명령형을 허용한다.
- 한국어는 [`../production/writing-rules.md`](../production/writing-rules.md)를 따른다. 사물 주어·번역 관용구·부자연스러운 도치를 피하고 소리 내어 읽는다.
- 기존 ELE 발화 지시 태그는 보존하지만 AI가 새로 만들거나 바꾸거나 지우지 않는다. 음성용 별도 지시는 음원 제작 규칙이 맡는다.

## 검수

기계 검사는 구조·빈값·상한·중복·금지 태그와 조사 묶음을 확인한다. 사람은 다음을 별도로 본다.

1. 발화자와 인물 신원이 맞는가.
2. 한마디가 실제 직접 발언이며 한영이 같은 발언인가.
3. 각 대사가 해당 상황에서 실제로 입 밖에 낼 수 있는 한 호흡인가.
4. 고유명사를 억지로 넣지 않아도 인물의 판단 방식이 들리는가.
5. 기존 태그와 다른 JSON 키를 보존했는가.

반영 패치는 현재 `lines` 해시와 고정한 slug 명단을 사용한다. 조회 순서나 offset을 작업 소유권으로 쓰지 않고, 반영 뒤 `lines`·`lines_en`을 다시 읽어 예상한 키와 문자열이 보존됐는지 확인한다.
