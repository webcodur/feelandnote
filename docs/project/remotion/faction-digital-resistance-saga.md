# 세력도 「디지털 레지스탕스」 — 탈중앙 일대기 확장 (확정 기획서)

기존 4세력(14인)에서 2013년경 멈춘 서사를 **2026년 현재까지** 잇는 확장 기획. 8개 조사 축(웹 조사, 약 64인 발굴)에서 **대중 인지선(도구 또는 서사가 대중에게 닿는가)**을 통과한 인물만 추려 확정했다.

## 확정 원칙 (대화로 합의됨)

1. **기존 4세력 동결** — 색·단체 사진·개인샷·음성 전부 보존. 재편·유실 없음.
2. **과거→현대 연장** — 신규 인물은 기존 세력의 **새 장면(그룹)**으로 붙이거나 신설 세력으로. 기존 장면은 안 건드리니 **재촬영 0**.
3. **대중 인지선 = 도구 또는 서사** — 인물 이름 유명세가 아니라, 그가 만든 도구(텔레그램·Tor·Sci-Hub 등)나 그의 이야기(체포·처형·전장)가 대중에게 닿으면 채택. 셋 다 없는 인물(주드 미혼·매트 블레이즈·가오자량 등)은 컷.
4. **백과사전화 금지** — 계보 완결성을 위한 무명 인물 채우기 금지. 원류(암호학자) 세력 신설 취소.
5. **두로프는 단독 엔딩** — 폭로자가 아니라 "국가와 홀로 맞선 자". 세력에 안 섞고 40년 계보의 마지막 단독 컷.

## 신규 인물 마스터 (13인)

발언은 조사 단계에서 확보한 출처. 편입 확정 후 person-quote-mining으로 자막용 verbatim 최종 채굴.

### 세력2 「익명의 돈」 — 비트코인 → 추적 없는 돈
- **주코 윌콕스오헌** / Zooko Wilcox-O'Hearn / 미국 — Zcash 창립. **차움의 DigiCash에서 실제 근무한 직계 사제**. 얼굴 공개. 발언: hackernoon.com privacy-and-zcash.
- **리카르도 스파니** / Riccardo Spagni (fluffypony) / 남아공 — Monero 전 리드. '익명 화폐의 얼굴'이 2021 체포·대륙 간 인도. 얼굴 공개. 발언: forbes.com 2019.
- **아미르 타키** / Amir Taaki / 영국-이란계 — 다크월렛. 비트코인 코더가 시리아 로자바에서 ISIS와 교전, 귀국 후 테러법 조사. 얼굴 공개. 발언 verbatim 재채굴 필요.

### 세력3 「파일 해방」 — 코드 해방 → 파일 해방
- **숀 패닝** / Shawn Fanning / 미국 — 냅스터(19세). 법정에 메탈리카 티셔츠 입고 출석. 얼굴 공개(Time 표지). 서사 위주(어록 빈약).
- **브람 코헨** / Bram Cohen / 미국 — 비트토렌트. "사업이 아니라 혁명을 시작할 계획이었다". 사이퍼펑크 출신. 얼굴 공개. 발언: medium 인터뷰.
- **카네코 이사무** / 金子勇 / 일본 — Winny. "코드를 짰다고 체포된 남자", 7년 반 재판 무죄 2년 뒤 별세. 2023 영화화. 얼굴 공개. 발언: ja.wikipedia·WIRED.jp.

### 세력4 「지식 해방」 — 폭로 → 지식 해방
- **알렉산드라 엘바키얀** / Alexandra Elbakyan / Александра Элбакян / 카자흐→러시아 — Sci-Hub '과학의 로빈후드'. 엘제비어 소송·FBI 수사, 스노든 옹호. 얼굴 공개. 발언: lefteast 인터뷰.
- **바셀 카르타빌** / Bassel Khartabil / باسل خرطبيل / 시리아 — CC 시리아·팔미라 3D 복원. 2012 아사드 정권 연행 → 2017 처형 확인. 슈워츠와 짝을 이루는 순교 정점. #FREEBASSEL 초상 유포. 발언: "Jail is not walls… it is the hidden fear in our hearts".
- **브루스터 케일** / Brewster Kahle / 미국 — 인터넷 아카이브·웨이백머신. 출판사 연합 소송(2023~24 패소). 얼굴 공개. 발언: archive.org 블로그.

### 세력5 「프라이버시 최전선」 — 감시를 뚫는 오늘의 도구 (신설)
- **로저 딩글다인** / Roger Dingledine / 미국 — Tor. **차움 믹스넷의 직계 구현**. NSA 최우선 표적('Tor Stinks'). 얼굴 공개. 발언: technical.ly 2017.
- **목시 말린스파이크** / Moxie Marlinspike (본명 Matthew Rosenfeld) / 미국 — 시그널. 짐머만 PGP의 완성. FBI 소환장에 넘길 데이터가 없었던 설계. 항해하는 아나키스트. 얼굴 공개. 발언: moxie.org 에세이.
- **clowwindy** / 익명(중국) — Shadowsocks(만리방화벽 우회 표준). 2015 상하이 경찰이 GitHub 코드 전량 삭제 강요. **익명 → 종이비행기 로고·실루엣 대체.** 발언: GitHub issue #124 "…live in a country where I have freedom to write any code I like without fearing".

### 엔딩 단독 「국가와 홀로 맞선 자」
- **파벨 두로프** / Pavel Durov / Павел Дуров / 러시아→UAE·프랑스 — 텔레그램. 크렘린 데이터 요구 거부→망명, 2024 프랑스 체포·12개 혐의. 어산지·스노든 박해의 2024년 반복. 매우 시네마틱한 얼굴. 발언: "I would rather be free than to take orders from anyone" (Tucker Carlson, 2024). ※체포 혐의는 사실대로, 미화 주의.

## 진행 단계

1. ✅ **골격 확정** — 세력·그룹·인물 배치 (본 문서)
2. **세력5 이름·색 확정** — 「프라이버시 최전선」 후보명, 신규 세력색 (최종: 적색 #e10600. 엔딩 단독은 텔레그램 공식 블루 #0088cc)
3. **신규 13인 셀럽 DB 등록 + 아바타** — 티어 분류(light/relation), 익명은 로고·상징 대체
4. **인물 이력(lines)·대사(quote) 작성** — faction.md 「인물 문구 작성 원칙」 준수, person-quote-mining
5. **faction-data.json 반영** — 세력·그룹·인물 스캐폴딩 (텍스트 먼저, 이미지·음성 나중)
6. **개인샷·그룹샷 발주** (유료, 사전 승인) → 렌더
