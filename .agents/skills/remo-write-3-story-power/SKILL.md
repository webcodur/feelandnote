# 스토리 힘 검토

반드시 다음을 읽는다.

- `docs/project/remotion/book-recommend/writer/3-story-power.md`
- SOLO면 `docs/project/remotion/book-recommend/solo.md`

## 작업 순서

1. `remo-write-story-dump`로 Markdown 원고를 뽑아 처음부터 끝까지 읽는다.
2. 책마다 중심 사건, 인물의 선택, 대가, 감정 변화, 마지막 회수를 한 줄씩 적는다.
3. 사실로 고칠 문제와 취향에 불과한 문제를 나눈다.
4. 이미 강한 장면은 보호하고, 약한 곳만 고친다.
5. 텍스트 확정 뒤 JSON에 반영한다.

점수는 비교를 돕는 메모일 뿐 합격 조건이 아니다. 자료가 허용하지 않는 인과관계나 감정을 만들어 점수를 올리지 않는다. 태생적 한계가 남으면 한계와 이유를 보고한다.
