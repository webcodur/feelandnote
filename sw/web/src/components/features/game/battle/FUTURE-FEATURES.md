# 패권 게임 — 추후 개발 예정 기능

## 승부수 (Double Down)

**상태: 추후 개발 예정**

### 개요

대전 관전 중 특정 라운드에 "승부수"를 걸어 획득 점수를 2배로 만드는 시스템. 패배 시에도 상대에게 2배 점수가 부여되므로 고위험·고수익 선택이다.

### 규칙

- 6라운드 중 **1회만** 사용 가능
- 카드 공개 **전**에 선언해야 함 (공개 후 불가)
- 해당 라운드 승리 시: 획득 점수 ×2
- 해당 라운드 패배 시: 상대 획득 점수 ×2
- AI도 독자적으로 승부수를 사용할 수 있음

### UI 설계 방향

- 각 라운드 시작 시 "승부수" 버튼 표시 (미사용 상태일 때만)
- 사용 시 화면 연출: 불꽃/강조 이펙트
- 사용 여부를 라운드 결과에 표시

### 구현 포인트

- `GameState`에 `playerDoubleDown: number | null` (사용한 라운드), `aiDoubleDown: number | null` 추가
- `resolveRound`에서 doubleDown 적용 시 `pointsAwarded` 2배 처리
- AI 승부수 판단: 자신의 배치 전투력이 상대 추정보다 압도적일 때 사용 (dominate 전략 + 점수차 열세)
- `BattlePhase`에 승부수 버튼 + 사용 연출 추가
