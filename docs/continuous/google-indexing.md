# 검색엔진 색인·수집 신청

**현재 도달점:** 공개 인물 6,626명의 한영 13,252주소와 주요 페이지 994주소가 사이트맵에 있다. 오늘 등록 13명이 빠져 있던 인물 사이트맵 캐시를 해당 경로만 갱신했고, 운영 응답에서 전원 등재를 확인했다. 10월 8일 이후 신규 공개 인물 739명의 한영 1,478주소를 IndexNow 공용 접수로 통지해 HTTP 200을 받았다. Google은 전체·인물 사이트맵을 다시 읽어 14,246·13,252주소를 확인했으며 오류·경고는 모두 0이다.

**엔진별 마지막 작업:** 아래 일시는 실행 기록에서 확인한 신청 묶음의 마지막 결과 확인 시각이며 모두 한국시간(KST, UTC+9)이다. 재개 시 먼저 이 표의 일시·한도 결과를 확인한다. 기록 교체 규칙은 [지속 과제](README.md)가 쥔다.

접수는 실제 재크롤·색인·대표사진 반영 완료를 뜻하지 않는다.

마지막 실제 검색 확인에서 네이버 「필앤노트 빌 게이츠」는 인물 상세 대신 탐색 페이지와 책 페이지를 먼저 보여 줬다. Google의 빌 게이츠·다리오 아모데이·젠슨 황 상세는 색인됐고, 빌 게이츠 저장 HTML에는 최신 제목과 대표사진이 있었다. 새 배포 뒤 검색 결과의 설명·사진 반영은 다시 확인해야 한다.

**다음 착수는 신규 인물 상세의 실제 검색 반영 확인이다.** Google URL Inspection에서 황현희는 「제출되고 색인이 생성되었습니다」이고 마지막 크롤은 10월 14일 19:42:42 KST다. 블레이크 라이블리는 사이트맵에서 발견됐지만 아직 색인이 생성되지 않았다. Daum 최근 색인문서에는 오늘 등록한 샤론 스톤·갤 가돗·리타 헤이워스·밀라 쿠니스·미셸 파이퍼·캐서린 랭퍼드·잉그리드 버그만·엘리자베스 올슨·캐서린 제타 존스·에바 가드너가 표시됐다. 사이트맵·브랜드·설명문 규칙은 [SEO](../project/operations/ops-02-seo.md)가 쥔다.

다음 일일 작업은 아래 순서로 진행한다.

1. 빌 게이츠·다리오 아모데이·젠슨 황의 실제 검색 결과에서 상세 주소·최신 제목·설명·대표사진을 확인한다. 아바타를 쓰는 경우 승인된 원래 황갈색 배경도 확인한다. 현재 운영 응답, 검색엔진 저장 문서, 실제 검색 결과를 대조해 메타를 이미 읽은 경우와 아직 재수집되지 않은 경우를 구분한다.
2. 네이버는 아래 미접수 주요 인물부터 이어서 실제 일일 한도까지 신청한다. 나머지 주요 인물 다음에 미접수 직군 명부와 허브를 신청한다.
3. Google은 미접수 신규 인물 `/celeb/eric-rohmer`부터 이어간다. 이미 최신 변경이 반영된 주소를 반복 신청하지 않는다. 수정·배포로 새로 달라진 주소는 운영 반영을 확인한 뒤 신청한다.
4. 셀럽 상세를 우선 처리한 뒤 세력 상세를 이어간다. 해리스 프리커와 의도적 noindex 작품은 후속 신청에서 제외한다.
5. 다음(Daum)은 최근 신규 인물 50명의 개별 수집과 RSS·사이트맵 Seed를 접수했다. 실제 검색 제목·설명·대표사진 반영을 확인한다. 사이트 검색에 남은 `Feel&Note`·HTTP 등록 변경은 최초 신청자 확인이 남았다.

Daum 리스트 Seed는 메인·탐색·인물 명부와 직군 명부 `leader`·`politician`·`commander`·`entrepreneur`·`investor`, 총 8개를 접수한 상태다. 기존 접수 주소는 반복 신청하지 않는다. 추가 Seed는 `scientist`부터 남은 직군 명부와 세력·신화·기관 선정 첫 목록을 이어간다. 공식 안내에서 고정 요청 한도는 확인하지 못했다.

네이버의 다음 신청은 **`/celeb/charles-darwin` → `/celeb/abraham-lincoln` → `/celeb/barack-obama`**다. 이후 아직 접수하지 못한 주요 인물은 넬슨 만델라·마하트마 간디·윈스턴 처칠·나폴레옹·리콴유·이순신·아리스토텔레스·니체·칸트·괴테·조지 오웰·스티븐 스필버그·쿠엔틴 타란티노·미야자키 하야오·송강호·테일러 스위프트·마이클 잭슨·폴 매카트니·프레디 머큐리·마이클 조던·르브론 제임스·리오넬 메시·크리스티아누 호날두·손흥민·김연아·로저 페더러다. 주요 인물 뒤에는 미접수 명부(`/explore/directory/politician`, `/explore/directory/director`, `/explore/directory/musician`, `/explore/directory/actor`)와 `/explore/faction`, `/explore/myth`를 이어간다.

신청 전에 운영 응답·자기 canonical·검색 허용과 기존 접수 내역을 확인한다. 대표 디렉토리만 신청하고 상세 주소가 모두 처리됐다고 간주하지 않는다. 같은 날 이미 접수한 주소, 영구 이동하는 옛 주소, 비공개·의도적 noindex 주소는 신청 대상에서 뺀다. 인물 주소는 현재 공개 사이트맵에서 확인하며 이름으로 slug를 추측하지 않는다.

## 신청과 반영 확인

- 사용자의 지시에 따라 로그인된 **Chrome 확장**으로 Google Search Console과 네이버 Search Advisor를 조작한다. 기존 로그인 계정을 유지한다.
- Google은 URL 검사 화면의 대상 주소가 신청하려는 주소와 일치한 뒤 「색인 생성 요청」을 누르고 결과를 확인한다. 이전 URL의 결과 대화상자를 닫은 뒤 다음 주소로 넘어간다. 접수 후에는 마지막 크롤 시점·색인 상태·저장된 페이지가 최신인지 확인한다.
- 네이버는 「요청 → 웹 페이지 수집」에서 정식 주소를 입력하고, 요청 내역의 실제 링크·등록일로 접수를 확인한다. 목록 갱신이 늦거나 이전 행의 접근성 이름이 남으면 실제 링크와 행 본문을 다시 읽고, 접수 여부를 확인하기 전에 재신청하지 않는다. 신청 뒤 실제 검색 결과의 인물 사진·제목·설명도 확인한다.
- Google의 「할당량 초과」 또는 네이버의 「사이트별 일간 최대 요청 수를 초과하였습니다.」가 뜨면 해당 엔진의 당일 신청을 끝낸다. 다른 주소로 우회해 계속 누르지 않는다. Google 접수 건수는 날마다 달랐으므로 고정 건수를 가정하지 않는다. 네이버는 이번에 50주소 접수 뒤 한도를 확인했다.
- Google의 「색인 생성 요청을 제출하는 중에 문제가 발생했습니다」는 할당량 초과와 구분한다. 해당 주소를 반복 요청하지 않고 다음 주소로 넘어간다. 결과 미확인·조작 실패가 이어지면 원인을 확인한 뒤 재개한다.

이 문서에는 현재 도달점·마지막 접수·한도 문구·다음 신청 대상만 갱신한다. 날짜별 이력이나 URL별 조사 파일을 따로 쌓지 않는다. 사이트맵·IndexNow·메타데이터 운영 규칙은 [SEO](../project/operations/ops-02-seo.md)가 쥔다.
