## 3. 책 (완료 — 남은 일 없음)

허용값 목록에서도 `naver_book`을 빼 다시 들어올 길을 막았다.

- 최종 이전: 네이버 도서 4,019권 → 카카오 3,893권(96.9%)
- 표지 97장은 대체재가 없어 **빈칸으로 뒀다**. 인물 96명의 기록 106건이 표지 없이 뜬다
- 못 옮긴 판본은 한국 유통 이력이 없는 희귀 리프린트·자가출판·비영어권 원서다.
  카카오·OpenLibrary·Goodreads 어디에도 없다(표본 실측)

**표지 확보 경로가 바뀌었다**: 카카오 → OpenLibrary → 표지 없음.

이미 확보한 `i.gr-assets.com` 표지 1,794장은 정상이므로 교체하지 않는다.
