## 1. 음악 데이터 이전 (진행 중)

- 26.08.01 18시 기준 **53곡 이전 완료 / 약 1,464곡 남음.**
- 도구: 세션 스크래치패드의 `reharvest_fast.py music`(1회 1건, 곡당 약 4초). 남은 분량은 한 시간 반가량.
- **미리듣기 음원(`metadata.previewUrl`)이 없는 곡은 옮기지 않는다.** 옮기는 순간 재생이 끊기기 때문이다.
  실제로 한 번 겪었다 — 80곡의 `external_id`를 아이튠즈 번호로 덮어써 재생을 죽였고 백업에서 되돌렸다.
- 이전이 끝나기 전까지 Spotify 곡과 아이튠즈 곡이 섞여 있는 게 정상이다. 재생기가 둘 다 처리한다.

## 2. Spotify 안내 문구 정리 (이전 완료 후)

`sw/web/messages/{ko,en}/content.json`에 아직 남아 있다.
- `contentDetail.spotify.*` — "PC에서 Spotify 로그인하면 전곡 감상" 안내
- `musicPlayer.noticeSpotify` / `noticeSpotifyLogin` / `noticeAgeAction`

**지금 지우면 안 된다.** 아직 1,400여 곡이 Spotify로 재생되고 그 사용자에게는 유효한 안내다.
이전이 끝나 Spotify 곡이 0이 되면 문구와 `SpotifyEmbed` 컴포넌트를 함께 걷는다.

## 3. 책 — 카카오로 못 옮긴 155권

`contents.external_source='naver_book'`으로 남아 있다. 성격이 갈린다.

| 성격 | 권수 | 처리 |
|------|-----:|------|
| 저자 정보가 비어 검증 불가 | 50 | 제목만으로 판본을 바꾸면 엉뚱한 책이 된다. **사람 판단 필요** |
| 리프린트·자가출판 영문본 | 다수 | 어디서도 안 잡힌다. 그대로 두거나 등록 자격 재검토 |
| 정상 영문 원서 | 24 | OpenLibrary로 보강 가능(단 표본 20건 중 메타 7·표지 4로 수확은 낮다) |

표지가 아직 네이버 서버인 것은 100장이다. 네이버가 이미지 서버까지 정리하면 이 100장이 깨진다.

## 4. 표지 정비 도구 (카카오판 미작성)

네이버 전용이던 `scripts/naver-thumb-{verify,refresh,title-search,author-search}.mjs` 4종은 삭제했다.
표지 일괄 점검·갱신이 다시 필요해지면 카카오 기준으로 새로 만든다.
저장된 표지 URL의 생존만 훑는 `scripts/naver-thumb-check.mjs`는 남겨 뒀다 — 네이버 표지 100장 감시용.
