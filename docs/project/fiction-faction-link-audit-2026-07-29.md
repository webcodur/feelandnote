## 적용한 원칙

- 얼굴은 식별·검색·관계 데이터의 선행 조건이 아니다. 아바타가 없는 인물도
  `status=active`, `celeb_tier=fiction` 프로필로 연결한다.
- 원전 검토를 하지 않은 대량 독백은 만들지 않는다. 신규 데이터형 209명의
  `virtual_monologue(_en)`는 null이며, 추후 `fiction-profile-monologue` 트랙에서
  개별 작성한다.
- 같은 존재의 작품별 임시 slug는 정규 slug로 합쳤다. 예:
  `athena-argonaut → athena`, `apollo-oresteia → apollo`,
  `nezha-fengshen → nezha`, `yang-jian → erlang-shen`.
- 실존 당나라 장군 이정과 《봉신연의》의 탁탑천왕 이정은 합치지 않았다.
  후자는 `li-jing-fengshen`으로 분리했다.
- 같은 클러스터에 주문왕과 본명 희창이 두 사람처럼 들어간 중복 1건은 주문왕
  한 행으로 합쳤다.
- 작품 세계 전체와 실제 원전 등장 명단을 같다고 보지 않았다.

## 사용자 화면

- 상단 인물 검색은 `fiction` 티어도 검색한다.
- 실존 인물의 `기록물` 자리는 fiction 인물에게 `원전·등장 작품`으로 보이며,
  대표 판본의 콘텐츠 상세로 이동한다. 콘텐츠 상세에서는 반대로 연결된
  등장인물 목록을 보여준다.
- 같은 기능을 복제하지 않고 fiction 문맥에 맞게 `타임라인 → 서사 연표`,
  `방명록 → 감상록`으로 표시한다. 제목·빈 상태·로그인 안내도 생애·방명록
  문구가 남지 않도록 국·영문을 함께 분기했다.
- 얼굴이 없는 209명은 이니셜 아바타로 표시하며 검색·원전·팩션 연결을 막지
  않는다.

아킬레우스와 브라흐마를 대상으로 KO/EN × desktop/mobile 8개 화면을 렌더해
직접 확인했다. 최종 스크린샷은
`.artifacts/i18n-audit-fiction-final/`에 있다.

## 구조 정리

- 18편을 DB에서 다시 export하고 전편 drift 0을 확인했다.
- 아이디어뱅크에 실행 JSON처럼 남은 비신화 초안 2종은 `draft-data.md`로 바꿔
  기획 자료로 보존했다.
- 아이디어뱅크의 `백기.png`는 활성 편 두 곳의 파일과 SHA-256이 같은 중복본만
  제거했다.
- `Gods-Greek/_docs/fiction-profiles.ko.json`은 일리아스 manifest의 완전 중복이라
  제거했다.
- `world-best-2026`은 보류 문서가 정한 유일한 root-only 편으로 그대로 뒀다.

## 재현

```bash
cd sw/web-bo
node --env-file=.env --import tsx scripts/audit-fiction-faction-links.ts --json
node --env-file=.env --import tsx scripts/sync-faction-fiction-data.ts
node --env-file=.env --import tsx scripts/sync-fiction-source-rosters.ts
node --env-file=.env --import tsx scripts/publish-fiction-faction-data.ts
```

세 sync/publish 스크립트는 기본 dry-run이며 실제 반영은 `--apply`를 붙인다.
원전 roster 교체는 `set_fiction_source_characters` RPC 한 트랜잭션으로 처리한다.

최종 감사에서 다음 값은 모두 0이었다.

- fiction 프로필 미해소
- 잘못된 tier 연결
- fiction 표시가 빠진 팩션 배치
- 태그·배정 누락
- `is_fiction`이 아닌 신화 태그
- 원전 없는 등장인물 목록
- 존재하지 않는 content FK
- 국·영문 locale 누락
- non-fiction 인물의 원전 관계
- DB↔로컬 신화 인물 드리프트
- 아이디어뱅크 실행 JSON·미디어 잔존

코드 검수는 web TypeScript·대상 ESLint·정적 i18n 감사·대표 3명 DB i18n
감사·8개 route 감사·web production build를 모두 통과했다.

이번 배치부터 관계 매니페스트는 현재 5명 안에서만 닫지 않는다. 같은 팩션 명단의

갤러해드↔랜슬롯·퍼시벌, 트리스탄↔랜슬롯·모르호스·퍼시벌을 실제 관계로 연결했다.
