# 대표사진 자세 아이디어

인물에게 어울리는 자세를 고르거나 기존 자세를 교정할 때 쓰는 선택용 참고표다. 좋은 본인 레퍼런스가 있으면 그 자세를 살린다. 생성·검수 기준과 오브젝트 사용 금지는 [대표사진 룰북](celeb-08-02-hero-photo.md)을 따른다.

손의 높이, 좌우 반전, 옷의 종류, 미소·긴장 정도만 다른 것은 같은 기본형의 변형으로 묶었다. 몸의 각도·체중 이동은 아래 기본형에 조합하는 조정이며 별도 아이디어로 세지 않는다. 손을 모두 담으려고 허리샷을 넓히지 않는다.

## 직업·활동에서 자세 고르기

본인의 실제 화보·공연·연설 사진에서 그 사람다운 쉽고 단순한 자세를 먼저 찾는다. 좋은 참조의 원래 자세를 존중하고, 자세를 바꾸기 위한 변형을 만들지 않는다. 복잡한 기술 동작은 구현하지 않는다. 아래 예시는 선택 방향이며 모든 종사자에게 일괄 배정하는 자세가 아니다.

| 인물의 활동 | 활용할 수 있는 자세 | 적용할 때 볼 부분 |
|---|---|---|
| 무술가·격투 선수 | 본인의 홍보 초상에서 확인되는 편안한 양팔 내림·단순한 팔짱 등. | 대전·가드·기술 자세는 새로 구현하지 않는다. 종목은 본인의 복식과 체구로 살린다. |
| 무용가·댄서 | 본인 화보의 단순한 팔 선이나 손 배치. | 복잡한 춤 동작 대신 자연스러운 정지 자세를 고른다. 다리 동작을 담으려고 허리샷을 넓히지 않는다. |
| 지휘자 | 본인 초상의 팔 내림이나 간단한 손 배치. | 지휘 동작을 새로 짜거나 존재하지 않는 지휘봉·악기를 쥔 흉내로 만들지 않는다. |
| 연설가·정치인·교육자 | 본인의 실제 연설에서 쓰는 설명 손짓이나 청중에게 건네는 인사. | 인물에게 익숙한 태도와 손짓을 고른다. 모두 같은 손인사나 검지 지적으로 통일하지 않는다. |
| 가수·배우·코미디언 | 본인의 프로모션 화보나 무대 인사에서 확인되는 개성 있는 몸짓·표정. | 직업을 보여주려고 마이크·소품을 추가하지 않는다. 본인다운 태도를 살리되 과장된 희화화나 다른 배역의 얼굴로 바꾸지 않는다. |

카메라 앞에서 자연스럽게 유지할 수 있는 단순한 초상 자세를 고른다. 방향·표정·조명·구도는 대표사진 룰북의 최신 기본 생성문을 따른다.

## 자세 선택표

손·팔의 실제 배치가 같으면 생각·고민·감사·환영 같은 의미만 다른 이름은 합친다. 손의 높이·좌우·한손/양손·큰/작은 크기와 다른 자세를 조합한 경우도 아래 변형 안에서 고른다. 기존 성별 지정과 이번에 명시한 공통 변형을 함께 표시했다.

| 몸에 손 올리기 | 골반손 | 여성 | 양손 또는 한손을 골반 옆에 낮게 둔다. |
| 몸에 손 올리기 | 허리손 | 여성 · 주먹 변형 공통 | 옆구리 짚기·허리에 주먹 대기·가슴 펴기는 이 배치의 변형이다. 골반손과는 손을 짚는 위치로 구분한다. |
| 몸에 손 올리기 | 반대팔 잡기 | 공통 | 한 손으로 반대쪽 팔뚝·아래팔·팔꿈치를 가볍게 잡는다. 몸 아래서 잡는 배치도 포함한다. |
| 몸에 손 올리기 | 반대쪽 어깨 잡기 | 공통 | 한 손을 몸 앞에서 가로질러 반대쪽 어깨에 댄다. 팔뚝을 낮게 잡는 배치와 구분한다. |

| 경례 | 손날 눈썹까지 올린 경례 | 공통 | 한 손의 손날을 눈썹 가까이 올린다. 가벼운 경례도 이 항목에 묶고, 인물에게 맞는 형태를 따른다. |

책상에 짚기·책/펜/서류 들기·안경을 벗어 들기·자료의 특정 부분 가리키기는 소품이 필요한 선택이라 일반 스튜디오 자세표에서 제외한다. 책을 펼친 듯하기·펜을 쥔 듯하기·허공에 글쓰기·없는 물건을 받치거나 들어 올리는 흉내도 추가하지 않는다. 손바닥만 펼쳐 소개하는 배치는 ‘열린 손으로 안내하기’에 포함한다.

고개 숙이기·위쪽 응시만으로 새 자세를 만들지 않는다. 방향·시선은 대표사진 룰북을 따르며 손을 모두 담으려고 인물을 작게 만들지 않는다. ‘메이저’인 팔 내림도 모든 인물의 고정 자세는 아니며, ‘가끔씩’ 자세를 다음 공통 기본값으로 바꾸지 않는다.
