# 감상배경 소스 원문 재구축 — 소급 처리

존 그린에서 확정한 방식(룰북 [`celeb-02-03-content-review.md`](../../project/celeb/celeb-02-03-content-review.md) 「2.1. 원문 발췌와 해설의 배치」 절)을, 감상 소스가 살아 있는 다른 실존 인물의 `celeb_contents.review`에도 소급 적용한다.

대상 상태: 짧은 편집 요약·3인칭 재서술로 쓰인 감상배경 중, 팟캐스트·인터뷰·에세이·감상문 등 verbatim 소스가 확인되는 기록. 원문과 맥락이 완성된 글이 이미 있는 경우(완성된 리뷰 경로)는 대상이 아니며, 맥락이 필요한 발췌만 쿠셔닝+구분선 구조를 적용한다.

## 기록당 파이프라인

1. **소스 확정** — `source_url`의 실제 원문(전사본·기사·에세이)을 입수한다. 전사본이 없으면 오디오·영상에서 받아쓰기한다. 없는 근거를 지어내지 않는다.
2. **verbatim 발췌** — 인물의 발언을 그대로 추출한다. 발언 이해에 필요한 상대방 질문·앞 문단을 함께 보존한다. 요약으로 바꾸지 않는다.
3. **번역** — 영문이면 자연스러운 한국어로 번역한다. 1인칭·어조·유머·문단을 유지하고 정발 한국어판 제목을 쓴다.
4. **어조 통일** — 상대방 대사가 있는 대화·인터뷰는 해요체, 에세이·독백은 해라체로 문장어미만 통일한다. 타인 인용은 그 화자의 어조를 유지한다.
5. **문단 복원** — 소스의 문단을 복원해 `\n\n`으로 저장한다. 없으면 문장 경계에서만 나누고 인용문 내부 절단 금지.
6. **맥락 쿠셔닝 + `-----`** — 발췌가 독립적으로 읽히지 않으면 개별 쿠셔닝(앞 상황 요약+소스명+한 줄 요지, 2~4문장)을 위에, 원문 블록을 아래에 둔다. 지시어 미해소 금지.
7. **적용** — `celeb_contents` UPDATE → 행별 리드백 → Remotion `contextMain` 동기화 → 캐시 무효화까지 한 세트로 끝낸다.

존 그린 레퍼런스는 DB의 `celeb_contents.review`·`review_en`에서 확인한다.

## 처리 큐

| 인물 | 상태 | 비고 |
|---|---|---|
| 빌 게이츠 | ⬜ | Gates Notes 완성 리뷰 경로 — 발췌형 기록에만 쿠셔닝 필요 여부 판정 |
| 일론 머스크 | ⬜ | 현재 DB의 출처에서 verbatim 소스를 대조한다 |
| 그 외 실존 인물 | ⬜ | `celeb_contents.review`가 재서술형이면서 verbatim 소스가 있는 인물을 감사로 추린 뒤 순차 처리 |

## 시작 전 확인

- 인물별로 verbatim 소스가 실제 있는지 먼저 감사한다 — 없는 기록을 억지로 발췌형으로 바꾸지 않는다.
- 소스 원문의 게재 권한은 「완성된 리뷰」 절의 규칙을 그대로 따른다.
