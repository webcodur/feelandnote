# 01. 게임 흐름

제목 화면에서 새 게임·이어하기·성도·길잡이를 선택한다. 새 게임에서는 공개 인물을 이름·시대·지역·병과·등급으로 찾아 주군을 고르고 난이도를 정한다.

주군의 고향에서 방랑을 시작한다. 이웃 영토로 이동하거나 인연을 찾으며 동료를 모은다. 인물 조우, 도적, 상인, 마을, 사원과 소문은 선택 결과를 판에 반영한다. 거병 가능한 땅에서는 동료와 세력을 세운다.

거병 뒤에는 영토의 농업·상업·성벽과 민심을 돌보고, 인재를 등용·이동·임명하며 시설을 건설한다. 군량을 준비해 이웃 영토로 출진하거나 사절을 보내 외교한다. 달을 넘기면 AI 세력도 같은 세계에서 움직이고 수입·유지비·인구·부상·사건을 처리한다.

## 결말

`mutate.ts`의 `checkOutcome()`이 전투·항복·월 진행 뒤 결말을 판정한다.

- 플레이어가 마지막 영토를 잃으면 패망한다.
- 남은 경쟁 세력이 없거나 모든 영토를 소유하면 통일한다. 남은 무주지는 통일 시 귀순한다.
- 난이도에 정해진 기간을 넘기면 시간 초과로 끝난다.

판이 끝나면 명부와 전적을 보여주고 제목 화면으로 돌아간다. 만남·동행·주군 기록은 성도에 남고, 끝난 판의 이어하기는 지운다. 저장 방식은 [기술 구조](08-tech.md)를 따른다.
