# 세력별 인물 소개

`faction_members.long_desc`·`long_desc_en`의 작성 규칙이다.

- 첫 문장은 테마와 관련된 대표 사실로 시작한다. 첫 문장 마무리와 본문의 인물 지칭은 [LLM 문구 처리 기준](../agent-rules.md#llm의-작업-구분-없는-문구-처리)을 따른다.

- 분량은 보통 2~4문장, 한국어는 공백 포함 150~300자, 영어는 40~90단어를 권장한다. 필요한 정보가 적으면 더 짧게, 입장 변화나 논쟁의 맥락이 필요하면 더 길게 쓸 수 있다. 분량을 채우려고 내용을 늘리지 않는다.
- 이어지는 문장에는 테마와 관련된 실제 역할·주장·저술·활동 중 필요한 정보만 남긴다. 설명 순서와 문장 구성은 인물에 맞게 조정한다.
- “우파에 편성한다” 같은 배정 판단, 후보·편집 메모, 앞 내용을 되풀이하는 결론은 넣지 않는다.
- 「좌와 우」는 좌우 입장이 분명한 인물과 루소·버크처럼 각 진영의 사상적 원류가 분명한 인물만 포함한다. 단순한 자유주의·시장 연구·불평등 연구나 후대의 영향만으로 배정하지 않으며, 인물 소개에는 해당 진영의 원류를 이루거나 직접 옹호한 저술·주장·활동을 구체적으로 쓴다.
- 한영에 같은 사실을 담되 각 언어에서 자연스럽게 쓴다. 문장 수와 구조를 똑같이 맞출 필요는 없다.
