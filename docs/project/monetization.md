## 현재 인프라 상태

### 제휴 링크 (26.08.08 가동)

- `content_locales.affiliate_url` JSONB 컬럼에 플랫폼별 링크를 담는다. 백오피스 콘텐츠 상세에서 편집한다
- `sw/web/src/constants/affiliatePlatforms.ts`: 플랫폼별 라벨·색·**locale**·대가성 문구. locale이 노출 국가를 가른다
- **조회 단일 지점은 `sw/web/src/actions/home/getAffiliateBooks.ts`다.** 링크가 걸린 도서 풀을 한 번 캐시하고 화면별로 걸러 쓴다 — 화면마다 다시 조회하면 그만큼 egress가 는다

**노출 지점과 선택 근거** (26.08.08 실측)

| 화면 | 무엇을 뽑나 |
|------|------|
| 홈·작품·탐색 | 링크 걸린 도서를 기록자 수 순 6권 (`PopularBooks`) |
| 콘텐츠 상세 | 그 작품의 링크. 화면 locale과 플랫폼 locale이 맞을 때만 |
| 인물 상세 | 등장 원전 → 읽은 책 → 같은 직군 → 인기 순 폴백 (`CelebAffiliateBooks`) |
| 세력도감 진영 소개 | **그 진영이 다루는 분야의 책** (`TagOriginBooks variant="topic"`) |
| 세력도감 서재 모드 | 그 진영 인물이 쓴 책, 없으면 그들이 읽은 책 (`variant="people"`) |

**진영에 어울리는 책을 고르는 기준** — 낱말 목록은 `sw/web/src/constants/factionBookTopics.ts`가 쥔다.

진영 인물이 **읽은** 책은 그 사람 취향일 뿐 진영 주제가 아니다. 실제로 디지털 레지스탕스에 『이솝 우화』가, 위대한 해커들에 『금강경』이, 반도체 제국에 『우리는 왜 잠을 자야 할까』가 떴다. 그래서 진영마다 분야 낱말을 적어 두고 그 책을 먼저 낸다. 신화 진영은 인물들이 나오는 원전이 곧 분야다.

🔴 **낱말을 짧게 쓰면 오탐이 터진다.** 「록」 한 글자는 자성록·회상록·고백록·어록을, 「신화」는 『시지프 신화』를, 「우주」는 아동 과학동화를 통째로 끌어왔다. 두 낱말 이상으로 좁히거나(그리스 신화) 그 분야에서만 쓰는 말을 골라라(자율주행).

- 카드에서 **표지·제목은 콘텐츠 상세로, 버튼만 판매처로** 간다. 카드 전체를 외부 링크로 두면 무엇을 눌러도 서비스를 떠난다
- 모바일은 가로 스크롤, 데스크톱은 줄바꿈 배치다(`AffiliateBookList`)
- 쿠팡·알라딘·YES24·교보문고는 ko 화면에서만, 아마존은 en 화면에서만 나온다

**🔴 자료를 SQL로 직접 넣으면 화면에 안 뜬다.** 화면 조각을 7일간 보관하므로 백오피스를 거치지 않은 변경은 반영되지 않는다. 백오피스 저장은 `revalidateWebCache(CACHE_TAGS.CONTENTS)`를 자동 호출하지만 직접 UPDATE는 그 경로를 지나치지 않는다. 이럴 땐 `/api/revalidate`에 `{tag, secret}`을 POST한다(secret은 `CRON_SECRET`). 인물·진영 목록은 `celebs` 태그도 함께 비운다.

### 쿠팡 파트너스 (26.08.08 실측)

- **최종 승인 전이다.** 오픈API 키 발급 화면(`추가 기능 > 파트너스 API`)은 있으나 「생성」 버튼이 비활성이다. **누적 매출 15만원**을 넘겨야 최종 승인이 나고 그때 키가 열린다
- 따라서 링크는 **파트너스 사이트에서 한 건씩 만드는 수밖에 없다.** 상품 검색은 `#affiliate/ws/link/0/<검색어>`로 바로 열리고, 상품 카드의 「링크 생성」을 누르면 `link.coupang.com/a/xxxx` 단축 주소가 나온다
- **Claude in Chrome 확장은 쿠팡 도메인을 차단한다.** 사이트 허용 목록으로 풀리지 않는다. 대신 크롬을 `--remote-debugging-port=9222`로 띄우고 사람이 직접 로그인한 뒤 puppeteer로 붙여 조작했다
- 최종 승인 조건에는 실적 외에 **활동 페이지에 링크가 게시된 화면 캡처 제출**이 있다. 그래서 링크 노출이 승인의 선행 조건이지 결과가 아니다
- 등록 사이트는 `https://feelandnote.com`으로 이미 올라가 있다

🔴 **상품은 자동으로 고르지 마라.** 점수로 1등을 뽑는 방식은 명백한 오탐만 걸러낼 뿐, "더 나은 후보가 있었는지"를 보지 못한다. 26.08.08 회차에서 그렇게 넣은 363권을 되짚으니 76권이 개별 서점 재고·묶음 상품·엉뚱한 판본이었다.

**올바른 순서** — 도구는 `cp-candidates.mjs`(후보만 수집) → 사람이 판단 → `cp-pick.mjs`(고른 것 하나만 생성)다.

1. **책 제목만으로** 검색해 후보 12개를 그대로 받는다. 저자·출판사를 붙이면 후보가 좁아져 더 나은 상품을 놓친다
2. 사람이 목록을 읽고 어느 상품이 맞는지 고른다
3. 고른 것 하나만 링크를 만들어 넣는다

판단 기준은 우리 판본과의 일치 > 정식 유통(개별 서점 재고 회피) > 완질·단권의 적절성 > 값이다. 같은 제목이 둘 이상인 책(자본론·로마제국 쇠망사 등)은 반드시 content_id로 지정한다.

**제목만으로 못 찾는 책이 있다.** 「풀잎」은 조화·인조식물, 「롤리타」는 향수, 「티마이오스」는 식품, 「자연학」은 자연 도감, 「해커스」는 토익 교재가 나온다. 이럴 때만 저자를 붙여 다시 찾는다.

**상품 고르기 함정** — 검색 첫 결과를 그대로 쓰면 엉뚱한 물건이 걸린다. 실제로 파운틴헤드→비치 텐트, 세븐 파워→편의점 장난감, 에누마 엘리시→화장품 세럼, 픽윅 클럽 여행기→데이비드 코퍼필드가 잡혔다. 상품명에 **ISBN이 박힌 상품이 가장 정확**하고(서경·마하바라타를 이걸로 맞췄다), 해설서·부교재 문구(입문·풀이·만화·필사)는 감점해야 원전이 잡힌다. 자동 선별 후 **사람이 제목 불일치 목록을 눈으로 훑는 단계를 반드시 둔다** — 26.08.08 회차에서 299건 중 21건을 이 단계에서 걸러냈다.

**26.08.08 기준 링크 보유 도서 322권.** 신화 원전 20종 중 아르고 호 이야기·아서 왕의 죽음·에누마 엘리시 3종은 쿠팡에 한국어판이 없어 비워 뒀다(카멜롯 왕실 진영은 그래서 구획이 접힌다).
