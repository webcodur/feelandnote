# 쓰레기 작문 금지

클로드 한국어 산문의 고질병은 멋 부린 문예 어휘를 자동으로 꺼내 쓰는 것이다. 다른 도구가 아니라 클로드 자신의 버릇이므로, 남 일처럼 검수하지 말고 자기 출력을 의심한다. 사람은 일상에서 "포개다", "벼리다" 같은 말을 쓰지 않는다. 글의 격은 어휘의 화려함이 아니라 사실의 밀도에서 나온다. **모든 한국어 글쓰기(에피소드 본문, 문서, 보고, 답변)에 적용한다.**

## 핵심 원칙

1. **기본 동사 우선.** 만들다, 세우다, 배우다, 넣다, 시작하다, 끝나다, 닮다, 남다. 평범한 동사로 충분하면 그걸로 쓴다.
2. **신문 기사 테스트.** 이 단어가 일반 신문 기사나 일상 대화에 나오는가? 안 나오면 쓰지 않는다.
3. **은유는 글 전체에서 최대 1회.** 그것도 글의 중심축일 때만. 장식용 은유는 0회.
4. **블랙리스트는 예시일 뿐이다.** 아래 표에 없어도 "내가 이 단어를 자주 쓰는 것 같다" 싶으면 그 자체로 금지 신호다. 일일이 지적받을 수 없으므로 스스로 거른다.

### 종결·어미 패턴

| 금지 | 처방 |
|---|---|
| ~한/했던/하는 셈입니다 | **전면 금지(0회).** ~했습니다, ~과 같습니다로 |
| ~인지 모릅니다 | 글 전체에서 최대 1회. 추측 남발 금지 |
| ~이기도 했습니다 | ~했습니다 |
| ~일 뿐입니다 (남발) | 단정문으로 |
| ~터였습니다 | ~했습니다, ~할 참이었습니다 |
| ~하곤 했습니다 (남발) | ~했습니다 |
| ~지요 (남발) | 단락 매듭 1회 이내, 나머지 ~습니다 |

## 함께 묶이는 기존 규칙 (중복 적용)

- em dash(—) 금지 → 마침표·쉼표·괄호
- 사물 주어·동격 구문 금지 → ko-detranslate 스킬
- 다 아는 사실 깔기 금지: "로켓이 아니라 게임이었다"처럼 누구나 아는 사실을 부정형 멍석으로 쓰지 않는다. 필요한 사실만 적는다
- 억지 은유 금지: 실제로 일어나지 않은 일을 은유로 단정하지 않는다 ("두 사람은 같은 발사대 앞에서 만났다" 류)
- 감상 단정 금지: "그 말대로 살았다", "삶으로 증명했다", "온몸으로 보여줬다" 같은 설교형 요약 문장을 쓰지 않는다. 사실을 나란히 놓고 판단은 시청자에게 맡긴다
- **같은 정보는 한 번만 쓴다.** 추천 사실, 결정 증거, 매듭 문장이 본문과 인용 해설에 두 번 나오면 한쪽을 지운다. 한 번 쓰기로 합의된 사실(예: 추천 이력)을 다른 단락에서 "두 차례나", "거듭" 같은 표현으로 재진술하는 것도 중복이다

## 자가 점검 — 송출 전

1. 블랙리스트 단어 검색(활용형 포함: 벼려/벼린, 길어 올린/올렸 등): 포개, 담그, 벼리, 빚어, 꿰뚫, 셈입니다, 인지 모릅니다, 머금, 깃들, 스며들, 아로새, 눌러 담, 길어 올, 말대로 살
2. 같은 종결 어미가 3문장 연속이면 변주
3. 은유 개수 세기: 2개 이상이면 1개만 남기고 사실 진술로 교체
4. "이 문장을 신문 기자가 쓸까?" — 아니면 재작문

## 검수 모드로 호출될 때

기존 텍스트 검수를 요청받으면:

1. 블랙리스트 grep으로 1차 수집
2. 블랙리스트 밖이라도 문예 어휘·반복 어미를 수동 적발
3. 보고 형식은 ko-detranslate와 동일 (원문/교정 쌍)
4. quote(인용문 원문)와 quoteSource는 손대지 않는다
