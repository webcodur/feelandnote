# 개인 메모

작업 참조 문서가 아니다. 프로젝트 규칙·규격의 근거로 쓰지 않는다.

| 파일 | 내용 |
|------|------|
| `리모션 단축키.txt` | Remotion Studio 단축키 표 |
| `오디오 맞춤 원리.txt` | 음성 타이밍 파이프라인 요약 메모. 정본은 `docs/project/remotion/book-recommend/voice/voice-timing-pipeline.md` |
| `책 요약 예시.txt` | 책 요약 요청 프롬프트 템플릿 |
| `구글 가족계정 확대처리.txt` | 프로젝트 무관 개인 메모 |

> 어록 채굴물은 여기 두지 않는다. 소속 에피소드 폴더의 `quotes/`에 둔다 — `factions/<에피소드>/quotes/` 또는 `episodes/<시리즈>/<인물>/quotes/`.
> 기존 `언사/` 18종은 26.07.16에 각 소속으로 이관 완료했다.
