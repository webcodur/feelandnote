# 아바타

`celebs.avatar_url`에 등록하는 얼굴 이미지의 신원·구도·크롭·검수 기준이다. 저장 경로와 다른 이미지 슬롯은 [`celeb-08-00-image-map.md`](celeb-08-00-image-map.md), 검색·크롭·업로드 명령은 `celeb-avatar-register` 스킬이 쥔다.

## SSoT

| 책임 | 원천 |
|---|---|
| 1차 크롭 목표·허용 범위 | `sw/web-bo/src/lib/avatar-geometry.ts`의 `AVATAR_SPEC` |
| 정규화 최종 규격(구도·빛 방향) | 같은 파일의 `AVATAR_SILHOUETTE_SPEC`·`AVATAR_LIGHT_SPEC` |
| 원본·작은 판 파일명, 출력 크기·품질, 해상도 선택 기준 | `packages/shared/src/constants/celeb-avatar-small.ts` |
| 사용자 웹의 실제 칸 크기·화면 배율 측정과 작은 판 실패 시 원본 복귀 | `sw/web/src/hooks/useCelebAvatarSrc.ts`, `sw/web/src/lib/celeb/avatar-size-observer.ts` |
| 등록·신원 근거·R2·DB 갱신 | `.agents/skills/celeb-avatar-register/SKILL.md` |
| 정규화 실행·전수 작업 | `.agents/skills/celeb-avatar-reframe/SKILL.md` |
| 공통 이미지 제작 원칙 | [`../production/image-generation.md`](../production/image-generation.md) |

눈높이·턱끝·중심축은 `AVATAR_SPEC`, 파일·출력 값은 공유 아바타 상수에서 읽는다. 숫자를 문서나 프롬프트 템플릿에 별도 상수로 만들지 않는다.

## 신원

구도보다 먼저 해당 인물인지 확인한다.

- 사진이 남은 실존 인물은 본인·소속기관·권위 매체의 사진과 얼굴을 대조한다.
- 사진이 없는 고대·역사 인물은 해당 인물을 위해 만든 제작본을 사용할 수 있다. 명명 초상이 없다는 이유만으로 결함 처리하지 않는다.
- 제작본은 QID와 프로필 신원, 시대·복식, 다른 인물용 얼굴의 재사용 여부를 확인한다.
- fiction은 원전·세력도감 명단으로 인물을 특정하고 다른 캐릭터의 얼굴을 돌려쓰지 않는다.
- 아바타와 대표 사진이 모두 있으면 나란히 보고 같은 인물인지 확인한다.

얼굴이 틀렸다면 크롭부터 고치지 않는다. `wikidata_qid` 등 식별 근거를 먼저 바로잡고 잘못된 이미지를 서비스 입력과 생성 참조에서 격리한다. 삭제·덮어쓰기는 루트 파일 안전 규칙을 따른다.

## 구도

아바타는 작은 원형에서도 얼굴을 알아보는 타이트한 정면 헤드숏이다. 아래는 원본에서 잘라낼 때의 1차 기준이고, 서비스에 보이는 최종 구도는 「정규화」가 정한다.

- 얼굴 중심축을 정사각 중앙에 둔다.
- 눈과 턱의 목표 위치는 `AVATAR_SPEC`을 따른다.
- 정면 또는 아주 얕은 3/4 회전으로 카메라를 바라본다.
- 얼굴 자체의 이마·눈썹·귀는 프레임 밖으로 자르지 않는다.
- 머리카락·모자·투구·왕관이 위쪽에 닿거나 일부 잘리는 것은 허용한다. 장식을 다 담으려고 얼굴을 작게 만들지 않는다.
- 턱 아래는 목·옷깃·갑옷·머리카락이 채울 수 있지만 쇄골과 가슴이 넓게 들어오는 흉상은 피한다.
- 한 사람만 두고 손·마이크·책·무기·글자·로고 같은 소품을 넣지 않는다.
- 실사 사진 질감과 자연스러운 색을 사용한다. 회화·삽화·조각·밀랍 인형처럼 보이면 실패다.

표정은 차분함부터 자연스러운 미소 사이에서 인물에 맞게 고른다. 같은 배치를 전부 무표정으로 만들지 않으며, 기존 이미지를 표정만으로 교체하지 않는다. 얼굴은 그 인물이 알려진 활동 시기를 우선하되 남은 자료가 다른 시기뿐이면 신원 보존을 우선한다.

## 얼굴이 공개되지 않은 인물

신원이 공개되지 않아 실제 얼굴 자체가 없는 인물은 눈·턱 기하의 대상이 아니다. 임의의 실존 얼굴을 만들지 않고 후드·복면처럼 익명성 자체를 형상화할 수 있다.

이 경우에도 정면, 한 명, 소품·글자 없음, 작은 원형에서의 식별성은 지킨다. 자동 얼굴 검출을 통과한 척하지 않고 스킬의 명시적 무얼굴 경로 또는 관리자 수동 크롭을 사용한다.

## 원본과 제작

출처 이름보다 신원 확실성, 얼굴 크기, 선명도, 정면성을 본다. Wikidata와 Commons는 신원 확인과 후보 탐색에 유용하지만 대표 이미지가 곧 좋은 아바타 원본이라는 뜻은 아니다. 공식 프로필·권위 매체·일반 웹의 더 나은 얼굴 사진도 후보가 될 수 있다.

가상·고대 인물의 승인된 대표사진이 측면을 보거나 장면 속 대상을 응시한다면 억지로 크롭하지 않는다. 그 대표사진을 얼굴 정체성 기준으로 삼아 보이지 않는 면의 골격을 일관되게 추론하고, 아래 구도에 맞는 아바타용 정면 헤드숏을 별도로 생성한 뒤 대표사진과 나란히 보아 같은 인물인지 검수한다.

## 대표 사진에서 잘라내기

사진이 없는 인물의 아바타는 **대표 사진을 먼저 만들고 그 얼굴을 잘라내는 경로**로 만들 수 있다. 얼굴 참조를 따로 찾지 않아도 되고, 두 이미지가 같은 사람으로 보여야 한다는 조건이 저절로 지켜진다. 대표 사진 규격은 [`celeb-08-02-hero-photo.md`](celeb-08-02-hero-photo.md)가 쥔다.

**생성 직후의 큰 원본에서 자른다.** R2 저장본은 공용 상수 크기로 줄어든 판이라 무릎 위 구도에서 눈~턱이 `AVATAR_SPEC` 목표의 몇 분의 일에 그친다. 저장본을 잘라 키우면 뭉개진다. 그래서 대표 사진을 만들 때 원본을 남기고, 크롭은 그 원본을 대상으로 한다.

원본에서도 픽셀이 모자라거나 고개·시선이 아바타 구도와 어긋나면 크롭을 결과물로 쓰지 않는다. **잘라낸 얼굴을 참조로 삼아 아바타 구도로 다시 생성한다.** 확대 흐림 없이 같은 얼굴이 유지된다.

어느 경로든 완성된 아바타는 대표 사진과 나란히 놓고 같은 인물인지 확인한다.

회화·도상을 참조해 새 이미지를 만들 때는 회화 양식을 복제하지 않게 하고, 기록으로 확인되는 나이·체형·수염·복식을 개별 지정한다. 사진이 남은 인물은 실제 사진을 우선한다. 유료 이미지 생성은 사용자가 명시한 뒤에만 실행한다.

## 생성 아바타 배치 — 아바타 없는 근현대 인물

사진이 남지 않거나 쓸 만한 얼굴이 없는 실존 근현대 인물은 씨앗 이미지를 참조로 실사 스튜디오 헤드숏을 생성해 등록한다. 작업 루트는 `data/celeb/avatar-collect/_gen/`이며 스크립트가 파이프라인 그대로다. 산출물은 문서가 아니라 데이터 폴더에 둔다.

1. **대상·씨앗** — `targets.json`(id·slug·qid·팩션)에 대상을 모으고, 씨앗 얼굴은 `avatar-collect/faces-final/` 등 수집분을 쓴다. 씨앗 자체의 신원 근거는 「신원」 절이 정한 것과 같다.
2. **생성** — `gen-gemini.mjs`가 Aside로 Gemini 웹을 조작해 씨앗+프롬프트를 넣고 결과를 `out/<slug>-gem.jpg`로 받는다. 프롬프트는 스튜디오 반신(bust-up) 계열(매끈한 피부·심리스 배경·정면·머리는 상단 1/3)을 쓴다 — 하이퍼리얼 지시는 피부가 거칠게 나온다. **반신 구도가 핵심이다: 우하단 다이아몬드(~0.88)가 얼굴 중심 크롭 밖에 떨어져 워터마크 제거 단계가 필요 없다.** 헤드샷으로 꽉 채우면 마크가 크롭 안에 남아 3번 처리가 필요하고, 얼굴도 커져 업스케일이 줄어드는 대신 그 비용을 치른다. 병렬은 큐 파일을 워커 수로 나눠 독립 실행한다. slug에 작은따옴표가 있으면 생성 JS가 깨지므로 `JSON.stringify`로 박는다.
3. **워터마크 제거** — 반신 구도로 생성한 결과는 마크가 크롭 밖이라 이 단계를 건넌다. 헤드샷 등 마크가 크롭에 걸치는 원본만 `clean-local.mjs`가 지운다: 주변이 매끄러우면(테두리 std 낮음) 사방 테두리색을 양방향 보간한 채움, 텍스처가 있으면 톤이 가장 가까운 인접 패치를 복제해 평균색을 보정한다. Photoroom 웹 자동화(`clean-photoroom.mjs`)는 Turnstile 익명 한도에 막혀 대량 처리에 쓰지 않는다.
4. **타이트 크롭** — `crop-tight.mjs`가 랜드마크로 얼굴 비율을 키워(span 0.4) `final/<slug>.webp`를 만든다. 모자·관모는 프레임 상단에서 잘리는 게 정상이며 얼굴 규격은 모든 인물이 같다. 원본 얼굴이 작아 800px 미만 크롭이 나오면 확대 플래그를 `_report.json`에 남긴다 — 뭉개짐 검수 대상이다.
5. **등록** — `sw/web-bo`의 `scripts/avatar/upload-local.ts`가 완성 정사각을 R2+DB에 넣는다(크롭은 하지 않는다). **`upload-local` 계열은 Node 22로 실행한다** — Node 20에는 네이티브 WebSocket이 없어 supabase 클라이언트가 생성 즉시 죽는다. 이 머신의 Node 22는 `~/AppData/Roaming/nvm/v22.14.0`다. id·slug 쌍은 `targets.json`에서 뽑아 배치한다.
6. **검수** — `build-gallery.mjs`가 `review/final-grid.html`에 정사각 격자를 만든다. 얼굴 닮음·잔여 마크·모자 잘림·확대 뭉개짐을 눈으로 보고 이상분만 재생성·재처리한다.

기타 함정: 이 폴더의 스크립트는 sharp를 `sw/web-bo/package.json` 기준 `createRequire`로 풀고, puppeteer는 저장소 고정 버전 경로를 직접 가리킨다. Windows에서 프로세스 조회 명령의 `$_`는 bash에 먹히므로 PowerShell 셸로 실행한다.

## 크롭

기본 경로는 얼굴 랜드마크의 눈과 턱을 직접 재 `avatar-geometry.ts`로 정사각 좌표를 계산하는 것이다. 얼굴 상자에 임의 배율을 곱하거나 호출마다 프레임 비율을 바꾸지 않는다.

- 랜드마크를 얻지 못한 상자 기반 폴백과 원본 여백 부족은 경고로 드러낸다.
- 얼굴을 찾지 못하면 임의 위치를 잘라 성공 처리하지 않는다.
- 이미 잘린 원본은 바깥 화면을 복원할 수 없다. 여백 부족 경고가 있으면 다른 원본을 찾거나 새 이미지를 만든다.
- 작은 판은 등록한 원본 아바타에서만 파생한다.
- 크롭 창의 「창을 열 때 AI 자동 맞춤 실행」을 끄면 창을 열 때 자동 계산이 돌지 않는다. 선택은 브라우저에 남아 다음 창에도 유지된다. 꺼 두더라도 기준은 같다 — 「AI 자동 맞춤」 버튼으로 직접 돌리거나 위 좌표 기준에 맞춰 맞춘다. 눈대중으로 임의 위치를 자르지 않는다.
- 크롭 창의 「적용과 동시에 nobg 배경 제거」를 켜면 적용한 아바타가 저장된 뒤 배경 제거가 큐에 자동으로 들어간다. 기본은 꺼짐이며 켠 선택은 다음 창에도 남는다. 누끼 결과는 실제 배경색에 얹어 확인한다 — 어두운 인물은 배경을 지우면 사이트 배경에 묻힌다.

## 정규화 — 등록된 아바타의 최종 규격

등록 경로가 Commons 크롭이든 생성본이든 관리자 크롭 창이든, 서비스에 보이는 아바타는 이 절의 규격으로 끝난다. 눈·턱 크롭(`AVATAR_SPEC`)은 원본에서 얼굴을 잘라내는 1차 규격이고, 정규화는 배경을 지운 결과를 한 세트로 맞추는 최종 규격이다. 값은 `AVATAR_SILHOUETTE_SPEC`(구도)과 `AVATAR_LIGHT_SPEC`(빛 방향)이 쥔다. 실행은 `celeb-avatar-reframe` 스킬이며 등록·교체 배치의 마지막 단계다(`celeb-avatar-register` 「등록의 마지막 단계」).

### 왜 따로 두는가

눈높이·턱끝이 같아도 정수리 여백, 턱 아래 몸통의 양, 빛의 방향이 제각각이면 나란히 놓았을 때 한 세트로 읽히지 않는다. 눈·턱 규격은 이 세 가지를 재지 않는다. 배경을 지운 아바타는 알파 실루엣으로 정수리를 잴 수 있고 좌우를 뒤집어도 구도가 깨지지 않으므로, 등록 뒤에 한 번 더 맞춘다.

### 구도 원칙 — 순서가 우선순위다

1. **하단을 먼저 고정한다.** 턱 아래 목이 끝나는 곳, 넥타이를 맸다면 매듭이 보이기 직전이다. 쇄골과 가슴은 넣지 않는다. 목 길이는 사람마다 달라 배수 하나로 모두 맞지 않으며, 수염이 긴 인물은 수염 밑에서 끝난다.
2. **얼굴 위치와 크기가 정수리보다 앞선다.** 눈높이 상한과 눈~턱 비율 범위(김봉진과 빌 게이츠 사이)를 지키고, 머리숱·투구·날개 장식으로 얼굴이 낮게 앉거나 작아지면 하단을 고정한 채 확대해 정수리를 자른다. 장식을 다 담으려고 얼굴을 내리지 않는다.
3. **정수리는 남는 범위에서 작은 여백을 둔다.** 원본에서 이미 잘린 정수리는 여백 없이 위에 붙인다.
4. **가로 기준은 얼굴의 지각 중심이다.** 정면·약한 부각은 얼굴 좌우 끝(턱선 양끝)의 중점을 중앙에 두고, 부각이 강한 3/4 얼굴은 부각된 쪽 눈 쪽으로 보간해 내민 얼굴면이 중앙에 오게 한다. 강한 부각에서 턱선 양끝 중점은 가려진 쪽 추정 오차로 얼굴이 반대로 밀려 보인다. 임계값은 `avatar-geometry.ts`의 `horizontalAnchor`가 쥔다. 머리카락·귀·장식은 얼굴 폭에 넣지 않는다.
5. **위아래로는 원본 밖으로 나가지 않는다.** 잘린 몸통 아래나 잘린 머리 위에 투명 여백을 붙이면 절단면이 드러난다. 좌우는 그 변에 실루엣이 닿아 있지 않을 때만 투명으로 넓힌다.

### 빛 방향

같은 명단 안에서 키라이트가 좌·우로 섞이면 구도를 맞춰도 흩어져 보인다. 코끝 기준 좌·우 뺨의 평균 밝기 비로 방향을 판정하고, 반대쪽이면 좌우를 뒤집는다. 정면광 구간은 손대지 않는다.

- 통일 방향은 **뷰어 왼쪽**이다. 초상화 관습과 시각 지각의 기본 가정이 왼쪽 위 광원이고, 아바타 오른쪽에 글자가 붙는 화면에서 그늘진 면이 글자 쪽을 향해 경계가 조용하다.
- **반전은 재배치보다 앞이다.** 뒤집으면 부각된 쪽이 바뀌므로 원본을 먼저 뒤집고 구도를 잡는다.

### 대상과 예외

- 배경이 지워진(알파 있는) 아바타만 대상이다. 배경이 있으면 `nobg-cutout`을 먼저 거친다. 도구는 실루엣이 없는 입력을 건너뛰고 보고한다.
- 얼굴을 못 찾는 외눈·짐승·가면 인물은 대상이 아니다. 사람이 관리자 크롭 창에서 자른다.
- **실존·허구를 가리지 않고 한 방향으로 맞춘다.** 실존 인물도 뒤집는다. 가르마·점·흉터가 거울상이 되고 대표 사진과 좌우가 어긋날 수 있지만, 서비스 전체가 한 세트로 읽히는 쪽을 택했다. 실존만 빼야 할 특수한 회차는 `--skip-real`을 명시한다.
- 안대·외눈·글자·문장처럼 좌우가 의미 있는 인물은 제외 목록으로 뺀다. 목록은 도달점 문서가 쥔다.

### 파이프라인

```bash
cd sw/web-bo
node scripts/avatar/pull-avatars.mjs --faction <slug> | --reality REAL|FICTION --offset N --limit 200 | --since <ISO>
npx tsx scripts/avatar/light-unify.ts <폴더> <폴더>-lit [--skip-real] [--exclude a,b]
npx tsx scripts/avatar/reframe.ts <폴더>-lit <폴더>-reframed --sheet
npx tsx scripts/avatar/upload-reframed.ts <폴더>-reframed          # 사용자 지시 뒤
npx tsx scripts/avatar/contact-sheet.ts --out <폴더> --slugs <a,b> --no-guides
```

내려받은 원본 폴더는 롤백 자료다. 지우지 않는다. 등록 전 `_sheet-*.png`(왼쪽 전·오른쪽 후)와 `_report.json`을 직접 본다.

### 재현성과 상태

상태 컬럼을 두지 않는다. 빛 방향과 구도는 매번 이미지 자체에서 다시 판정하므로 같은 명단을 두 번 돌려도 원상복구되거나 흔들리지 않는다. 새로 등록·교체된 아바타는 `avatar_url`의 캐시 버스터(`?v=`) 시각으로 골라낸다. 마지막 통과 시각과 명단별 도달점은 지속 과제 문서에 적는다.

### 값을 바꿀 때

기준 인물 두어 명을 실측해 시작값을 잡고, 명단 하나(50명 내외)를 돌려 대조 시트를 본 뒤, 지적을 규격 값 하나로 환원해 다시 돌린다. 눈으로 본 문제를 좌표 규칙으로 바꾸지 못하면 값을 만지지 않는다. 바꾼 값은 코드 주석에 이유를 적고 문서에는 복제하지 않는다.

## 검수

기계 판정과 눈 검수를 모두 수행한다.

```bash
cd sw/web-bo
npx tsx scripts/avatar/measure.ts <이미지폴더>
npx tsx scripts/avatar/contact-sheet.ts --out <출력폴더> --slugs <slug-a,slug-b>
```

기계는 중심축과 극단적인 기하 이탈을 거르는 1차 체다. 얼굴 잘림, 고개와 시선, 상반신 유입, 손·소품·글자, 배경, 질감, 실제 신원은 직접 본다.

- 원본 크기만 확대하지 말고 서비스에서 쓰는 작은 원형과 확대 뷰를 함께 본다.
- 머리 장식 잘림, 표정, 목표치와 조금 다른 얼굴 크기만으로 기존 자산을 재작업하지 않는다.
- 얼굴이 점처럼 작거나 프레임 한쪽에 몰리고, 얼굴 자체가 잘리거나 흉상·소품·다른 사람이 들어오면 불합격이다.
- 생성하거나 교체한 이미지는 저장 직후 직접 열어 결함부터 확인한다.

불합격이면 먼저 더 넓은 원본에서 재크롭이 가능한지 본다. 불가능하면 더 나은 실제 사진을 찾고, 그것도 없을 때만 승인받은 제작을 사용한다.
