## 상세 페이지 개선 아이디어

### 빛과 그림자
- **UI/UX 표현:** 화면이나 카드를 정확히 반으로 나누어 밝은 영역과 어두운 영역(또는 카드 앞뒷면 뒤집기)으로 극적인 시각적 대비
- **기획 의도:** "맹목적인 찬양을 방지하고 태생적 한계와 치명적 결함을 함께 기록한다"는 Feelandnote의 편집 원칙과 완벽하게 호응하는 기획

### 다감각 몰입 경험
ㄴ 영상과 음성 인프라로 웹 페이지 레이아웃과 결합하여, 단순한 정보 페이지를 '인터랙티브 전시관'으로 격상

- **공간음 / 앰비언트 사운드 (Ambient BGM):** 
ㄴ 인물의 성향이나 소속 팩션에 맞는 배경음
ㄴ 베토벤은 피아노 조율 소리, 철학자는 타닥거리는 장작 소리, 장수는 바람과 깃발 소리
ㄴ 상단의 '테마 켜기' 버튼을 통해 유저가 선택적으로 몰입할 수 있게 합니다.

- **오디오 도슨트 투어 (Audio Guide):** 
ㄴ 현재 텍스트로만 제공되는 '인물 읽어보기'를 인물의 합성 음성으로 재생.
ㄴ 재생되는 동안 화면이 타임라인과 주요 걸작 섹션으로 서서히 자동 스크롤되는 시네마틱 연출.

- **동적 시네마틱 헤더 (Cinematic Header):** 
ㄴ 단조로운 프로필 이미지 배경 대신, 인물의 소속 진영이나 시대 배경을 나타내는 잔잔한 루프 영상을 화면 최상단에 깔아 압도적인 첫인상 주기

- **동적 테마 컬러 (Dynamic Color Variables):** 
ㄴ Tailwind 4.1의 CSS 변수를 활용하여, 인물의 티어나 성향에 따라 페이지 전체의 포인트 컬러 변경
