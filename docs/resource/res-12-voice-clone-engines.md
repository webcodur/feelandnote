# 음성 복제 TTS 엔진 고르기

짧은 참고 음성으로 특정 인물의 목소리를 복제해 한국어 장문 내레이션을 만들려 할 때, 로컬 엔진과 클라우드 엔진을 어떻게 고르고 시험하는지 정리한다. 엔진 목록과 기능은 2026년 7월 공개 자료 기준이다. 모델은 빠르게 바뀌므로 채택 전에 공식 저장소를 다시 확인한다.

## 1. 공개 성능표를 믿지 않는 이유

- 오픈소스 음성 복제 모델의 공식 성능표는 대개 중국어·영어 시험으로 **발음 일치도와 음색 유사도**만 잰다. 자연스러움·감정·음질은 그 수치로 평가되지 않으며, 공식 설명도 실제 자료로 직접 시험하라고 적는다.
- 활용 생태계가 크다는 사실(캐릭터 짧은 대사, 버튜버 실시간 대화, 디스코드 봇, 대량 더빙)은 **한국어 성우형 장문**의 품질을 보증하지 않는다.
- 감정 선택을 붙인 프로젝트들은 글로 연기를 지시하기보다 기쁨·분노·슬픔으로 말한 참고 음성을 여러 개 준비해 바꿔 끼운다. 중립적인 인터뷰 음성 하나로 연기를 만들려는 목표와는 전제가 다르다.

## 2. 현장 녹음의 잔향이 따라오는 이유

목소리 복제 모델은 음색만 분리해서 배우지 않는다. 마이크 거리, 방의 울림, 압축 음질, 주변 공기 소리, 말끝 습관까지 목소리 특징으로 받아들인다. 현장 인터뷰를 참고시키면 `그 사람의 목소리`와 함께 `현장에서 녹음된 소리`가 재현된다.

잔향 제거 전처리를 넣으면 나아질 수 있지만, 강하게 걸면 자음과 음색까지 훼손한다. 잔향을 줄인 참고 음성이 원본보다 항상 낫다고 가정하지 않고 둘 다 시험한다.

## 4. 한 번의 비교 시험으로 끝낸다

학습·미세 조정부터 하지 않는다. 짧은 참고 음성으로 바로 시험한다.

1. 원본 참고 음성과 잔향을 약하게 줄인 참고 음성 두 가지로 생성한다.
2. 지시 없음, 단호하고 희망적으로, 성우처럼 또렷하게 세 가지 말투를 비교한다.
3. 세 문장 정도의 고정 시험 문장을 모든 후보에 똑같이 쓴다.

채택 기준은 모두 만족해야 한다.

- 문장을 빠짐없이 정확히 읽는다.
- 0초·무음·엉뚱한 말이 나오지 않는다.
- 녹음 공간의 잔향과 웅웅거림이 두드러지지 않는다.
- 문장 끝이 매번 축 처지지 않는다.
- 말투 지시 전후 차이를 사람이 바로 알아듣는다.
- 목소리가 목표 인물과 유사하게 유지된다.

자동 받아쓰기 일치율은 발음 정확성과 파일 정상 여부만 알려 준다. 잔향·자연스러움·유사성은 사람이 들어서 판정한다. 한 번의 비교에서 기준을 못 넘으면 로컬 엔진 탐색에 시간을 더 쓰지 않고 클라우드 엔진으로 전환한다.

## 5. 설치 메모

- CosyVoice 계열은 공식 설치 안내가 리눅스 중심이다. Windows에서는 전용 가상환경(파이썬 3.10)이나 WSL이 안정적이다. 빌드·실행 모두 `setuptools<70`이 필요했다(`pkg_resources`).
- 0.5B 모델은 12GB GPU에서 돈다. 첫 로드는 수 분, 이후 합성은 문장당 수십 초였다.
- 일부 전처리가 CUDA 라이브러리 세대 차이로 CPU 대체 실행돼도 결과 생성에는 문제가 없었다.
