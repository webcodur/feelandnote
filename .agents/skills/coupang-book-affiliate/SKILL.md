# 쿠팡 도서 제휴 링크

상품 URL 확보가 아니라 **살 만한 상품 선정**이 이 작업의 핵심이다.

## 먼저 읽기

- 상품 판정은 `docs/project/operations/monetization.md`의 「쿠팡 파트너스」를 따른다.
- 후보 수집·확정 명령과 입력 형식은 `sw/web-bo/scripts/coupang/README.md`를 따른다.
- 인물의 등장·연관 작품을 새로 찾거나 기존 작품 구성을 재선정하는 작업은 `../fiction-source-curation/SKILL.md`에서 먼저 확정한다.

## 실행

1. 기존 콘텐츠는 한국어판 ISBN을 확정한다. 신규 인물 도서는 앞 단계에서 확정한 작품을 먼저 한 번만 등록하고, 충실한 한국어판을 그 작품 아래 판본으로 둔다. 판매 상태가 좋다는 이유로 다른 작품이나 느슨한 관련서를 대신 고르지 않는다.
   - 완역·번역자·출판사·축약·분권처럼 읽는 경험이 실제로 다른 판본은 같은 작품 아래 여러 개 둘 수 있다. 개수를 채우지 말고 선택할 이유가 있는 판본만 남긴다.
   - 인물의 등장 관계는 작품에만 둔다. 판본이나 쿠팡 상품을 바꿔도 관계를 옮기거나 지우지 않는다. 번호가 붙은 분권은 후속권 하나만 단독 판매 진입점으로 내지 않는다.
2. `candidates.mjs`로 후보를 모으고, 같은 ISBN 후보의 상품 화면을 직접 연다. 로켓배송·도착 보장 같은 배송 배지가 실제 선택 상품에 붙어 있는 후보만 남긴 뒤 구매 또는 상품평 신호·판매자·재고·가격을 비교한다. 배송 배지가 없으면 판매량이나 평점이 높아도 링크를 비워 둔다.
3. 선택 자료에는 후보의 `productId`와 `productUrl`, 파트너스 `affiliateUrl`, 화면에서 확인한 `qualityEvidence`를 보존한다. `qualityEvidence`에는 실제 배송 배지 문구가 반드시 들어가야 하며 검색 순번은 상품 식별자가 아니다.
4. `pick.mjs`가 검토한 상품 ID·판매 항목과 현재 검색 결과가 일치할 때만 파트너스 링크를 만든다.
5. 같은 판본·플랫폼에는 활성 상품 하나만 둔다. 교체할 때 기존 상품은 이력으로 비활성화하고 새 상품만 활성화한다. 반영 뒤 DB의 최종 URL이 `https://link.coupang.com/a/...`인지, 그 링크가 선택한 상품으로 가는지 다시 확인한다. 같은 상품 안의 도착 보장 판매자를 골랐더라도 단축 링크가 판매자를 고정하지 못해 무배지 기본 판매자로 열리면 탈락시킨다. 바뀐 콘텐츠 ID만 캐시 무효화한다.
6. 인물 도서 BOOK은 작품 소개도 확인한다. 카카오 검색 요약이 문장 중간에서 끊겼다면 `fiction:source:descriptions`를 dry-run한 뒤 반영한다. 이 도구는 같은 ISBN의 전체 소개와 현재 앞부분이 일치할 때만 늘리고, 관련 작품·인물 캐시까지 갱신한다.

## 탈락

- 같은 작품의 다른 판본을 기존 ISBN 상품인 것처럼 연결하지 않는다. 새 판본으로 등록하거나 비워 둔다.
- 해설서·현대 재화·일부 발췌본을 원작 전체처럼 지정하지 않는다. 더 적절한 등장 작품이 이미 같은 인물을 포괄하면 중복 작품 지정을 다시 판단한다.
- 로켓배송·도착 보장 같은 배송 배지가 실제 선택 상품에 없으면 비워 둔다. 공식 판매자·상품평·판매량은 배송 배지를 대신하지 못한다.
- 묶음·분권·중고·해설서·해외판이 콘텐츠 범위와 다르면 탈락시킨다.
- 일반 `www.coupang.com/vp/products/...` 주소는 후보 근거로만 쓴다. DB에는 파트너스 단축 주소만 저장한다.

## 감사 완료 조건

링크가 열리는지만 세지 않는다. 작품 자체의 선정 가치까지 다시 보고, 각 연결에 대해 판본, 선택 상품 ID, 배송·판매 근거, 최종 파트너스 링크가 서로 맞아야 통과다. 현재 상품 정보를 복원할 근거가 없으면 미확인이지 통과가 아니다.
