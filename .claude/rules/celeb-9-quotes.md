# 셀럽 명언 검수·교정 룰북

기존 셀럽 명언(quotes)을 검수하고 교정하는 전용 가이드.

---

## 작업 흐름

### 1. 배치 조회

```sql
SELECT id, nickname, profession, quotes
FROM profiles
WHERE profile_type = 'CELEB'
ORDER BY nickname
LIMIT 30 OFFSET {offset};
```

- 30명씩 배치로 처리한다
- 각 배치마다 문제 있는 명언을 식별 → 교정 → UPDATE

### 2. 문제 식별

각 명언을 아래 **검수 체크리스트** 순서대로 판정한다.

### 3. 교정

- 문제가 있는 명언만 교정한다. 정상 명언은 건드리지 않는다
- 교정이 필요한 인물은 **웹 검색으로 올바른 명언을 확인**한 뒤 교체
- 검색해도 적절한 명언이 없으면 빈 문자열로 처리

### 4. 배치 UPDATE

```sql
UPDATE profiles SET quotes = CASE id
  WHEN '{id1}' THEN '{교정된 명언1}'
  WHEN '{id2}' THEN '{교정된 명언2}'
  ...
END
WHERE id IN ('{id1}', '{id2}', ...);
```

- 개별 UPDATE 금지. 반드시 CASE문으로 배치 처리

## 검수 체크리스트 (판정 순서)

아래 순서대로 확인하며, **하나라도 해당하면 교정 대상**이다.

### A. 즉시 탈락 (검색 불필요)

| # | 판정 기준 | 예시 | 조치 |
|---|----------|------|------|
| A1 | **빈 값** | `""` | 웹 검색으로 명언 확보, 불가 시 유지 |
| A2 | **캐릭터 대사** (영화·드라마·소설·게임) | "I'll be back", "나한테 말하는 거야?" | 본인 실제 발언으로 교체 |
| A3 | **노래 가사** | "앉아라, 케말라" | 본인 인터뷰 발언으로 교체 |
| A4 | **복수 명언 합본** (`/`로 연결) | "명언1" / "명언2" / "명언3" | 가장 상징적인 1문장만 선택 |
| A5 | **따옴표 래핑** | `'명언 내용'` | 따옴표 제거 |
| A6 | **원문 미번역** (한문·외국어 그대로) | 學問之道無他 | 한국어로 번역 |
| A7 | **50자 초과** | 장문의 명언 | 핵심만 추려 50자 이내로 축약 |
| A8 | **이스케이프 문자** (`\"` 등) | `\"교향곡은...\"` | 정상 문자열로 교정 |

### B. 검색 필요 판정

| # | 판정 기준 | 예시 | 조치 |
|---|----------|------|------|
| B1 | **타인 명언 오귀속 의심** | 벤저민 그레이엄에게 워렌 버핏 명언 | 웹 검색으로 원발화자 확인 → 교체 |
| B2 | **중복 귀속 의심** | 봉준호·마틴 스콜세지 동일 명언 | 원발화자 확인 → 비원발화자쪽 교체 |
| B3 | **AI 생성 의심** (범용적·검증 불가) | "연기는 진실을 찾는 과정이다" | 웹 검색으로 실제 발언 확인 → 교체 또는 빈 문자열 |
| B4 | **슬로건/구호** | "미국을 다시 위대하게" | 인물의 철학이 담긴 실제 발언으로 교체 |
| B5 | **풍자 대상의 말을 본인 말로** | 볼테르에게 라이프니츠 주장 등록 | 정확한 출처 확인 후 교체 |

### C. AI 생성 의심 판별법

아래 패턴 중 **2개 이상** 해당하면 AI 생성을 의심한다.

1. **"X는 Y이다"** 정의형 문장 (예: "연기는 진실을 찾는 과정이다")
2. 해당 인물만의 **고유한 맥락/사건/작품**이 전혀 없는 범용 문장
3. **같은 직군의 다른 인물**이 말해도 전혀 어색하지 않음
4. 웹 검색 시 해당 인물과 연결된 출처가 **하나도 없음**

→ 의심 시 `"{인물 영문명} famous quote"` 또는 `"{인물 한글명} 명언"`으로 웹 검색
→ 검색 결과에서 출처가 확인되면 해당 명언으로 교체
→ 확인 불가 시 빈 문자열

## 교정 시 명언 선정 기준

### 우선순위

1. **역사적으로 가장 유명한 발언**: 해당 인물 하면 바로 떠오르는 한마디
2. **인물의 핵심 철학/신념**: 인터뷰·연설·저서에서 나온 대표 발언
3. **빈 문자열**: 검증 가능한 발언이 없으면

### 출처 허용/불허

| 허용 | 불허 |
|------|------|
| 인터뷰, 연설, 기자회견 | 출연작 캐릭터 대사 |
| 저서, 서한, 조서 | 타인이 해당 인물에 대해 한 말 |
| 공식 SNS 본인 발언 | 작품 속 인물 대사 |
| 역사서에 기록된 직접 발언 | 노래 가사 |

### 포맷

- **50자 이내**, 한 문장
- 한국어로 작성 (외국어 원문 병기 금지)
- 따옴표(`""`, `''`)로 감싸지 않음
- 문자열 내 큰따옴표는 작은따옴표로 대체

## 검색 전략

### 확실한 인물 (검색 생략 가능)

역사적 위인, A급 유명인 등 대표 명언이 **명백하게** 알려진 인물은 검색 없이 판정 가능.
- 예: 데카르트, 링컨, 간디, 아인슈타인 등

### 불확실한 인물 (검색 필수)

B~C급 배우, 현대 기업인, 인플루엔서 등 대표 명언이 불명확한 인물.

```
"{영문 인물명} famous quote"
"{영문 인물명} best quotes"
"{한글 인물명} 명언"
```

- 검색 결과에서 **복수의 출처**가 동일 발언을 인용하면 신뢰
- 단일 출처이거나 quote aggregator 사이트만 나오면 추가 검증 필요
- Brainyquote, Goodreads Quotes 등은 참고용으로만 (오귀속 많음)

### 배치 효율화

- 30명 배치에서 즉시 탈락(A 카테고리)은 바로 처리
- B 카테고리 의심 건만 모아서 한 번에 검색
- 검색은 **배치당 최대 10건** 이내로 제한 (효율)

## 보고 형식

각 배치 처리 후 아래 형식으로 보고한다.

```
## 배치 {N} (OFFSET {offset})
- 검수: {총 인원}명
- 정상: {정상 수}명
- 교정: {교정 수}명
  - A1(빈값): {n}건
  - A2(캐릭터 대사): {n}건
  - B3(AI 생성): {n}건
  - ...
- UPDATE 실행 완료
```
