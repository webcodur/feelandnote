# 이미지 생성기의 물리학

디퓨전 계열 이미지 생성기가 어떤 그림은 잘 그리고 어떤 그림은 못 그리는 구조적 이유와, 거기서 나오는 프롬프트 기법이다. 특정 작품·인물과 무관하게 소재가 바뀌어도 살아남는 원리만 남겼다. 예시는 실제 생성 실패에서 가져왔다.

## A. 구조적 특성 여섯

### A1. 빈도 의존성 — 흔한 장면은 강하고 희귀한 장면은 평균으로 회귀한다

생성기는 학습 사진의 분포를 따른다. 스튜디오 정물·인물 포트레이트·풍경은 수억 장을 학습해 강하지만, 특정 나라의 개표소나 전용 기계처럼 학습 사진이 희소한 피사체를 요구하면 가장 가까운 흔한 것들(프린터·복합기·키오스크)의 평균을 내놓는다. **재시도해도 분포가 바뀌지 않으므로 재롤은 무의미하다.** 구조를 바꾼다(아래 「재롤 규칙」).

### A2. 글자는 언어가 아니라 무늬다 — 네거티브는 상관관계를 못 이긴다

생성기는 글자를 픽셀 패턴으로 그린다. 더 치명적인 건 **「글자 쓰지 마」라는 지시가, 글자가 있어야 자연스러운 면이 화면에 있는 한 무력화**된다는 점이다. 시위 군중을 그리면 팻말이 나오고, 팻말이 나오면 학습 데이터에서 가장 흔한 시위 문구가 환각된다(`no readable text`를 명시했는데 실존 구호가 통째로 박혀 나온 사례가 있다 — 정치적으로도 위험한 폐기물).

- **해법은 네거티브가 아니라 면의 제거다.** 팻말은 뒷면만(`blank back sides of signs`), 화면은 정전·노이즈만, 코드는 추상 광으로.
- 봉인 스티커·띠지처럼 특정 실물을 알아보게 하는 표식도 결국 글자다. 시도하지 않는다.

### A3. 다인물 붕괴 — 어텐션은 인물 수만큼 쪼개진다

얼굴 하나에 쓸 수 있는 디테일 예산이 인물 수에 반비례한다. 대략 **3인 이상 + 중경 거리**부터 얼굴이 뭉개지기 시작하고 6인 이상이면 전멸한다.

- 해법 사다리(강→약): ① 역광 실루엣(얼굴을 그릴 의무 자체를 제거) ② 뒷모습 ③ 아웃포커스 보케 ④ 1~2인만 또렷하게, 나머지는 흐림.
- 군중의 감정은 몸짓과 빛으로 전하고 얼굴은 그리지 않는다.

### A4. 단일 피사체 집중은 최강이다 — 매크로·정물·단독 포트레이트

어텐션이 한 곳에 모이면 종이의 섬유, 유리의 굴절, 청동의 녹청, 홍채의 반사까지 나온다. 잘 나온 컷은 거의 전부 단독 인물·단독 사물·단독 동상이었다. 따라서 **「한 컷 = 주인공 하나」가 기본 문법**이다. 문장 하나를 사물 하나가 지게 한다.

### A5. 반복 일관성이 없다 — 같은 프롬프트도 매번 다른 사물

생성마다 디자인이 흔들린다. 여러 컷에 같은 사물이 나오면 참조 이미지 없이는 컷마다 다른 물건이 된다. 반복 사물은 **히어로 REF를 먼저 1장 굳히고** 전 컷이 그 이미지를 참조한다. 실존 인물 REF와 같은 원리다.

### A6. 막연한 형용사는 평균을 부른다 — 「cinematic」의 함정

`cinematic`이라고만 쓰면 평균적 시네마틱(스톡 사진)이 나온다. 특정한 그림은 **카메라(렌즈 mm·앵글·조리개)와 조명(방향·색온도·광원 수)을 구체적으로 지정**해야 나온다. 추상 거인(`titan`)을 막연히 요구하면 검은 덩어리가 나온다 — 형태가 특정된 사물(청동 동상, 구체적 자세)로 못 박는다. 막연한 대상 + 역광 + 어두운 하늘이 겹치면 표면이 「기름을 뒤집어쓴」 질감으로 뭉개진다.

## B. 추상 개념의 사물화 — 「살짝의 추상」

부패·해킹·시간 같은 개념을 직접 그리라면 실패한다. **개념 = 사물의 상태 변화**로 번역한다.

| 개념 | 사물 + 상태 변화 |
|---|---|
| 부패 | 흰 종이 더미에 검은 잉크가 스며 오름 (오염) |
| 해킹 | 아날로그(종이·상자) 위를 디지털 빛이 기어감 (잠식) |
| 약탈 | 상자에서 종이가 어둠의 손으로 떠오름 (이탈) |
| 조종·선동 | 실루엣 손목에 매인 꼭두각시 줄 (속박) |
| 권력 이동 | 거대 화면의 죽음 + 작은 폰 불빛들의 점화 (반전) |
| 거짓의 폭로 | 회색 가면이 빛 속에서 깨지는 순간 (파열) |

이 공식이 작동하는 이유는 **초현실이지만 물리 법칙은 유지**되기 때문이다. 종이가 떠오르고 잉크가 번지는 건 생성기가 그릴 줄 아는 물리 현상이고(A4), 보는 사람도 한눈에 읽는다. 물리를 깨는 추상(개념 콜라주, 초현실 합성체)은 생성도 불안하고 독해도 느리다.

**합격선 — 사건이 본질을 직격하는가.**

- ✅ 사물에 일어나는 사건이 곧 문제 그 자체인 것. 「코드 빛이 종이를 덮친다」(=해킹), 「잉크가 흰 종이에 스며 오른다」(=부패).
- ❌ **기성 상징물(모래시계·저울·천칭 등)을 빌려와 관념을 대신 말하게 하는 것.** 「보관 기간 동안 무방비로 놓인다」는 문제를 모래시계로 그리면 「시간이 흐른다」는 일반론일 뿐이다. 정답은 「깊은 밤 보관소에 홀로 놓인 상자」처럼 **그 문제의 현장을 그대로 무대화**하는 것이다.
- 판별 질문: 「이 그림의 사건을 한 문장으로 말하면 본문의 문제 진술과 같은 문장이 되는가?」

생성기가 못 그리는 기계류는 사다리로 내려간다: ① 생성 금지하고 다른 소재로 ② 추상 대체(빛이 기계를 잠식) ③ 실루엣·부분 클로즈업 ④ 실물 보도사진 확보 후 어둡게 그레이딩.

## C. 공통 레시피

### 프롬프트 골격 (이 순서대로)

```
[무대: 보이드/안개/자연] + [주인공 1개: 사물 또는 인물] + [상태/행위 하나]
+ [광원 1개 + 악센트 1색] + [카메라: 렌즈mm·앵글·조리개·포커스 대상]
+ [공통 스타일] + [네거티브: 글자·로고·페인터리·3D렌더]
```

### 재롤 규칙

같은 프롬프트가 **2회 실패하면 재롤을 멈춘다.** 분포가 바뀌지 않는다(A1). 대신 구조를 바꾼다.

1. 피사체 수를 줄인다 (군중 → 한 명, 더미 → 한 장)
2. 글자 면을 제거한다 (정면 → 뒷면, 켜진 화면 → 꺼진 화면)
3. 거리를 당긴다 (와이드 → 매크로)
4. 그래도 안 되면 소재의 단을 바꾼다 (추상 ↔ 실사 폴백)

### 검증 순서 (비용 절감)

1. 히어로 REF부터(반복 사물·인물). 시안 확정 전 본 컷을 뽑지 않는다.
2. 본 컷은 「주인공 하나」 컷부터(성공률 높음). 복합 컷은 뒤로.
3. 결과 검수: 얼굴 뭉개짐 / 글자 환각 / 손가락 / 닮음(REF 컷) / 톤 일탈.
4. 실존 인물 REF 합성은 강점이지만 거리가 생명이다. 인물이 원거리·로우키면 닮음이 사라진다. REF 인물은 화면에서 충분히 크게 둔다.
