# 편집국 검토

반드시 다음을 읽는다.

- `docs/project/remotion/book-recommend/writer/5-editorial-board.md`

## 절차

1. `remo-write-story-dump`로 검토용 Markdown을 만든다.
2. 분야 정확성, 사료, 영상 이야기, 한국어 자연성 네 관점으로 읽는다.
3. 강한 장면, 치명 결함, 개선 가능점, 자료상 한계를 책별로 기록한다.
4. 사실 오류·인과 비약·죽은 등장인물·이해 불가능한 문장을 우선 수정한다.
5. 텍스트를 확정한 뒤 JSON에 반영하고 구조를 검사한다.

숫자 점수는 사용자에게 비교가 필요할 때만 사용한다. 모든 책에 같은 점수를 요구하지 않고, 검증되지 않은 사건·감정·인과관계를 만들어 등급을 올리지 않는다. 등장인물은 실제 행동이나 갈등을 담당해야 하며, 그렇지 않으면 뺀다.
