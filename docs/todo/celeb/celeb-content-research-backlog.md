# LIGHT 콘텐츠 조사 잔량

> 상태: **대기** · 기준 실측: 2026-08-12

## 다음 작업

2026-08-03 KST에 연속 생성된 `light` 224명의 BOOK·VIDEO·GAME·MUSIC을 전수 조사한다.
이 묶음은 최근 음악인 조사 묶음과 다르며, 현재 224명 모두 실제 콘텐츠 0건이고
`content_research_confirmed_empty_at`도 비어 있다.

| 기준선 | 값 |
|---|---:|
| 생성 구간 | 2026-08-03 16:51:42~20:35:37 KST |
| 인원 | 224명 |
| 콘텐츠 1건 이상 | 0명 |
| 0건 조사 확정(`-1`) | 0명 |
| 조사 미확정(`0`) | 224명 |
| 공개 상태 | 전원 `suspended` |

직군은 기업인 71명, 기타 43명, 지도자 20명, 정치인 18명, 운동선수 16명,
지휘관 12명, 과학자 11명, 음악가 9명 등이다. 따라서 이 잔량을 “최근 가수 224명”으로
해석하지 않는다.

## 대상 재조회

위 건수는 착수 기준선일 뿐 고정 명단이 아니다. 실행 직전에 live DB에서 다음 조건을 모두
만족하는 인물을 다시 조회한다.

- `celeb_tier = 'light'`
- `publication_status = 'suspended'`
- `created_at >= '2026-08-03T16:51:42+09:00'`이고
  `created_at < '2026-08-03T20:35:38+09:00'`
- 실제 `celeb_contents`가 0건
- `content_research_confirmed_empty_at IS NULL`

`suspended`는 일반 콘텐츠 조사 화면의 모집단에서 제외되므로 화면의 기본 잔량만 보고 이 묶음을
완료로 판정하지 않는다. 이번 작업은 사용자가 명시적으로 지정한 일회성 코호트 조사이며,
조사를 이유로 공개 상태를 바꾸거나 일괄 활성화하지 않는다.

## 실행 계약

- [`RESEARCH_RELAY_ALGORITHM.md`](../../../RESEARCH_RELAY_ALGORITHM.md)에 따라 인물 한 명을
  한 조사 레인이 조사·최종 저장·자체검증까지 책임진다.
- 세부 수집 규칙은 [`celeb-2-content-collector.md`](../../project/celeb/celeb-2-content-collector.md)를 따른다.
- BOOK·VIDEO·GAME·MUSIC 네 유형을 모두 조사한다.
- 유효한 콘텐츠를 찾으면 `contents`·KO/EN `content_locales`·`celeb_contents`에 즉시 완성된
  상태로 등록하고, `review`·`review_en`·`source_url`까지 같은 작업에서 검증한다.
- MUSIC은 iTunes의 정확한 트랙과 `previewUrl`이 확인된 경우에만 등록한다.
- 네 유형을 모두 조사해도 유효한 콘텐츠가 0건인 인물만 0건 확정 시각을 기록한다.
- 조사 큐·후보·진행 상태를 저장할 새 테이블이나 컬럼을 만들지 않는다.

## 완료 조건

1. 재조회한 코호트 전원이 실제 콘텐츠 1건 이상 또는 0건 조사 확정 상태다.
2. 코호트의 조사 미확정 표시값 `0`이 0명이다.
3. 신규 콘텐츠의 KO/EN locale, 출처, 한영 감상경위와 타입별 외부 메타가 모두 저장됐다.
4. 저장 후 같은 조사자가 자기 결과를 재조회해 동명이인·중복·출처 불일치·저장 실패가 없음을 확인했다.
5. `publication_status`는 이 작업에서 변경하지 않았다.

## 이미 끝난 인접 묶음

2026-08-07~09 KST에 생성된 최근 음악인 222명은 현재 콘텐츠 보유 154명,
0건 조사 확정 68명, 조사 미확정 0명이다. 완료 보고에서 빠졌던 지인은 2026-08-12에
게임 2건을 등록해 보정했다. 이 222명은 다시 조사하지 않는다.

`mentor`·`amphinomus`는 `fiction`이므로 콘텐츠 조사 대상이 아니다. 이들의 표시값 `0`은
대표 원전 연결 여부로 별도 처리한다.
