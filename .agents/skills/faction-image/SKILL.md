# 세력도감 이미지 규칙

도감의 서비스 안내용 불씨·부엉이·사자 활용은 [서비스 캐릭터 규칙](../../../docs/project/service/service-07-mascots.md)을 따른다.

테마마다 정체성이 드러나는 다채롭고 고유한 콘셉트 아트로 표지를 설계한다.

공통 발주·자가 검수 기준은 [이미지 생성·발주 규칙](../../../docs/project/production/prod-01-image-generation.md)이 쥔다. 유료 생성과 서비스 반영은 사용자의 명시적 지시 뒤에 실행한다.

## 테마 표지

- **3:2 가로, 1536×1024** 한 장으로 만든다.
- 인물·군중·사건·행동·사물·상징·추상 표현·공간·풍경을 모두 허용한다. 테마의 핵심을 가장 잘 보여 주는 소재와 구도를 고른다.
- 실사·회화·일러스트·콜라주·그래픽·초현실·3D 등 화풍을 자유롭게 선택한다. 테마별 색감·재질·규모·시점도 달리해 고유한 인상을 만든다. 빈 방·건축 풍경·책상 위 소품을 기본 구도로 고정하지 않는다.
- 실제 조직의 로고·문장은 확인된 형태를 쓰고, 창작 상징은 실제 조직의 공식 표식처럼 제시하지 않는다. 실존 인물의 신원과 역사적 사건의 사실관계는 공통 규칙을 따른다.
- 작은 크기에서도 주제와 핵심 형태가 읽히게 설계한다. 화면에서 이름을 별도로 표시하므로 그림 안 제목·UI 문구와 제목을 위한 넓은 빈 공간을 강제하지 않는다.

### 표지 발주문과 검수

실제 생성용 발주문에는 테마를 드러내는 시각적 아이디어, 주요 소재·행동, 화풍, 색감·광원, 구도, 산출 경로를 담는다. 장소는 아이디어에 필요할 때 지정한다.

테마별 작업 폴더와 복구본·작업 자료의 정리는 [작업 파일·백업 원칙](../../../docs/project/data/README.md#작업-파일백업)을 따른다. 표지 후보는 해당 작업 폴더의 `_staging/cover.png`에 둔다. 기존 확정 자산의 교체는 원본을 보존하고 사용자 승인 뒤에 반영한다.

생성 결과는 직접 열어 테마의 전달력, 선택한 화풍의 완성도, 구도·색감·광원·재질, 인물이나 사물의 오류, 작은 크기에서의 가독성을 검수한다. 여러 표지는 소재·화풍·구도가 관성적으로 반복되는지도 확인한다. 이전 최선본보다 개선되지 않은 후보는 교체하지 않는다.

표지의 서비스 표시와 기존 이미지 묶음 처리는 [세력도감 화면 규격](../../../docs/project/service/service-01-explore.md#세력도감-explorefaction-explorefactionslug), 업로드·저장 규격은 [세력도감 운영](../../../docs/project/apps/apps-01-web-bo.md#세력도감)을 따른다.

## 주요 장면

1:1 이미지로 만든다.

장면별 해설 분량, 내용에 따른 이미지 분할·추가 제작, 완성 표시는 [주요 장면 룰북](../../../docs/project/production/prod-02-myth-image-captions.md)을 따른다.
