# 서재탐방 책 순서 검토

책 순서는 `books/NN-책이름/`의 번호가 결정한다. 단순한 JSON 배열 재배치가 아니며, 쇼츠 번호·SOLO 번호·음성 폴더·이미지·업로드 기록에 영향을 줄 수 있다.

## 기본 원칙

시간순은 이해하기 쉬운 기본값이지만 강제하지 않는다. 다음 가운데 한 가지 이유가 있을 때만 순서를 바꾼다.

- 인물의 선택과 결과를 시간순으로 따라가야 이해되는 경우
- 첫 장면에 가장 강한 사건을 놓아야 하는 경우
- 마지막 책이 시작의 질문을 회수하는 경우
- 두 책의 대비를 붙여야 의미가 생기는 경우

“느낌상 더 좋다”만으로 바꾸지 않는다.

## 검토 절차

1. Markdown 원고를 책 순서대로 읽는다.
2. 각 책의 핵심 사건 연도와 인물 생애 단계를 적는다.
3. 시간 역행이 의도인지 실수인지 판정한다.
4. 현재 순서와 제안 순서의 이야기 이득을 비교한다.
5. 순서 변경이 영향을 주는 자산을 확인한다.
6. 사용자에게 제안하고 승인받은 뒤 이동한다.

## 순서 변경 영향

- `books/NN-` 폴더 번호
- 쇼츠 슬롯과 기존 업로드 번호
- SOLO의 `B{NN}` 영상·음성 경로
- 책별 음성 및 자막 시각
- 앞뒤 책을 잇는 문장
- 이미지·렌더·유튜브 기록
- 인물 공통 음성 설정 안의 책 순서 정보

따라서 이 스킬은 기본적으로 분석과 제안만 한다. 사용자가 순서 변경을 승인하면 `remo-shorts-slot-map`으로 충돌을 확인하고, 관련 자산을 한 작업으로 함께 갱신한다.
