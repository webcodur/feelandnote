## 작업 목표

시리즈 출연 인물 48명 전원의 실제 어록을 웹에서 채굴해 **인물별 md 파일**로 정리한다.

- 인당 최대 **50개** 목표. 단, 사료가 없는 인물은 있는 만큼만 (부풀리기 금지)
- 형식: **대사 (출처 링크)** — 한국어 대사체 번역 + 원문 + 맥락 한 줄 + URL
- verbatim 원칙: 사료 전승 발언만. 창작·추측 금지. 위작은 `[위작 의심/출처 불명]` 표시
- 위작 소굴 주의 인물: 아리스토텔레스, 나폴레옹, 키케로, 알렉산드로스 (Wikiquote Misattributed 섹션 필수 확인)
- 셰익스피어·영화 대사는 실제 어록 아님 (수록 시 `[셰익스피어 창작]` `[영화 창작]` 구분 표시)

### 인물 파일 형식

```markdown
# <인물명> 어록

> 확보: N건 (실제 사료 M건 / 위작 의심 K건) · 조사일 YYYY-MM-DD

## 주제분류

1. **"한국어 대사체 번역 (~다 종결, 축약 아님)"**
   - 원문: "원어/영어"
   - 맥락: 언제·어디서·누구에게 (한 줄)
   - [출처명](URL)

## 대사화 추천 TOP 3~5
(사건·감정·전환 발화 우선. 단순 정보 진술 제외)
```

직접 어록이 없는 인물(헤파이스티온·록사나 등)은 "직접 전승 어록 없음" 명시 후
`## 관련 발언 (타인이 이 인물에 대해)` 섹션 허용 — 화자 명확 구분.
