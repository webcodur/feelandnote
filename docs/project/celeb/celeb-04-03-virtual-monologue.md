# 가상독백

`celebs.virtual_monologue`은 인물이 자기 삶과 철학을 자기 목소리로 말하는 한국어 원고다. 현재 사용자 화면에는 노출하지 않으며 담화와 후속 제작의 원천으로 쓴다. 영문은 한국어가 확정된 뒤 별도로 다룬다.

## 생성과 검수

작가는 최소 입력으로 문장력을 살린다.

```text
<인물 이름>. 자신만의 말투로 자신의 삶과 철학을 독백한다. 분량은 A4 반 페이지.
```

첫 호출은 agy의 `gemini-3.8-flash-high`가 위 최소 입력만 받고 쓴다. 두 번째 호출은 agy에서 같은 모델의 새 세션이 웹으로 신원과 중심 사실을 독립 확인하고 초안을 고친다. 세 번째 호출은 로그인된 Claude CLI의 `--model opus`가 앞선 원고와 출처를 사실로 믿지 않고 다시 열어 본 뒤 최종 판정과 수정을 맡는다. 최종본도 A4 반 페이지 분량으로 쓴다.

두 검수자는 기록에 없는 장면·감정·동기·직접 인용·사후 지식을 제거한다. 전기 요약, 현대인의 반성문, 임종 무대, 판박이 역사극 말투도 고친다. 출처가 실제 주장을 지지하지 않거나 근거가 부족하면 글을 완성한 척하지 않고 `hold`로 끝낸다.

세 호출은 서로 다른 세션이다. `sw/web-bo/scripts/celeb/virtual-monologue.mjs`가 각 stdout을 다음 호출의 입력으로 바로 넘기므로 중간 원고를 Codex 대화에 출력하지 않는다. 둘째 Gemini 응답이 구조·근거 계약을 통과하지 못해도 그 원문을 실패 자료로 봉인해 Opus까지 넘긴다. 후보 파일에는 세 단계 결과를 남기되 DB에는 Opus 최종본만 반영할 수 있다. 호출 오류 뒤 같은 입력과 버전으로 다시 실행하면 완료된 단계는 재사용하고 실패한 단계부터 재개한다. Opus의 `hold`와 기계 검사 실패는 최종 탈락이며 자동 재시도나 다른 모델 호출을 붙이지 않는다.

## 최종 검토 위험도

스크립트가 인물 정보로 1차 위험도를 정하고 검수자가 필요하면 `high`로 올린다. 한 번 올라간 위험도는 낮추지 않는다.

- `standard`: 현대의 유명 인물처럼 직접 발화와 공개 기록이 풍부하고 중심 서사가 명확하다. 최종 검토자는 `inspect --slugs ...`가 돌려주는 검수 사유·출처 수·첫머리·끝머리를 개략적으로 보고 이상 신호가 있을 때만 전문을 연다.
- `high`: 오래된 인물, 원전이 희박한 인물, 전설과 사실이 섞인 인물, 폭력·전쟁·자살·종교·철학처럼 동기와 책임을 꾸미기 쉬운 인물이다. 자동 검수가 통과해도 상태는 `review-required`이며, 최종 검토자가 전문과 출처를 열고 중심 주장만 독립적으로 대조한다.

최종 `hold`와 기계 검사를 통과하지 못한 후보는 DB에 쓰지 않는다. 반영은 검토 뒤 `apply --apply`를 명시한 경우만 실행하며, `high`는 `--approve-high`도 함께 요구한다. 현재값이 여전히 비어 있고 잠기지 않은 인물만 갱신한다.

후보 파일은 `data/celeb/virtual-monologue/candidates/`에 덮어쓰며 서비스 값의 원천은 DB다. 회차별 보고서와 과거 후보를 쌓지 않는다.
