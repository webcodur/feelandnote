# 주인장 자유글

채널 주인장(공개 활동명 **아가톤**)이 쓰는 자유글이다. 필앤노트 홍보, 플랫폼 업데이트 소식, 잡소리까지 주제를 가리지 않는다. **공지사항이 아니다** — 공지(`notice-publish` 스킬, `/agora/board/notice`)는 서비스 운영 사실의 전달이고, 자유글은 주인장의 목소리로 쓰는 글이다.

## 나가는 곳

| 채널 | 위치 | 게시 |
|---|---|---|
| 유튜브 커뮤니티 | 필앤노트 채널 게시글 탭 | 사용자가 Studio에 붙여 넣는다 |
| 자유게시판 | `/ko/agora/board/free` | 운영자 계정 로그인 후 글쓰기 (익명 글은 비밀번호 글이라 주인장 글에 쓰지 않는다) |

## 글 규칙

- 1인칭 주인장 시점. 이름은 `주인장`이 아니라 **아가톤**으로 쓴다. 이름의 유래(플라톤 『향연』의 비극 시인)는 처음 소개하는 글이나 가끔만 짧게 곁들인다.
- 한국인이 한국어로 쓴 글답게 쓴다. 번역투와 AI SLOP(과장·추상 평론투·억지 의미 부여·문예 수사)는 뺀다.
- 홍보글도 자유글이다. 기능 나열이 아니라 주인장이 무엇을 왜 만들었는지를 말한다.
- 유튜브 게시글은 몇 문단으로 짧게. 자유게시판은 조금 더 풀어도 된다. 같은 주제라도 채널별로 따로 쓰고 한 원고를 양쪽에 복붙하지 않는다.
- 초안은 `data/free-posts/<NNN>-<slug>.ko.md`에 둔다. 파일 머리말에 채널·상태(초안/게시)·게시일을 적는다.
- 초안만 만들어 사용자에게 보여준다. 게시는 사용자가 한다. 외부 채널에 직접 올리지 않는다.
- 잡소리 계열(세상사·업계 소감)은 필앤노트를 억지로 엮지 않는다. 주인장이 읽고·보고·느낀 것 자체가 글감이다.
- 밈·농담 프레임(「랩틸리언 형님」류)을 써도 된다. 다만 아래 깔린 사실은 정확하게 — 웃기는 방향이지 지어내는 방향이 아니다. 인류 공영 같은 거룩한 톤은 주인장 글감이 아니다.
