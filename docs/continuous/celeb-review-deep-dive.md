# 인물 감상배경 딥다이브

인물×작품 감상경위(`review`·`review_en`)를 여유가 날 때마다 원문 수준으로 깊게 만드는 지속 과제다. 작성·감사 규칙은 [`celeb-02-03-content-review.md`](../project/celeb/celeb-02-03-content-review.md)·[`celeb-02-04-content-audit.md`](../project/celeb/celeb-02-04-content-audit.md), 영상→DB 흡수는 [`remo-db-review-backfill`](../../.agents/skills/remo-db-review-backfill/SKILL.md)이 쥔다. 이 문서는 규칙을 복제하지 않고 어디까지 갔는지만 기록한다.

## 최초 등록 때 다 하지 않는 이유

최초 등록은 출처 1건과 단문으로 얇게 들어가 커버리지를 넓힌다. 딥다이브(원문 열람·후속 언급 추적·인용逐字 대조·오귀속 적발)는 건당 비용이 커서 등록 시점에 하면 등록 자체가 멈춘다. 얇은 등록 때 심층 후보를 표시해 두고 이 과제로 회수한다.

## 작업 방식 (머스크 선례)

1. 1권 시범 → 초안·팩트체크 보고 → 승인 후 확장한다.
2. 기존 DB를 base로 두고 새 정보만 흡수한다. 통째 덮어쓰기 금지.
3. 신규 길이는 기존 이상이어야 한다. 감소분은 사료 손실 신호로 차단한다.
4. 영상 `book.en.json`은 폴더 간 오삽입이 있으므로(머스크 4건 실측) `review_en` 근거로 쓰기 전 제목·본문을 대조한다.
5. 확인 못한 항목은 미해결로 분리하고 본문에 넣지 않는다.
6. 구체 저작이 특정되지 않으면 등록하지 않는다. 인물 일반 언급을 대표작으로 바꾸지 않는다.
