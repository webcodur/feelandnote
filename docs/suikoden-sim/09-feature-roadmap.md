# 09. 기능 로드맵

> 기획서(01~08) 대비 현재 구현 상태 분석 및 우선순위별 구현 계획.

---

## 현재 구현 상태 (2026-02-28)

### 완료

| 시스템 | 구현 내용 |
|--------|----------|
| **턴제 엔진** | `advanceTurn()` — 시간 진행(+10일/턴), 건설/자원/식량/훈련/민심/인구 처리 |
| **2단계 셋업** | 시대/난이도 선택 → `previewWorld()` → AI 세력 미리보기 + 방랑자 중 주군 선택 → `finalizeGame()` |
| **Grade 기반 세력 분리** | Grade ≥ 55: AI 세력 자동 배정 / Grade < 55: 플레이어 선택 가능 방랑자 |
| **페르소나 Grade** | `celeb_persona` 4능력 가중평균 우선, 없으면 `total_score` 폴백 |
| **방랑 페이즈** | 지역 이동, 동료 모집(최대 5명), 랜덤 이벤트(객장/도적/풍경/소문), 거병 |
| **건설** | 15종 건물 정의, 건설→시공→완성, 카드 기반 UI |
| **자원 생산** | 건물별 자원 생산, 근무자 배치 보너스 |
| **식량 소비** | 병력 기반 식량 소모, 부족 시 사기/충성 하락 |
| **근무 배치** | 캐릭터를 건물에 배치 → 생산 보너스 |
| **순찰** | 위협 출몰 → 캐릭터 배정 → 해결 판정 |
| **인재 영입** | 선술집 방문자 등용, 명성 기반 영입 제한 |
| **자동 내정** | idle 캐릭터 자동 배치 (건설/근무/순찰) |
| **전투** | 6전술 상성 시스템 (돌격/방어/계략/화공/고무/유인), 최대 10라운드, 성벽 효과 |
| **포로 처분** | 전투 승리 시 패배 장수 등용/감금/처형/석방 |
| **AI** | 세력별 성향(정복/책략/경제/인덕/문화), 내정·전투·침공 판단 |
| **세계맵** | 10지역, 22영토, 영토 간 연결, 세계맵 뷰 |
| **UI** | GameHUD(상단), GameToolbar, CommandMenu(사이드), 건물 카드 그리드, 캐릭터 상세 |
| **아이템** | 콘텐츠 기반 장비 시스템 (타입/등급 정의) |
| **인사** | 훈련(연병장), 포상(금 50→충성+10), 체력 소모/회복 |
| **외교** | 동맹/정전/조공/항복 권유, 관계도 시스템 |
| **경영** | 세율 조정, 건물 철거, 민심 시스템, 인구 변동 |
| **이벤트** | 계절 이벤트 7종, 랜덤 이벤트 4종, 위협 4종 |
| **명성** | 0~1000, 등급별 영입 요구치, 건설/점령/영입/외교 트리거 |
| **급여** | 등급별 급여 자동 지불 |
| **대사** | DB 개인화 대사(celeb_dialogues) + 톤별 기본 대사(defaultLines) |

### 미구현 (기획서에 있으나 아직 없는 것)

| 카테고리 | 미구현 항목 |
|----------|-----------|
| **전투 확장** | 일기토(1:1 무장 대결) |
| **인사 확장** | 학당 학습(intellect/virtue 성장) |
| **외교 확장** | 이간(두 AI 세력 간 관계 악화) |
| **경영 확장** | 징병(인구→병력 전환), 민심 세분화(폭동/반란) |
| **승리 조건** | 문화 승리, 외교 승리 (통일 승리만 체크 중) |
| **아이템 활용** | 장비 장착 UI, 아이템 획득 로직, 전투 중 효과 적용 |
| **이벤트 확장** | 캐릭터 조합 이벤트, 이벤트 팝업 UI |
| **세이브/로드** | localStorage 세이브 (UI 마련, 기능 미구현) |

## 구현 우선순위 (잔여)

### Phase A: 이벤트 팝업 + UI 개선

| 항목 | 설명 |
|------|------|
| **이벤트 팝업** | 이벤트 발생 시 화면 중앙 팝업, 확인 버튼 |
| **영토 비교** | 세력별 영토/자원/병력 비교 테이블 |

### Phase B: 인사/경영 확장

| 항목 | 설명 |
|------|------|
| **학당 학습** | 학당에 배치 → intellect/virtue 성장 |
| **징병** | 병영에서 인구→병력 전환, 민심 -5 |
| **민심 세분화** | 폭동(0-19) 시 건물 파괴/인재 이탈 이벤트 |

### Phase C: 승리 조건 + 전투 확장

| 항목 | 설명 |
|------|------|
| **일기토** | martial ≥ 50 장수끼리 1:1 대결 |
| **문화 승리** | 극장/사원 문화 영향력 → 전체 60% 이상 |
| **외교 승리** | 2/3 이상 세력과 동맹 체결 |

### Phase D: 아이템 + 세이브

| 항목 | 설명 |
|------|------|
| **장비 장착 UI** | 캐릭터 상세에서 scroll/treasure 교체 |
| **아이템 획득** | 전투 승리/이벤트/교역으로 획득 |
| **세이브/로드** | localStorage 기반 세이브 슬롯 3개 |
