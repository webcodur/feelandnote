# 젠슨 황 — 「축하 대신 고통을 빕니다」 대본 근거

이 편은 젠슨 황의 성공담을 늘어놓지 않는다. **성공한 CEO가 왜 학생들에게 고통을 빌었는가**라는 한 질문만 좇는다.

## 사실 골격

1. 젠슨 황은 아홉 살 때 켄터키의 Oneida Baptist Institute에서 생활했고, 기숙사 화장실 청소를 맡았다.
2. 청소년기에는 Denny's에서 설거지 담당으로 시작해 버스보이와 웨이터로 일했다.
3. 엔비디아 창업 뒤 여러 차례 공개적이고 굴욕적인 실패를 겪었다.
4. 그는 낮은 기대치가 회복탄력성을 키웠다고 말한다.
5. 2024년 Stanford SIEPR 행사에서 학생들에게 고통과 시련이 닥치기를 바란다고 말하며, 위대함은 지능이 아니라 고통 속에서 형성된 인격에서 나온다고 설명했다.

화장실 청소와 Denny's 설거지는 **서로 다른 시기의 경험**이다. 일부 2차 기사가 둘을 한 일화처럼 섞지만, Stripe 공식 인터뷰에서 별개의 경험으로 설명한다.

## 채택 원칙

1. 큰따옴표를 쓴 대사는 `origin`의 실제 영어 발언을 옮긴 것이다.
2. 사실을 연결하는 재구성 대사에는 큰따옴표와 `origin`을 붙이지 않는다.
3. 세가·NV1 구제 일화는 기존 서재 탐방 쇼츠와 겹쳐 중심 사건에서 제외한다.
4. 고통을 미화하거나 타인에게 강요하는 이야기로 넓히지 않는다. 이 편에서 말하는 고통은 젠슨 황 자신의 회고와 회복 철학에 한정한다.
