# AI 코딩 에이전트 조사 — Command Code · opencode · Oh My OpenCode

> 작성: 2026-08-06. 저장소 루트 `연구활동/` 폴더 신설 1호 문서.
> 용도: 에이전트 도구 선택·확장 판단을 위한 조사 기록.

## 1. Command Code 조사

- 제품: **commandcode.ai** — "코딩 취향을 배우는" 터미널 코딩 에이전트. Dan Abramov 주도 (React 창시자).
- 컨셉: **taste-1** 메타 신경기호 모델. 수락·거절·수정을 신호로 삼아 프로젝트 스킬·개인 메모리를 자동 생성. 규칙 작성·프롬프트 유지 불필요.
- 모델: 600+ 지원(BYOK). Anthropic·OpenAI·Google·xAI·DeepSeek·Qwen·Kimi·GLM·MiniMax. 오픈 모델 $1/월, 무료 크레딧 $10~40.
- 설치: `npm i -g command-code`, 실행 `cmd`.
- 주요 기능: 에이전틱 `/review`(PR 스코어링+리뷰 코멘트 등록), `/design` 17종 모드(터미널 UI 재설계), 인터랙티브·헤드리스·플랜·자동수락 모드, Studio 대시보드(사용량·비용·API 키), 취향 패키지 팀 공유, 멀티 디렉토리 워크스페이스, `cmd update` 자가 업데이트, 단일 바이너리 ~40MB.
- 단일 바이너리 경량 → 클라우드 그린필드·CI·원격 셸에 적합.
- 상용 제품(시드 $5M 조달), 깃허브는 사실상 랜딩 리포.

## 2. 표준 opencode의 자체 특징

- **에이전트 + 하위 에이전트** — `build`(기본)·`plan`(계획)·`explore`(탐색)·`general` 역할 분리, Task 도구로 병렬 위임
- **스킬(skills)** — `.claude/skills`·`.agents/skills` 지시서 자동 로드. 이 저장소는 스킬 40여 개 작동 중
- **MCP 서버 연결** — DB·검색·브라우저를 도구로
- **모델 자유 교체** — provider별 설정, `opencode auth login`, 터미널에서 전환
- **AGENTS.md** — 프로젝트 지침 자동 반영
- **플러그인·테마·키바인딩** — TUI 커스터마이즈

## 3. opencode 확장 — 그리스 신화 에이전트 (Oh My OpenCode)

Sisyphus·Hephaestus·Prometheus·Atlas 이름은 opencode 자체 기능이 아니라 **Oh My OpenCode (OmO)**라는 서드파티 확장판의 에이전트 프리셋이다.

현재 환경(`~/.config/opencode/opencode.jsonc`는 빈 껍데기, 프로젝트 `.opencode/`·`~/.opencode` 없음)에는 이 에이전트들이 **없다.** 이 세션에서 호출 가능한 건 기본 제공 `explore`(탐색)·`general`(일반)뿐.

### 4주역

| 이름 | 역할 | 얽힌 모델 |
|------|------|-----------|
| **Sisyphus 시시포스** | 기본·주역 에이전트. 지시를 받아 도구·스킬·하위 에이전트를 조합해 끝까지 진행 | Claude·Kimi 계열 |
| **Hephaestus 헤파이스토스** | 자율 딥워커. 목표만 주면 혼자 코드를 파고들어 완성. fallback 없어 **GPT 계정 없으면 아예 못 씀** | GPT 계열 전용 |
| **Prometheus 프로메테우스** | 전략·설계 담당. 모델 계열을 런타임 감지해 프롬프트 자동 전환 | GPT / Kimi 자동감지 |
| **Atlas 아틀라스** | 작업 지휘자. 복잡한 일을 계획으로 쪼개고 순서 설정 | Claude / GPT 자동감지 |

### 나머지

- **Oracle 오라클** — 아키텍처 자문. GPT 계열.
- **Metis 메티스** — 협업·커뮤니케이션형. Claude 계열.
- **Momus 모무스** — 코드 비평·반박 검토. GPT 계열.

설치하면 에이전트 탭이 `시시포스 → 헤파이스토스 → 프로메테우스 → 아틀라스` 순으로 고정된다.

핵심: 이름 자체보다 **"역할별로 모델 계열을 갈아 끼우는 구조"**가 본질이다 — 시시포스·헤파이스토스는 계열 고정, 프로메테우스·아틀라스는 자동 전환.

## 4. Command Code vs opencode — 비교우위

**둘 다 가진 것**(터미널 에이전트, 멀티 모델 BYOK, MCP, 스킬, 슬래시 커맨드, AGENTS.md, 하위 에이전트, 모드 4종)은 건너뛰고 **차이나는 축만** 기록.

### Command Code 비교우위 (opencode에 없는 것)

1. **취향 학습** — 수락/거절/수정 → 스킬·메모리 자동 생성. opencode는 AGENTS.md를 사람이 직접 작성.
2. **상용 관리형 서비스** — Studio 대시보드(사용량·토큰 비용·API 키), 자동 업데이트. opencode는 구성 전부 수동 관리.
3. **에이전틱 `/review`** — PR 자동 추출·스코어링·리뷰 등록. opencode는 내장 코드 리뷰 워크플로 없음.
4. **`/design` 17종** — 터미널에서 UI 시스템 점검·재설계. opencode엔 디자인 계열 도구 전무.
5. **취향 패키지 공유** — 팀 표준 push·pull. opencode는 AGENTS.md 손복사.
6. **경량·속도** — 단일 바이너리 ~40MB, 서브초 기동.

### opencode 비교우위 (Command Code에 없는 것)

1. **완전 오픈소스 MIT, 무료** — Command Code는 상용, opencode는 0원 + 75개 provider.
2. **완전 로컬 운영** — Ollama/LM Studio 1급 지원, 민감 코드 외부 전송 차단 가능.
3. **클라이언트-서버 아키텍처** — TUI·데스크톱·VS Code 확장·웹 UI·헤드리스 서버·JS/TS SDK·JSON 이벤트 스트림으로 임베드 가능.
4. **타입스크립트 플러그인 훅** — `tool.execute.before`·`shell.env` 등 실행 단계 훅으로 도구 가로채기 확장.
5. **LSP 연동** — 편집 후 언어 서버 진단을 LLM에 피드백.
6. **git 스냅샷 + `/undo`·`/redo`** — 변경 전 스냅샷 롤백.
7. **에이전트별 세분 권한** — 도구 권한 deny-by-default, `permission.task`로 하위 에이전트 호출 제어.

### 위험 요인

- **Command Code**: 폐쇄 소스 + 스타 3.5K(소규모 커뮤니티) + 상용이라 결정권이 회사에.
- **opencode**: 설정 수동 + 내장 코드 리뷰·자동 커밋 없음 + 멀티 에이전트 오케스트레이션 부재 + 같은 모델로 Claude Code 대비 ~78% 느리다는 벤치(Builder.io).

### 판단 요약

- **자동 학습·관리형·팀 표준**을 원하면 → Command Code
- **무료·오픈소스·로컬/임베드 확장·권한 통제**를 원하면 → opencode

## 5. opencode vs Command Code — 항목별 비교

동일한 건 건너뛰고 차이나는 축만 항목으로. 쓴 사람 차이부터 바로잡는다 — **opencode는 SST팀(Dax Raad)**, 한국인 개발자 김연규가 만든 건 확장판 Oh My OpenCode다.

### 1 TUI
- **OPEN**: SST팀이 SST용 TUI를 만들어 온 노하우 → Bubble Tea/Lipgloss 기반, 최근 TUI 전면 교체. 터미널 에뮬레이터에 따라 동작이 갈린다는 지적 있음. 한국어 입력은 오히려 OmO(한국산 확장판) 덕에 반응 좋다는 쪽.
- **CMDC**: 리액트 창시자가 개발해서 TUI가 "말끔함"을 최우선으로 설계됨 — 내 입력 하이라이팅, 서브초 응답, 아름다운 레이아웃이 셀링포인트.

### 2 모델 자유도
- **OPEN**: 75+ provider (Anthropic·OpenAI·Google·DeepSeek·Groq·Ollama·LM Studio). 완전 로컬 모델 1급 지원.
- **CMDC**: 600+ 모델 BYOK. 다만 상용 서비스(Studio) 중심이라 로컬 모델은 opencode만큼 자연스럽지 않음.

### 3 가격/오픈소스
- **OPEN**: 완전 오픈소스 MIT, 무료. API키만 있으면 0원.
- **CMDC**: 상용. 무료 크레딧 $10~40 → 이후 유료, 오픈 모델 $1/월 라인.

### 4 취향 학습
- **OPEN**: AGENTS.md를 사람이 직접 써야 한다. 명시적이지만 수고.
- **CMDC**: 수락/거절/수정을 신호로 스킬·메모리 자동 생성. 규칙 안 써도 됨. → 이게 최대 차이.

### 5 VS Code/CLI 통합
- **OPEN**: 클라이언트-서버 아키텍처로 데스크톱·VS Code 확장·웹 UI·SDK·헤드리스 서버까지. 임베드가 목표.
- **CMDC**: CLI 중심. IDE 확장 언급 미.

### 6 이전 비용(기존 설정 이식)
- **OPEN**: 그대로 자기 세팅 살림.
- **CMDC**: `/import claude|codex|cursor|opencode|gemini` 한 번이면 스킬·에이전트·커맨드·MCP·AGENTS.md가 그대로 복사됨. 호환 포맷은 변환 없이 이식. → 이전 비용 낮음.

### 7 디자인·리뷰
- **OPEN**: 내장된 UI 재설계·PR 리뷰 워크플로 없음.
- **CMDC**: `/design` 17종 모드(터미널 UI 점검·재설계) + 에이전틱 `/review`(PR 스코어링·리뷰 포스팅). → 터미널에서 UI/리뷰까지 다 하려면 이것.

### 8 권한·안전
- **OPEN**: 에이전트별 deny-by-default, `permission.task` 굵은 제어, git 스냅샷 `/undo`/`/redo`.
- **CMDC**: 세분성은 덜 강조.

### 9 커뮤니티·리스크
- **OPEN**: 스타 150K+, 500+ 기여자, 커뮤니티 기반. 회사 의존 없음.
- **CMDC**: 폐쇄 소스 + 스타 3.5K, 상용이라 기능·가격 결정권이 회사에.

### 판정
- 그 기능마다 우열이 갈리는데 **이 프로젝트는 데이터 파이프라인·문서·스킬 운영이 주작업이라** OPEN의 무료·로컬·권한 통제가 각 축에서 우세. UI 재설계·PR 리뷰·팀 규약 공유를 하기 시작하면 그때 CMDC 가치가 올라온다.
