# 신화의 세계 인수인계

`/explore` 신화 구획(신화의 세계)의 남은 작업과 그 앞에 깔린 구조를 넘긴다. 표기·계보 공백은
[`myth.md`](myth.md)가 쥔다. 여기는 **화면과 데이터 구조**만 담는다.

조회는 `sw/web/src/actions/home/getMythAtlas.ts`, 화면은
`sw/web/src/components/features/user/explore/myth/`가 쥔다.

## 먼저 알아야 할 구조

**전승 공개 여부는 DB가 쥔다.** `celeb_tags.atlas_published`가 참인 전승만 열린다. 거짓이면
칩이 잠기고 「작업 예정」이 붙는다. 코드에 이름 목록을 적던 방식을 걷어냈으므로 **전승을 열고
닫는 데 배포가 필요 없다.** 백오피스 세력도감 목록에서 신화 갈래 테마에만 뜨는 「신화 공개」
토글로 켜고 끈다. 태그 행이 바뀌면 DB가 스스로 캐시를 비운다.

**신화 테마의 명단·그룹·차례는 모두 웹이 쥔다(26.09.12).** 차례는 웹 배정(`celeb_tag_assignments`)의 `sort_order` 하나이고,
정비 스크립트는 「그룹 차례 × 1000 + 그룹 안 차례 × 10」으로 매긴다. 그룹 탭 차례는
`celeb_tag_groups.sort_order`다. 손으로 고칠 때는 백오피스 「신화 편집」(`/myths`)에서 구획 안
끌어 정렬로 바꾼다.

**차례를 다시 줄 세우지 마라.** 연결 작품 수로 인물을 재정렬하는 코드가 조회와 화면 양쪽에
있었고, 그것이 전승마다 잡아 둔 계보·이야기 순서를 통째로 뒤집었다. 두 곳을 걷어냈다.
비슷한 정렬을 다시 넣으면 같은 사고가 난다.

**구매 링크는 인물 도서 사슬을 그대로 쓴다.** 인물 → 작품 → 판본(ISBN) → 상품이 이미
연결돼 있고 아틀라스가 그 사슬을 읽는다. 팩션 전용 연결을 따로 만들 필요가 없다.

## 남은 작업 1 — 새 명단·그룹의 뒷일

**명단·그룹 정비는 끝났다(26.09.12).**
- 신화 37개 가운데 인물이 있는 36개를 모두 웹 명단으로 옮겼다(영상 연결 0). 원전 기준으로
  명단을 판정하고 그룹을 새로 짰다.
- 일리아스·그리스 신화·오디세이아는 26.09.11 사람이 짰다. 나머지 33개는 Devin(무료 SWE-2)에
  신화 하나씩 맡겨 정비안을 받고, 규칙 검사·원전 대조·손질을 거쳐 반영했다.
- 결과는 980명·그룹 223개다. 설명 빈 그룹 0, 한 줄 소개(한·영) 빈 인물 0이다.
- **상세 소개도 다 채웠다(26.09.13).** 세력도감 전체 재편의 마지막 층에 신화 테마를 함께 태웠다.
  소속 없던 13명은 「서아시아 건국 전승」을 새로 세워 10명, 메소포타미아 신화로 3명이 들어가 모두 자리를 찾았다.

그룹 기준은 [`../project/service/explore.md`](../project/service/explore.md) 「신화 그룹 기준」이 쥔다.

- Devin 위임 절차·검수에서 자주 걸린 흠: `devin-swe` 스킬
- 백업: `data/celeb/_backup/faction-web-roster/`. 영상 이관은 `<slug>-*.json`, 정비안 반영 직전
  명단은 `myth-plan-<slug>-*.json`이다.

남은 것:

- **전승 제목 그림**: 37개 중 21개가 비었다. 만들 목록과 규격은 [`img/faction-theme-image.md`](img/faction-theme-image.md)가 쥔다.
- **미등록 인물**: 정비안이 넣자고 했지만 아직 등록되지 않은 사람들이다. 목록과 사유는
  [`data/celeb/myth-plan/missing-figures.md`](../../data/celeb/myth-plan/missing-figures.md)에 있고,
  등록한 뒤 명단에 넣는다. 인물이 적어 1~2명뿐인 그룹(페르시아·고려세계 등)이 이때 채워진다.
- **인물 표기**: 서유기 명단의 「사부육」은 원작의 철선공주(나찰녀)다. 인물 기록의 이름이 맞는지 확인한다.
- **공개 — 끝났다(26.09.13).** 인물이 있는 전승 37개를 모두 열었다. 명단·그룹·소개가 다 채워져 잠가 둘 이유가 없었다. 닫을 전승이 생기면 `/myths` 공개 스위치로 닫는다.
- **「한국 신화」 빈 테마 — 지웠다(26.09.13).** 인물도 하위 테마도 없었고, 한국 전승 8개(신라·가야·백제 등)는 이 테마가 아니라 `myth-korea-` 앞머리로 신화 화면 「한국」 칸에 선다. 쓰이지 않던 제목 그림(`title-art/myth-korea.png`)도 함께 뺐다.
- **이미지·대사**: 그룹이 확정됐으니 다음 차례다. 숨긴 인물 399명은 아바타가 생기면 공개한다.

**검토했다가 접은 안**을 적어 둔다. 같은 실수를 반복하지 않기 위해서다.

- *순번에 간격을 주고 웹 인물에 사이 값을 준다* — 인물 249명 각각에 숫자를 사람이 매겨야
  하고, 영상 대본에 인물이 하나만 늘어도 그 숫자가 전부 어긋난다.
- *영상 인물 행에 웹 전용 묶음·순서 칸을 얹는다* — 영상 대본을 다시 들여오는 도구가 그
  에피소드의 묶음과 인물을 통째로 지우고 새로 만든다. 웹이 적은 값이 날아간다. 지금도
  `web_hidden` 454명이 같은 위험에 놓여 있다.
- *묶음 이름을 인물마다 문자열로 적는다* — 오타 하나로 묶음이 갈라지고 이름을 바꾸려면
  여러 행을 고쳐야 한다.


## 남은 작업 2 — 오디세이아를 다시 연다

인물 구성을 손봐야 해서 잠가 두었다. `celeb_tags.atlas_published`를 참으로 바꾸면 열린다.

레거시 에피소드(`Homer-Odyssey-Legacy`)는 인물 24명과 그룹 5개를 비활성으로 내려 정리했다.
사라진 인물은 없다. 지금 오디세이아는 55명·9그룹이고 그룹 설명과 한 줄 소개(한·영)를 모두
갖췄다(26.09.12).

## 배포

전승 여닫이는 DB만 바꾸면 된다. 코드를 고쳤을 때만 배포한다.

```
pnpm deploy:web:oracle                                     # 계획 확인
pnpm deploy:web:oracle -- --execute --confirm DEPLOY-FEELANDNOTE-WEB
pnpm purge:web:cloudflare -- --scope <범위> --execute       # 출력이 요구할 때만
```

## 쿠팡 상품을 다룰 때

공개 전승이 쓰는 링크 10건은 전수 대조를 마쳤다. 기록은
`data/coupang/myth-edition-verify-2026-09-05.json`과 `data/coupang/myth-source-picks-2026-09-05.json`에 있다.

- `inspect.mjs`의 `hasDeliveryEvidence`를 1차 판정으로 쓰지 않는다. 페이지 전역을 긁어
  상단 메뉴의 로켓 아이콘까지 담는다. 후보 7건이 전부 「근거 있음」으로 나왔지만 실제 배지는
  3건뿐이었다. `.prod-atf` 안에서 읽고 「도착 보장」만 진짜 신호로 본다. 「무료배송」은
  일반 택배도 붙으므로 근거가 아니다.
- 상품 상세에 ISBN이 있다. 상품명 문자열로 판본을 판정하지 말고 `verify-edition.mjs`로
  대조한다.
- 쿠팡이 누적 요청량으로 차단한다. 차단 페이지는 「배지 없음·ISBN 미노출」과 구분되지
  않으므로, 출판사·ISBN·배송문구가 전부 비면 차단을 의심한다. 차단은 IP가 아니라
  **세션·프로필 단위**다. 같은 스크립트를 다른 프로필의 크롬으로 돌리면 즉시 풀린다
  (`COUPANG_CHROME_PORT`). 지연을 늘리기 전에 프로필을 바꾼다.
