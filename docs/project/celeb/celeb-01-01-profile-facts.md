# 프로필 사실

이 문서는 모든 티어의 `nickname`·`nickname_en`·`profession`·`gender`·`nationality`·`birth_date`·`death_date`·`wikidata_qid`를 조사하고 판정하는 규칙을 쥔다. 소개 문구는 [`celeb-01-02-profile-intro.md`](celeb-01-02-profile-intro.md)에서 작성한다.

## 이름

- `nickname`은 한국에서 가장 널리 통용되는 정확한 이름을 쓴다. 외래어 표기법과 실제 통용 표기가 갈리면 한국 매체와 검색 결과를 확인한다.
- `nickname_en`은 slug 생성에 필요한 영문 이름이다. 강세부호가 있어도 되며 slug는 ASCII로 변환된다.
- 기존 인물의 `nickname_en`을 바꾸면 slug와 공개 URL도 바뀐다. 이름 교정과 주소 변경을 같은 작업으로 검토한다.
- 형제·자매·듀오처럼 여러 사람이 한 프로필을 공유해도 이름과 소개가 먼저 세운 대표 인물을 생몰 기준으로 삼는다. 그룹 결성·해체 연도를 생몰 자리에 넣거나 서로 다른 사람의 생년과 몰년을 섞지 않는다.

## Wikidata QID

- `wikidata_qid`는 외부 링크·관계 자료·자동 이미지 수집에서 인물을 식별하는 선택값이다. 이름이 비슷한 다른 항목을 넣으면 여러 기능이 함께 오염되므로 확신할 수 없으면 비워 둔다.
- 저장 전 Wikidata 항목의 이름과 설명을 읽고 생몰·국적·직업·활동 시기를 프로필과 대조한다. 이름이나 생년 하나만 맞는 것은 충분한 근거가 아니다.
- 듀오·그룹·fiction·비인간 존재는 사람 항목(`P31=Q5`) 여부를 일률적으로 요구하지 않고 프로필이 가리키는 실체와 항목 유형이 같은지 확인한다.
- [`bulk-qid.mjs`](../../../sw/web/scripts/bulk-qid.mjs)는 사람 항목과 생년을 자동 대조한 뒤 DB에 바로 저장하는 일괄 도구다. 그 조건이 맞는 실존 인물에만 사용하고, 동명이인·그룹·비인간 후보는 수동으로 판정한다.

## 직군

직군 허용값과 한국어·영어 표시명의 코드 SSoT는 [`celeb-professions.ts`](../../../packages/shared/src/constants/celeb-professions.ts)다. 등록 화면과 공개 서비스는 이 상수를 사용하며, 이 문서는 값 목록을 복제하지 않고 분류 판단만 맡는다.

먼저 인물의 대표 활동이나 원전의 대표 서사 역할과 가장 가까운 직군을 고른다. 부수적 이력이나 한 사건의 행동으로 대표 직군을 바꾸지 않는다.

- `leader`: 실존 인물은 종교·사회운동 지도자가 대표 활동일 때 쓴다. fiction은 원전상 신·여신·명시적 신격이거나 종족·인류 계보를 시작하는 시조일 때 쓴다.
- `politician`: 정치 권력을 행사한 인물에게 쓴다. 실존과 fiction을 가리지 않고 왕·황제·왕가 혈통·왕실 배우자는 이쪽에 둔다. 신격과 겹치면 `leader`를 우선한다.
- `commander`: 대표 경력·서사에서 군사 지휘나 직접 전투가 중심인 비왕족 인물에게 쓴다. 상징적 수호나 단발 충돌만으로 주지 않는다.
- `influencer`: 공연·방송·대중 소통 자체가 대표 활동인 공적 유명인에게 쓴다. 실존 무대 마술사는 여기에 둔다. 전령, 일대일 설득, 신격의 권능, 한 사건의 촉발처럼 단지 누군가에게 영향을 준 역할은 해당하지 않는다.

대표 활동만으로 확정되지 않을 때는 다음 순서로 귀속한다.

1. 신·여신·명시적 신격이면 `leader`다.
2. 왕족이면 `politician`이다. 신격과 왕족이 겹치면 신격을 우선한다.
3. 주요 정치 공작자는 `politician`, 정보전 책임자나 무장 파벌 수장은 `commander`, 실제 대중 매체·공개 활동이 대표인 공적 유명인은 `influencer`에 둔다.
4. 대표 서사가 반복적인 전투·공격인 적대 괴물은 `commander`, 신체 능력이 정체성인 동물은 `athlete`, 지배 세력 수뇌부의 배우자는 `politician`, 독립적으로 목축·생산 생업을 운영하는 인물은 `entrepreneur`에 둔다.

괴물·거인·동물·정령·귀족과 비왕실 배우자를 신격이나 왕족으로 확대하지 않는다. 이 규칙까지 적용해도 기존 직군이 성립하지 않을 때만 `other`를 최종값으로 쓴다. `other`는 조사 전 기본값이나 자동 폴백이 아니며, 판단이 어려우면 사용자와 결정한다.

## 성별

`gender`는 boolean이다.

| 값 | 의미 |
|---|---|
| `true` | 남성 |
| `false` | 여성 |
| `null` | 판정 불가 또는 해당 없음 |

- 역사적 인물은 문헌, 현대 인물은 공식 프로필이나 본인 발언을 근거로 판정한다.
- fiction은 대표 원전에서 성별이 명확하면 채운다. 신·영웅·왕·요정뿐 아니라 괴물·동물도 원전의 계보와 서사상 성별을 따른다.
- 문법적 성만 있고 서사상 성별 근거가 없거나, 집단·비인격 존재이거나, 논바이너리로 명시된 경우처럼 실제로 판정할 수 없을 때만 `null`로 둔다.

## 국적과 문화적 배경

`nationality`는 ISO 3166-1 alpha-2 코드다.

- 실존 인물은 출신·성장·대표 활동을 기준으로 한다. 고대 인물은 해당 지역의 현재 국가 코드로 재구성한다.
- fiction은 작품·신화 세계의 문화적 배경 지역을 현재 국가 코드로 재구성한다. 예를 들어 그리스 신화는 `GR`, 중국 고전은 `CN`, 북유럽 신화는 `NO`, 인도 서사는 `IN`, 아서왕 전설은 `GB`를 기본으로 삼되 작품별 배경이 다르면 그 근거를 우선한다.
- 빈 문자열은 아직 조사하지 않았거나 초지역적 원초 존재처럼 지리적 배경 자체가 적용되지 않는 경우다.
- 배경은 적용되지만 조사 뒤에도 국가를 특정할 수 없으면 `XX`를 쓴다. 익명 활동가·해커처럼 신원 비공개가 정체성인 인물도 활동 언어나 수사 관할로 국적을 추정하지 않고 `XX`로 둔다.
- `XX`의 코드 SSoT는 `packages/shared/src/lib/countries.ts`의 `UNKNOWN_COUNTRY_CODE`다.

## 생몰

- 정확한 날짜를 알면 `YYYY-MM-DD`, 연도만 알면 연도만 쓴다. 기원전은 음수다.
- 몰년을 모르면 비운다. 몰년이 없다는 이유만으로 생존자로 판정하지 않는다.
- 화면과 서버의 생사·나이 계산은 `sw/web/src/lib/celeb/lifespan.ts`의 헬퍼와 상수를 사용한다. 각 기능에서 생사 기준을 다시 만들지 않는다.

### 생년 결손 조사와 추정

`birth_date`는 정렬·동시대 인물·연대기에서 사용하므로 공개값이 없더라도 근거가 허용하는 범위에서 대표 연도를 정한다. 별도 추정 플래그나 테이블은 만들지 않는다.

1. 이름·영문명·직군·국적·기존 QID와 연결된 팩션·원전 문맥으로 동명이인을 먼저 막는다.
2. 실존 인물은 공식 프로필·기관 기록·기업 공시·본인 발언처럼 날짜가 명시된 출처를 우선한다. Wikidata는 QID의 인물 유형·직업·국적·활동 시기를 프로필과 대조한 뒤 사용한다.
3. 공개 생년이 없으면 특정 연도의 공개 나이, 졸업·학위, 첫 경력, 임원 취임 같은 시간 단서를 사용한다. 가능하면 독립적인 단서 둘 이상을 맞추고 날짜를 만들지 말고 대표 연도 하나만 저장한다.
4. fiction은 실제 생일이 아니라 창작 배경 연도다. 작품 세계의 기준 사건과 부모·자녀·쌍둥이·세대 관계를 함께 잡아 상대 연도를 정한다. 여러 팩션에 나온 같은 프로필은 하나의 연도를 공유한다.
5. 기존 비결손 값은 별도 근거 없이 덮어쓰지 않는다. 부모가 자녀보다 늦게 태어나거나 쌍둥이 연도가 갈리는 등 관계·서사와 충돌하는 값을 반영 전에 막는다.
