# 쇼츠 베스트 케이스

쇼츠 텍스트 작성 시 모범으로 삼을 레퍼런스. 실제 완성된 에피소드 3편을 길이별로 분석하고, 재현 가능한 패턴을 추출한다.

> 쇼츠 기본 구조·포맷 원칙은 [shorts.md](shorts.md), 이미지 시스템은 [shorts-image.md](shorts-image.md) 참조.

---

## 두 축의 베스트 분류

쇼츠 베스트는 두 축으로 분류한다.

**축 1 — 길이별 골격**: 세그먼트 수·셀럽 인용 횟수·book-context 분할 기준이 길이에 따라 갈린다. 골격 설계 시 참조.
**축 2 — 임팩트 기법**: hook 설계·서사 모순·인용 직격성·결구 한 줄 등 "재미를 만드는 무기"가 무엇인지로 분류. 재미를 끌어올려야 할 때 참조.

### 축 1: 길이 분류

| 유형 | 레퍼런스 | 세그먼트 | 시간 | 셀럽 인용 | 파일 |
|------|----------|----------|------|-----------|------|
| **짧은편** | 알렉스 카프 — 파우스트 | 4 | ~100초 | 1회 | `alex-karp/shorts/ko-2.json` |
| **중간편** | 이순신 — 오자병법 | 6 | ~123초 | 2회 | `yi-sun-sin/books/05-오자병법/shorts.ko.json` |
| **긴편** | 링컨 — 유클리드 | 8 | ~153초 | 3회 | `abraham-lincoln/shorts/ko-2.json` |

### 축 2: 임팩트 기법

| 유형 | 레퍼런스 | 핵심 무기 | 파일 |
|------|----------|----------|------|
| **대화체 4합** | 제갈량 — 손자병법(쇼츠2) | 두 화자 ping-pong + 사료 직인용 + 결정타 | `three-kingdoms/zhuge-liang/books/02-손자병법/shorts.ko.json` |
| **숫자 반전 + 호통** | 이순신 — 오자병법 | "13 대 133이 아니었습니다. 1 대 133이었습니다" + "안위야, 군법에 죽고 싶으냐!" | `yi-sun-sin/books/05-오자병법/shorts.ko.json` |
| **자기부정 모순** | 고흐 — 풀잎 | "걸작 = 완벽한 실패" + 편지 4통 직인용 | `vincent-van-gogh/books/06-풀잎/shorts.ko.json` |
| **선물의 모순 + 어긋난 여정** | 고흐 — 크리스마스 캐럴 | "책 선물 → 책을 그린 그림" + 발작 속 20km | `vincent-van-gogh/books/07-크리스마스 캐럴/shorts.ko.json` |

## 1. 짧은편: 알렉스 카프 — 파우스트 (~85초)

### 왜 모범인가

기본 구조를 가장 정석적으로 따른다. **hook → intro → celeb → book-context**, 군더더기 없이 하나의 일화에 집중하여 "이 사람은 왜 이 책에 미쳤을까?"의 답을 60~90초 안에 마친다.

### 구조

```
hook      (10.0s)  태극권으로 방문객을 넘기는 CEO + 영혼 거래하는 고전
intro     (10.6s)  독일 철학 박사 → 팔란티어 CEO → 파우스트 소개
celeb-mid  (8.8s)  "세상에서 가장 아름다운 텍스트는 괴테의 파우스트입니다"
book-ctx  (55.9s)  파우스트 설명 → 태극권 사건 → 낭독 장면 → 파우스트=카프 대구
```

### 핵심 패턴

**일화 단일 집중형.** book-context 하나가 전체 분량의 65%를 차지한다. 태극권 패대기 → 파우스트 낭독이라는 하나의 에피소드만 깊이 파고든다.

**대구로 착지.** 마지막 세 문장이 쇼츠 전체를 수렴시킨다:
```
진리를 갈망하다 악마의 계약서에 서명한 파우스트.
평화를 동경하다 전장의 파수탑을 세우는 알렉스 카프.
카프가 이 극에서 읽고 있었던 것은 어쩌면 자기 자신이 아니었을까요?
```

**이미지 밀도**: book-context에 9개 전환점. ~6초마다 한 번씩 시각 변화.

### 설계 원칙

- **한 일화만 쓴다.** 배경 설명은 intro에서 끝내고, book-context는 장면 묘사에 올인.
- **셀럽 인용은 1회로 충분.** 짧은편에서 셀럽 인용이 2회 이상이면 서사 흐름이 끊긴다.
- **마지막 문장이 쇼츠의 얼굴.** book-context의 마지막 2~3문장에 여운을 집중한다.

## 2. 중간편: 이순신 — 오자병법 (~105초)

### 왜 모범인가

기본 4비트에 **celeb 추가 삽입**으로 감정 피크를 두 번 만든다. 첫 번째 셀럽 인용(celeb-mid)이 배경 제시, 두 번째(celeb-1)가 전장에서의 실시간 호통 — 역할이 다르다.

### 구조

```
hook           (6.0s)  "13 대 133이 아니었습니다. 1 대 133이었습니다."
intro          (7.9s)  수군 궤멸 → 오자병법 인용
celeb-mid     (25.7s)  "반드시 죽고자 해야 살고..." (난중일기 연설 전문)
book-ctx-1    (40.5s)  원균 패전 → 12척 → 대장선 홀로 돌격 → 안위 합류
celeb-1        (6.3s)  "안위야, 군법에 죽고 싶으냐!"
book-ctx-2    (19.1s)  나머지 합류 → "한 사람의 각오가 군대 전체를 살렸습니다"
```

### 핵심 패턴

**셀럽 인용의 이중 역할.** celeb-mid(25.7초)는 전쟁 전 연설 — 묵직하고 길다. celeb-1(6.3초)은 전투 중 호통 — 짧고 날카롭다. 긴 인용 → 서사 → 짧은 인용의 배치가 감정 곡선을 끌어올린다.

**크레셴도 구조.** 서사가 한 방향으로만 올라간다:
```
궤멸 → 연설 → 열두 척 → 홀로 돌격 → 호통 → 합류 → "한 사람의 각오"
```
되돌아가거나 설명하는 문장이 없다.

**수사 한 줄 마무리**: "오자병법은 군대가 죽기를 각오하면 산다고 했습니다. 하지만 명량에서는 단 한 사람의 각오가, 군대 전체를 살렸습니다." — 책의 명제를 뒤집어 여운을 남긴다.

### 설계 원칙

- **셀럽 인용 2회일 때, 성격을 다르게 한다.** 하나는 내면(독백/연설), 하나는 외면(실시간 발화).
- **두 번째 인용은 짧게.** celeb-1은 6초. 전투 한가운데 삽입되어 리듬을 쪼갠다.
- **book-context를 2개로 분리.** 첫 번째가 위기의 정점, 두 번째가 해소. 사이에 셀럽 인용이 끼어들어 "전환점"을 만든다.

### 부가 요소

| 요소 | 내용 |
|------|------|
| `tts.replace` | 숫자 읽기 보정 (`"133척의"` → `"백삼십삼 척의"` 등) |
| `bgm` | track2.mp3, volume 0.55 |
| `style` | `"숨소리 안나게 발화"` — 긴박한 전투 톤 유지 |

## 3. 긴편: 링컨 — 유클리드 (~135초)

### 왜 모범인가

**나레이션-셀럽 교차 구조**가 가장 정교하다. 셀럽 인용 3회가 서사의 단계별 전환점에 정확히 배치되어, 나레이터가 배경을 깔고 → 셀럽이 그 위에 임팩트를 얹는 구조를 반복한다.

### 구조

```
hook           (5.3s)  "400만 노예를 묶었던 공리. 이를 깬 건 수학책이었습니다"
intro          (5.9s)  40대 변호사 링컨, 유클리드를 구해옴
celeb-mid      (7.0s)  "'입증'이란 단어부터 알아야..." (동기 고백)
book-ctx      (12.1s)  밤마다 유클리드 학습 → 수학자의 방법 시도
celeb-2       (21.2s)  피부색 기준이라고? → 삼단 귀류법 (직접 발화)
book-ctx-2    (25.8s)  1860년 쿠퍼 유니언 → 남부의 공리 → 칠판 위로 끌고 옴
celeb-3       (46.8s)  39인 투표 기록 → 워싱턴·매디슨 실명 반증 → "옳기에 강한 것"
book-ctx-4    (11.3s)  공리 붕괴 → 기립 → 대통령 후보
```

### 핵심 패턴

**귀류법의 서사화.** 유클리드의 증명 기법(귀류법)이 링컨의 실제 연설 논법과 겹치는 구조다. celeb-2에서 링컨이 귀류법으로 노예제를 논파하고, celeb-3에서 실증으로 마무리한다. 책의 핵심 개념이 서사의 구조 자체가 되는 사례다.

**나레이터-셀럽 교차 리듬:**
```
narrator → celeb (동기)
narrator → celeb (논법)
narrator → celeb (연설)
narrator (결과)
```
4번의 교차가 일정한 리듬을 만든다. 셀럽 발화 시간이 7초 → 21초 → 47초로 점층한다.

**셀럽 인용의 점층 배치.** 가장 긴 인용(celeb-3, 46.8초)이 클라이맥스에 배치된다. 짧은 고백(celeb-mid) → 중간 논법(celeb-2) → 긴 연설(celeb-3)의 크레셴도.

**마지막은 나레이터가 닫는다.** 셀럽 인용이 클라이맥스여도, 착지는 나레이터의 객관적 결과 진술("공리는 무너졌고, 천오백 청중은 일제히 기립했습니다")로 끝낸다.

### 설계 원칙

- **셀럽 인용 3회는 반드시 점층한다.** 짧은 것부터 긴 것 순서. 역순은 안티클라이맥스.
- **나레이터가 매번 "왜 이 인용이 나오는지"를 선행 설명한다.** 셀럽 인용이 갑자기 튀어나오면 시청자가 이탈한다.
- **최장 셀럽 인용(celeb-3)은 책의 핵심 개념을 직접 시연하는 장면이어야 한다.** 단순 감상이 아니라, 책의 논리를 실전에 적용하는 장면.
- **bgm은 긴편에서 필수.** 2분 이상 음성만으로는 리텐션 유지가 어렵다.

## 공통 패턴

### 훅 설계

| 에피소드 | 훅 전략 | 길이 |
|----------|---------|------|
| 카프-파우스트 | 기이한 행동 + 미스터리 ("영혼을 거래하는 고전") | 10초 |
| 이순신-오자병법 | 숫자 반전 ("13 대 133이 아니었다. 1 대 133이었다") | 6초 |
| 링컨-유클리드 | 의외의 인과 ("노예를 묶은 공리를 깬 건 수학책") | 5초 |

**공통점**: 결과를 먼저 보여주고, "왜?"를 남긴다. 이름을 밝히지 않는다.

### 셀럽 인용 배치 법칙

```
짧은편 (1회):  hook → intro → [celeb] → book-ctx
               책에 대한 1인칭 소감. 서사에 방향성을 부여하는 역할.

중간편 (2회):  hook → intro → [celeb-A] → book-ctx → [celeb-B] → book-ctx-2
               A=내면(연설/독백), B=외면(실시간 발화). 성격이 달라야 한다.

긴편  (3회):   hook → intro → [celeb-A] → book-ctx → [celeb-B] → book-ctx-2 → [celeb-C] → book-ctx-3
               A=동기, B=논법/행동, C=클라이맥스. 분량이 점층해야 한다.
```

### book-context 분할 기준

| 길이 | book-context 수 | 분할 기준 |
|------|-----------------|-----------|
| 짧은편 | 1 | 분할하지 않는다. 단일 일화에 집중. |
| 중간편 | 2 | 위기의 정점에서 분할. 셀럽 인용이 전환점. |
| 긴편 | 3~4 | 서사 단계(배경 → 시도 → 클라이맥스 → 결과)마다 분할. |

### 마무리 문장

세 편 모두 마지막 나레이션이 **책의 명제를 인물의 삶에 대입하는 한 줄**로 끝난다:

- 카프: "카프가 이 극에서 읽고 있었던 것은 어쩌면 자기 자신이 아니었을까요?"
- 이순신: "하지만 명량에서는 단 한 사람의 각오가, 군대 전체를 살렸습니다."
- 링컨: "남부의 공리는 무너졌고, 천오백 청중은 일제히 기립했습니다."

### 이미지 전환 밀도

세 편 모두 book-context 구간에서 **5~7초마다 1회** 이미지 전환이 발생한다. 이 밀도가 정적 화면 3초 금지 원칙과 음성 리듬에 가장 잘 맞는 구간이다.

## 임팩트 베스트 4편 — 재미를 만드는 무기

길이 골격이 정해진 다음에는 "재미"를 한 단계 끌어올릴 무기가 따로 있다. 아래 4편은 그 무기를 한 가지씩 가장 선명하게 보여 준 사례다.

### 4-1. 제갈량 — 손자병법(쇼츠2) · 대화체 4합

`three-kingdoms/zhuge-liang/books/02-손자병법/shorts.ko.json`

**무기**: 두 화자(제갈량·손권) ping-pong을 4합 주고받는다. 일반 쇼츠가 narrator + celeb 1인 구조라면, 이 편은 책사와 군주 두 명의 voiceLock·voice tags·style을 분리해 영상극 톤을 만든다.

**4합 구조**:
```
1합  제갈량: 군주의 자존심을 자극("자신 없으면 항복하시지요")
2합  손권:   유비는 왜 항복 안 했냐 반박
3합  제갈량: 한실 핏줄이라 받아치기
4합  손권:   회의 토로 → 제갈량의 손자병법 군쟁편 인용으로 결정타
```

**결정타 인용**: "병법에 이르길, 무리한 강행군은 정예군마저 쓰러뜨린다 하였습니다 ... 아무리 강한 화살이라도 끝에 가서는 얇은 비단조차 뚫지 못하는 법." — 손자병법 군쟁편 인용이 4합의 마지막에 박힌다. 그 직후 손권이 검을 뽑아 책상을 내리치는 sfx + 외침. 한 호흡으로 적벽 결정 장면까지 끌고 간다.

**재현 포인트**:
- `speakers` 배열로 두 화자 분리. 각 celeb 세그먼트의 `speaker` 필드와 `voiceLock`·`voice.tags`·`style`을 따로 지정
- 4합 안에서 사료 직인용은 마지막 합에 박는다. 앞 3합은 인물의 정서·자존심 자극으로 긴장 축적
- sfx(unsheathe·crate smash) + `gapAfter`로 결정 장면의 시청각 호흡을 만든다

### 4-2. 이순신 — 오자병법 · 숫자 반전 + 호통

`yi-sun-sin/books/05-오자병법/shorts.ko.json`

**무기**: 두 가지가 한 쇼츠에 박힌다.
1. **숫자 반전 hook** — "13 대 133이 아니었습니다. 1 대 133이었습니다." 청자가 익히 아는 숫자(13대133)를 한 번 뒤집어, 진짜 전투 구도가 무엇이었는지 5초 안에 깨닫게 한다.
2. **사료 직인용 호통** — "안위야, 군법에 죽고 싶으냐! 도망간다고 어디 가서 살겠느냐!" 난중일기 그대로의 짧은 외침이 전투 한가운데 박혀 서사 리듬을 쪼갠다.

**재현 포인트**:
- hook에 익숙한 숫자(공식 기록·통념)를 먼저 던지고, 그것이 사실 다른 숫자였다고 즉시 정정
- 두 번째 celeb 인용은 짧고 날카롭게(5~7초). 본문 한가운데 박아 리듬 전환

### 4-3. 고흐 — 풀잎 · 자기부정의 모순

`vincent-van-gogh/books/06-풀잎/shorts.ko.json`

**무기**: 작가가 자기 걸작을 스스로 부정한 사료를 hook에 박는다. "인류사에 다시 없을 걸작. 작가는 이를 '완벽한 실패'라고 불렀습니다." 청자가 익히 아는 '별이 빛나는 밤'을 작가 본인이 부정했다는 충돌이 30분 동안 머릿속을 떠나지 않게 만든다.

**편지 4통 직인용으로 구조 받침**:
```
ctx-1   → 9월 카페 테라스 시작 다짐(빌에게 보낸 편지)
ctx-2   → 별이 빛나는 밤 다짐(빌에게 보낸 편지)
ctx-3   → 1889년 6월 새벽 샛별(테오에게 보낸 편지)
ctx-4   → "완벽한 실패다"(베르나르에게 보낸 편지)
```

각 celeb 세그먼트마다 `quoteSource`로 편지 출처(수신자·발신지·날짜)를 명시. 사료의 무게가 자기부정의 모순을 떠받친다.

**결구**: "예술의 정점에 닿고도 끝내 투박한 현실을 택하며 스스로 작품을 밀어낸 화가. 자신을 향한 그 지독한 부정은 그림을 완성한 진정한 물감이었습니다." — hook의 모순을 마지막에 가서 의미로 닫는다.

**재현 포인트**:
- 인물 본인의 부정 발언을 hook에 박을 때 가장 효과가 크다(외부 비평이 아닌 자기부정)
- 편지·일기·정사 본문 등 1차 사료 4건 이상을 시간 순으로 배열하면 자기부정의 무게가 확보된다
- 결구는 hook의 모순을 의미로 재정의하는 한 줄로 닫는다

### 4-4. 고흐 — 크리스마스 캐럴 · 선물의 모순 + 어긋난 여정

`vincent-van-gogh/books/07-크리스마스 캐럴/shorts.ko.json`

**무기**: 두 층의 모순.
1. **선물의 모순** — "책을 선물하고 싶었던 화가. 그가 준비한 건 책을 그린 '그림'이었습니다." 화가는 책이 아니라 책을 그린 초상화를 선물한다. 한 줄로 인물 정체성(화가)과 책의 사용 방식이 충돌한다.
2. **어긋난 여정** — 발작 속에 20km를 걸어 카페로 향하다 끝내 닿지 못하고 의식을 잃는다. 책의 주제(닫힌 문을 열고 다른 이에게 향하는 한 걸음)와 실제 인물의 실패한 한 걸음이 의미로 겹친다.

**결구**: "'크리스마스 캐럴'은 닫힌 문을 열고 다른 이에게 향하는, 그 한 걸음의 무게를 그린 이야기입니다. 누구보다 그 책에 깊이 빠져들었던 고흐. 책이 일러 준 한 걸음을 자기 두 발로 옮기는 것. 한 권의 책을 읽었다는 것은 그에게 그런 뜻이었는지도 모릅니다." — 책의 주제와 인물의 실패한 행동을 같은 평면에 놓고 닫는다.

**재현 포인트**:
- hook의 모순이 인물 정체성(화가)과 책 사용 방식(그림으로 그려 선물)의 충돌일 때 가장 신선하다
- 실패한 여정·완성 못한 약속처럼 비극적 어긋남이 책의 메시지와 의미로 겹치면 결구가 자연스럽다
- "한 권의 책을 읽었다는 것은 그에게 그런 뜻이었는지도 모릅니다" 같은 의문형 여운이 시청자에게 해석 여백을 남긴다

## 임팩트 무기 정리

| 무기 | 사용 시점 | 효과 |
|------|----------|------|
| **대화체 4합** | 두 인물의 핵심 결정 장면이 사료에 남았을 때 | 영상극 톤, 긴장 축적 → 결정타 한 줄 |
| **숫자 반전** | 통념과 다른 진짜 숫자가 사료에 있을 때 | 5초 안에 청자 패러다임 전환 |
| **자기부정 모순** | 인물이 자기 걸작·결정을 부정한 사료가 있을 때 | hook이 30분 동안 머릿속에 남는다 |
| **선물의 모순** | 인물 정체성과 행동 방식이 한 줄로 충돌할 때 | 인물 정체성을 단숨에 드러낸다 |
| **사료 직인용 호통** | 짧은 외침이 정사·일기에 남았을 때 | 본문 리듬을 쪼개는 임팩트 |
| **편지 다건 직인용** | 인물의 사상 변화가 편지에 시간 순으로 남았을 때 | 사료 무게로 모순·전환을 떠받침 |
| **어긋난 여정** | 인물이 책의 메시지를 따라 행동했으나 실패한 사료가 있을 때 | 결구에서 책·인물·실패가 한 평면에 묶인다 |
