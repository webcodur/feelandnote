# title 팩트체크 규격

574명 `celebs.title`의 사실 주장을 웹 검색으로 검증한다.

## 대상

`_in/bNN.json` — `[{nick, title, title_en, file}]`

## 검증 기준 (celeb-01-02-profile-intro.md)

1. **실제 통용 호칭**이면 통과 — 「이집트학의 아버지」처럼 한국어/영어권에서 실제로 쓰이는 명칭.
2. **대표작·대표 사실**이면 사실이 맞아야 통과 — 「테트리스 창시자」는 본인이 만들었으면 통과.
3. **창시자·설립·발명가·최초·아버지/어머니 계열 주장**은 근거가 없거나 귀속이 분쟁이면 위반.
   - 와이파이의 어머니(헤디 라머)처럼 과장된 통용어 → 위반
   - 텐세그리티 발명가(스넬슨)처럼 발명 귀속 분쟁 → 위반
   - 실제로는 공동업적인데 단독 표기 → 위반
4. **회사 설립 표기**: 실제 설립자·공동설립자면 통과. 회사와 무관하면 위반.
5. title_en도 같은 사실을 담아야 한다. ko/en가 다른 사실을 말하면 위반.

## 출력

`_out/bNN.json` — 문제가 있는 항목만 배열로:

```json
[
  {
    "nick": "인물명",
    "title": "현재 title",
    "issue": "wrong|overstated|disputed|en-mismatch|duplicate",
    "why": "왜 문제인지 1~2문장, 검색 근거 포함",
    "fix_ko": "수정안 (사실에 근거한 대체 수식어)",
    "fix_en": "영문 수정안"
  }
]
```

문제 없으면 빈 배열 `[]`. **통과 항목은 쓰지 않는다.**

## 주의

- 각 인물당 최소 1회 web_search. 추측으로 판정하지 않는다.
- title은 2~12자 수식어라 짧게 — 수정안도 그 길이를 지킨다.
- nickname이 서비스 표기라 원어 명칭과 다를 수 있다(예: 루빈→Rubin). 검색은 원어로.
- 「왕/제왕/여왕」류는 실제 통용 별명이면 통과.
