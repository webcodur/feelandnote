# 04. 거점 경영

세력은 금·군량·명성을, 영토는 인구·농업·상업·성벽·민심·시설·향병·위협을 보관한다. 병력은 각 인재가 거느린다.

`economy.ts`가 영토 수입과 세력 수지를 계산한다. 계절·민심·시설·위협·난이도·성호 집결 보정을 반영한다. 화면의 월 수지와 실제 월 정산이 같은 함수를 사용한다. 군량이 부족하면 금으로 사들이며, 둘 다 부족하면 병사가 흩어진다.

## 명령

`commands.ts`의 `runCommand()`를 플레이어와 AI가 함께 사용한다. 농업·상업·성벽 개발, 구휼, 징병, 훈련, 토벌, 탐색, 등용, 이동, 건설, 포상, 해임, 태수 임명과 내정 위임을 처리한다.

인재는 달마다 명령 여부를 기록한다. 완료된 판이나 전투 중에는 내정 명령을 실행하지 않는다. 미결 사건을 처리하기 전에는 달을 넘기지 않는다. 명령 비용과 효과·경험치는 `COMMANDS`·`LOYALTY`·`RECRUIT` 등 담당 상수를 따른다.

## 시설

시설 목록·건설 비용·기간은 `BUILDINGS`, 효과는 `BUILDING_EFFECT`가 쥔다. 완공한 시설만 효과를 내며, 같은 시설의 중복 건설과 슬롯 초과를 막는다. 조선소는 해안 조건을 검사한다.

농장과 시장은 수입을 늘린다. 병영은 병력 운용을, 학당은 훈련을, 사원은 회복과 민심을 돕는다. 극장은 민심과 명성을 높이며, 성채는 성벽을 보강하고 주막은 인재 탐색과 방문을 돕는다.

태수는 영토의 인재 중에서 임명한다. 위임한 영토는 `runDelegation()`이 식량 형편·방어·성장·인재를 보고 명령한다. 사람이나 영토가 이동하면 태수의 소속과 위치도 다시 맞춘다.
