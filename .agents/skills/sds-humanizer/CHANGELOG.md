## [1.9.0] - 2026-08-03
### Added

  검토에서 검증된 갭만 이식.** 사전 검토(6-에이전트 워크플로우: 양측 전수 정독 → 커버리지/
  충돌/옵션 3렌즈 → 적대적 반증)로 "병설 설치는 기각, 규칙 단위 선별 흡수만" 결정 —
  KWR 은 improve 모드가 원본 파일을 in-place 편집하고 트리거("자연스럽게 다듬어 줘")가 이

  KWR 파일·스킬 자체는 설치·배포하지 않으며 아래 항목은 전부 문구 재구성이다.
- **signal-taxonomy `V. Formulaic Reversal` 신설** — `단순히 X가 아니라 Y`·`X를 넘어 Y로`·
  `중요한 것은 X가 아니라 Y`·`더 이상 X가 아닌 Y` 반전 프레임 반복(전 항목 humanizer 내
  기존 커버 0건 — grep 실측). 경계: **1회의 명확한 대비는 KEEP**, 반복만 기계 흔적.

  `개선을 도모하다`·`적용이 가능하다` → 동사형 축약, 공문서 필요 명사형은 유지) + 행위자
  기지(旣知) 피동 연쇄 명시(README 의 "피동 남용" 서술과 실물 정합 해소).

## [1.7.0] - 2026-07-28
### Changed
- **Source Profile 게이트를 2문항 구조로 개편 — 장르 × 말투 분리** (`intake-flow.md`·SKILL.md).
  실사용 사례(2026-07-28, `sds/sds-humanizer/enhance_sds_humanizer.md`): `~다` 리서치 보고서를
  해요체로 바꾸려던 사용자가 1문항 게이트의 단일 매핑(격식체만 노출)에 막혀 "지원 안 되는
  기능"으로 읽었고, 장르 전환 후 말투 미확인까지 겹쳐 전체 재작성이 두 번 발생. 이제
  AskUserQuestion **1회 호출에 Q1 장르(유지/대안 장르/직접 지정) + Q2 말투(진단 말투 유지 +
  나머지 표준 말투 전부)** 를 함께 묻는다. 격식체(~습니다)·경어체(~해요)는 원문 말투가 아닌 한
  **항상 둘 다 메뉴에 노출**되고, 기존 (원문 문체 × 장르) 매핑 규칙은 전환 후보 정렬(2번 슬롯)
  용도로 강등. 에이전트 로그 소스는 구어체 슬롯을 에이전트 해석체로 교체, 변칙 말투(반말 등)는
  자동 "Other"가 수용. 강도 3문항 추가는 질문 피로로 비채택(기본 Standard 유지).
- **장르 전환 후 말투 미확인 갭 해소** — 장르·말투가 독립 문항이므로 장르 전환을 골라도 말투는
  항상 Q2 답으로 확정된다. 전환 장르 프리셋의 기본 문체로 조용히 추론하지 않으며, "장르 전환 +
  말투 유지" 조합은 basis line 에 명시.
- **SKILL.md Source Profile 절 슬림화** — 게이트 옵션 목록이 SKILL.md·intake-flow.md 두 곳에
  중복 서술돼 드리프트 위험. 상세(문구·슬롯 규칙·에지 케이스)는 intake-flow.md 를 단일 원천으로
  하고 SKILL.md 는 요약 + 포인터만 유지.
### Fixed
- **rewrite_guard.py 경로 토큰 오탐 제거** — 경로 추출이 다음 공백까지 탐욕 매칭이라 후행
  마크다운 강조·괄호·쉼표·한글 어미가 토큰에 붙었고, 특히 어미가 붙는 유형은 문체 전환 작업에서
  구조적으로 항상 FAIL 했다. 경로 문자 집합 밖 첫 문자에서 절단 + 후행 문장부호 rstrip 정규화

  "/anthropics/skills다." · "/.claude/skills/<name>/`,") 재현 테스트로 소거 + 실제 경로 소실은
  여전히 FAIL 회귀 확인.

## [1.0.0] - 2026-07-08

초본(baseline). 이 버전이 담고 있는 것:

- **Operating Model 5단계**: Profile → Brief → Compass → Passes → Guardrails.
- **Source Profile 게이트**: 원문의 현재 문체(종결어미 분포)·장르(구조 신호)·도달 범위를 먼저
  진단하고, "유지 vs 전환"을 AskUserQuestion 으로 확인. 원문 문체·장르 보존이 디폴트.
- **2축 장르 좌표계** (`references/use-case-matrix.md`): 도달 범위(팀→사내→대외→공개) ×
  글의 역할(알림/설득/기록/해설/교류). 뉴스 기사·보도자료·사내 게시판·사용 안내·인터뷰 정리 등
  14개 프리셋 + 미등재 장르 즉석 배치 규칙.
- **파일 입력 규칙**: 원본 무수정 — `<이름>_humanized<확장자>` 새 파일로만 산출(원복 = 파일 삭제).
- **K 에이전트 동작 어휘** 치환 체계 + 보안 용어 예외. 치환표는 "탐지 우선순위이지 금지어가
  아니다" — 대체어 회전으로 어휘 수렴(새 기계 지문) 방지.
- **`scripts/rewrite_guard.py`**: 보호 리터럴 소실·K 잔존·AI 단어 군집 스모크 테스트.
  AI 단어는 밀도 임계값(1,000자당 2건 하한)으로만 경고, hash 는 [a-f] 필수(순수 숫자 오탐 방지),
  주입 어휘는 ±80자 보안 문맥 면제, 굽은따옴표·낫표 보호, 단위+조사(원과/개월) 처리.
- 스킬 자기완결 — 외부 폴더·타 스킬 참조 없음. 빌드는 claude 단일(형제 빌드 없음).
