# 사료 검증 규칙

에피소드 텍스트에 등장하는 역사적 사실, 인용문, 일화의 진위를 검증하는 기준.
책별로 검증 대상을 나누되, 검토 인원이나 도구 수를 할당량처럼 강제하지 않는다. 서로 독립된 주장은 검색을 병렬로 진행할 수 있다.

---

## 에피소드 파일 경로

```
sw/remotion/public/episodes/{person}/meta.{locale}.json
sw/remotion/public/episodes/{person}/books/NN-책이름/book.{locale}.json
sw/remotion/public/episodes/{person}/books/NN-책이름/solo.{locale}.json
sw/remotion/public/episodes/{person}/books/NN-책이름/shorts.{locale}.json
```

- `{locale}`: `ko` | `en`

먼저 Markdown 편집 원고에서 검증할 문장을 표시하고, 결과가 확정된 뒤 제작 데이터에 반영한다.

---

## 검증 대상

| 필드 | 검증 항목 | 우선순위 |
|------|-----------|----------|
| context | 연도, 장소, 인물 관계, 사건 경위 | **최우선** |
| quotePairs[].after | 후속 사건 사실 여부 | 높음 |
| quotePairs[].quote | 실제 발언 여부 | **최우선** |
| quotePairs[].quoteSource | 문헌 실존 여부 | **최우선** |
| source | 참고 문헌 실존 여부 | 높음 |
| celebIntro | 인물 기본 정보(생몰년, 직함, 업적) | 중간 |
| philosophy | 셀럽 발언 기반이면 발언 존재 여부 | 중간 |
| shorts 세그먼트 | 롱폼과 동일 기준 적용 | 높음 |

---

## 검증 기준

### 1. 연도·장소

- 서기/기원전 표기가 정확한가
- 사건이 발생한 도시·국가가 맞는가
- 인물의 나이와 연도가 일치하는가

### 2. 일화

- 해당 일화가 최소 1개 이상의 공인 출처(문헌, 학술서, 인터뷰)에서 확인되는가
- "~라고 전해진다"류 표현이 있으면, 실제로 전해지는 사료가 있는가
- 여러 출처 간 상충이 있으면, 가장 신뢰도 높은 출처를 채택하고 상충 사실을 명시

### 3. 인용문 (quotePairs[].quote)

- 원문(번역 전)이 실존하는가
- 번역이 원문의 의미를 왜곡하지 않는가 (번역 차이는 허용, 의미 변질은 불가)
- quotePairs[].quoteSource가 가리키는 문헌에 해당 발언이 실제로 존재하는가
- AI가 생성한 가짜 인용이 아닌가

### 4. 출처 문헌 (source)

- 해당 문헌이 실존하는가 (저자, 제목, 출판년도)
- 저자명이 정확한가 (예: "플루타르코스" vs "플루타크")
- 문헌 내에 해당 내용이 실제로 기술되어 있는가

### 5. 인물 기본 정보

- 생몰년이 정확한가
- 직함·칭호가 정확한가 (예: "마케도니아의 왕" vs "그리스의 황제")
- 주요 업적 서술이 사실과 일치하는가

---

## 검증 방법

### 웹 검색 교차 검증

1. 핵심 팩트(연도+장소+사건)를 키워드로 웹 검색
2. 최소 2개 이상의 독립된 출처에서 확인
3. 위키백과는 1차 출처가 아닌 출발점으로만 사용

### 인용문 검증

1. 원문 언어로 검색 (영문 인물이면 영어 원문)
2. 인용문 데이터베이스 (Wikiquote 등) 대조
3. 출처 문헌의 구체적 위치(장, 절) 확인 가능하면 기록

---

## 판정 등급

| 등급 | 기준 |
|------|------|
| ✅ 확인 | 2개 이상의 출처에서 일치 |
| ⚠️ 주의 | 출처 1개만 확인, 또는 출처 간 미세 차이 |
| ❌ 오류 | 출처와 명백히 불일치 |
| 📌 검증 불가 | 관련 출처를 찾을 수 없음 (오류와 다름) |

---

## 금지 사항

- 검증 불가를 오류로 판정하지 않는다
- 번역 차이를 의미 왜곡으로 오인하지 않는다
- 오류 발견 시 즉시 수정한다. 검증 불가·논쟁 중인 사안은 보고 후 판단을 구한다
- 학계에서 논쟁 중인 사안을 한쪽으로 단정하지 않는다
- 검증 중 문체·구성·시간순 문제가 보이면 함께 지적하고 수정한다

## 보고 형식

```
## [인물명] 사료 검증 결과

### ✅ 검증 통과
- Book 1 "[책제목]": context 사실 확인 (출처: [문헌명])

### ⚠️ 주의 (확인 필요)
- Book 3 "[책제목]": 연도 불일치 — 일부 사료에서 다른 기록 존재

### ❌ 오류 발견
- Book 5 "[책제목]": contextQuote 원문과 불일치

### 📌 검증 불가
- Book 7 "[책제목]": source "XXX" — 해당 문헌 확인 불가
```

- ❌ 오류 발견 시 **즉시 수정**한다. 보고서만 남기지 않는다.
- ⚠️ 주의 항목은 수정안을 제시하고 적용한다.
- 검증 중 문체·구성·시간순 문제가 보이면 함께 수정한다.
