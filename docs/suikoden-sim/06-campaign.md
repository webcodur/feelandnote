# 06. 캠페인 (맵과 세력)

## 세계관

"시간의 경계가 무너진 세계."
고대부터 근대까지의 위인들이 하나의 세계에 공존한다.
플레이어는 한 명의 주군을 선택하여 이 혼돈의 세계를 통일한다.

## 세력 생성

### Grade 기반 세력 분리 (2단계 셋업)

게임 시작 시 `previewWorld()`가 캐릭터를 Grade 기준으로 나눈다.

| Grade | 역할 | 배정 |
|-------|------|------|
| ≥ 55 (B 이상) | AI 세력 멤버 | 자동 세력 배정 |
| < 55 (C 이하) | 방랑자 풀 | 플레이어 선택 가능 |

### AI 세력 구성

```
1. Grade ≥ 55 인물을 Grade 내림차순 정렬
2. 난이도별 세력 수(3/5/7)에 따라 상위 인물을 리더로 선정
3. 리더의 nationality 기반 영토 배정
4. 같은 지역 인물을 멤버로 배정
5. 남은 Grade ≥ 55 인물도 가장 가까운 세력에 분배
```

### 방랑 인재

AI 세력에 배정되지 않은 인물(Grade < 55)은 방랑자로 존재한다.
시대 필터를 적용하여 선택한 시대에 해당하는 인물만 표시한다.
