# 독재자들 — 남은 정비

- [ ] 공개 전 한영 한 줄 정의와 명단 앞쪽 인물을 정한다. 검색 제목은 명단 앞 두 사람으로 만들고, 한 줄 정의가 있어야 검색 설명에 앞의 그룹 3개가 들어간다. 한 줄 정의 규격은 [탐색](../project/service/service-01-explore.md#한-줄-정의-faction_lv2headlineheadline_en)을 따른다. 현재 노출 스위치가 꺼져 있어 운영 주소는 404이며 사이트맵에 없다.

현재 메타 생성 함수는 한 줄 정의가 있을 때 앞의 그룹 3개로 「공산주의, 신정통치, 파시즘 등으로 나뉜 인물들을 만나 보세요!」를 만든다. 그룹 선택은 `?group=`으로 표시하며 검색 정본은 팩션 주소 하나다. 그룹 설명은 선택 후 모달에서 읽는다. 공유 썸네일은 현재 사이트 공통 이미지를 쓴다.

기존 [《독재자들》 편집](http://localhost:3001/factions/dictators)에서 이어서 정비한다.

이름을 바꿀 때 참고할 후보: **철권의 시대**, **침묵의 지배자들**, **권력의 철옹성**, **닫힌 권좌**, **국가 위의 권력**. 현재 이름은 《독재자들》이다.

철권통치 컨셉 표지는 한 장이다. [등록된 표지](https://assets.feelandnote.com/faction/0de696d3-f98e-40da-8ef9-d737a81fcc81/team/52143efd-31e8-4026-8f70-176f80369e06.display.webp). 인물·글자 없이 철제 통제문과 정부 청사를 그린 1536×1024 이미지다.
