# 셀럽 큐 관리 룰북

신규 셀럽 후보를 발굴·등록·추적하는 가이드.

---

## 큐 파일

- **경로**: `docs/celeb-queue.md`
- **형식**: 마크다운 테이블

---

## 큐 파일 형식

```markdown
| 이름 | 시대 | 직군 | 우선순위 | 상태 | 단계 | 비고 |
|------|------|------|---------|------|------|------|
| 소동파 | 중세 | author | 1 | pending | - | 시문에 독서 기록 풍부 |
```

### 상태(status)

| 값 | 의미 |
|-----|------|
| `pending` | 대기 중 |
| `in_progress` | 작업 중 |
| `done` | 전체 완료 |
| `skip` | 자료 부족 등으로 건너뜀 |

### 단계(step)

파이프라인 진행 단계를 기록한다. **콘텐츠 수집 → 감상 철학 순서를 반드시 지킨다.**

| 값 | 의미 |
|-----|------|
| `-` | 미시작 |
| `basic` | 기본정보 완료 |
| `influence` | 영향력 완료 |
| `persona` | 페르소나 완료 |
| `content` | 콘텐츠 수집 완료 |
| `philosophy` | 감상 철학 완료 (= 전체 완료) |

### 우선순위

| 값 | 기준 |
|-----|------|
| **1** | 누구나 아는 인물 (교과서급 인지도) |
| **2** | 역사에 관심 있으면 아는 인물 |
| **3** | 해당 분야 전공자가 아는 인물 |

## 파이프라인 실행 순서

```
1. basic      → celeb-basic-profile 에이전트 (profiles 레코드 확보)
2. content    → celeb-content-collector 에이전트 (감상 기록 파악)
   ↓ 0건이면 skip 처리, 다음 인물로
3. influence  → celeb-influence 에이전트
4. persona    → celeb-persona 에이전트
5. philosophy → celeb-philosophy 에이전트 (콘텐츠 기반 작성)
```

### 게이트: 콘텐츠 수집 결과에 따른 분기

- **콘텐츠 1건 이상** → 3~5단계 계속 진행
- **콘텐츠 0건** → `skip` 처리. influence/persona/philosophy 생성하지 않음

### 병렬 실행 규칙

- **1단계** (basic): 배치 내 전원 병렬 실행 가능
- **2단계** (content): 1단계 완료 후 배치 내 전원 병렬 실행 가능
- **3~4단계** (influence + persona): 2단계 통과한 인물만, 병렬 실행 가능
- **5단계** (philosophy): **반드시 2단계(content) 완료 후 실행**

### 배치 처리

한 번에 3~5명씩 처리한다. 큐에서 `pending` 상태를 우선순위순으로 꺼낸다.

```
1. 큐에서 pending 3~5명 선택, 상태를 in_progress로 변경
2. 1단계: basic 병렬 실행
3. 2단계: content 병렬 실행
4. 게이트: 콘텐츠 0건 → skip 처리
5. 3~4단계: influence + persona 병렬 실행 (통과 인물만)
6. 5단계: philosophy 실행
7. 상태를 done으로 변경
```

## 후보 선정 기준

### 1순위: 인지도 (가장 중요)

유저가 "이 사람도 있네?"라고 반응할 인물을 우선한다. 감상 기록이 빈약해도 인지도가 높으면 구실을 찾아서 등록한다.

### 2순위: 직군 밸런스

특정 직군(학자·문인)에 편중되지 않도록 한다. 특히 **commander(지휘관)·leader(지도자)** 비중을 의식적으로 확보한다.

### 감상 기록 구실 유형 (빈약한 인물용)

기록이 직접적이지 않아도 아래 논리로 콘텐츠를 연결할 수 있다:

| 유형 | 논리 | 예시 |
|------|------|------|
| **시대 필수 교양** | 해당 시대 지배층이라면 반드시 접한 텍스트 | 항우 → 병법서, 초사 |
| **과거/무과 커리큘럼** | 시험 과목에 포함된 경전·병서 | 이성계 → 무경칠서 |
| **직접 인용** | 연설·서한·조서에서 인용한 구절 | 당태종 → 정관정요에서 경전 인용 |
| **수집·편찬 지시** | 직접 읽지 않아도 수집·편찬 주도 | 건륭제 → 사고전서 |
| **사관 기록** | "왕이 ~를 읽었다"는 사서 기록 | 정조 → 일성록 독서 기록 |
| **교육 배경** | 스승·학파가 가르친 교재 | 한니발 → 그리스 교육 (크세노폰 등) |

### 검색 키워드

```
"famous historical figures" reading habits books
역사 인물 독서 목록 추천 도서
{인물명} 독서 기록 경전 인용
{인물명} favorite books reading
```

### 중복 확인

후보 추가 전 반드시 기존 DB 확인:

```sql
SELECT nickname FROM profiles
WHERE profile_type = 'CELEB'
  AND nickname LIKE '%{검색어}%';
```
