# 책과 사람 — 한 권 형식 쇼츠

인물 한 명이 책 한 권으로 무엇을 했는지를 60초 안팎의 세로 쇼츠로 만든다. 제작 규격과 데이터 형식은 [`docs/project/remotion/book-person/README.md`](../project/remotion/book-person/README.md)가 쥔다. 여기에는 왜 이 형식인지, 어떤 순서로 만들며 어디까지 왔는지만 둔다.

## 왜 이 형식인가

KO 채널 실측(26.09.02): 총조회 27만 중 쇼츠 「OO의 한 권」 22편이 18.6만, 롱폼 서재탐방 8편이 530이었다. 「일론 머스크의 한 권」 7편이 전체의 83%다. 같은 공정으로 만든 일곱 편이 2천에서 12만까지 갈렸으니 제작 품질이 아니라 인물 인지도와 주제가 조회를 정한다. 그 쇼츠들은 은유로 열고 30초 서술로 이어져 첫 3초에 인물도 책도 나오지 않았다. 사용자 진단: "구조를 잡아가는 방식이라 인트로에서 다 빠진다."

그래서 한 편의 규칙은 넷이다.

1. **첫 문장은 인물 + 이 책 + 한 일.** "일론 머스크는 열네 살에 자본론을 읽었습니다." 은유·질문으로 열지 않는다.
2. **책 한 권이 한 편.** 묶음 형식(인물 1명·책 N권)은 쓰지 않는다.
3. **문장 하나에 화면 하나.** 60초면 7~8문장, 이미지 7~8장.
4. **인물은 검색되는 사람으로.** 인지도 순으로 고른다. 제갈량·고흐·링컨은 같은 형식으로 1~3천에서 멈췄다.

## 제작 순서

```
DB 감상배경 고르기 (facts.json으로 편 폴더에 보존)
 → 원고 (ko.json)            첫 문장 문법 고정. 재료 밖 발언·표정·줄거리·감상형 마무리 금지
 → 검수 (review.mjs, agy 무료)   이상점만 받는다. 제안 문장은 쓰지 않는다
 → 이미지                    인물 사진·표지는 DB. 장면은 Wikimedia 실사 검색(CC0·PD·CC BY). 출처는 credits.json
 → 음성 (tts.ts)             Gemini는 무료 시험용, ElevenLabs는 사용자 지시 뒤에만. 대상은 이름 지정만
 → Studio 확인               렌더하지 않는다. localhost:3002/BookPerson-<편>-KO-S-VID
 → 승인 뒤 다음 편
```

- **한 편을 끝까지 만들어 승인받은 뒤 늘린다.** 6편을 동시에 진행하다 교정받았다(`agent-rules.md` 2-1).
- **agy 이미지 생성은 쓰지 않는다.** 하루 쿼터가 3~5장에서 끊기고 생성물은 AI 티가 난다. 실사 검색으로 간다. agy에 웹 검색으로 이미지를 찾게 하는 것도 두 번 시도해 둘 다 빈손이었다.
- **agy 검수는 "흥미롭지만 내가 결정".** 번역투·되풀이·재료 밖 표정은 잘 잡는다. 재료로 준 목록을 놓치는 오탐이 있고, 고친 문장에서 사실을 지어낸다(강백호 등번호 17번, 왓슨이 읽었다는 책 두 권). 지적만 받고 문장은 사람이 다시 쓴다.
- 내 원고의 반복 결함: 마지막 문장을 감상으로 닫기, 줄거리 한 줄 끼우기, 재료에 없는 표정·태도("웃으며", "굴러다니던"). 검수가 매번 이 셋을 짚었다.

## 명령

```bash
pnpm --filter remotion exec node scripts/book-person/review.mjs <편>                       # 검수 (무료)
pnpm --filter remotion exec tsx scripts/book-person/tts.ts --episode <편>                  # Gemini 무료
pnpm --filter remotion exec tsx scripts/book-person/tts.ts --episode <편> --engine elevenlabs --voice-id <id>   # 유료, 지시 뒤에만
pnpm render:staged -- --episode <편> --series book-person BookPerson-<편>-KO-S-VID out/BookPerson/<편>.mp4      # 최종 출고 때만
```
