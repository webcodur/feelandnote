# 독서방식 문단 나누기 (끊는 자리만 답한다)

입력 파일의 각 인물(`## slug`)마다 400자 넘는 문단(`### P번호`)이 문장 번호와 함께 한국어(KO)·영어(EN)로 실려 있다. 글은 고치지 않는다. **몇 번 문장 뒤에서 문단을 끊을지만** JSON으로 답한다.

## 끊는 기준 (룰북 docs/project/celeb/celeb-05-02-reading-way.md 「문단」)
- 다루는 일화나 생각이 바뀌는 곳에서 끊는다. 한 문단에는 일화 하나나 생각 하나만 둔다.
- 끊은 한 조각은 2~4문장, 250자 안팎. 한국어 조각은 반드시 450자 이하.
- 실린 문단은 모두 최소 한 번 끊는다. 한 문장짜리 조각은 피한다.
- EN은 KO와 같은 내용 지점에서 끊는다. KO 조각 k와 EN 조각 k가 같은 내용을 담아야 한다(연도·책 제목이 같은 조각에 오도록). KO와 EN의 끊는 개수는 같아야 한다.
- 번호가 문장 중간(따옴표 속 제목 「…?」·"Who Am I?" 뒤 등)을 가리키는 경우는 그 자리를 고르지 않는다.

## 출력
- 입력이 `<작업 폴더>/paragraph/in/bNN.txt`면 같은 폴더의 `out/bNN.json` 하나만 Write로 쓴다. 다른 파일·DB는 건드리지 않는다.
- 형식: `{"slug": {"P3": {"ko": [4], "en": [5]}, "P5": {"ko": [3, 6], "en": [3, 7]}}}` — 숫자는 "그 번호 문장 뒤에서 끊는다". 오름차순.
- 입력의 모든 slug와 모든 P를 빠짐없이 넣는다. JSON 외 설명은 쓰지 않는다.
