# 06. 캠페인 (맵과 세력)

## 세계관

"시간의 경계가 무너진 세계."
고대부터 근대까지의 위인들이 하나의 세계에 공존한다.
플레이어는 한 명의 주군을 선택하여 이 혼돈의 세계를 통일한다.

## 세력 생성

### 시나리오 기반 (현행)

셋업 1단계에서 시나리오를 고르면 `previewScenario()`가 세계를 구성한다.

| 구성 요소 | 출처 |
|----------|------|
| AI 세력 | 시나리오 정의의 `aiFactions` (리더 + 거점 지정) |
| 주군 후보 | 시나리오 정의의 `playerCandidates` |
| 방랑자 | 시나리오 정의의 `wandererIds` |
| 활성 거점·지역 | 위 세력·후보의 거점에서 자동 도출 (`activeTerritoryIds`/`activeRegionIds`) |

`finalizeGame(preview, playerLeaderId)`에서 플레이어가 고르지 않은 후보는 AI 세력으로 자동 전환된다.

| 시나리오 | id | 시대 | 난이도 |
|---------|-----|------|-------|
| 삼국쟁패 | `three_kingdoms` | ancient | normal |
| 십자군 전쟁 | `crusades` | medieval | hard |
| 전국시대 | `sengoku` | modern | normal |
| 나폴레옹 전쟁 | `napoleonic` | modern | hard |
| 대몽골제국 | `mongol_empire` | medieval | hard |

시나리오는 등장 인물을 프로필 UUID로 지정한다(`scenarios.ts`의 `ID` 맵, 51개).

### Grade 기반 세력 분리 (자유 모드 — 미사용)

시나리오 없이 시대/난이도만으로 세계를 만드는 설계다. `previewWorld()`로 엔진에 남아 있으나 **현재 호출되지 않는다.**

| Grade | 역할 | 배정 |
|-------|------|------|
| ≥ 55 (B 이상) | AI 세력 멤버 | 자동 세력 배정 |
| < 55 (C 이하) | 방랑자 풀 | 플레이어 선택 가능 |

```
1. Grade ≥ 55 인물을 Grade 내림차순 정렬
2. 난이도별 세력 수(3/5/7)에 따라 상위 인물을 리더로 선정
3. 리더의 nationality 기반 영토 배정
4. 같은 지역 인물을 멤버로 배정
5. 남은 Grade ≥ 55 인물도 가장 가까운 세력에 분배
```

방랑자에는 시대 필터를 적용해 선택한 시대에 해당하는 인물만 표시한다.

## 외교

### 외교 행동

| 행동 | 비용 | 효과 | 명성 |
|------|------|------|------|
| **동맹 제안** | 금 200 | 상호 불가침, 관계 +50 | +3 |
| **정전 협정** | 금 100 | 관계 +20 | +2 |
| **조공** | 금 가변 | 관계 +gold/10 | - |
| **항복 권유** | - | 전력 30% 이하 시 가능 | +10 |

### 관계도

- 범위: -100 ~ 100
- 동맹 = 50 이상

### 성공률 (`calcDiplomacyRate`)

동맹·정전 등 행동을 가리지 않고 하나의 공식을 쓴다. 실패하면 관계도가 소폭 떨어진다.

```
확률 = clamp(0.05 ~ 0.95,
             0.3 + 주군intellect×0.003 + 주군charm×0.002
                 + 관계도×0.005
                 + min(0.2, (전력비 - 1)×0.1)
                 + min(0.15, fame×0.00015))
```

**이간**(두 AI 세력 관계 악화)은 미구현이다.

### 위협 시스템

영토에 위협(도적단·야수·역병·첩자)이 출몰한다. 캐릭터를 배정하여 해결한다.

| 위협 | 아이콘 | 난이도(power) 범위 |
|------|--------|-----------|
| 도적단 | 🏴 | 2~6 |
| 야수 | 🐺 | 3~7 |
| 역병 | ☠️ | 1~5 |
| 첩자 | 🕵️ | 4~8 |

- 출몰: 영토별 매 턴 10% 확률, 영토당 최대 2개
- 지속: 5턴. 방치하고 만료되면 민심 −10
- 토벌 판정: 배정 다음 턴에 `clamp(10~95, 40 + martial×0.4 + courage×0.2 - power×5)`%. 성공 시 명성 +5와 금, 실패 시 HP 손실 후 재시도 가능
- 순찰소 근무자는 미배정 위협을 자동 토벌한다
- **위협 유형별 판정 공식 분기는 미구현**이다. 역병에도 무력으로 맞선다
