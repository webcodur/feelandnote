# 작품·판본 정합성 — 남은 확인

- 더글러스 애덤스 `5e61f875-7e61-5587-b5a4-2996554ab9ea`: ISBN `9781447259565`의 실제 수록 작품·출판사·연도를 독립 서지로 확인한다. OpenLibrary 기록은 연대가 모순된다. 영어 대표 카드는 ISBN 없는 표시용이며, 판본 `14829`의 원자료는 `metadata.unverifiedEditions`에 보존하고 노출용 판본에서는 제거했다.
- 정확한 판본 범위: Recorded Books의 《천 개의 찬란한 태양》 카세트판, Asiapac 《아Q》의 완전성·개작 여부, 아시모프 자서전 1995년 한국어판 1·2의 완전성, 범우사 베이컨 수상록 `9788908061477`의 수록 편수는 미확정이다. 확인되지 않은 범위는 완역으로 표시하지 않았다.
- 박정희·정주영의 나폴레옹 독서: 정확한 저자·작품을 확인한다. 원문·출처·감상 ID는 비공개로 보존했다. 작품 ID는 각각 `0c3aa7df-9a2a-4a36-af09-a6bfef8260fe`, `9a8c6ab5-fe09-48ea-9b96-a931dcef2742`다.
- 작품별 직접 감상 근거: 레비스트로스·저우언라이·진독수의 《자본론》, 티무르·술레이만·지단·정화의 꾸란, 나관중·호쿠사이·조설근·박지원의 수호전, 디즈니·데즈카의 보물섬, 브레이디 코르베의 《아우스터리츠》, 마윈의 천일야화 기록은 근거가 확보될 때까지 비공개로 보존한다. 김영하의 《쇼코의 미소》는 수록 단편을 다룬 근거만 확인되어 전체 소설집 감상은 비공개다.

새 근거를 반영할 때는 [콘텐츠 감사](../project/celeb/celeb-02-04-content-audit.md)를 따르고, 같은 감상 ID와 작품·판본 연결을 다시 조회한다.
