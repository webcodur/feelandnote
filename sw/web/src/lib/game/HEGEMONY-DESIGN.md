# 패권(Hegemony) v3 — 게임 디자인 문서

턴제 국정 운영 카드 전략 게임. 인재를 적재적소에 배치하여 상대를 굴복시킨다.

---

## 기본 정보

| 항목 | 값 |
|------|-----|
| 장르 | 1v1 턴제 전략 (vs AI) |
| 턴 수 | **10턴** (서든데스 가능) |
| 인재 수 | 각 6장 (스네이크 드래프트) |
| 배치 수 | **턴당 3명** (나머지 3명 대기) |
| 명령 종류 | 5종 |
| 중복 배치 | 같은 명령 2명 가능 |
| 공개 방식 | **동시 공개** |

---

## 국가 상태

| 항목 | 초기값 | 설명 |
|------|--------|------|
| **국력** | 20 | HP. 0 이하 = 즉시 패배. 회복 불가 |
| **민심** | 50 | 0 이하 = 반란 (국력 −5, 민심 10 리셋) |

---

## 명령 체계

```
공격계:  출전 ──→ 상대 국력 타격    ← 수비가 방어
         모략 ──→ 상대 민심 타격    ← 외교가 방어
방어계:  수비 ──→ 출전 감쇄
         외교 ──→ 모략 감쇄
자원계:  내정 ──→ 자국 민심 회복
```

### 명령별 상세

| 명령 | 효과 | 적성 공식 | 페널티 |
|------|------|----------|--------|
| **출전** | 상대 국력 타격 | strategic + martial/10 | 자국 민심 **−3** |
| **모략** | 상대 민심 타격 | tech + intellect/10 | 없음 |
| **수비** | 출전 타격 감쇄 | social + command/10 | 없음 |
| **외교** | 모략 타격 감쇄 | political + charisma/10 | 없음 |
| **내정** | 자국 민심 +적성 | (economic+cultural)/2 + diligence/10 | 없음 |

### 데이터 매핑

| 명령 | 도메인 (0-10) | 능력/덕목 (/10 → 0-10) |
|------|--------------|----------------------|
| 출전 | strategic | martial |
| 모략 | tech | intellect |
| 수비 | social | command |
| 외교 | political | charisma |
| 내정 | (economic + cultural) / 2 | diligence |

- 적성 범위: 0~20
- 6도메인 전부 사용: strategic, tech, social, political, economic, cultural

## 타격 공식

### 출전 (상대 국력 타격)

```
수비 있음:  max(0, ⌊(출전적성 − 수비적성) / 1.5⌋) + ⌊출전적성 × 0.1⌋
수비 없음:  max(0, ⌊(출전적성 − 5) / 1.5⌋) + ⌊출전적성 × 0.1⌋
```

### 모략 (상대 민심 타격)

```
외교 있음:  max(0, ⌊(모략적성 − 외교적성) / 1.5⌋) + ⌊모략적성 × 0.1⌋
외교 없음:  max(0, ⌊(모략적성 − 5) / 1.5⌋) + ⌊모략적성 × 0.1⌋
```

### 핵심 수치

- **기본 방어력**: 5 (수비/외교 미배치 시)
- **관통 데미지**: ⌊공격적성 × 0.1⌋ (방어가 있어도 통과)
- **내정 회복**: 민심 +적성 (그대로)

### 예시

| 상황 | 계산 | 타격 |
|------|------|------|
| 출전 18 vs 수비 18 | ⌊0/1.5⌋ + ⌊1.8⌋ | **1** (관통만) |
| 출전 18 vs 수비 16 | ⌊2/1.5⌋ + ⌊1.8⌋ | **2** |
| 출전 18 vs 수비 없음(기본5) | ⌊13/1.5⌋ + ⌊1.8⌋ | **9** |
| 출전 23(중복) vs 수비 16 | ⌊7/1.5⌋ + ⌊2.3⌋ | **6** |

## 특수 규칙

### 피로도

- **발동**: 동일 인재가 **2턴 연속** 같은 명령 수행
- **효과**: 해당 인재 적성 **×0.7** (소수점 버림)
- **해제**: **1턴 쉬면** (대기 또는 다른 명령) 즉시 해제
- 예: 칭기즈(출전18) 2턴 연속 → 18×0.7 = **12**

### 중복 배치

- 같은 명령에 2명 배치 가능
- 효과: **max(적성1, 적성2) + 5**
- 예: 모략(19) + 모략(16) → **24**
- 같은 명령 3명은 불가 (배치 3명 제한상 비현실적)

### 반란

- **발동**: 턴 결산 시 민심 ≤ 0
- **효과**: 국력 **−5**, 민심 **10으로 리셋**
- 모든 민심 변동은 **동시 적용 후** 판정

### 출전 페널티

- 출전 명령 사용 시 자국 민심 **−3** (전쟁 피로)
- 중복 출전이어도 −3 (1회만)

## 승리 조건

1. **즉시 승리**: 상대 국력 0 이하
2. **10턴 종료**: 국력 비교 → 높은 쪽 승리
3. **서든데스**: 국력 동률 시 추가 턴. 국력 차이 발생까지 계속

## 게임 흐름

```
[로비] → [드래프트 12턴] → [국정 운영 10턴] → [결과]

매 턴:
  1. 배치 단계  — 6명 중 3명을 명령에 할당
  2. 공개 단계  — 양측 동시 공개
  3. 결산 단계  — 타격 계산 → 국력/민심 변동 → 반란 판정
```

## 전략 삼각 구도

```
출전 (국력 직접 타격)
  ↕ 수비가 방어
모략 (민심 타격 → 반란 → 국력 −5)
  ↕ 외교가 방어
내정 (민심 회복 → 반란 방지)
```

| 전략 | 강점 | 약점 |
|------|------|------|
| 출전 집중 | 국력 직접 감소 | 민심 −3 누적, 수비에 막힘 |
| 모략 집중 | 반란 유발 (−5) | 외교에 막힘, 국력 직접 못 깎음 |
| 수비+외교 | 철통 방어 | 관통 1~2 누적, 반격 불가 |
| 내정 집중 | 민심 안정 | 수비/외교 빈틈 → 직격 |
