# 03. 전투 시스템

## 전투 개요

**방식**: 턴제 전술 선택형 (카드/전술 상성)
**참여 인원**: 세력당 최대 5명 출진
**턴 제한**: 최대 10라운드
**승패**: 적 전원 괴멸, 또는 라운드 소진 시 무승부

---

## 6전술 상성 시스템

매 라운드 공격 측·방어 측이 각각 전술 1개를 선택한다.
전술 간 상성에 따라 배율이 적용된다.

### 전술 종류

| 전술 | 아이콘 | 설명 | 병사 소모율 |
|------|--------|------|-----------|
| **돌격** | 🐎 | 강력한 돌격. 피해↑ 손실↑ | 15% |
| **방어** | 🛡️ | 피해 경감. 화공에 강함 | 0% |
| **계략** | 🪭 | 지력 대결. 사기전에 강함 | 5% |
| **화공** | 🔥 | 광역 피해. 방어에 약함 | 10% |
| **고무** | 📯 | 사기 회복. 계략에 약함 | 0% |
| **유인** | 🗡️ | 반격. 돌격에 강함 | 5% |

### 상성 매트릭스

| 공격↓ · 방어→ | 돌격 | 방어 | 계략 | 화공 | 고무 | 유인 |
|-------------|------|------|------|------|------|------|
| **돌격** | 1.0 | 0.65 | 1.4 | 1.0 | 1.0 | 0.65 |
| **방어** | 1.0 | 1.0 | 1.0 | 1.4 | 1.0 | 1.0 |
| **계략** | 0.65 | 1.0 | 1.0 | 1.0 | 1.4 | 1.4 |
| **화공** | 1.0 | 0.65 | 1.0 | 1.0 | 0.65 | 1.0 |
| **고무** | 1.0 | 1.0 | 0.65 | 1.0 | 1.0 | 1.0 |
| **유인** | 1.4 | 1.0 | 0.65 | 1.0 | 1.0 | 1.0 |

- **1.4**: 유리 (40% 추가 피해)
- **0.65**: 불리 (35% 피해 감소)

## 병과별 전술 보정

각 병과는 특정 전술 사용 시 추가 위력을 얻는다.

| 병과 | 보정 전술 | 추가 위력 |
|------|----------|----------|
| **장수** | 돌격 | +30% |
| **책사** | 계략 +40%, 화공 +30% |  |
| **관료** | 방어 | +20% |
| **예인** | 고무 | +50% |
| **유격** | 유인 +40%, 화공 +10% |  |
| **장인** | 방어 | +20% |

## 전투 진행

### 라운드 순서

```
1. 플레이어: 전술 선택 (TacticSelectPanel)
2. AI: 성향 기반 전술 선택
3. 양측 전술 공개 → 상성 배율 적용
4. 대미지 계산 → 병사 손실 → 사기 변동
5. 괴멸 판정
6. 10라운드까지 반복 또는 한쪽 전멸 시 종료
```

### 사기 시스템

시작 사기 100. 사기 0 = 괴멸.

| 이벤트 | 사기 변동 |
|--------|----------|
| 적 처치 | +10 |
| 계략 적중 | +5 |
| 아군 피격 | -5 |
| 아군 사망 | -15 |
| 주군 피격 | -20 |
| 고무 전술 | 사기 회복 |
| 턴 경과 (공격 측) | -1/턴 |

## 성벽 효과

방어 측 영토에 성벽(`walls`)이 있으면:

- 방어 측 방어력 +40%
- 공성 시 장인 병과 효과 3배

---

## 전투 결과

| 결과 | 조건 | 후속 |
|------|------|------|
| **공격 승리** | 방어 측 전원 괴멸 | 영토 점령 + 포로 처분 화면 |
| **방어 승리** | 공격 측 전원 괴멸 | 공격 측 후퇴 |
| **무승부** | 10라운드 소진 | 양측 후퇴 |

### 포로 처분 (Disposition)

승리 시 패배 장수에 대해 처분을 결정한다.

| 선택 | 효과 |
|------|------|
| **등용** | 영입 시도 (성공/실패) |
| **감금** | 포로로 유지 |
| **처형** | 영구 제거 |
| **석방** | 명성 상승 |

## AI 전술 선택

AI 세력의 성향(`aiPersonality`)에 따라 전술 선택 경향이 다르다.

| 성향 | 선호 전술 |
|------|----------|
| 정복형 (`conqueror`) | 돌격, 화공 |
| 책략형 (`schemer`) | 계략, 유인 |
| 경제형 (`economist`) | 방어, 고무 |
| 인덕형 (`virtuous`) | 고무, 방어 |
| 문화형 (`culturist`) | 계략, 고무 |
