# Audio BO 음성 생성 엔진 조사

조사일: 2026-07-14

## Fun-CosyVoice 3 실제 시험 결과

같은 공항 인터뷰 참고 음성과 같은 세 문장으로 설치·생성 시험을 완료했다. 원본 참고 음성과 잔향을 줄인 참고 음성 각각에 기본·단호함·희망적 말투를 적용해 총 6개를 만들었다. 모든 모델·임시 자료·결과는 `D:\audios\interview-cleaner` 아래에 두었다.

- 6개 모두 정상 길이의 음성으로 생성됐고 무음 파일은 없었다.
- 자동 받아쓰기 기준 5개는 원문과 100% 일치했다.
- 잔향을 줄인 참고 음성의 기본 결과 1개만 `기회는`을 `뒤에는`으로 인식해 97.1%였다.
- 기본보다 단호함·희망적 말투가 더 빠르고 크게 생성돼 말투 지시는 실제로 반영됐다.
- 원본 참고 음성에 강한 말투를 적용한 결과는 목소리 높이가 크게 올라갔다. 표현력이 늘어난 대신 목표 인물의 음색이 달라졌을 가능성이 있으므로 사람의 청취 판정이 필요하다.
- 중심 음성 모델은 GPU로 실행됐다. 일부 음성 전처리는 설치된 CUDA 라이브러리 세대 차이로 CPU 대체 실행됐지만 결과 생성에는 문제가 없었다.

결과는 Audio BO의 `공항 인터뷰 UI 시험` 작업, `4. 새 음성 만들기` 화면에 등록했다. 자동 검사는 발음 정확성과 파일 정상 여부만 확인한다. 잔향, 자연스러움, 목표 인물과의 유사성은 아래 결과를 직접 듣고 최종 판정한다.

## 결론

현재 Audio BO에 연결된 GPT-SoVITS v2Pro는 `현장 인터뷰 음성으로 특정 인물의 한국어 성우형 내레이션을 만든다`는 목표에 맞지 않는다. 짧은 캐릭터 대사나 음색 복제에는 쓸 수 있지만, 이번 시험에서는 발음 누락·무음 파일·처지는 억양·잔향 복제가 반복됐다.

무료 로컬 후보가 전혀 없는 것은 아니다. **다음 시험은 Fun-CosyVoice 3 한 가지만 진행한다.** 이 모델은 공식적으로 한국어, 짧은 참고 음성을 이용한 목소리 복제, 감정·속도·음량 등의 말투 지시를 함께 지원한다고 밝힌다. 같은 자료와 같은 문장으로 한 번 비교한 뒤 기준을 통과하지 못하면 로컬 엔진 탐색을 중단하고 **ElevenLabs Eleven v3를 사용한다.**

현재 PC는 RTX 4070 12GB이고 D드라이브 여유 공간도 충분하다. Fun-CosyVoice 3는 0.5B 모델이므로 시험 후보로는 현실적이지만, 공식 설치 안내가 리눅스 중심이어서 Windows 직접 설치보다 별도 환경 또는 WSL이 안정적일 가능성이 높다. 실제 설치 가능 여부와 생성 속도는 설치 시험에서 확정한다.

## GPT-SoVITS 시험 결과

### 사용 자료

- `jsp`: 약 57.6초, 8개 발화
- `park`: 원본 영상 4분 53초부터 약 28.3초, 4개 발화
- 현재 도구: `D:\GPT-SoVITS\GPT-SoVITS-v2pro-20250604`

처음 만든 `jsp`는 사용자가 의도했던 4분 53초 구간이 아니라 영상 앞부분으로 학습됐다. 그러나 올바른 구간으로 만든 `park`를 다시 시험해도 발음과 억양이 개선되지 않았다. 따라서 잘못 고른 구간만이 실패 원인은 아니다.

### 확인된 현상

- 기본 생성부터 문장 끝 음이 원본보다 크게 내려가고 힘이 빠졌다.
- `힘차게`에 해당하는 속도·음량·음색 보정을 강하게 줄수록 끝 음이 더 내려갔다.
- 여덟 개 참고 발화를 번갈아 사용해도 처지는 말투는 해결되지 않았다.
- 올바른 `park` 모델에서도 `불가능이란 없다. 자신을 믿으세요.`가 정확히 발음되지 않았다.
- 일부 학습 결과는 0초 또는 지나치게 짧은 파일을 만들었다.
- 참고 음성과 학습 자료에 남은 공간 잔향과 거리감이 생성 음성에도 따라왔다.

현재 설치본은 2025년 6월 4일판이다. 공식 변경 기록에는 같은 달 9일에 수치 오류로 무음이 생성될 수 있는 문제를 수정했다고 적혀 있다. 최신판은 0초 파일을 줄일 가능성이 있지만, 발음·연기·잔향 문제까지 해결한다는 근거는 없다.

## 사람들이 GPT-SoVITS를 사용하는 방식

공개된 활용 프로젝트는 주로 다음 범위에 모여 있다.

- 애니메이션·게임 캐릭터의 짧은 대사
- AI 캐릭터와 버튜버의 실시간 대화
- 화면 읽기, 디스코드 음성 봇, 단어장 발음
- 영상 더빙과 오디오북의 대량 생성
- 같은 문장을 여러 번 만든 뒤 괜찮은 결과를 고르는 작업

실제 활용 생태계는 크지만 이것이 한국어 성우형 장문 내레이션의 품질을 보증하지는 않는다. 공식 성능표도 중국어 시험을 중심으로 발음 일치도와 음색 유사도를 측정한다. 공식 설명 자체가 이 수치로는 자연스러움, 감정의 풍부함, 음질을 평가할 수 없으며 실제 자료로 직접 시험해야 한다고 명시한다.

다른 프로그램에서 감정 선택 기능을 붙일 때도 글로 연기를 지시하기보다는 기쁨·분노·슬픔으로 말한 참고 음성을 미리 여러 개 준비하고 선택에 따라 교체하는 방식을 사용한다. 중립적인 공항 인터뷰 하나만으로 성우 연기를 만드는 현재 목표와는 전제가 다르다.

## 잔향과 잡음이 따라오는 이유

목소리 복제 모델은 사람의 음색만 완전히 분리해서 배우지 않는다. 마이크 거리, 방의 울림, 압축 음질, 주변 공기 소리와 말끝 습관도 목소리 특징으로 받아들일 수 있다. 그러므로 현장 인터뷰를 참고시키면 `그 사람의 목소리`와 함께 `현장에서 녹음된 소리`까지 재현될 수 있다.

공식 도구에 잔향 제거 과정이 포함되어 있고 관련 오류가 계속 수정된 사실도 이 문제가 실제 작업에서 반복된다는 점을 보여준다. 다만 강한 잔향 제거는 자음과 음색까지 훼손할 수 있으므로 원본보다 항상 낫다고 볼 수 없다.

### 1. Fun-CosyVoice 3

현재 목표에 가장 직접적으로 맞는다. 공식 저장소는 한국어를 포함한 9개 언어, 여러 언어 간 목소리 복제, 감정·속도·음량 지시를 지원한다고 밝힌다. Apache 2.0 라이선스이고 0.5B 모델이라 로컬 시험 부담도 비교적 작다.

다만 공개 설명과 데모만으로 한국어 남성 인터뷰 음색의 보존, 한국어 감정 지시 정확도, 현장 잔향 복제 정도를 판단할 수 없다. 설치 전에 성공으로 간주하지 않고 동일 자료 시험을 거친다.

공식 자료: https://github.com/FunAudioLLM/CosyVoice

### 2. Chatterbox Multilingual V3

한국어와 짧은 참고 음성을 이용한 목소리 복제를 지원하고 MIT 라이선스다. 감정 강도를 높이는 값과 참고 음성을 얼마나 따를지 조절하는 값이 있어 GPT-SoVITS보다 직접적인 표현 조절이 가능하다.

그러나 한국어 전용 모델이 아직 없고 `단호하게 설득하듯`, `희망을 북돋우며` 같은 세밀한 연기 지시보다 전체 감정 강도를 키우는 방식에 가깝다. Fun-CosyVoice 3보다 우선순위가 낮다.

공식 자료: https://github.com/resemble-ai/chatterbox

### 3. Qwen3-TTS

한국어, 자유로운 목소리 설계, 자연어로 감정과 운율을 지시하는 기능이 강하다. 한국어 기본 음성도 별도로 제공하며, 목소리 복제 모델은 약 3초 참고 음성을 사용할 수 있다.

하지만 현재 공개 모델은 역할이 나뉘어 있다. 특정 인물의 목소리를 복제하는 모델에는 자유로운 감정 지시가 없고, 감정 지시가 가능한 모델은 미리 제공된 음성이나 새로 설계한 가상 음성을 사용한다. 특정 인물의 음색을 유지하면서 성우형으로 바꾸려는 현재 요구에는 바로 맞지 않는다. 특정 인물 복제를 포기하고 좋은 한국어 성우 음성을 만드는 용도라면 다시 검토할 가치가 있다.

공식 자료: https://github.com/QwenLM/Qwen3-TTS

### 4. ElevenLabs Eleven v3

한국어를 포함한 70개 이상의 언어를 지원하고, 문장 안에 `[천천히]`, `[웃으며]`, `[속삭이며]`, `[슬프게]` 같은 지시를 직접 넣을 수 있다. 현재 조사 대상 중 표현력과 사용 편의성의 근거가 가장 분명하다.

단점은 유료 클라우드 서비스이며, 표현력을 높일수록 복제한 목소리와 달라질 수 있다는 점이다. 공식 안내도 일부 전문 복제 음성은 v3의 표현 기능과 아직 완전히 맞지 않을 수 있다고 밝힌다. 그래도 로컬 후보가 실제 한국어 시험을 통과하지 못하면 더 이상의 설치·학습 시간을 쓰기보다 ElevenLabs를 쓰는 것이 합리적이다.

공식 자료:

- https://elevenlabs.io/ko/v3
- https://elevenlabs.io/docs/best-practices/prompting
- https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning

## 다음 비교 시험

Fun-CosyVoice 3는 별도 학습부터 하지 않고 짧은 참고 음성으로 바로 시험한다.

1. 원본 참고 음성으로 생성한다.
2. 잔향을 약하게 줄인 참고 음성으로 같은 문장을 생성한다.
3. 아무 지시 없음, 단호하고 희망적으로, 성우처럼 또렷하게 세 가지를 비교한다.
4. 아래 세 문장을 동일하게 사용한다.

```text
불가능이란 없다. 우린 우리 자신을 믿어야 합니다.
끝까지 포기하지 않으면 기회는 반드시 옵니다.
그렇게 최선을 다한 사람만이 자신이 만든 결과를 받아들일 수 있습니다.
```

다음 조건을 모두 만족해야 Audio BO의 새 생성 엔진으로 채택한다.

- 세 문장을 빠짐없이 정확히 읽는다.
- 0초·무음·엉뚱한 말이 나오지 않는다.
- 공항 공간의 잔향과 웅웅거림이 결과에서 두드러지지 않는다.
- 문장 끝이 매번 축 처지지 않는다.
- 말투 지시 전후 차이를 사람이 바로 알아들을 수 있다.
- 목소리가 목표 인물과 유사하게 유지된다.

한 번의 비교 시험에서 이 기준을 통과하지 못하면 추가 학습이나 미세 조정으로 시간을 쓰지 않는다. Audio BO의 영상 준비·편집·받아쓰기 기능은 유지하고, 음성 생성은 ElevenLabs 연결 방식으로 전환한다.
