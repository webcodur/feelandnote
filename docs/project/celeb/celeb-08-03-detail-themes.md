# 인물 상세 세계 표현

인물 상세는 국적·생몰연도·fiction 여부로 정한 세계를 배너·액자·구획 번호·재질에 함께 적용한다. 직군은 아이콘과 직군명만 결정하며 배너나 화면 색을 정하지 않는다.

## SSoT

| 책임 | 코드 |
|---|---|
| 세계 목록·국적과 연도 판정·개별 override | `sw/web/src/lib/celeb/world.ts` |
| 세계별 액자·구획 번호 | `sw/web/src/lib/celeb/worldStyle.ts` |
| 세계별 재질 계열과 색 토큰 | `sw/web/src/lib/celeb/worldMaterial.ts` |
| 배너 파일 존재와 경로 | `sw/web/src/lib/celeb/worldImages.ts` |
| 배너 자산 제작 | [`celeb-08-04-world-banners.md`](celeb-08-04-world-banners.md) |
| 인물 이미지 fallback | [`celeb-08-00-image-map.md`](celeb-08-00-image-map.md) |

세계 ID·연대 경계·재질 배정·픽셀값을 이 문서에 복제하지 않는다. 판정이 틀리는 인물은 직군이나 slug 해시로 색 예외를 만들지 않고 `worldOverride`로 세계만 바로잡는다.

## 화면 구성

1. 서버 레이아웃이 프로필로 세계 하나를 결정한다.
2. 같은 세계 ID로 PC·모바일 배너, 대표 사진 액자, 구획 번호, 바깥 배경과 UI 재질을 정한다.
3. 배너 아래에는 수식어·이름·한 줄 정의·메타·소개·한마디를 하나의 입장부로 배치한다.
4. 대표 사진이 있으면 사각 화보를 사용하고, 없으면 큰 원형 아바타가 정식 대체 레이아웃이 된다. 둘 다 있으면 작은 아바타를 이름 옆 식별자로 함께 보여준다.
5. 하단 기록은 내용이 필요한 곳에만 내부 카드를 사용하고 모든 구획을 다시 이중 박스로 감싸지 않는다.
6. PC 목차는 본문 폭을 빼앗지 않고 바깥 여백에서 현재 구획을 안내한다. 좁은 화면에서는 숨긴다.

이름은 상세의 유일한 `h1`이다. 한 줄 정의를 대형 선언문으로 되풀이하거나 PC 목차에 아바타·이름 카드를 다시 만들지 않는다. 공유는 한 개의 진입 버튼으로 모으고 모바일에서는 본문 흐름 뒤에 둔다.

구획 제목 서체는 세계별로 갈라지지 않고 서비스 공통 서체를 쓴다. 세계 구분은 배너·액자·번호·재질로 충분해야 한다.

## 세계 재질

한 세계는 `WORLD_MATERIAL_BY_WORLD`가 지정한 재질 계열 하나를 쓴다. 재질 계열은 세 역할을 조합한다.

- **바깥 배경**: 공간의 공기와 넓은 면
- **기록 박스**: 긴 글이 올라가는 고르고 조용한 표면
- **테두리**: 면을 결구하는 얇은 재질

텍스처는 본문보다 먼저 보이지 않는 미세한 결이어야 한다. 넓은 얼룩·반복 격자·과한 블러·시대 건축물을 흉내 낸 CSS 선 장식을 만들지 않는다. 특정 세계가 어색하면 인물·직군 예외를 추가하기 전에 세계와 재질의 배정을 검토한다.

## 상호작용과 접근성

- 조작 요소의 즉각 반응은 [`../platform/code-rules.md`](../platform/code-rules.md)와 `ui-hover` 스킬을 따른다.
- 현재 목차 표식은 키보드 포커스와 마우스 hover를 함께 반영하고, 손을 떼면 현재 구획으로 돌아간다.
- 강조 텍스트는 배경 대비 WCAG AA를 충족한다.
- 텍스처는 `pointer-events: none`이며 스크롤과 조작을 막지 않는다.
- 재질 때문에 레이아웃 크기나 콘텐츠 순서가 달라지지 않는다.
- 서버가 첫 HTML에서 세계와 재질을 확정할 수 있는 순수 매핑을 사용한다.
- 움직임 줄이기 설정에서는 장식 이동을 줄이고 정보 상태는 그대로 전달한다.

## 검수

`/[locale]/lab/celeb-worlds`에서 세계 판정·배너·액자·번호를, `/[locale]/lab/celeb-themes`에서 재질 원형과 대표 조합을 확인한다. 실제 인물 상세도 PC와 모바일에서 함께 본다.

- 배너에서 본문으로 내려왔을 때 같은 세계의 공간처럼 이어지는가.
- 배경과 기록 박스가 구별되면서 긴 본문이 안정적으로 읽히는가.
- 테두리와 질감이 인물과 정보보다 먼저 보이지 않는가.
- 대표 사진 보유·미보유 레이아웃이 모두 의도된 첫 화면으로 보이는가.
- 직군에 따라 배경색이 달라지거나 세계 판정이 흔들리지 않는가.
- locale이 바뀌어도 목차와 입장부가 화면 밖으로 넘치지 않는가.

핵심 구현은 `CelebWorldMaterialScope`, `CelebWorldBanner`, `CelebWorldFrame`, `CelebHeroSection`, `CelebRecordSections`와 인물 상세 레이아웃이 쥔다. 컴포넌트 이동 이력은 문서에 남기지 않고 코드에서 찾는다.
