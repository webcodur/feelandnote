## 공통 기준

- 사실·인용·숫자·날짜·링크는 먼저 보호한다.
- 이미 자연스럽고 구체적인 문장은 고치지 않는다.
- 정보 없는 추상 평가와 자동 결말은 구체적인 행동·장면으로 바꾼다.
- 출처가 불명확한 성능·가격·법령·탐지기 통과 주장은 `VERIFY`로 둔다.
- 계정 우회, 크랙, 침투, 성인 프롬프트, 표절성 재창작, 가짜 작업 기록은 보관하지 않는다.
