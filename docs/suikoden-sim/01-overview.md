# 01. 게임 개요

## 컨셉

**장르**: 턴제 전략 시뮬레이션 (웹게임)
**테마**: 역사 속 실존 인물들이 세력을 형성하여 문명을 통일하는 가상 역사
**참조**: 코에이 수호전 천도 108성 (1996)

---

## 핵심 게임 루프

```
[시작] 시대/난이도 선택
  → 세력 구성 미리보기 (Grade ≥ 55 인물이 AI 세력 구축)
  → 방랑자 중 주군 선택 (Grade < 55 인물)
  → 방랑 (인재 조우, 동료 모집, 지역 이동)
  → 거병 (빈 영토에 세력 수립)
  → 거점 경영 (건설, 자원 관리, 내정)
  → 전투/외교 (인접 세력과 대결)
  → 영토 확장
  → [승리] 전 지역 통일
```

---

## 게임 시작 플로우

```
로비 → 설정 1단계 (시대 + 난이도)
     → previewWorld() 호출 (AI 세력 자동 구축)
     → 설정 2단계 (AI 세력 미리보기 + 방랑자 중 주군 선택)
     → finalizeGame() → 방랑 페이즈로 게임 시작
```

- **Grade ≥ 55 인물**: AI 세력의 리더/멤버로 자동 배정
- **Grade < 55 인물**: 플레이어가 선택 가능한 방랑자 풀
- 수호전 천도 원작의 "약자가 일어서는" 컨셉

---

## 승리 조건

| 조건 | 설명 |
|------|------|
| **통일 승리** | 모든 영토를 지배하에 둔다 |
| **문화 승리** | 문화 영향력이 전체 세력 합산의 60% 이상 도달 |
| **외교 승리** | 전체 세력의 2/3 이상과 동맹 체결 |

---

## 패배 조건

| 조건 | 설명 |
|------|------|
| **거점 상실** | 자신의 모든 거점이 함락 |
| **턴 초과** | 제한 턴 내 미통일 시 "역사의 망각" 엔딩 |

---

## 게임 흐름

### 방랑 페이즈

주군 선택 직후. 거병 전까지 세계를 방랑하며 동료를 모은다.

- 매 턴 랜덤 이벤트 (인물 조우, 도적, 소문 등)
- 인접 지역으로 이동 가능 (20턴 소요)
- 동료 최대 5명 모집
- 빈 영토에서 거병하여 전략 페이즈로 전환

### 전략 페이즈 (1턴 = 10일)

```
[내정] 건설 / 근무 배치 / 자원 관리
[인사] 영입 / 훈련 / 포상
[군사] 전투 / 순찰
[외교] 동맹 / 정전 / 조공 / 위협
```

---

## 원작 레퍼런스 (수호전 천도 108성)

원작의 캐릭터·병력 시스템 스펙. 본 게임의 수치 설계 시 참조한다.

### 캐릭터 개인 스탯

| 항목 | 범위 | 설명 |
|------|------|------|
| **HP** | 0~100 | 장수 개인 체력. 0이면 전사 |
| **병력** | 0~1,000 | 장수가 이끄는 부대 병사 수 |
| **사기** | 0~100 | 병력(부대)의 전투 의지. 0이면 괴멸 |

### 병력 장비 (부대 단위 지급)

| 장비 | 최대 수량 | 용도 |
|------|----------|------|
| **무기** | 10,000 | 공격력 보정 |
| **군마** | 1,000 | 기동력·돌격 보정 |
| **조선** | 1,000 | 수상전 보정 |
| **부적** | 1,000 | 계략 방어 보정 |

### 본 게임과의 차이

| 항목 | 원작 | 본 게임 | 비고 |
|------|------|---------|------|
| HP | 0~100 | 0~100 | 동일 |
| 병력 | 0~1,000 | `troops/maxTroops` | 축소 운용 |
| 사기 | 0~100 | `morale` 0~100 | 동일 |
| 장비 | 무기/군마/조선/부적 | 두루마리/보물 | 콘텐츠(책/영화 등) 기반 아이템으로 대체 |
