# 각성모드 — 사용자 웹 도입

각성 이미지는 팩션 데이터가 아니라 인물 자체의 선택형 보조 이미지다. 저장·관리 규격은 [`celeb-08-00-image-map.md`](../../project/celeb/celeb-08-00-image-map.md)가 쥐며, 사용자 웹은 아직 이 값을 조회하거나 표시하지 않는다.

## 서비스 도입 전에 정할 것

1. **화면 전환.** 호버·탭·스크롤 중 무엇으로 바꿀지, 모바일에서는 어떻게 할지.
2. **적용 범위.** 이집트 21인만인지, fiction 티어 전체로 넓힐지.

비교 화면과 제작 자료에서는 대표 사진과 각성 이미지를 같은 인물 단위로 붙여 보여준다. 슬롯별 목록을 따로 만들면 기본형과 각성형의 차이를 판단하기 어렵다.
