# 에피소드 이미지 생성 가이드

## 배경

Remotion(React 기반 영상 프레임워크)으로 제작하는 "서재 탐방" 시리즈다. 역사적 인물이나 현대 유명인의 추천 도서를 소개하는 유튜브 영상을 만든다.

## 에피소드란

셀럽(인물) 한 명의 추천 도서를 소개하는 영상 단위다. 각 에피소드는 인물 디렉토리에 JSON 데이터와 리소스를 담고 있다.

```
public/episodes/{status}/{person}/
  ko.json                 ← 에피소드 콘텐츠 (텍스트, 메타, 이미지 정보)
  ref/                    ← 인물 레퍼런스 사진
    face-1.jpg
  images/                 ← 배경연출 이미지
    {n}-{slot}.jpg          예: 1-1.jpg, 1-2.jpg, 2-1.jpg
  covers/                 ← 책 표지 이미지
```

에피소드 JSON 안에 `books` 배열이 있고, 각 책마다 다음 텍스트 섹션을 가진다:

| 섹션 | 설명 |
|------|------|
| `summary` | 책의 핵심 요약 |
| `context` | 셀럽이 이 책을 만난 배경·맥락 |
| `contextAfter` | 후속 맥락 (선택) |
| `directQuote` | 셀럽의 직접 인용문 (선택) |

이 텍스트 섹션들의 서사를 시각화하는 것이 이미지 생성의 목적이다.

## 원칙

서사에서 주목할만한 순간이 있으면 모두 이미지화한다. 섹션별로 몇 장이라는 공식이 아니라, 텍스트를 읽고 시각화할 가치가 있는 장면을 판단하여 생성한다.

### 분량
— summary 1장 + context 1장이 하한선 
- 주목할 만한 장면이 많으면 더 생성한다 
- 주요 장면은 2문장 정도에 하나씩 생성 

## 생성 방식

프롬프트 + 레퍼런스 사진(`ref/`)으로 1장씩 생성한다.
생성된 이미지는 `images/` 에 저장 후, 에피소드 JSON의 `images` 배열에 파일명과 텍스트 앵커를 등록한다.

## 주의사항

### 레퍼런스 사진 활용
- 각 인물 디렉토리의 `ref/` 폴더에 인물 사진는 경우 참조용으로 활용한다. (보통은 인물 포스터)

### 프롬프트는 정교하게
- 조금이라도 복잡성이 있는 장면이면 프롬프트가 길어지는 걸 두려워하지 않는다.
- 발생 가능한 모든 이슈(AI 아티팩트, 시대고증 오류, 구도 혼란 등)를 사전에 대처할 수 있도록 프롬프트에 명시한다.
- 필수 포함: 시대·장소·시간대, 인물 포즈·의상·소품, 카메라 렌즈·앵글·피사계심도, 조명 방향·색온도, 네거티브 지시(`no text, no letters, no watermarks`).

### 다수 인물 장면
- 한 이미지에 여러 인물이 등장하는 경우, 각 인물의 외모·의상·체형·포즈를 개별적으로 최대한 묘사한다. "a group of people" 같은 뭉뚱그린 표현은 AI가 인물을 구분하지 못하게 만든다.

### 밀랍인형 방지
- 21세기 카메라로 촬영한 듯한 실사감이 목표이나, "hyper-realistic" 등을 과잉 강조하면 오히려 밀랍인형처럼 부자연스러워진다.
- **자연광 활용** — 직사광선, 창문광, 골든아워 등 실제 광원을 명시한다.
- **피사계심도(DoF) 블러** — 포커스 대상 외 영역은 적극적으로 블러 처리한다. `f/1.4~2.8` 수준의 얕은 심도가 CG 느낌을 방지한다.
- **미세 결함 허용** — 약간의 그레인, 렌즈 플레어, 비네팅은 오히려 실사감을 높인다. 모든 디테일이 균일하게 날카로우면 CG처럼 보인다.
