# 에피소드 이미지 생성 가이드

> **최종 실측 체크: 26.07.16** — 쇼츠 이미지 규격 3중 중복을 이 문서로 통합. 흡수 과정에서 코드 실측으로 죽은 규칙 다수 폐기(`images/shorts/{slug}.png` 경로·`CINEMATIC_EPISODES`·`prompts.json` 모두 부재 확인), 필터값은 실측 `brightness(0.35) saturate(0.5)`로 교정

## 배경

Remotion(React 기반 영상 프레임워크)으로 제작하는 "서재 탐방" 시리즈다. 역사적 인물이나 현대 유명인의 추천 도서를 소개하는 유튜브 영상을 만든다.

## 에피소드란

셀럽(인물) 한 명의 추천 도서를 소개하는 영상 단위다. 각 에피소드는 인물 디렉토리에 JSON 데이터와 리소스를 담고 있다.

```
public/episodes/{status}/{person}/
  ko.json                 ← 에피소드 콘텐츠 (텍스트, 메타, 이미지 정보)
  ref/                    ← 인물 레퍼런스 사진
    face-1.jpg
  images/                 ← 배경연출 이미지
    {scene-description}.jpg   예: pilgrim-wading-through-swamp.jpg
  covers/                 ← 책 표지 이미지
```

### 파일명 규칙

이미지 파일명은 **장면을 묘사하는 영문 케밥케이스**로 짓는다. 넘버링(`1-1.jpg`, `2-3.jpg`)은 사용하지 않는다.

- `pilgrim-wading-through-swamp-toward-castle.jpg` ✅
- `nine-year-old-lincoln-grieving-mother.jpg` ✅
- `fox-reaching-for-grapes-at-sunset.jpg` ✅
- `1-1.jpg`, `2-3.jpg`, `img_001.jpg` ❌

에피소드 JSON 안에 `books` 배열이 있고, 각 책마다 다음 텍스트 섹션을 가진다:

| 섹션 | 설명 |
|------|------|
| `summary` | 책의 핵심 요약 |
| `contextMain` | 셀럽이 이 책을 만난 배경·맥락 |
| `quotePairs[].after` | 후속 맥락 (선택) |
| `quotePairs[].quote` | 셀럽의 인용문 (선택) |

이 텍스트 섹션들의 서사를 시각화하는 것이 이미지 생성의 목적이다.

---

## 핵심 원칙: summary와 context는 피사체가 다르다

이미지 생성에서 가장 중요한 구분이다.

| 섹션 | 피사체 | 셀럽 등장 |
|------|--------|-----------|
| **summary** | **책의 장면** — 작품 내 등장인물, 사건, 배경 | **금지** (저자는 가능) |
| **context** (contextMain+quotePairs[].quote+quotePairs[].after) | **셀럽의 장면** — 인물이 이 책과 관련된 인생 사건 | 필수 또는 주요 소재 |
| quotePairs[].quote | 맥락에 따라 판단 | 허용 |

### summary 이미지 — 책 속 세계를 그린다

summary는 책의 내용을 요약한 텍스트다. 이 섹션의 이미지는 **책이 묘사하는 세계**를 시각화한다.

**올바른 예 (링컨 - 천로역정)**:
- 감옥에서 글 쓰는 번연 (저자) ✅
- 짐을 진 순례자가 멸망의 도시를 떠나는 장면 ✅
- 절망의 늪을 헤치는 여행자 ✅
- 십자가 앞에서 짐을 내려놓는 순례자 ✅

**틀린 예**:
- 링컨이 책을 읽고 있는 장면 ❌ (이것은 context 이미지)
- 링컨의 초상 ❌ (summary와 무관)
- 링컨이 서재에 앉아있는 장면 ❌ (인물의 장면은 context)

**왜 이 구분이 필요한가**: AI 이미지 생성 도구는 에피소드의 주인공(셀럽)에 대한 프롬프트를 받으면, summary에서도 셀럽 이미지를 만들어버리는 경향이 강하다. summary 이미지의 주인공은 셀럽이 아니라 **책 속 인물과 사건**이다.

### context 이미지 — 인물의 인생을 그린다

context는 셀럽이 이 책을 읽게 된 배경, 영향, 역사적 맥락을 서술한다. 이 섹션의 이미지는 **셀럽의 실제 인생 장면**을 시각화한다.

**올바른 예 (링컨 - 천로역정)**:
- 어머니 무덤 옆에 서서 책을 든 아홉 살 소년 ✅
- 비 내리는 변경의 길을 혼자 걷는 청년 링컨 ✅
- 게티즈버그 연설하는 대통령 ✅

**틀린 예**:
- 순례자가 절망의 늪에 빠진 장면 ❌ (이것은 summary 이미지)
- 책 표지 클로즈업 ❌ (covers/ 디렉토리에 별도 존재)

## 분량 기준

서사에서 시각화할 가치가 있는 장면을 모두 이미지화한다. 섹션별 "몇 장"이라는 기계적 공식이 아니라, 텍스트를 읽고 판단한다.

### 하한선
- summary 최소 1장 + context 최소 1장

### 밀도 기준
- 주목할 만한 장면은 2~3문장마다 1장
- 극적 전환점(죽음, 발견, 대결 등)은 반드시 시각화
- 평이한 서술 구간은 이미지 간격을 넓혀도 무방

### summary vs context 비율
- 고정 비율은 없다. 텍스트 분량과 시각적 소재의 풍부함에 따른다
- summary 텍스트가 서사적으로 풍부하면(소설, 역사서 등) summary 이미지가 많아진다
- context 텍스트가 극적이면(전쟁, 투옥, 연설 등) context 이미지가 많아진다

## 기술 규격

| 용도 | 포맷 | 비율·해상도 |
|------|------|-------------|
| 배경연출 이미지 (`images/`) | JPG | **16:9 가로**, 1920×1080 이상 |
| 쇼츠 리빌 배경 (`revealBg`) | PNG | **2:3 세로**, 1024×1536 |

- 배경연출 이미지는 **정사각형 금지**. 생성 도구가 정사각형만 지원하면 16:9로 확장해 확보한다
- 두 종류 모두 어두운 기반 + 드라마틱 라이팅. 코드에서 밝기를 크게 깎으므로 원본이 밝으면 필터 후 밋밋해진다
- 공통 스타일 프리픽스: `cinematic, dramatic lighting, rich tones, no text, no letters, no words, 16:9 widescreen`

## 생성 방식

프롬프트 + 레퍼런스 폴더의 자료 이미지들(`ref/`)로 1장씩 생성한다.

**최종 경로에 바로 생성한다.** 다른 경로에 만든 뒤 옮기는 작업은 하지 않는다.

### 레퍼런스 사진 활용
- `ref/` 폴더에 인물 사진이 있으면 **context 이미지 생성 시** 참조한다 (보통 인물 포스터)
- **summary 이미지에는 ref 사진을 사용하지 않는다** — 책 속 세계에 셀럽 얼굴이 들어가면 안 된다
- 예외: summary에 저자 묘사가 있고 저자 ref가 따로 있는 경우

## 프롬프트 규칙

### 공통
- 복잡한 장면일수록 프롬프트를 길게 쓴다. 짧은 프롬프트를 두려워하지 않되, 필요한 정보를 생략하지 않는다
- 발생 가능한 이슈(AI 아티팩트, 시대고증 오류, 구도 혼란)를 사전에 대처할 수 있도록 명시
- 필수 포함: 시대·장소·시간대, 인물 포즈·의상·소품, 카메라 렌즈·앵글·피사계심도, 조명 방향·색온도
- 반드시 포함: `no text, no letters, no watermarks`

### summary 프롬프트 특칙
- **셀럽 이름이나 외모를 프롬프트에 넣지 않는다**
- 책 속 인물은 작품의 시대·배경에 맞게 묘사한다
- 저자를 그리는 경우 "17th-century Puritan preacher"처럼 직업·시대로 묘사하되 셀럽과 혼동되지 않게 한다

### context 프롬프트 특칙
- 셀럽의 나이·외모·복식을 해당 시점에 맞게 묘사한다
- 역사적 장면의 시대고증에 주의한다

### 다수 인물 장면
- 각 인물의 외모·의상·체형·포즈를 개별적으로 최대한 묘사한다
- "a group of people" 같은 뭉뚱그린 표현은 AI가 인물을 구분하지 못하게 만든다

### 밀랍인형 방지
- 21세기 카메라로 촬영한 듯한 실사감이 목표이나, "hyper-realistic" 등을 과잉 강조하면 밀랍인형처럼 부자연스러워진다
- **자연광 활용** — 직사광선, 창문광, 골든아워 등 실제 광원을 명시
- **피사계심도(DoF) 블러** — `f/1.4~2.8` 수준의 얕은 심도. 포커스 대상 외 영역은 적극 블러 처리
- **미세 결함 허용** — 약간의 그레인, 렌즈 플레어, 비네팅은 실사감을 높인다. 모든 디테일이 균일하게 날카로우면 CG처럼 보인다

## 쇼츠 리빌 배경 이미지 (`revealBg`)

쇼츠(9:16)의 **책 공개 구간 배경**이다. 위 배경연출 이미지와 목적·규격이 다르다.

### 지정 방법

책별 `shorts.ko.json`의 `revealBg`에 파일명만 적는다. 에피소드 `images/` 폴더에서 해석되므로 파일명 규칙은 본문과 같다(장면 묘사 케밥케이스).

```json
"revealBg": "joseon-naval-battle-burning-sunset.png"
```

비워두면 공용 배경(`common/images/reveal-bg.jpg`)으로 대체된다.

### 표시 조건

코드에서 `brightness(0.35) saturate(0.5)` + radial gradient 오버레이가 걸리고 `object-fit: cover`로 잘린다. 금색(`#c8a46e`)·아이보리(`#e8e0d0`) 텍스트가 이 위에 얹히는 **분위기 텍스처** 역할이다.

### 필수

- **얼굴·피부 노출 금지** — 밝기를 깎으면 유령처럼 보인다. 뒷모습 실루엣은 허용
- **강한 명암 대비** — 하이라이트(촛불, 빛줄기, 달빛)와 깊은 그림자. 대비가 약하면 필터 후 뭉개진다
- **심플한 구도** — 디테일보다 분위기. 사물 2~3개 이하
- **다크 톤 기본** — 밝은 하늘·바다 등 밝은 배경을 피한다

### 권장

- 촛불·횃불·램프 등 **점 광원 하나** → 어둡게 깎여도 하이라이트가 살아남는다
- **따뜻한 톤**(앰버·세피아·금색 계열) — 채도가 절반으로 줄어드는 것을 감안한다
- **오브제 중심** — 책, 도구, 상징물 클로즈업
- **질감** — 오래된 나무, 돌, 금속, 양피지, 가죽

### 금지

- 만화·일러스트·판타지 스타일 (리얼리스틱 사진 품질만)
- 밝은 하늘, 낮 풍경, 파스텔 톤
- 복잡한 군중 장면, 전투 장면
- AI 생성 티가 나는 과도한 디테일·광택

### 검증

생성 후 아래 CSS를 걸어 구도와 분위기가 남아있는지 확인한다.

```css
filter: brightness(0.35) saturate(0.5);
```
