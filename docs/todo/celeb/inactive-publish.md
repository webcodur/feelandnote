26.11.12 사용자 지시: 등록 중인 실존 인물의 필수 데이터를 완비하고 공개한다. 공개 기준은 [active 요건](../../project/celeb/celeb-00-02-active-requirements.md), 상태 전환은 [인물 공개 상태](../../project/celeb/celeb-00-05-publication.md)를 따른다. 사용자 결정: 결과 행이 0건인 조사 항목(집필 도서·등장 도서·관계망·소속 세력)은 조사를 마쳐 반영하거나 0건을 확정한 뒤 공개한다. 변희재·송소희·송원근도 빠진 데이터를 채워 함께 공개한다.

- 대상: `publication_status=inactive`이고 `celeb_reality`가 REAL·BOTH인 56명. 전원 아바타·대표사진이 있다.

- 조사 기록은 DB 결과 행으로만 남으므로, 아래 표의 0건 항목은 조사를 다시 한다. 조사 결과 0건이면 그 사실을 이 표에 적고 충족으로 본다.
