# 태그 후보 — 미등록 인물 목록

DB에 등록되지 않아 태그 생성이 보류된 인물들. 등록 후 태그 생성 가능.

---

## 빈의 세기말 (Fin-de-siècle Vienna)

1900년 전후 빈에 모인 천재들. 정신분석, 미술, 음악, 철학이 한 도시에서 폭발한 시대.

**DB 보유 (2명):**
- 루트비히 비트겐슈타인 (Ludwig Wittgenstein)
- 구스타프 말러 (Gustav Mahler)

**미등록 — 등록 필요 (5~6명):**
- 지그문트 프로이트 (Sigmund Freud) — 정신분석의 창시자
- 구스타프 클림트 (Gustav Klimt) — 키스, 빈 분리파
- 에곤 쉴레 (Egon Schiele) — 표현주의 화가
- 슈테판 츠바이크 (Stefan Zweig) — 어제의 세계, 유럽 최고 베스트셀러 작가
- 아르투어 슈니츨러 (Arthur Schnitzler) — 빈 모더니즘 극작가
- 에르빈 슈뢰딩거 (Erwin Schrodinger) — 양자역학 (빈 출신)

**색상 제안:** #C9A96E (빈 금빛)

## 잃어버린 세대 (The Lost Generation)

1920년대 파리. 1차 대전의 환멸을 안고 몽파르나스 카페에 모인 예술가들.

**DB 보유 (2명):**
- 어니스트 헤밍웨이 (Ernest Hemingway)
- 파블로 피카소 (Pablo Picasso)

**미등록 — 등록 필요 (4~5명):**
- F. 스콧 피츠제럴드 (F. Scott Fitzgerald) — 위대한 개츠비
- 거트루드 스타인 (Gertrude Stein) — "잃어버린 세대"를 명명한 장본인
- 살바도르 달리 (Salvador Dali) — 초현실주의 화가
- 제임스 조이스 (James Joyce) — 율리시스 (파리에서 출판)
- 헨리 밀러 (Henry Miller) — 북회귀선

**색상 제안:** #8B7355 (몽파르나스 세피아)

## 브리티시 인베이전 (British Invasion)

1960~70년대, 영국 음악이 세계를 정복한 시대.

**DB 보유:** 0명

**미등록 — 등록 필요 (6~8명):**
- 존 레논 (John Lennon) — 비틀즈
- 폴 매카트니 (Paul McCartney) — 비틀즈
- 믹 재거 (Mick Jagger) — 롤링 스톤스
- 데이비드 보위 (David Bowie) — 글램 록의 아이콘
- 프레디 머큐리 (Freddie Mercury) — 퀸
- 엘튼 존 (Elton John) — 피아노맨
- 에릭 클랩튼 (Eric Clapton) — 기타의 신
- 지미 페이지 (Jimmy Page) — 레드 제플린

**색상 제안:** #D4243B (유니언잭 레드)
