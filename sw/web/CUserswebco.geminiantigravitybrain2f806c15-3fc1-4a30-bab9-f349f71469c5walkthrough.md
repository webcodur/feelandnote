## ��� 디자인 추가 개선 (피드백 반영)

요청하신 피드백을 반영하여 테마 선택 UI의 아이템 디자인을 한층 다듬었습니다.
* **폰트 변경:** `serif` 서체를 제거하고 깔끔하고 명시적인 `sans-serif`로 변경하여 가독성을 높이고 모던한 느낌을 더했습니다.
* **컴팩트한 크기:** 각 아이템의 여백(Padding)과 텍스트 크기를 살짝 줄여, 한 화면에 더 많은 태그가 오밀조밀하고 정돈되게 보이도록 개선했습니다.

* **PC 조율 (선택 유지):** 데스크톱(PC) 모드에서는 한 번 열어둔 테마 그리드가 다른 태그를 골라도 바로 닫히지 않고 열린 상태를 유지하도록 로직을 수정했습니다. 덕분에 탐색이 더욱 자유로워졌습니다.

* **뷰 모드 탭 시안성(Visibility) 강화:** 스포트라이트 / 공유 서재 / 연대기 탭이 배경과 분리되지 않아 눈에 띄지 않던 문제를 해결했습니다. 
  * 전체 탭을 감싸는 둥근 컨테이너(Pill box) 모양의 유리 질감(Glassmorphic) 배경을 추가해 뒤 배경과 확실히 분리시켰습니다.
  * 탭 글씨 크기를 키우고(`text-[14px]`) 주변에 약간의 빛 번짐(Glow) 효과를 추가하여 현재 활성화된 탭이 두드러지게 보이도록 개선했습니다.

* **태그 색상표(Dot UI) 제거:** 데스크톱 모달 내부의 주제 리스트와 모바일 바텀시트 리스트 각각의 각 타일에 붙어있던 포인트 컬러 동그라미(Dot) 요소를 완전히 제거했습니다. 이를 통해 화면이 훨씬 정돈되고 깔끔해졌습니다.

* **Dot 제거 이후의 카드 UI 정렬 및 프리미엄화:** 기존 좌측의 도트가 빠지면서 발생한 직업군 아이콘들의 들여쓰기(Indentation) 오류를 수정하여, **카드 좌측 라인에 텍스트와 아이콘이 완벽하게 일렬로 정렬**되도록 바로잡았습니다.
* **Ambient Glow 이펙트 추가 (Glassmorphism):** 도트 색상이 빠진 허전함을 채우고 프리미엄 감성을 극대화하기 위해, 각 카드의 **우측 상단 모서리에 해당 태그의 고유 색상(Color)을 띈 부드러운 빛 번짐(Glow) 효과**를 추가했습니다. 호버 시 빛이 살짝 더 퍼지도록 애니메이션을 부여해 매우 모던하고 우아한 느낌을 줍니다.
