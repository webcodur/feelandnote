# 이미지 생성 테크닉 연구 — 소재별 표현법과 그 근거

> **최종 실측 체크: 26.07.16** — 전문 통독. 코드 경로·스크립트·필드명 참조가 하나도 없는 순수 프롬프트 기법 문서라 대조 대상이 없었고, 고칠 것도 없었다. 본문의 실측 근거(생성분 20장 판정, 컷 ID)는 원본 생성물이 남아 있지 않아 재확인 범위 밖

머스크 『아틀라스』 쇼츠 v1 생성분 20장의 실측 결과에서 출발한 소재별 표현 테크닉.
"왜 이 소재는 이렇게 그려야 하는가"를 생성기의 구조적 특성 + 실측 증거로 뒷받침한다.
스토리가 바뀌어도 살아남는 시리즈 공통 자산이다.

---

## A. 생성기의 물리학 — 왜 어떤 그림은 되고 어떤 그림은 안 되는가

테크닉의 근거가 되는 생성기(디퓨전 계열)의 구조적 특성 6가지.

### A1. 빈도 의존성 — 흔한 장면은 강하고 희귀한 장면은 평균으로 회귀한다

생성기는 학습 사진의 분포를 따른다. 스튜디오 정물·인물 포트레이트·풍경은 수억 장을 학습해 강하지만, **한국 개표소·투표지분류기·도미니언 개표기**는 학습 사진 자체가 희소하다. 희소한 피사체를 요구하면 생성기는 가장 가까운 흔한 것들(프린터·복합기·키오스크)의 평균을 내놓는다 — "개판으로 나온다"의 구조적 원인이다. **재시도해도 분포가 바뀌지 않으므로 재롤은 무의미하다.**

- 실측: 한국 개표장·투표소 컷은 생성 단계에서 전부 막혔다(v1 미생성 12컷의 대부분).

### A2. 글자는 언어가 아니라 무늬다 — 네거티브는 상관관계를 못 이긴다

생성기는 글자를 픽셀 패턴으로 그린다. 더 치명적인 건 **"글자 쓰지 마"라는 지시가, 글자가 있어야 자연스러운 면이 화면에 존재하는 한 무력화**된다는 점이다. 시위 군중을 그리면 팻말이 나오고, 팻말이 나오면 학습 데이터에서 가장 흔한 시위 문구가 환각된다.

- 실측: HK-01에 `no readable text`를 명시했으나 BLM 시위 문구("BLACK LIVES MATTER", "DEFUND THE POLICE")가 통째로 박혀 나왔다. 정치적으로도 위험한 폐기물.
- **해법은 네거티브가 아니라 면의 제거다**: 팻말은 뒷면만(blank back sides of signs), 화면은 정전·노이즈만, 코드는 추상 광으로.

### A3. 다인물 붕괴 — 어텐션은 인물 수만큼 쪼개진다

얼굴 하나에 쓸 수 있는 디테일 예산이 인물 수에 반비례한다. 대략 **3인 이상 + 중경 거리**부터 얼굴이 뭉개지기 시작하고, 6인 이상이면 전멸한다.

- 실측: INT-02(1950년대 군중 난투)에서 중경 인물 전원의 얼굴이 녹아내렸다.
- 해법 사다리(강→약): ① 역광 실루엣(얼굴 그릴 의무 자체를 제거) ② 뒷모습 ③ 아웃포커스 보케 ④ 1~2인만 또렷+나머지 흐림.

### A4. 단일 피사체 집중은 최강이다 — 매크로·정물·단독 포트레이트

어텐션이 한 곳에 모이면 생성기는 경이로운 디테일을 낸다. 종이의 섬유, 유리의 굴절, 청동의 녹청, 홍채의 반사까지.

- 실측: 수작 판정 컷 전부가 이 패턴이다 — 단독 머스크(INT-01, CM-01, CMd-01), 단독 사물(END-03 전구), 단독 동상(협곡 아틀라스).
- 따라서 **"한 컷 = 주인공 하나"**가 기본 문법이다. 문장 하나를 사물 하나가 지게 한다.

### A5. 반복 일관성이 없다 — 같은 프롬프트도 매번 다른 사물

생성마다 디자인이 흔들린다. 여러 컷에 같은 사물(투표함 등)이 등장하면 REF 이미지 참조 없이는 컷마다 다른 물건이 된다.

- 해법: 반복 사물은 **히어로 REF를 먼저 1장 굳히고** 전 컷이 그 이미지를 참조(`(REF)`)한다. 인물 REF(머스크·트럼프)와 같은 원리.

### A6. 막연한 형용사는 평균을 부른다 — "cinematic"의 함정

`cinematic`이라고만 쓰면 평균적 시네마틱(스톡사진)이 나온다. 특정한 그림은 **카메라(렌즈mm·앵글·조리개)와 조명(방향·색온도·광원 수)을 구체적으로 지정**해야 나온다. 같은 원리로 추상 거인(titan)을 막연히 요구하면 검은 덩어리가 나온다 — 형태가 특정된 사물(청동 동상, 록펠러식 자세)로 못 박아야 한다.

- 실측: 아틀라스 거인이 "석유 뒤집어쓴 텍스처"로 나온 원인 = 막연한 titan + 역광 + 어두운 산업 하늘의 삼중 작용.

## B. 소재별 표현법

### B1. 투표지(종이) — 이 에피소드의 주인공 소재

**종이는 생성기 최강 영역이다.** 정물·매크로 학습 데이터가 풍부하고, 텍스처가 단순하며, 백지로 두면 글자 환각이 원천 차단된다.

| 표현 목적 | 기법 | 프롬프트 핵심어 |
|---|---|---|
| 의지·희망 | 빛 받는 한 장, 반투명 발광 | `a single white ballot catching the light` |
| 훼손·오류 | 찢김 매크로(섬유 디테일) | `torn nearly in half, focus on torn paper fibers` |
| 약탈·이동 | 낙하·부유 정지 화면 | `levitating, frozen mid-fall, high-speed still` |
| 규모 | 무더기·강·행렬 | `a river of millions of ballots` |
| 시간 누수 | 모래시계 속 종이 | `ballots falling through an hourglass neck` |
| 오염 | 흰 더미에 번지는 잉크 | `black ink bleeding up through the stack` |

규칙:
- **반드시 백지**. 기표 도장·후보명·선관위 마크를 넣는 순간 한글 환각 지뢰. 의미는 빛과 상태(찢김·물듦·발광)로 입힌다.
- 색 문법: 깨끗한 표=차가운 백색 / 훼손된 표=붉은 경고 악센트 / 희망의 표=따뜻한 앰버.
- 실패 모드: 여러 장이 겹치면 가장자리끼리 녹아 붙는다 → 장수를 줄이거나 한 장을 주인공으로.

### B2. 투표함 — 수미상관의 닻

- **일반형 투명 아크릴 함 + 흰 투입구**는 안전하다. 단순 기하 + 투명 재질은 강한 영역.
- **한국 사전투표함 특정(봉인 스티커·띠지) 시도 금지** — 스티커는 곧 글자다(A2).
- 에피소드 안에서 같은 투표함이어야 하는 이유: 첫 장에서 도둑맞던 함에 마지막 장에서 시민이 표를 넣는 수미상관. **히어로 REF 1장 고정**(A5) 후 전 컷 참조.
- 실패 모드: 투명 함 속 내용물이 왜곡된다 → 내용물은 "white ballots"로 단순 지시.

### B3. 분류기·개표기(기기류) — 생성 금지, 대안의 사다리

**왜 그리면 안 되는가** (세 겹의 근거):
1. **A1 빈도** — 한국 분류기는 학습 사진이 보도사진 수백 장 수준, 도미니언도 각도 다양성이 없다. 흔한 사무기기의 평균으로 회귀한다.
2. **A2 글자** — 기기 표면은 라벨·버튼·LCD 투성이다. 기기를 그리는 순간 글자 환각 지뢰밭에 들어간다.
3. **법적 민감** — 도미니언은 명예훼손 소송 전력(폭스뉴스, 약 7.9억 달러 합의)이 있는 실존 상표다. AI가 "비슷하게" 그린 기기에 조작 뉘앙스가 얹히면 리스크가 생긴다.

**대안의 사다리** — "기기를 어디까지 보여줄 필요가 있나"로 단을 고른다:

| 단 | 기법 | 언제 |
|---|---|---|
| 1단 | **결과물만** — 찢긴 표 한 장, 기계는 프레임 밖 | 오류·사고를 말할 때 (기본값) |
| 2단 | **추상 대체** — 코드 빛이 투표함·종이를 잠식 | 해킹·디지털 위협을 말할 때 (기본값) |
| 3단 | **어둠 속 실루엣** — 본체 80%를 로우키 어둠에 묻고 투입구와 쏟아지는 표만 빛에 | 기계의 존재감 자체가 필요할 때. 글자 면이 어둠에 잠겨 환각 봉쇄 |
| 4단 | **실물 보도사진** — 도미니언·한국 분류기·사전투표함 실사 확보, 어둡게 그레이딩+비네팅으로 톤 맞춤 | "이거 진짜다" 인지가 신뢰의 핵심일 때. 단 도미니언은 중립 묘사만, 조작 암시는 내레이션이 진다 |

3단이 미사용 옵션인데, 추상(1·2단)이 어색하고 실사(4단)가 과할 때의 중간값이다:
`A machine's paper slot catching a cold beam in heavy darkness, ballots spilling from it, the body of the machine swallowed by shadow — only the slot and the paper visible.`

### B4. 군중 — 감정은 몸짓과 빛으로, 얼굴은 절대 그리지 않는다

- 기법 사다리는 A3 참조 (실루엣 > 뒷모습 > 아웃포커스 > 1~2인 집중).
- **군중의 감정은 얼굴이 아니라 몸짓+조명으로 말한다**: 치켜든 팔(분노·열광), 늘어진 어깨(체념), 일제히 같은 방향(휩쓸림), 폰 불빛(자발성).
- **동세 오독 방지** — 실측: END-06에서 "휩쓸리는 군중"이 난투극으로 그려졌다. "swept/drifting" 같은 서술만으론 생성기가 몸싸움으로 해석한다. **모션 블러를 물리적으로 지정**(`slow-shutter motion blur on the swept crowd, tack-sharp standing figure`)해야 "흐름 vs 정지"의 대비로 읽힌다.
- 실루엣 군중 + 역광 + 안개는 검증된 안전 조합(CMd-03 수작).

### B5. 글자·팻말·화면 — 면을 없애는 것이 유일한 해법

- 근거와 실측은 A2. 요약: 네거티브 지시는 진다. **글자가 앉을 면 자체를 화면에서 제거한다.**
- 면 제거의 구체 기법: 팻말 뒷면(`only the blank back sides of signs visible`), 정전·노이즈 화면(`dead blue static, no readable imagery`), 추상 코드 광(`abstract glitching code light, unreadable`), 역광 실루엣화(팻말이 검은 사각형이 됨).
- 어차피 쇼츠는 자막이 정보를 전부 말한다. **이미지가 글자를 질 이유가 없다.**

### B6. 실존 인물(머스크·트럼프) — REF 합성은 강점, 단 거리가 생명

- 실측: REF 합성 컷 전부 얼굴 우수(INT-01, INT-04, CM-01, CMd-01, END-02). **단독 + 미디엄 이상 크기 + 또렷한 단일 키 조명** 조합이 공식.
- 실패 실측: CD-01(서류 협곡)은 인물이 원거리+로우키라 머스크 닮음이 소실됐다. **REF 인물은 화면에서 충분히 커야 닮는다** — 원거리 배치가 필요하면 닮음을 포기하고 익명 인물로 간주하든가, 구도를 당긴다.
- 상시 명시: `(REF, exact likeness)`, `preserve REF face`. 손이 나오면 `natural five-fingered hand`.
- 제3 정치인(트럼프)은 REF 있을 때만 또렷이. 없으면 실루엣·블러로 우회.

### B7. 아틀라스 동상 — 누적 교훈의 종합

시행착오 전체가 이 소재에 응축돼 있다. 실패 3단계와 해법:

1. 막연한 'titan/giant' → **검은 석유 덩어리** (A6: 형태 미특정의 평균 회귀)
2. 역광 + 어두운 산업 하늘 → **실루엣화로 질감 소실** (조명이 형태를 죽임)
3. 천구의(고리)·우주에서 본 지구 → **과밀·키치** (불필요한 복잡도)

확정 공식 (협곡판으로 검증 완료):
- 형태 특정: `realistic bronze Atlas statue, muscular male figure kneeling on one knee`
- 드는 것 단순화: `plain heavy round metal orb — NOT a detailed earth, NOT rings, NOT a space view`
- 조명: `bright clear side daylight raking the statue` (측면광이 청동 질감을 살림)
- 배경: `vast cinematic natural landscape` (광활한 자연 — 동상과 밝기 분리)
- 네거티브: `NOT a black silhouette, NOT backlit, NOT oily black surface`

### B8. 추상 개념의 사물화 공식 — "살짝의 추상"의 정체

부패·해킹·시간 같은 개념을 직접 그리라면 실패한다. **개념 = 사물의 상태 변화**로 번역하는 것이 공식이다:

| 개념 | 사물 + 상태 변화 |
|---|---|
| 부패 | 흰 종이 더미에 검은 잉크가 스며 오름 (오염) |
| 해킹 | 아날로그(종이·함) 위를 디지털 빛이 기어감 (잠식) |
| 표의 약탈 | 투표함에서 표가 어둠의 손으로 떠오름 (이탈) |
| 사전투표 기간 | 모래시계 + 금 간 틈으로 새는 표 (누수) |
| 조종·선동 | 실루엣 손목에 매인 꼭두각시 줄 (속박) |
| 언론→시민 권력 이동 | 거대 화면의 죽음 + 작은 폰 불빛들의 점화 (반전) |
| 거짓의 폭로 | 회색 가면이 빛 속에서 깨지는 순간 (파열) |

이 공식이 작동하는 이유: **초현실이지만 물리 법칙은 유지**되기 때문이다. 종이가 떠오르고 잉크가 번지는 건 생성기가 그릴 줄 아는 물리 현상이고(A4), 시청자도 한눈에 읽는다. 물리를 깨는 추상(개념 콜라주, 초현실 합성체)은 생성도 불안하고 독해도 느리다.

**추상의 합격선 — 사건이 본질을 직격하는가** (아틀라스 편 실전 교훈):
- ✅ 합격: 사물에 일어나는 사건이 곧 문제 그 자체인 것. "코드 빛이 투표지를 덮친다"(=해킹), "잉크가 흰 종이에 스며 오른다"(=부패).
- ❌ 탈락: **기성 상징물(모래시계·저울·천칭 등)을 빌려와 관념을 대신 말하게 하는 것.** 사전투표 이슈를 모래시계로 그렸다가 폐기됐다 — "시간이 흐른다"는 일반론일 뿐, 본질(표가 며칠 밤 무방비로 보관됨)과 닿지 않는다. 정답은 "깊은 밤 보관소에 홀로 놓인 투표함"처럼 **그 문제의 현장을 그대로 무대화**하는 것이었다.
- 판별 질문: "이 그림의 사건을 한 문장으로 말하면 본문의 문제 진술과 같은 문장이 되는가?"

## C. 공통 레시피

### 프롬프트 골격 (이 순서대로)

```
[무대: 보이드/안개/자연] + [주인공 1개: 사물 또는 인물] + [상태/행위 하나]
+ [광원 1개 + 악센트 1색] + [카메라: 렌즈mm·앵글·조리개·포커스 대상]
+ [공통 스타일] + [네거티브: 글자·로고·페인터리·3D렌더]
```

### 재롤 규칙

같은 프롬프트 **2회 실패 시 재롤 중단**. 분포가 바뀌지 않는다(A1). 대신 구조를 바꾼다:
1. 피사체 수를 줄인다 (군중 → 한 명, 더미 → 한 장)
2. 글자 면을 제거한다 (정면 → 뒷면, 켜진 화면 → 꺼진 화면)
3. 거리를 당긴다 (와이드 → 매크로)
4. 그래도 안 되면 소재의 단을 바꾼다 (B3 사다리: 추상 ↔ 실사 폴백)

### 검증 순서 (비용 절감)

1. 히어로 REF부터 (반복 사물·인물) — 시안 확정 전 본 컷 금지
2. 본 컷은 "주인공 하나" 컷부터 (성공률 높음) → 복합 컷(2요소)은 후순위
3. 결과 검수 체크: 얼굴 뭉개짐 / 글자 환각 / 손가락 / 닮음(REF 컷) / 톤 일탈
