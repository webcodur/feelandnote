# 독서 방식 필드 기획

인물이 책을 **어떻게 읽는가**를 담는 인물 단위 속성을 `celebs`에 둔다. 무엇을 읽었는가(감상 관계)와 다른 축이다. 아직 미구현이다.

## 데이터 정의

- **범위**: 독서만 다룬다. 영상·게임·음악의 감상 방식은 이 필드의 대상이 아니다.
- **성격**: 인물의 특성이지 작품별 기록이 아니다. 인물당 한 값이며, `celeb_contents`가 아니라 `celebs`에 둔다.
- **근거**: 본인 발언·인터뷰·자서전·전기처럼 확인된 사실만 쓴다. 추측으로 만들지 않는다.

## 작성 규칙

인물의 독서 습관, 책을 대하는 태도, 상징적 일화를 중심으로, 구체적인 묘사를 살려 450자 내외(공백 포함)의 평어체 에세이로 자유롭게 작성한다. 생존 인물은 현재형(~한다), 고인은 과거형(~했다)으로 쓴다. 확인된 사료에 있는 내용만 쓰고 일화를 창작하지 않는다. 읽은 책의 목록 나열과 인물에 대한 평가·찬사는 넣지 않는다 — 무엇을 읽었는가는 감상 관계가 담당한다. 영문은 한국어를 직역하지 않고 같은 사실을 자연스러운 영어로 쓴다.

## 컬럼

`reading_way`, `reading_way_en` (text, NULL 허용). 채움 기준·노출 위치는 확정 후 적용한다.
