# OpenAI / GPT 사용 가이드

마지막 확인: 2026-06-30

이 문서는 Feelandnote에서 OpenAI API를 사용할 때 모델, 비용, 이미지 생성 옵션을 고르는 기준을 정리한다. 모델명, 가격, 지원 옵션은 바뀔 수 있으므로 실제 대량 작업 전에는 공식 문서를 다시 확인한다.

## 공식 문서

- 이미지 생성 가이드: https://developers.openai.com/api/docs/guides/image-generation
- 이미지 API 레퍼런스: https://developers.openai.com/api/docs/api-reference/images
- 가격표: https://developers.openai.com/api/docs/pricing

## API 선택

- 단발 이미지 생성·편집: Image API를 우선 사용한다.
- 대화형 이미지 수정, 여러 차례 이어지는 편집, 이미지 생성이 포함된 복합 작업: Responses API를 사용한다.
- Responses API에서 이미지 생성 도구를 쓰면, 선택한 대화 모델의 토큰 비용도 이미지 생성 비용과 별도로 붙는다.

## 이미지 생성 기본값

시안, 후보 뽑기, 프롬프트 테스트는 아래 값을 기본으로 둔다.

```json
{
  "model": "gpt-image-2",
  "quality": "low",
  "size": "1024x1024"
}
```

가로형·세로형이 필요하면 처음부터 필요한 비율로 작게 만든다.

| 용도 | 권장값 |
|------|--------|
| 정사각형 시안 | `1024x1024`, `quality: "low"` |
| 가로형 시안 | `1024x640` 또는 `1280x512`, `quality: "low"` |
| 세로형 시안 | `640x1024` 또는 `512x1280`, `quality: "low"` |
| 최종본 | 필요한 실제 비율 + `quality: "medium"` 또는 `"high"` |
| 2K 이상 | 최종 산출물이 명확할 때만 사용 |

`gpt-image-2`는 아래 조건을 만족하면 임의 해상도를 받을 수 있다.

- 두 변 모두 16px 배수
- 긴 변 / 짧은 변 비율이 3:1 이하
- 한 변 최대 3840px
- 전체 픽셀 수 655,360 이상, 8,294,400 이하

작은 쪽에서 쓸 수 있는 예시는 `816x816`, `896x768`, `768x896`, `1024x640`, `640x1024`, `1280x512`, `512x1280`이다. 정사각형은 보통 더 빠르게 생성된다.

## 비용 판단

이미지 생성 최종 비용은 아래 합으로 본다.

- 프롬프트 텍스트 입력 토큰
- 이미지 편집·참조 이미지가 있을 때의 입력 이미지 토큰
- 생성 이미지 출력 토큰

`gpt-image-2`는 공식 문서의 계산기로 요청 크기와 품질에 따른 출력 비용을 추산한다. 이전 GPT Image 모델들은 보통 해상도가 크고 품질이 높을수록 이미지 출력 토큰이 증가한다.

2026-06-30 공식 문서 기준 참고값:

| 모델 | 품질 | 1024x1024 | 1024x1536 | 1536x1024 |
|------|------|-----------|-----------|-----------|
| GPT Image 2 | low | $0.006 | $0.005 | $0.005 |
| GPT Image 2 | medium | $0.053 | $0.041 | $0.041 |
| GPT Image 2 | high | $0.211 | $0.165 | $0.165 |

위 숫자는 작업 판단용 참고값이다. 비용 표는 바뀔 수 있으므로 코드나 사용자 화면에 장기 고정하지 않는다.

## 비용 절감 규칙

- 후보 이미지는 `quality: "low"`로 만든다.
- 최종본이 확정되기 전에는 2K·4K로 만들지 않는다.
- 한 번에 여러 장을 만드는 `n` 값은 비용이 거의 장수만큼 늘어난다고 본다.
- 기존 이미지를 넣어 편집하거나 참조시키면 입력 이미지 토큰이 추가된다.
- `gpt-image-2`는 이미지 입력을 고충실도로 처리하므로, 참조 이미지가 많은 편집 요청은 비용이 커질 수 있다.
- 스트리밍 중간 이미지를 받는 `partial_images`는 중간 이미지마다 추가 이미지 출력 토큰이 붙는다.
- 투명 배경이 꼭 필요하면 모델 지원 여부를 먼저 확인한다. `gpt-image-2`는 현재 투명 배경을 지원하지 않는다.
- 지연 시간이 중요하면 PNG보다 JPEG 또는 WebP 출력을 우선 검토한다.

## 품질 한계

이미지 생성 모델은 다음 작업에서 실패가 날 수 있다.

- 정확한 글자 배치와 작은 텍스트 렌더링
- 반복 등장 인물, 브랜드 요소, 소품의 장기 일관성
- 구조가 중요한 레이아웃에서의 정확한 위치 제어

이런 작업은 한 번에 최종본을 기대하지 말고, 낮은 품질로 구도와 프롬프트를 잡은 뒤 최종 품질로 다시 생성한다.

## 작업 전 체크리스트

- 필요한 최종 비율이 정해졌는가?
- 시안 단계인데 `quality: "medium"` 이상을 쓰고 있지 않은가?
- 불필요하게 큰 해상도를 요청하고 있지 않은가?
- 참조 이미지가 정말 필요한가?
- 여러 장 생성이 필요한 경우 예상 장수와 비용을 먼저 공유했는가?
- 공식 가격표를 확인한 지 오래되지 않았는가?
