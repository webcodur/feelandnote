# 편집국 사이클 시스템

5인 편집국이 책별로 비판하고 재귀적으로 수정한다. 모든 책이 합격 임계에 도달할 때까지 라운드를 반복한다. 완전체가 나오기 전에는 게임을 끝내지 않는다.

비판 렌즈의 단일 SSoT다. 위생(렌즈 1~6) + 도끼(렌즈 7~11) + 번역투 + 사료 + 직업 분야가 모두 이 한 파일에서 운영된다.

---

## 동기

`remo-write-1`(사료) · `remo-write-3`(서사) · `remo-write-4`(문장)는 단일 렌즈로 한 번 검토한다. 한 번 검토는 한 시각의 한 회차일 뿐이다.

도끼로 박히는 영상은 **네 시각이 동시에 통과**해야 한다.

- **셀럽 분야의 정확성** — 미술인을 다루는데 미술적 통찰이 빈약하면, 분야 사람이 한 줄도 안 보고 떠난다.
- **사료의 정확성** — 인명·연도·일화 어긋나면 신뢰가 한 번에 무너진다.
- **영상 극으로서의 호소력** — 두 가지가 통과해도 영상으로 무미건조하면 시청자에게 닿지 않는다. 위생·도끼 렌즈가 여기서 작동.
- **한국어 자연성** — 클로드 산출물은 번역투(영어식 어순·사물 주어·직역체)가 자주 섞인다. 의미가 맞아도 번역투면 모국어 청자에게 거리감을 만든다. **무조건 매 라운드 점검 대상**.

이 넷을 한 사이클 안에서 **각각 점수 매기고**, 미합격 항목을 편집국이 모아 한 번에 수정하고, 다시 평가한다. 합격 임계 도달까지 멈추지 않는다.

| 셀럽 자신의 시각 일치 | 20 | 셀럽이 직접 적은 글·인터뷰 톤과 어긋나지 않는가 |

### 3. 영상극 전문가 — 위생·도끼 검수 (단일 SSoT)

영상이라는 매체로 풀어냈을 때의 호소력을 본다. **위생(오류·비약·과장 제거)과 도끼(충격·전복·잔상)를 한 자리에서 운영**한다.

작성 시에는 공감과 몰입으로 글을 쓴다. 검토 시에는 의도적으로 잔인해진다.

#### 평가 기준 (100점)

| 항목 | 배점 | 평가 내용 |
|---|---|---|
| 서사 구조 | 30 | 도입–전개–매듭이 한 책 안과 책 간에 모두 살아 있는가 |
| 감정 곡선 | 25 | 이입 → 몰입 → 여운까지 곡선이 평탄하지 않은가 |
| 인물 입체성 | 20 | 모순·갈등·취약함·결단의 다층이 보이는가 |
| 영상 호흡 | 15 | TTS 친화·문장 길이·이미지 앵커 자리 |
| 청자 호소력 | 10 | 일반 청자가 한 줄에서도 도끼를 맞는가 |

#### 최상위 기준: 도끼 테스트

> "책은 우리 안의 얼어붙은 바다를 깨뜨리는 도끼여야 한다." — 프란츠 카프카

비판적 검토의 목적은 **오류를 찾는 것이 아니다**. 오류 없는 영상은 만들 수 있다 — 그것만으로는 디지털 쓰레기와 구별되지 않는다.

진짜 목적: **"이 에피소드를 다 듣고 나서, 시청자의 이마에 도끼가 박혔는가?"** 모든 검토는 이 질문으로 돌아온다. 도끼가 박히지 않으면 깔끔해도 실패한 영상이다.

검토는 두 단계로 진행한다.

| 단계 | 목적 | 비유 |
|---|---|---|
| **위생** | 오류·비약·과장·미설명 제거 | 수술 전 소독 |
| **도끼** | 충격·전복·잔상 강화 | 수술 자체 — 시청자의 인식을 바꾸는 절개 |

위생만 하고 도끼를 무시하면 안전하지만 무의미. 도끼만 노리고 위생을 무시하면 찬란하지만 무너진다. **둘 다** 한다.

#### 위생 6렌즈 — 출시의 최소 조건

| 렌즈 | 점검 | 🔴 예시 | ✅ 교정 |
|---|---|---|---|
| 1. "그래서 뭐?" | 각 문장에 즉각적인 답이 있는가 | "그는 많은 책을 읽었습니다" | "감옥에서 27년간 매일 새벽 4시에 책을 읽었습니다" |
| 2. 논리 비약 | A→B 중간 단계가 있는가 | "이 책을 읽었다. 그래서 혁명을 일으켰다" | 읽고 나서 무엇이 바뀌었는지 중간 과정 |
| 3. 과장·미사여구 | 사실보다 부풀려졌는가 | "가장 위대한", "전무후무한", "눈물 없이 읽을 수 없는" | 수식 빼고 더 강해지면 그 수식은 쓰레기 |
| 4. 미설명 전제 | 시청자가 모를 단어가 있는가 | "변증법적 유물론" | "모든 역사는 지배·피지배의 투쟁이라는 마르크스의 사상" |
| 5. 일방적 미화 | 어두운 면을 감췄는가 | "좋은 사람이 좋은 일을 했다" | 어두운 면 포함이 서사를 강하게 하면 누락은 손실 |
| 6. 시청자 이탈 | 흥미 하락·외부지식·동기 부재 | 같은 정보 3문장 이상 반복, 30초 안에 끝까지 볼 이유 없음 | 새 정보·전환·질문 삽입 |

판정 기준:
- 렌즈 1: 정보 전달에 그치는 문장, 수식 포장 빈 문장 = 🔴
- 렌즈 2: 비약 1개 = 🔴 (시청자는 "어? 왜?" 순간 이탈)
- 렌즈 3: 사료 인용은 예외 ("플루타르코스가 '역사상 가장 위대한 정복자'라 기록한" — 인용이지 미사여구 아님)
- 렌즈 4: "고등학생이 즉시 이해하는가" 기준
- 렌즈 5: 학술 논문 아니라 대중 영상. 모든 반론 다룰 필요는 없되, 어두운 면이 서사 강도에 기여하면 빼지 말 것

**🔴가 1개라도 있으면 출시 불가.**

#### 도끼 5렌즈 — S급 진입 조건

위생이 통과된 다음에 적용한다.

| 렌즈 | 점검 | 통과 기준 |
|---|---|---|
| 7. 전복 | 시청 전후 인물상이 바뀌는가 | 시청자의 상투적 이미지가 되돌릴 수 없게 교체됨 |
| 8. 잔상 | 3일 뒤에도 떠오르는 장면이 있는가 | 시각적 선명·감정 충전·테마 직결 3박자 이미지 1개 이상 |
| 9. 전염 | hook을 말로 전했을 때 반응 | "진짜?" ✅ / "그래서?" 🔴 / "음..." (무관심) → hook 폐기 |
| 10. 불가역 | 알면 잊을 수 없는 사실이 있는가 | 같은 사실이라도 배치·맥락이 만드는 불가역성 1개 이상 |
| 11. 시간 | 10년 뒤에도 유효한가 | 보편 인간 경험·사료 기반. 시사·트렌드·밈 의존 회피 |

판정:
- 전복 없음 = 위키백과와 차별 없음
- 도끼 5개 중 4개↑ 통과 → S급
- 0~2개 → A급 출시는 가능하나 구조적 재설계 검토

**완전 전복 없으면 S급 아님. 불가역 사실 0개면 위키백과와 차별 없음.**

#### 심각도 분류

| 심각도 | 기준 | 조치 |
|---|---|---|
| 🔴 치명 | 위생 1·2·4 위반 / 사실 왜곡 / "그래서 뭐?" 실패 / 감정 명령 | 즉시 수정. 출시 불가 |
| 🟠 구조 | 도끼 7·8·9·10 부재 | S급 실패. 구조적 재설계 |
| 🟡 약점 | 위생 3·5·6 부분 위반 | 수정 권장. 등급 상승 가능 |
| ✅ 양호 | 위생·도끼 모두 통과 | 확인만 |

🔴 1개라도 있으면 출시 불가. 🟠 3개 이상이면 S급 불가능.

#### 핵무기 식별·보호

비판만 하고 강점을 무시하면 안 된다. 에피소드에서 **가장 도끼에 가까운 문장/장면 3개**를 뽑는다 — 이것들이 핵무기다. 보호하고 강화한다.

주변의 약한 문장이 핵무기 임팩트를 깎고 있으면, 약한 문장을 제거하거나 핵무기를 더 돋보이게 재배치한다.

#### 영상극 전문가 행동 원칙

- 위생(렌즈 1~6)에서 문제 발견 시 **즉시 수정안 제시** — 보고서만 남기지 않는다
- 도끼(렌즈 7~11)에서 부족 발견 시 **구체적 개선안** ("전복이 부족하다"가 아니라 "Book 4의 context를 이렇게 바꾸면 전복이 발생한다" 수준)
- 주관적 취향을 구조적 문제로 위장하지 않는다 — "마음에 안 든다"와 "시청자 이탈을 유발한다"는 다르다
- A급에서 멈추지 않는다 — 위생 통과로 만족 금지. 도끼 테스트로 S급 끌어올릴 지점을 반드시 기록

> 도끼 테스트의 등급 판정 SSoT는 `3-story-power.md`이다. 위 도끼 5렌즈는 그 판정을 **텍스트 수준에서 실행하는 방법론**이다.

### 4. 번역가 (한국어 번역투 검수) — 무조건 매 라운드 참여

LLM 산출물은 영어로 사고한 결과를 한국어로 옮긴 흔적이 자주 남는다. 의미는 맞아도 모국어 청자에게는 거리감을 만든다. 번역가는 그 흔적을 잡아낸다.

평가 기준 (100점):

| 항목 | 배점 | 평가 내용 |
|---|---|---|
| 자연 어순 | 25 | 한국어다운 주어–목적어–서술어. 도치·끼워넣기 남발 없음 |
| 능동·주체 명료 | 20 | 사물 주어("매 페이지가 권합니다"), 무생물 행위자, 수동태 남용("~로 인해 ~되다") 부재 |
| 직역체·번역투 어휘 부재 | 25 | "~에 대한", "~에 있어서", "~을 수행하다", "~를 진행하다", "~의 일환으로", "~중 하나" 등 영어·일본어식 군더더기 적발 |
| 한국어 고유 어휘 | 15 | 같은 의미의 일상어가 있을 때 한자어·외래어 남발 안 함. "수행하다→하다", "동행→길동무", "진정한→참된" 등 |
| 청자 호흡 | 15 | 한 호흡에 쥐어지는 문장 길이. 종결어미 단조(~지요·~습니다 반복) 회피 |

#### 번역가가 즉시 적발해야 할 패턴

| 🔴 번역투 | ✅ 자연 한국어 |
|---|---|
| 한 시대를 함께 짊어지는 동행 | 한 시대를 함께 살아낸 사람 / 한 시대의 또 다른 주인공 |
| 삶 전체를 자기 어깨에 진다 | 다른 사람의 일생을 통째로 떠맡는다 |
| 그는 그가 평생 단 한 번 꾸려 본 가정과 그 가을에 흩어졌습니다 | 평생에 단 한 번 꾸렸던 그의 가정은 그해 가을에 무너졌습니다 |
| 매 페이지가 권합니다 | 모든 장에 같은 결로 새겨져 있습니다 |
| 매개만 다를 뿐 동일한 목표를 수행하는 도구 | 모양만 다를 뿐 같은 일을 하는 두 자루 |
| ~에 대한 평을 듣습니다 | ~로 꼽힙니다 |
| 책장으로 들여다본 한 권 | 책으로 처음 들여다본 한 권 |
| 사람 사는 곳의 살갗 | 사람의 살림 |
| ~을 통해 ~할 수 있게 되었습니다 | ~로 ~하게 됐습니다 |
| ~로 인하여, ~에 의하여 | ~때문에, ~로 |
| 그것에 의해 영향받은 | 그것에 영향받은 / 거기서 영향을 받은 |
| 보답받은 참이었습니다 | 답장이 돌아온 참이었습니다 |
| 한 명을 구원해 보려 한 시도 | 한 사람을 구해 보겠다는 그의 시도 |

번역가는 위 패턴 외에도 **"내가 이 문장을 처음 떠올린다면 이렇게 쓸까?"** 자가 점검을 매 문장에 적용한다. 떠올리지 않을 어휘·어순이면 적발.

### 5. 편집국

위 4인(직업군·역사·영상극·번역가)의 비판을 합산하고 충돌을 조정하여 본문을 수정한다.

원칙:
- 셋 이상이 동일 지점을 짚으면 → 최우선
- 둘이 충돌하면 → **사료 정확성이 다른 무엇보다 우선**, 그다음 한국어 자연성, 그다음 영상 호흡
- 미학·서사 vs 사료 충돌 → 사료 보존 + 미학은 다른 자리에서 보강
- **번역가 vs 직업군 전문가** 충돌 (예: 분야 전문 용어 vs 일상어): 일반 청자 영상이므로 번역가 우선, 단 1차사료 인용문 안의 분야 용어는 보존
- 점수가 낮은 전문가의 지적을 우선 반영

---

## 라운드 진행

> **이 사이클은 텍스트 전용이다.** ko.json 텍스트 갱신만 다룬다. 음성 합성·후처리(TTS, transcribe, align, chunk)는 일절 다루지 않는다 — 텍스트 마감 후 사용자가 별도 도구(`/voice-sync` 등)로 진행한다.

### 라운드 0: 사전 준비

1. ko.json 경로 확정 — `sw/remotion/public/episodes/{stage}/{person}/ko.json`
2. 셀럽 직업 추출 → 직업군 전문가 1인 결정
3. `node sw/remotion/scripts/extract-story.mjs <person>` 으로 평문 markdown 추출 (remo-write-story-dump 스킬 활용)
4. 평문을 4인이 공유 (실제로는 한 에이전트가 4인 역할 수행)
5. 사용자에게 "라운드 0: 직업군 전문가는 X로 결정. 평문 추출 완료. 라운드 1 시작" 안내

### 라운드 N: 평가 → 수정 사이클

#### 1단계: 4인 비판서 작성

각 전문가(직업군·역사·영상극·번역가)가 책별로 평가서를 쓴다. 동일 포맷.

```
## 책 N. 제목 — [전문가 역할]

점수: 87/100 (분야 정확성 26 / 미학 20 / 동시대 정합 22 / 셀럽 시각 19)

### 합격 항목
- 들라크루아·밀레 짝짓기는 1880년대 빈센트의 실제 미학 위치와 일치
- ...

### 지적 항목
1. [위생|번역투] quotePairs[0].after — "매개만 다를 뿐 동일한 목표를 수행하는 도구"는 영어식 직역체. 자연 한국어로 "모양만 다른 같은 도구"
2. [도끼] summary — "19세기 사실주의 출발점" 단언 후 빈센트 자신의 글에서 발자크의 무엇을 놓아두는지 한 단계 더 구체로
3. ...
```

각 지적은 [위생|도끼|번역투] 태그 + 위치(필드) + 문제 진술 + 교정 방향. 번역가는 [번역투] 태그 전용. 영상극 전문가는 [위생|도끼] 둘 다 사용.

#### 2단계: 편집국 종합 보고

```
# 라운드 N 편집국 종합

## 책 1
- 직업군: 87 (동시대 평단 정합 미흡)
- 역사: 92 (사료 정확)
- 영상극: 78 (감정 곡선 평탄, 도끼 5개 중 2개만 통과)
- 번역가: 81 (사물 주어·직역체 3건)
평균: 84.5
판정: **미합격** (임계 95)
공통 지적: contextMain 후반 인과 비약 (영상극+직업군), summary 마지막 문장 번역투 (번역가 단독)
🔴 치명: 1건 (위생 1 "그래서 뭐?" 실패) — 즉시 수정
🟠 구조: 1건 (전복 부재) — 구조적 개선안 필요

## 책 2
- 직업군: 96
- 역사: 95
- 영상극: 96 (도끼 5개 중 4개 통과 → S급)
- 번역가: 95
평균: 95.5
판정: **합격** (재평가 면제)

...

## 라운드 N 종합
- 합격: 책 2, 책 5 → 다음 라운드 면제
- 미합격: 책 1, 책 3, 책 4, 책 6 → 편집국 수정 → 라운드 N+1
- 핵무기 식별: 책 4 quotePairs[1] "..." (반드시 보호)
```

#### 3단계: 편집국 수정안

미합격 책에 한해 본문 수정안 작성. 사용자에게 표 형식 제시.

```
## 책 1 수정안

| # | 위치 | 원문 | 수정 | 이유 |
|---|---|---|---|---|
| 1 | quotePairs[0].after | "새하얗게 달궈진 쇳덩이..." | "..." | 직업군: 비유 풀이 압축 + 영상극: 감정 곡선 가팔라야 |
| 2 | contextMain | "..." | "..." | 영상극: 인과 비약(위생 2) 메움 |
| 3 | summary | "매개만 다를 뿐 동일한 목표를 수행하는 도구" | "모양만 다를 뿐 같은 일을 하는 두 자루" | 번역가: 영어식 직역체 |
```

각 수정안 옆에 자평 점수 (95+ 목표). 사용자가 동의/일부 채택/추가 수정 결정.

#### 4단계: ko.json 적용

사용자 동의 후 Edit tool로 ko.json에 적용한다. 음성·타이밍 파일(`ko.timing.json`, `voice/`)은 건드리지 않는다.

#### 5단계: 재평가 (라운드 N+1 진입)

수정 적용된 책만 다시 1단계 평가. 합격된 책은 패스.

## 종료 조건

| 조건 | 판정 | 후속 |
|---|---|---|
| 모든 책의 모든 전문가 점수 ≥ 임계 | **완전체 종료** | 최종 보고서 출력 |
| 직전 라운드 대비 평균 점수 변화 < 1점, 라운드 3+ 누적 | **정체 종료** | 미합격 책 + 정체 사유 보고 + 사용자 결정 |

| 사용자 명시적 중단 | **수동 종료** | 현 상태 저장 + 미해결 지적 목록 보고 |

## 임계 점수 옵션

```
/remo-write-5-editorial-board <에피소드명> [--strict | --lenient]
```

- 기본: **95** (책별 모든 전문가 95+ 시 합격)
- `--strict`: 99 (사용자가 사이클을 더 빡빡하게 돌리고 싶을 때)
- `--lenient`: 90 (시간 제약 등 빠른 합격 필요할 때)

---

## 음성·타이밍 파일은 다루지 않는다

이 사이클은 **텍스트 전용**이다. `voice/`, `ko.timing.json`, `shorts/ko-N.timing.json`, TTS 합성, transcribe·align·chunk 파이프라인은 일절 건드리지 않는다. 텍스트 마감 후 음성 동기화는 사용자가 별도 도구(`/voice-sync` 등)로 처리한다.
