# 현행 설계 — 그리드 턴제

## 전투 개요

**방식**: 3×5 그리드 배치 + 속도순 개별 유닛 턴제
**참여 인원**: 세력당 최대 5명 출진
**턴 제한**: 최대 30턴 (`BATTLE_MAX_TURNS`)
**승패**: 적 전원 괴멸, 사기 0 이하, 또는 턴 소진 시 무승부

---

## 진형

전투 시작 전 `PlacementScreen`에서 3×5 격자에 유닛을 배치한다.

| 행 | 이름 | 기본 배치 병과 |
|----|------|--------------|
| 0 | 전열 | 장수, 관료 |
| 1 | 중열 | 유격, 장인 |
| 2 | 후열 | 성인, 책사, 예인 |

- 기본 배치는 `CLASS_DEFAULT_ROW`가 정한다. 플레이어는 확정 전에 자유롭게 옮기고 서로 교환할 수 있다
- **전투 중 이동은 없다.** 위치는 타겟팅(전열 우선)과 행 단위 광역기에만 관여한다

---

## 행동 순서

```
속도 = 10 + CLASS_SPEED_BONUS[병과] + floor(martial / 25)
```

속도 내림차순으로 `turnOrder`가 결정되고, `TurnOrderBar`에 초상 스트립으로 표시된다.

| 병과 | 속도 보정 |
|------|----------|
| 유격 | +4 |
| 책사 | +2 |
| 장수 | 0 |
| 성인 | 0 |
| 관료 | −1 |
| 예인 | −2 |
| 장인 | −3 |

---

## 행동

자기 턴에 유닛은 아래 중 하나를 고른다 (`ActionPanel`).

| 행동 | 설명 |
|------|------|
| **공격** | 근접 공격. 타겟은 적 전열 우선 |
| **스킬** | 병과·스탯 조건을 만족하는 스킬 (아래) |
| **방어** | 다음 피격까지 받는 피해 50% 감소 |
| **후퇴** | 전장 이탈 |

AI는 `selectAIAction()`이 고른다.

### 스킬 14종

`constants.ts`의 `SKILL_DEFS`에 정의하고, `skills.getAvailableSkills(unit)`이 병과·스탯 조건으로 거른다.

```
charge(돌격), duel_provoke(일기토 도발), heal(치유), barrier(결계),
confuse(혼란), fire_attack(화공), iron_wall(철벽), diplomacy_threat(외교 위협),
inspire(고무), culture_sway(문화 감화), trap(함정), siege_strike(공성 타격),
ambush(매복), detect_trap(함정 탐지)
```

- `charge`만 특례 조건 — `martial ≥ 50` **또는** `command ≥ 70`
- `duel_provoke`는 대상과 1:1로 상호 타격한다. 시전자가 1.3배 선공하고, 대상이 생존하면 1.1배로 반격한다
- `trap`은 적 전열에 함정을 걸어 다음 행동 직전 최대 HP 20% 피해를 주며, `detect_trap`은 아군에게 남은 함정을 해제한다
- 혼란·방어·철벽·결계는 다음 행동 또는 다음 피격까지만 유지된다. 모든 대상 지정 기술은 플레이어 화면에서 대상을 직접 고른다

---

## 대미지 공식

```
HP        = max(10, round(300 + command×2.0 + martial×1.0))
근접      = max(1, round(martial×0.8 × CLASS_ATTACK_MULT × weaponMod
                        × (1 - defRate - defending) × moraleMod × rand(0.85~1.15)))
  weaponMod = 1 + weapons/10000 × 0.3     (최대 +30%)
  defRate   = min(0.5, command×0.004 + courage×0.002)
  defending = 방어 상태면 0.5
계략      = max(1, round(intellect×0.7 × (1 - 대상intellect×0.004)
                        × charmResist × rand(0.9~1.1)))
  charmResist = 1 - charms/1000 × 0.3
```

> 월드맵의 `GameCharacter.hp`는 다른 공식(`100 + command×0.5 + martial×0.3`)으로 만들어진다. 전투 진입 시 `calcUnitHp`가 별도로 계산한다.

### 병과별 공격 배율 (`CLASS_ATTACK_MULT`)

| 병과 | 배율 |
|------|------|
| 장수 | 1.3 |
| 유격 | 1.0 |
| 장인 | 0.85 |
| 관료 | 0.6 |
| 성인 | 0.4 |
| 책사 | 0.4 |
| 예인 | 0.2 |

### 스킬 배율

| 스킬 | 계산 |
|------|------|
| 돌격 | 근접 ×1.5 × 군마 보정, 자상 = 가한 피해의 15% |
| 매복 | 근접 (사기 배율 1.2 고정) |
| 공성 타격 | 근접 ×3 — **성벽 보유 시에만** |
| 치유 | 대상 maxHp의 30% 회복 |

## 사기 시스템

0~100 범위. 진영 단위로 `allyMorale` / `enemyMorale`을 따로 관리한다. 사기 0 이하 = 패배.

### 사기 배율 (`getMoraleMod`)

| 사기 | 배율 |
|------|------|
| 90+ | 1.15 |
| 70~89 | 1.05 |
| 50~69 | 1.0 |
| 30~49 | 0.85 |
| 10~29 | 0.7 |
| 0~9 | 0.5 |

### 사기 변동

현재 실제로 적용되는 변동은 **리더 격파 −30** 하나뿐이다. 아군 사망에 따른 감소는 `updateMorale`이 계산은 하지만 적용하지 않는다(미완). 사기 변동표 확장은 로드맵 Phase A 이후 과제다.

## 장비 보정

전투 시 캐릭터의 개인 장비(`TroopEquipment`)가 대미지에 보정을 준다.

| 장비 | 적용 타이밍 | 보정 공식 | 최대 효과 |
|------|-----------|----------|----------|
| **무기** | 근접 공격 전체 | `×(1 + weapons/10000 × 0.3)` | +30% |
| **군마** | 돌격 | `×(1 + horses/1000 × 0.2)` | +20% |
| **부적** | 계략 피격 시 | `×(1 - charms/1000 × 0.3)` | -30% 피해 |
| **조선** | — | 미구현 | — |

→ 장비 배분은 `commandEquip()` 또는 AI `aiDistributeEquipment()` 참조.

- 공성 타격(`siege_strike`)이 이때만 발동 — 근접 ×3

## 전투 결과

| 결과 | 조건 | 후속 |
|------|------|------|
| **공격 승리** | 방어 측 전원 괴멸 또는 사기 0 | 영토 점령 + 포로 처분 화면 |
| **방어 승리** | 공격 측 전원 괴멸 또는 사기 0 | 공격 측 후퇴 |
| **무승부** | 30턴 소진 | 양측 후퇴 |

종료 처리 순서: `checkBattleEnd` → `syncLegacyParticipants` → `applyBattleResult` → `collectDispositionTargets` → `resolveCampaignOutcome`. 기존 부상과 병력 비율을 전투 시작 HP에 반영하고, 종료 시 남은 체력·병력을 캠페인 인물에 다시 기록하므로 다음 전투에서 원상 복구되지 않는다. 포로가 있으면 `disposition` 페이즈로 이동하고, 처분까지 끝난 뒤에도 같은 중앙 캠페인 판정으로 통일·패망·제한 턴을 결정한다.

### 포로 처분 (Disposition)

승리 시 패배 장수에 대해 처분을 결정한다.

| 선택 | 효과 |
|------|------|
| **등용** | 영입 시도 (`calcRecruitRate`로 확률 산정) |
| **처형** | 영구 제거 |
| **석방** | 명성 상승 |

> 기획에 있던 **감금**은 구현되지 않았다.

## AI 행동 선택

AI 세력의 성향(`aiPersonality`)은 내정·침공 판단에 쓴다. 전투 중 개별 행동은 `selectAIAction()`이 유닛 상태를 보고 고른다.

| 성향 | 경향 |
|------|------|
| 정복형 (`conqueror`) | 적극 공격, 영토 확장 |
| 책략형 (`schemer`) | 계략·외교 우선 |
| 경제형 (`economist`) | 내정 우선, 자원 축적 |
| 인덕형 (`virtuous`) | 영입 우선, 물량전 |
| 문화형 (`culturist`) | 문화 승리 추구 |

전술 간 상성에 따라 배율이 적용된다.

### 전술 종류

| 전술 | 아이콘 | 설명 | 병사 소모율 |
|------|--------|------|-----------|
| **돌격** | 🐎 | 강력한 돌격. 피해↑ 손실↑ | 15% |
