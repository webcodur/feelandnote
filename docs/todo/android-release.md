앱 구조와 Play 요건은 [`apps-03-android.md`](../project/apps/apps-03-android.md), 빌드·서명 절차는 [`sw/android/README.md`](../../sw/android/README.md)가 쥔다. 코드로 가능한 범위(신고·차단, PWA, 정책 창구, 셸)는 26.07.30에 구현했고 아래는 코드 밖 일이다.

## 사용자가 정할 것

| 항목 | 현재 값 | 왜 |
|---|---|---|
| 앱 식별자 | `com.feelandnote.app`(후보) | 배포 후 바꿀 수 없다. 상표·조직 소유·기존 사용 여부 확인 |
| 계정 삭제 처리 기간 | 회신 영업일 3일·완료 7일(임의) | 운영 절차 근거가 없다 |
| 계정 삭제 요청 항목·메일 제목 규칙 | 임의 | 같은 이유 |
| 약관 개정일 표기 | 2026-01-11 그대로 | 제7·8조를 추가했으니 올릴지는 법적 판단 |
| `www` 하위 도메인 App Links | 넣지 않음 | 실제 서비스 여부 미확인 |
| Play 등록 아이콘 | 192px 원본을 512로 확대 | 벡터나 1024px 원본이 있으면 다시 뽑는다 |
| Gradle 계열 버전(AGP 8.9.1·androidbrowserhelper 2.5.0·Gradle 8.11.1) | 미검증 | Android Studio 동기화 때 확인·조정 |
