# 천도 (天導) — 셀럽 전략 시뮬레이션

> **최종 실측 체크: 26.07.30** — 천도 코드·진입 경로·기획서 구현 상태 대조

> **개발 재개·핵심 완주 흐름 구현.** 시나리오 선택부터 방랑·거병·경영·전투·외교·통일/패망까지 코드상 연결됐다. 브라우저 실제 한 판 완주, 실 DB 시나리오 UUID, 전체 web 빌드는 아직 최종 검증 전이다. 세부 구현과 검증 한계는 `10-implementation-status.md`를 기준으로 한다.

> 수호지 천도 108성에서 영감을 받은 턴제 전략 시뮬레이션 웹게임.
> 역사 속 실존 인물들로 세력을 키우고, 문명을 통일한다.

**이 디렉토리는 게임 설계(기획서)의 단일원천이다.** 개발 규칙·코드 경로·작업 절차는 [`dev-guide.md`](./dev-guide.md)(룰북)에 있다.

## 문서 읽는 법

01~09는 **설계**다. 설계와 코드가 갈라진 지점에는 「구현됨/미구현/설계안」을 병기한다.
10은 **코드 실측 결과**다. 설계와 코드가 충돌하면 10이 사실이고, 01~09는 의도다.

## 데이터 소스

- **캐릭터**: Supabase `profiles` + `celeb_influence` + `celeb_persona`
- **대사·명언**: Supabase `celeb_dialogues`
- 게임 진입 시 `SUIKODEN_CHARACTER_IDS`에 포함된 **시나리오 고정 인물만** DB에서 읽는다. 전체 활성 인물을 끌어오지 않는다.
- 선택 시나리오의 필수 프로필 UUID가 조회 결과에 없으면 해당 시나리오는 시작할 수 없고 누락 안내를 표시한다.
- **아이템 DB 연동은 폐기됐다.** 콘텐츠(`contents`/`user_contents`) 기반 아이템 시스템은 2026-03에 수량제 장비로 교체됐다.
