# 26.09.20 세력도감 작업 중 발견한 미등록 인물

세력을 짜다가 「이름은 있는데 인물이 DB에 없어」 성립이 막힌 후보들이다.
등록되면 해당 세력·그룹이 성립하거나 채워진다. 등록 절차는 `register-checklist.md`.

## 일루미나티 (바바리아 일루미나티, 1776~1785)

실존 조직. DB에 회원은 괴테(대내명 아바리스) 1명뿐이라 세력 미성립.
창립자와 실무진이 들어오면 `이면 세계` 산하에 세운다.

| 인물 | 한 줄 서사 |
|---|---|
| 아담 바이스하우프트 | 잉골슈타트 대학 교회법 교수. 1776년 5월 1일 일루미나티 창립, 대내명 「스파르타쿠스」 |
| 크니게 남작 | 아돌프 폰 크니게, 대내명 「필로」. 조직을 전국으로 키운 실무자. 예절 책 『인간관계론』 저자로도 유명 |
| 요한 고트프리트 헤르더 | 대내명 「다마수스 폰티펙스」. 바이마르의 궁정 목사이자 계몽 사상가 |
| 카를 아우구스트 공작 | 작센바이마르 공작. 괴테·헤르더의 군주이자 동지 회원 |
| 페르디난트 폰 브라운슈바이크 | 공작, 대내명 「아리우스」. 북부 독일 조직의 수장 |
| 프리드리히 니콜라이 | 베를린 계몽주의 출판인. 회원 여부는 문헌상 논쟁 — 검증 후 판정 |
