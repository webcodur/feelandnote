잔 다르크와 나폴레옹은 보이스가 인물에 맞지 않아 2026-09-11에 한영 보이스와 음원을 모두 제거했다. 다시 만들 때는 새 보이스를 고른다.

음원 버전(`voice_v`)과 웹 배속(`voice_speed`)은 DB가 쥔다. 이 문서에 옮겨 적지 않는다.

데미스 허사비스의 현재 대표대사는 `먼저 지능을 해결한다. 그리고 이것으로 세상의 모든 걸 해결한다.`이고, 맥스 레브친의 현재 대표대사는 `코드가 아니라 사람이 어렵습니다.`다.

감정 태그는 화면용 DB 대사와 분리해 합성 입력에만 둔다. 안전 문구와 끝부분 절단은 기본 생성에 쓰지 않고 실제 후행 이상 발화가 검출된 음원에만 적용한다.

## 웹 배속

`voice_speed`는 인물 상세에서 한영 재생에 함께 걸리고, 게임 대사에서는 한국어에만 걸린다. 음성 보유 인물 전원에 같은 규칙을 적용한다.

- 한국어 대사 22개의 발화 속도 중앙값(앞뒤 무음 제외)에 배속을 곱한 값이 초당 6.0자에 가깝도록 0.05 단위로 정한다.
- 배속은 1.0~1.2배 안에서만 쓴다. 헤라클레스 1.3배를 들어 보니 너무 빨랐다.
- 같은 배속을 곱한 영어가 초당 3.25단어를 넘으면 그 아래로 내린다.
- 음원을 새로 만들면 그 인물만 같은 기준으로 다시 잰다.

## 들숨·쉼 정리

대사 음원도 문장 사이 들숨이 감상을 방해하므로 지운다. 규칙·구현·적용 지점은 [`voice-cleanup.md`](../project/production/voice-cleanup.md)가 쥐고, 여기에는 대사에만 해당하는 것을 적는다.

- `celeb-dialogue-voice-generate.py`는 합성 직후, web-bo 대사 작업대는 미리듣기를 돌려주기 전에 공용 정리(`dialogue` 프로필)를 거친다. 작업대의 들숨 편집기는 자동 정리 뒤 남은 곳을 사람이 손볼 때 쓴다.
- ElevenLabs가 MP3(`mp3_44100_128`)를 돌려주므로 정리본은 한 번 더 인코딩된다. **샘플레이트는 원본을 유지한다.** 24kHz로 고정했던 시험본은 대역이 절반 가까이 줄었다. PCM으로 받으면 1세대로 처리할 수 있으나 요금제 지원 여부를 확인하지 않았다.
- 대사는 짧은 문장이 많아 말끝 여운이 들숨 후보로 잡히는 비율이 읽어보기의 두 배(54%)였다. 세기 상한은 두 프로필에 똑같이 적용된다(`voice-cleanup.md` 「탐지」 4단계).
- web-bo 대사 작업대에서 만드는 음원은 이 자동 정리를 거치지 않는다. 작업대의 들숨 제거 도구로 손본다.
- 이순신 영어 인사2(`g2.mp3`)만 24kHz다. 서비스본도 같으며 다른 1,099개는 44.1kHz다. 청감상 문제가 없어 그대로 둔다.
- 기존 발행분을 다시 정리할 때는 발행 run을 고치지 않고 새 run을 만든다. 등록 사전 점검이 샘플 문장을 현재 DB 대사와 대조하므로, 슬롯 구조만 기존 manifest를 본뜨고 문장·보이스 ID는 현재 DB에서 채운다. 로컬 run이 없는 인물은 R2 음원을 받아 같은 방식으로 run을 꾸린다.

## 대사·음원 대조

- 대조는 공개 음원 전량을 받아써 DB 대사와 비교한다. 받아쓰기 가상환경에는 CUDA 12 cuBLAS가 없으므로 `D:\audios\interview-cleaner\enhance-venv\Lib\site-packages\torch\lib`를 PATH 앞에 붙여 GPU로 돌린다.
- 짧은 돌격 대사와 고유명사는 오인식이 잦다. 어긋나 보이면 무음 필터를 끄고 DB 문장을 힌트로 준 받아쓰기로 한 번 더 듣는다. 힌트를 줘도 다르게 들리면 실제 불일치다.
- 한마디는 검증된 DB 문장을 두고 음원을 다시 만든다. 상황 대사는 원래 음원 문장으로 되돌린다.
- 백오피스 대사 편집기는 음량을 키우거나 앞뒤를 잘라 올린 칸을 WAV로 다시 저장한다. 그래서 확장자만 `.mp3`인 WAV가 생긴다. 목소리와는 무관하다. `dialogue-voice-publish.ts`는 MP3만 받으므로 기존 칸을 담아 다시 게시할 때는 MP3로 변환해 올린다.
