# 쇼츠 베스트 케이스

쇼츠 텍스트 작성 시 모범으로 삼을 레퍼런스. 실제 완성된 에피소드 3편을 길이별로 분석하고, 재현 가능한 패턴을 추출한다.

> 쇼츠 기본 구조·포맷 원칙은 [shorts.md](shorts.md), 이미지 시스템은 [shorts-image.md](shorts-image.md) 참조.

---

## 길이 분류

| 유형 | 레퍼런스 | 세그먼트 | 시간 | 셀럽 인용 | 파일 |
|------|----------|----------|------|-----------|------|
| **짧은편** | 알렉스 카프 — 파우스트 | 4+CTA | ~100초 | 1회 | `live/alex-karp/shorts/ko-2.json` |
| **중간편** | 이순신 — 오자병법 | 6+CTA | ~123초 | 2회 | `done/yi-sun-sin/shorts/ko-1.json` |
| **긴편** | 링컨 — 유클리드 | 8 | ~153초 | 3회 | `live/abraham-lincoln/shorts/ko-2.json` |

## 1. 짧은편: 알렉스 카프 — 파우스트 (~85초)

### 왜 모범인가

4비트 기본 구조를 가장 정석적으로 따른다. **hook → intro → celeb → book-context → CTA**, 군더더기 없이 하나의 일화에 집중하여 "이 사람은 왜 이 책에 미쳤을까?"의 답을 60~90초 안에 마친다.

### 구조

```
hook      (10.0s)  태극권으로 방문객을 넘기는 CEO + 영혼 거래하는 고전
intro     (10.6s)  독일 철학 박사 → 팔란티어 CEO → 파우스트 소개
celeb-mid  (8.8s)  "세상에서 가장 아름다운 텍스트는 괴테의 파우스트입니다"
book-ctx  (55.9s)  파우스트 설명 → 태극권 사건 → 낭독 장면 → 파우스트=카프 대구
cta              CTA
```

### 핵심 패턴

**일화 단일 집중형.** book-context 하나가 전체 분량의 65%를 차지한다. 태극권 패대기 → 파우스트 낭독이라는 하나의 에피소드만 깊이 파고든다.

**대구로 착지.** 마지막 세 문장이 쇼츠 전체를 수렴시킨다:
```
진리를 갈망하다 악마의 계약서에 서명한 파우스트.
평화를 동경하다 전장의 파수탑을 세우는 알렉스 카프.
카프가 이 극에서 읽고 있었던 것은 어쩌면 자기 자신이 아니었을까요?
```

**이미지 밀도**: book-context에 9개 전환점. ~6초마다 한 번씩 시각 변화.

### 설계 원칙

- **한 일화만 쓴다.** 배경 설명은 intro에서 끝내고, book-context는 장면 묘사에 올인.
- **셀럽 인용은 1회로 충분.** 짧은편에서 셀럽 인용이 2회 이상이면 서사 흐름이 끊긴다.
- **마지막 문장이 쇼츠의 얼굴.** book-context의 마지막 2~3문장에 여운을 집중한다.

## 2. 중간편: 이순신 — 오자병법 (~105초)

### 왜 모범인가

기본 4비트에 **celeb 추가 삽입**으로 감정 피크를 두 번 만든다. 첫 번째 셀럽 인용(celeb-mid)이 배경 제시, 두 번째(celeb-1)가 전장에서의 실시간 호통 — 역할이 다르다.

### 구조

```
hook           (6.0s)  "13 대 133이 아니었습니다. 1 대 133이었습니다."
intro          (7.9s)  수군 궤멸 → 오자병법 인용
celeb-mid     (25.7s)  "반드시 죽고자 해야 살고..." (난중일기 연설 전문)
book-ctx-1    (40.5s)  원균 패전 → 12척 → 대장선 홀로 돌격 → 안위 합류
celeb-1        (6.3s)  "안위야, 군법에 죽고 싶으냐!"
book-ctx-2    (19.1s)  나머지 합류 → "한 사람의 각오가 군대 전체를 살렸습니다"
cta                  CTA
```

### 핵심 패턴

**셀럽 인용의 이중 역할.** celeb-mid(25.7초)는 전쟁 전 연설 — 묵직하고 길다. celeb-1(6.3초)은 전투 중 호통 — 짧고 날카롭다. 긴 인용 → 서사 → 짧은 인용의 배치가 감정 곡선을 끌어올린다.

**크레셴도 구조.** 서사가 한 방향으로만 올라간다:
```
궤멸 → 연설 → 열두 척 → 홀로 돌격 → 호통 → 합류 → "한 사람의 각오"
```
되돌아가거나 설명하는 문장이 없다.

**수사 한 줄 마무리**: "오자병법은 군대가 죽기를 각오하면 산다고 했습니다. 하지만 명량에서는 단 한 사람의 각오가, 군대 전체를 살렸습니다." — 책의 명제를 뒤집어 여운을 남긴다.

### 설계 원칙

- **셀럽 인용 2회일 때, 성격을 다르게 한다.** 하나는 내면(독백/연설), 하나는 외면(실시간 발화).
- **두 번째 인용은 짧게.** celeb-1은 6초. 전투 한가운데 삽입되어 리듬을 쪼갠다.
- **book-context를 2개로 분리.** 첫 번째가 위기의 정점, 두 번째가 해소. 사이에 셀럽 인용이 끼어들어 "전환점"을 만든다.

### 부가 요소

| 요소 | 내용 |
|------|------|
| `tts.replace` | 숫자 읽기 보정 (`"133척의"` → `"백삼십삼 척의"` 등) |
| `bgm` | track2.mp3, volume 0.55 |
| `style` | `"들숨 없이"` — 긴박한 전투 톤 유지 |

## 3. 긴편: 링컨 — 유클리드 (~135초)

### 왜 모범인가

**나레이션-셀럽 교차 구조**가 가장 정교하다. 셀럽 인용 3회가 서사의 단계별 전환점에 정확히 배치되어, 나레이터가 배경을 깔고 → 셀럽이 그 위에 임팩트를 얹는 구조를 반복한다.

### 구조

```
hook           (5.3s)  "400만 노예를 묶었던 공리. 이를 깬 건 수학책이었습니다"
intro          (5.9s)  40대 변호사 링컨, 유클리드를 구해옴
celeb-mid      (7.0s)  "'입증'이란 단어부터 알아야..." (동기 고백)
book-ctx      (12.1s)  밤마다 유클리드 학습 → 수학자의 방법 시도
celeb-2       (21.2s)  피부색 기준이라고? → 삼단 귀류법 (직접 발화)
book-ctx-2    (25.8s)  1860년 쿠퍼 유니언 → 남부의 공리 → 칠판 위로 끌고 옴
celeb-3       (46.8s)  39인 투표 기록 → 워싱턴·매디슨 실명 반증 → "옳기에 강한 것"
book-ctx-4    (11.3s)  공리 붕괴 → 기립 → 대통령 후보
```

### 핵심 패턴

**귀류법의 서사화.** 유클리드의 증명 기법(귀류법)이 링컨의 실제 연설 논법과 겹치는 구조다. celeb-2에서 링컨이 귀류법으로 노예제를 논파하고, celeb-3에서 실증으로 마무리한다. 책의 핵심 개념이 서사의 구조 자체가 되는 사례다.

**나레이터-셀럽 교차 리듬:**
```
narrator → celeb (동기)
narrator → celeb (논법)
narrator → celeb (연설)
narrator (결과)
```
4번의 교차가 일정한 리듬을 만든다. 셀럽 발화 시간이 7초 → 21초 → 47초로 점층한다.

**셀럽 인용의 점층 배치.** 가장 긴 인용(celeb-3, 46.8초)이 클라이맥스에 배치된다. 짧은 고백(celeb-mid) → 중간 논법(celeb-2) → 긴 연설(celeb-3)의 크레셴도.

**마지막은 나레이터가 닫는다.** 셀럽 인용이 클라이맥스여도, 착지는 나레이터의 객관적 결과 진술("공리는 무너졌고, 천오백 청중은 일제히 기립했습니다")로 끝낸다.

### 설계 원칙

- **셀럽 인용 3회는 반드시 점층한다.** 짧은 것부터 긴 것 순서. 역순은 안티클라이맥스.
- **나레이터가 매번 "왜 이 인용이 나오는지"를 선행 설명한다.** 셀럽 인용이 갑자기 튀어나오면 시청자가 이탈한다.
- **최장 셀럽 인용(celeb-3)은 책의 핵심 개념을 직접 시연하는 장면이어야 한다.** 단순 감상이 아니라, 책의 논리를 실전에 적용하는 장면.
- **bgm은 긴편에서 필수.** 2분 이상 음성만으로는 리텐션 유지가 어렵다.

## 공통 패턴

### 훅 설계

| 에피소드 | 훅 전략 | 길이 |
|----------|---------|------|
| 카프-파우스트 | 기이한 행동 + 미스터리 ("영혼을 거래하는 고전") | 10초 |
| 이순신-오자병법 | 숫자 반전 ("13 대 133이 아니었다. 1 대 133이었다") | 6초 |
| 링컨-유클리드 | 의외의 인과 ("노예를 묶은 공리를 깬 건 수학책") | 5초 |

**공통점**: 결과를 먼저 보여주고, "왜?"를 남긴다. 이름을 밝히지 않는다.

### 셀럽 인용 배치 법칙

```
짧은편 (1회):  hook → intro → [celeb] → book-ctx → cta
               책에 대한 1인칭 소감. 서사에 방향성을 부여하는 역할.

중간편 (2회):  hook → intro → [celeb-A] → book-ctx → [celeb-B] → book-ctx-2 → cta
               A=내면(연설/독백), B=외면(실시간 발화). 성격이 달라야 한다.

긴편  (3회):   hook → intro → [celeb-A] → book-ctx → [celeb-B] → book-ctx-2 → [celeb-C] → book-ctx-3
               A=동기, B=논법/행동, C=클라이맥스. 분량이 점층해야 한다.
```

### book-context 분할 기준

| 길이 | book-context 수 | 분할 기준 |
|------|-----------------|-----------|
| 짧은편 | 1 | 분할하지 않는다. 단일 일화에 집중. |
| 중간편 | 2 | 위기의 정점에서 분할. 셀럽 인용이 전환점. |
| 긴편 | 3~4 | 서사 단계(배경 → 시도 → 클라이맥스 → 결과)마다 분할. |

### 마무리 문장

세 편 모두 마지막 나레이션이 **책의 명제를 인물의 삶에 대입하는 한 줄**로 끝난다:

- 카프: "카프가 이 극에서 읽고 있었던 것은 어쩌면 자기 자신이 아니었을까요?"
- 이순신: "하지만 명량에서는 단 한 사람의 각오가, 군대 전체를 살렸습니다."
- 링컨: "남부의 공리는 무너졌고, 천오백 청중은 일제히 기립했습니다."

### 이미지 전환 밀도

세 편 모두 book-context 구간에서 **5~7초마다 1회** 이미지 전환이 발생한다. 이 밀도가 정적 화면 3초 금지 원칙과 음성 리듬에 가장 잘 맞는 구간이다.

## 길이별 체크리스트

### 짧은편 (~60~90초)

- [ ] 세그먼트 4+CTA 이하
- [ ] 셀럽 인용 1회, 책에 대한 직접 소감
- [ ] book-context 1개, 단일 일화
- [ ] 마지막 2~3문장에 대구 또는 질문형 여운
- [ ] imageChangeAt ~6초 간격, 8~10개 전환

### 중간편 (~90~120초)

- [ ] 세그먼트 6~7+CTA
- [ ] 셀럽 인용 2회, 내면/외면 역할 분리
- [ ] book-context 2개, 위기-해소 분할
- [ ] 두 번째 셀럽 인용 10초 이하
- [ ] 마무리 문장이 책의 명제를 뒤집거나 확장
- [ ] bgm 권장

### 긴편 (~120~150초)

- [ ] 세그먼트 8~10
- [ ] 셀럽 인용 3회, 분량 점층 (짧은→긴)
- [ ] book-context 3~4개, 서사 단계별 분할
- [ ] 최장 셀럽 인용에서 책의 핵심 개념을 직접 시연
- [ ] 나레이터-셀럽 교차 리듬 유지
- [ ] 마지막은 나레이터의 객관적 진술로 착지
- [ ] bgm 필수
