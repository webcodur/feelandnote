# 셀럽 고유 대사 생성 룰북

인물별 18개 고유 대사(6상황 × 3변형)를 생성하는 가이드.

---

## 말투(speech_tone) 6종

각 인물에게 1개의 speech_tone이 배정되어 있다. `celeb_persona` 테이블의 `speech_tone` 컬럼.

| 코드 | 한국어 | 어미 | 대상 인물 유형 | 주의 |
|------|--------|------|----------------|------|
| `loyal` | 충의 | 극존대 ("-옵니다", "-사옵니다") | 충성심 강한 군인, 충신 | 반말 절대 금지 |
| `composed` | 침착 | 차분한 반존대 ("-입니다", "-이지요") | 학자, 전략가, 분석적 인물 | 감정 과잉 금지 |
| `bold` | 당돌 | 당당한 반말 ("-겠다", "-이다") | 정복자, 개혁가, 자신감 넘치는 인물 | 겸양 표현 금지 |
| `humble` | 겸양 | 품격 있는 겸양 ("-겠습니다", "-합니다") | 성인, 덕장, 종교인 | 자신감 과잉 금지 |
| `gentle` | 온화 | 부드러운 여성체 ("-해요", "-예요") | 여성 인물 다수, 부드러운 예술가 | 공격적 표현 금지 |
| `free` | 호방 | 쾌활한 반존대 ("-지요", "-합시다") | 시인, 음악가, 자유분방한 인물 | 격식 표현 금지 |

---

## 대사 상황 6종

서비스 전체에서 범용으로 사용된다. **특정 게임 맥락에 종속된 표현을 피하고**, 인물의 존재감·성격이 드러나는 대사를 작성한다.

| 코드 | 의미 | 톤/감정 | 설명 |
|------|------|---------|------|
| `select` | 인물 활성화/부름 | 등장, 응답, 각성 | 인물이 호출되거나 클릭되었을 때. 인물 고유의 등장 인사가 이상적 |
| `deploy` | 임무 투입/출전 | 기세, 각오, 전의 | 인물이 행동에 나설 때. 전투뿐 아니라 임무·과제·도전 등 넓은 맥락 |
| `battle_win` | 성공/승리 | 통쾌, 여유, 자부 | 대결·과제에서 좋은 결과를 얻었을 때 |
| `battle_draw` | 무승부/미결 | 다음을 기약 | 결과가 애매하거나 비겼을 때 |
| `battle_lose` | 실패/패배 | 분함, 아쉬움, 비통 | 결과가 좋지 않았을 때 |
| `clash_attack` | 순간 행동/기합 | 짧고 강렬 | 짧은 액션 순간. 감탄사·기합·한마디 |

---

## 대사 작성 규칙

### 필수

1. **`[emotion, emotion]` 태그**: 모든 대사 앞에 감정 디렉션 태그 필수
   - 예: `[loyal, solemn] 존명, 받들겠사옵니다.`
2. **speech_tone 말투 유지**: 해당 인물의 speech_tone에 맞는 어미/존칭 사용
3. **인물 개성 반영**: 역사적 발언, 성격, 시대적 특성을 대사에 녹임
4. **3변형 차별화**: 같은 상황의 3개 대사는 뉘앙스/감정이 달라야 함
5. **[emotion] 태그 다양화**: 모든 대사에 같은 emotion 쓰지 말 것. 상황별 적절한 감정 배합

### 분량

| 상황 | 최대 글자수 |
|------|------------|
| select, deploy, battle_win, battle_draw, battle_lose | 20자 이내 |
| clash_attack | 10자 이내 |

- `[emotion]` 태그는 글자수에 포함하지 않음

### 금지

| 금지 | 설명 | 예시 |
|------|------|------|
| 현대 슬랭/인터넷 용어 | | |
| 다른 인물의 유명 대사 도용 | | |
| 역사적 사실과 모순되는 표현 | | |
| **화자 시점 일탈** | 대사는 독백·각오·자책·감탄 등 **1인칭 시점**이어야 함. 제3자에게 명령/간청하는 형태 금지 | ❌ "물러서지 마옵소서!" → ⭕ "물러서지 않겠나이다" |
| **어색한 문어체** | 구어로 자연스러운 문장만. 한문 직역투 금지 | ❌ "물러나되 다음을 기약하옵니다" |
| **코웃음/비웃음** | "흥,", "훗,", "쯧" 등 금지 | ❌ "흥, 나를 부른 건 잘한 결정이다" |
| **본인 일화 메타 인용** | 자기 사건/업적을 직접 언급하면 부자연스러움. 사건의 **정신**만 반영 | ❌ "고르디아스 매듭처럼 끊어버리지" |
| **타칭 별명 자칭 금지** | 타인이 붙인 별명을 본인이 쓰면 부자연스러움. 자칭만 허용 | ❌ 제갈량 "잠든 용이 깨었다" (와룡은 타칭) |
| **직업군 일반 대사** | "아무나 할 수 있는 말" 금지. 그 인물만의 고유 이미지가 필요 | ❌ "계책대로 나아가겠습니다" (아무 전략가나 가능) |
| **단순 키워드 기합** | clash_attack에 직업 키워드 나열 금지 | ❌ "북학!", "참/거짓!" |

## 역사적 고유 이미지 활용 (핵심)

개인별 대사의 존재 의의는 **그 인물만의 유니크함**이다. 직업군 일반 대사는 공통 대사(voiceLines.ts)로 충분하다.

| 방법 | 설명 | 예시 |
|------|------|------|
| **상징물** | 인물의 대표 상징을 은유로 활용 | 제갈량 → 깃털 부채, 이순신 → 바다 |
| **고유 능력/특기** | 해당 인물만의 특수 능력 | 제갈량 → 바람/별 읽기, 한신 → 배수진 |
| **삶의 서사** | 인생 여정에서 오는 독특한 시선 | 제갈량 → 초야에서 불려나온 사람 |
| **자칭 비유** | 본인이 스스로 비유한 것만 | 제갈량 → 관중·악의에 자신을 견줌 |

**금지**: 본인 일화를 대놓고 인용 ("적벽에서처럼!", "삼고초려를 떠올리며")
**허용**: 일화의 **정신/이미지**를 자연스러운 독백으로 ("바람의 향방은 이미 읽었습니다")

## 철학·사상 인물 특별 주의

- 철학자/사상가/종교인의 대사는 해당 사상 체계를 정확히 반영해야 한다
- 단순 "이 인물은 학자" 수준이 아니라, **핵심 교리/사상의 언어**로 대사 작성
- 예: 장자 → "도"와 "자연", 공자 → "인"과 "예", 석가모니 → "자비"와 "깨달음"
- 사상에 맞지 않는 전투적/공격적 표현은 인물 성격에 따라 조절

## 배치 운영

- **배치 크기**: 최대 5명 (품질 보장)
- **프롬프트에 인물별 맥락 필수 포함**:
  - 역사적 발언/일화 1~2개
  - 성격 특성
  - 고유 상징물/특기 (대사에 녹일 소재)

## 레퍼런스: 공통 대사 (톤/분량 참고)

파일 위치: `sw/web/src/lib/game/voice/voiceLines.ts`

공통 대사의 길이·톤·감정을 참고하되, 개인별 대사는 해당 인물의 **고유한 성격과 역사적 배경**을 반영한다.

## 출력 형식

```sql
INSERT INTO celeb_dialogues (celeb_id, lines)
VALUES
  ('{celebId}', '{
    "select": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "deploy": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "battle_win": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "battle_draw": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "battle_lose": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"],
    "clash_attack": ["[e1] 대사1", "[e2] 대사2", "[e3] 대사3"]
  }')
ON CONFLICT (celeb_id) DO UPDATE SET lines = EXCLUDED.lines, updated_at = now();
```

여러 인물을 배치로 INSERT한다.

## 작업 흐름

1. 인물 목록 조회: `SELECT id, nickname FROM profiles WHERE profile_type = 'CELEB' AND death_date IS NOT NULL`
2. speech_tone 확인: `SELECT celeb_id, speech_tone FROM celeb_persona WHERE celeb_id IN (...)`
3. 인물별 18개 대사 생성 (AI 일반 지식 기반)
4. 배치 INSERT로 celeb_dialogues 등록
