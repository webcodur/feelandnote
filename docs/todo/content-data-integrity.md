# 작품·판본 정합성 — 남은 작업

현재 서비스 BOOK 35,204작품 중 검수 색인에 포함된 작품은 33,876개이며, 아직 검수하지 못한 작품은 1,328개다. 대조 이후에도 작품 정체성·역자·정상 대표·선정·소개 등의 추가 수리가 남은 정확한 색인은 15,728개다. 첫 대조 수는 개선 완료 수가 아니다. 미처리 ID와 실제 사유는 이번 대화 세션의 색인에 남긴다.

확정한 교정은 DB에 반영하고 서버 재조회로 검증했다. 원문·캐시·작업용 원장은 폐기한다. 감상경위·가시성·회원 리뷰는 작품·판본 작업에 포함하지 않는다.

담당 규칙: [작품·판본](../project/celeb/celeb-02-05-figure-books.md), [소개 출처](../project/celeb/celeb-02-06-content-introduction-sources.md), [외부 서비스](../project/platform/platform-05-external-services.md), [API 키 용도](../project/platform/platform-04-env-vars.md).
