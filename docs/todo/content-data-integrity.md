# 작품·판본 정합성 — 남은 확인

- 더글러스 애덤스 `5e61f875-7e61-5587-b5a4-2996554ab9ea`: ISBN `9781447259565`의 실제 수록 작품·출판사·연도를 독립 서지로 확인한다. OpenLibrary 기록은 연대가 모순된다. 판본 `14829`의 원자료는 `metadata.unverifiedEditions`에 보존하고 노출용 판본에서는 제거했다.
- 손빈병법 `9ad7af72-d7a5-4fdb-b3c1-4b285912347c`: 초기 등록 ISBN `9787544905701`의 실제 판본·수록 작품을 확인한다. 당시 원자료에는 손자병법·손빈병법 소개와 서로 다른 ISBN이 혼재했다. 초기 백업의 수집값은 `metadata.unverifiedEditions`에 보존하며 현재 손빈병법 판본으로 검증하지 않았다.
- 정확한 판본 범위: Recorded Books의 《천 개의 찬란한 태양》 카세트판, Asiapac 《아Q》의 완전성·개작 여부, 아시모프 자서전 1995년 한국어판 1·2의 완전성은 미확정이다. 확인되지 않은 범위는 완역으로 표시하지 않았다.
- 박정희·정주영의 나폴레옹 독서: 정확한 저자·작품을 확인한다. 원문·출처·감상 ID는 비공개로 보존했다. 작품 ID는 각각 `0c3aa7df-9a2a-4a36-af09-a6bfef8260fe`, `9a8c6ab5-fe09-48ea-9b96-a931dcef2742`다.
- 작품별 직접 감상 근거: 저우언라이·진독수의 《자본론》, 티무르·지단·정화의 꾸란, 나관중·호쿠사이·조설근·박지원의 수호전, 데즈카의 보물섬, 마윈의 천일야화 기록은 해당 작품을 직접 접한 근거가 확보될 때까지 비공개로 보존한다. 강연·창작 참여·이야기 언급만으로 원전 독서를 확정하지 않는다.

새 근거를 반영할 때는 [콘텐츠 감사](../project/celeb/celeb-02-04-content-audit.md)를 따르고, 같은 감상 ID와 작품·판본 연결을 다시 조회한다.
