# 패권(Hegemony) v6 — 게임 디자인 문서

동시 행동 1v1 카드 전략 게임. 역사적 인물 카드로 명령을 내려 상대 국가를 굴복시킨다.

---

## 기본 정보

| 항목 | 값 |
|------|-----|
| 장르 | 1v1 동시 행동 전략 (vs AI) |
| 라운드 | 무제한 (자원 소진 시 종료) |
| 인재 수 | 각 5장 (배치 드래프트) |
| 배치 수 | 턴당 1명 |
| 명령 종류 | 3종 (가위바위보 상성) |
| 공개 방식 | 동시 공개 |

---

## 국가 상태

| 항목 | 초기값 | 상한 | 설명 |
|------|--------|------|------|
| **국력** | 30 | 35 | HP. 0 이하 = 즉시 패배 |
| **민심** | 50 | 60 | 0 이하 = 반란 + 민심 붕괴 |

---

## 명령 체계 (3명령 RPS)

```
전투(assault) > 내정(govern) > 책략(stratagem) > 전투
```

| 명령 | 효과 | 카드 소모 | 비고 |
|------|------|----------|------|
| **전투** | 상대 국력 타격 | 소모됨 | 민심 -3 (상성 무관, 항상 지불) |
| **책략** | 상대 민심 타격 | 소모됨 | - |
| **내정** | 국력+민심 회복, 버린패 1장 회수 | 유지 | 카드 보존 |

### 상성 결과

| 결과 | 효과 배수 |
|------|----------|
| **승** | 내 효과 ×1.5, 상대 효과 ×0 |
| **패** | 내 효과 ×0, 상대 효과 ×1.5 |
| **무승부** | 적성 높은 쪽 ×1.0, 낮은 쪽 ×0. 동률 시 양쪽 ×0.5 |

---

## 적성 공식

### 기본 적성 (0~20 범위)

| 명령 | 공식 | 도메인 | 능력치 |
|------|------|--------|--------|
| **전투** | (strategic + social) / 2 × (1 + martial/100) | 전략, 사회 | 무력 |
| **책략** | (political + tech) / 2 × (1 + intellect/100) | 정치, 기술 | 지력 |
| **내정** | (economic + cultural) / 2 × (1 + command/100) | 경제, 문화 | 통솔 |

- 도메인: 0-10 범위 (영향력)
- 능력치: 0-100 범위 (페르소나)

### 주장 보정

| 조건 | 보정 |
|------|------|
| 주장이 손패에 있고 **다른 카드**가 출전 | 해당 카드 적성 **+15%** |
| **주장 본인**이 출전 | 본인 적성 **×1.5** |
| 주장이 버린패(소모됨) | 보너스 없음 |

### 천명 보정

매 라운드 천명(풍운/암중/태평)이 공개된다. 해당 명령과 일치하면 적성 **×1.5**.

### 별점 변환 (UI 표시)

| 적성 점수 | 별점 |
|----------|------|
| 17-20 | ★★★★★ |
| 13-16 | ★★★★ |
| 9-12 | ★★★ |
| 5-8 | ★★ |
| 0-4 | ★ |

## 타격 공식

### 전투 (상대 국력 타격)

```
피해 = round(round(적성 / 2) × 상성배수 × 에스컬레이션)
```
- 민심 -3 항상 지불 (상성 무관)
- 상성 패 시 피해 0이지만 민심 -3은 지불

### 책략 (상대 민심 타격)

```
피해 = round(round(적성 / 2) × 상성배수 × 에스컬레이션)
```

### 내정 (자국 회복)

```
국력 회복 = round(round(적성 / 3) × 상성배수 × 에스컬레이션)
민심 회복 = round(round(적성 / 2) × 상성배수 × 에스컬레이션)
```
- 카드 유지 (소모되지 않음)
- 버린패 1장 회수 (상성 무관, 항상 회수)

### 에스컬레이션 (라운드 진행 배수)

| 라운드 | 공격 배수 | 회복 배수 |
|--------|----------|----------|
| 1~4 | ×1.0 | ×1.0 |
| 5 | ×1.15 | ×1.0 |
| 7 | ×1.45 | ×1.0 |
| 10 | ×1.90 | ×1.0 |
| 12 | ×2.20 | ×1.0 |

공격만 단방향 증가하여 자연스럽게 8~12라운드에 결판.

---

## 특수 규칙

### 반란

1. **민심 0 이하 초과분** → 국력 피해로 전환 (민심 0으로 고정)
2. **민심 0 도달** → 반란 발생. 국력 -(3 + 라운드)
   - R1=4, R5=8, R10=13

### 카드 자원 관리

- **전투/책략**: 카드 소모 → 버린패로 이동
- **내정**: 카드 유지 + 버린패 1장 회수
- **손패 소진 시**: 다음 라운드 시작 시 버린패에서 랜덤 1장 자동 회수
- **양쪽 모두 자원 소진**: 게임 종료

## 드래프트

### 풀 구성

15장을 DB에서 생성. 14장 순수 랜덤 + 마지막 1장은 풀에서 가장 약한 명령을 보강하는 카드 선정.

### 드래프트 순서

- 배치당 3장 공개 → 2장 픽 + 1장 폐기
- 5배치 = 10픽 (각 5장)
- 배치별 선공 교대:
  - **normal**: 플레이어 → AI → 플레이어 → AI → 플레이어
  - **hard**: AI → 플레이어 → AI → 플레이어 → AI

### AI 드래프트 전략

- 첫 픽: 종합 적성 최고 카드
- 이후: 자기 팀에서 가장 약한 명령을 보강하는 카드 우선

---

## 주장(지휘관) 선택

드래프트 후 5장 중 **주장 1명** 선택.

| 역할 | 효과 |
|------|------|
| 손패에 대기 | 출전하는 다른 카드 적성 +15% |
| 직접 출전 | 본인 적성 ×1.5 (오라 소멸) |
| 버린패 | 보너스 소멸 |

AI 주장 선택: 종합 적성 중간 순위 카드 (오라 효율 극대화).

---

## 천명 시스템

매 라운드 시작 시 천명 1개 공개.

| 천명 | 대상 명령 | 효과 |
|------|----------|------|
| 풍운의 천명 | 전투 | 적성 ×1.5 |
| 암중의 천명 | 책략 | 적성 ×1.5 |
| 태평의 천명 | 내정 | 적성 ×1.5 |

- 8개 사전 셔플 (연속 동일 방지)
- 양측 모두 적용 (해당 명령 선택 시)

---

## 게임 흐름

```
[로비] → [드래프트] → [주장 선택] → [배틀] → [결과]

매 라운드:
  1. 천명 공개
  2. selecting — 카드+명령 동시 선택
  3. clashing  — 양측 카드+명령 공개 (연출)
  4. resolving — 결산 (타격/회복/반란)
  5. 승리 판정 (국력 0 이하 → 게임 종료)
  6. 다음 라운드 진행
```

---

## 승리 조건

1. **즉시 승리**: 상대 국력 0 이하
2. **자원 소진**: 양측 손패+버린패 모두 0 → 국력 비교
3. **무한 라운드**: 에스컬레이션으로 자연 종료 (8~12라운드)

## AI 전략

### 가중치 시스템

| 상황 | 조정 |
|------|------|
| 국력 우위 > 5 | 전투 가중치 ↑ |
| 민심 위기 ≤ 15 | 내정 가중치 ↑↑, 전투 ↓ |
| 버린패 없음 | 내정 가중치 ↓ |
| 후반 + 국력 우위 | 전투 가중치 ↑↑ |
| 손패 ≤ 2장 | 내정 ↑, 전투 ↓ |

### 패턴 예측

최근 3라운드 플레이어 행동을 분석하여 상성 유리한 명령 가중치 +30%.
