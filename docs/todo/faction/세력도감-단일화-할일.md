## 지금 서 있는 자리

세력도감은 **영상 제작 데이터가 유일한 원천**이어야 한다. 그런데 도감 인물을 손으로 넣는 별도 명단(`celeb_tag_assignments`)이 남아 있어, 백오피스가 도감과 다른 걸 띄우는 자리가 생긴다.

- 손 명단 잔여(정비 후 실측): **영상 편에 걸린 테마 0명** + 영상이 아예 없는 16테마·123명
- 해법(확정): 손 명단 인물을 그 편 안으로 넣는다. 같은 이름의 회사 세력이 있으면 **그 안에**, 없으면 「영상 제외」 세력으로.
- 도구: `sw/web-bo/scripts/migrate-atlas-manual-to-production.ts`(신규 제작 자리로 이관) · `merge-atlas-groups-into-companies.ts`(기존 세력으로 합치기) · `link-atlas-manual-to-existing-production.ts`(옛 slug 제작 자리 연결) · `adopt-atlas-backup-into-production.ts`(이미 삭제된 수동 행을 전체 백업에서 복구·흡수). 모두 dry-run 경로가 있다.

영상에 사람이 안 나오고 회사·장비만 서는 편들. 손 명단이 통째로 도감을 떠받치고 있어 지금 **도감에서 내려 둔 상태**다.

- [x] 정보기관(8) — CIA·MI6·모사드 기존 세력 안으로 이관 완료
- [x] 특수부대(9) · 하늘의 제조사(9) · 전기차와 배터리(8) · 자율주행(8) · 무인기(7) · 가면 쓴 해커(6)
- [x] 7편의 사람별 소속을 이관 스크립트 `GROUP_BY_PERSON`에 기록하고 dry-run→이관→기존 세력 병합 완료
- [x] 임시로 내린 6테마 노출 복구 + 캐시 갱신. 원래 비노출인 `masked-hackers`는 `false` 유지

### 2. 잔재 21명 — 편별 판단 필요

영상에 안 나오는데 도감에는 넣고 싶어 손으로 넣은 사람들. 테마가 여러 편에 걸치거나 대응 편이 없어 자동 이관이 막힌다.

- [x] 피터 틸(틸 유니버스) · 채염(삼국지) · 한비자(초한지) 제작 편으로 이관
- [x] 갈릴레오 · 마키아벨리 · 로렌초 데 메디치 제작 편으로 이관, 라파엘로는 기존 제작 자리 연결 정규화
- [x] 우르반 · 찬다를르 할릴 파샤 · 콘스탄티노스 11세 — 두 오스만 제작 편의 기존 자리 6건 연결 정규화
- [x] 방위 산업 경영진 7명 · 국가의 해커 2명 제작 편으로 이관
- [x] 허깅페이스 2명(줄리앙 쇼몽 · 토마스 울프) — 기존 제작 자리 활성화·수동 소개 흡수

### 3. 영상 없는 큐레이션 테마 16개·123명

자수성가 · 독학가 · 결핍 · 망명자처럼 영상 없이 사람만 모아 둔 테마. 담을 편이 없다.

- [ ] 테마마다 「영상 제외」 편을 만들지, 손 명단을 이 경우에만 정식으로 인정할지 결정
- [ ] 결정 전까지는 그대로 둔다(지금 서비스에 정상 노출 중)

### 4. 편집기 「직접 추가」 처리

셀럽 계정 없이 인물을 만들 수 있어, 도감에 못 가는 인물이 생긴다(로봇·기업명이 이 통로로 들어왔다).

- [ ] 둘 중 하나 결정 — ① 이 버튼을 없애고 셀럽에서만 고르게 한다 ② 직접 넣는 순간 셀럽 계정이 함께 생기게 한다
- [ ] 사람이 아닌 등장(기계·조직)을 계속 쓸 거라면 그 용도를 이름에 드러낸다
