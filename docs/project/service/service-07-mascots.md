# 서비스 캐릭터 활용

불씨·부엉이·사자는 필앤노트의 안내와 사용자 행동을 돕는 캐릭터다. 화면·빈 상태·도움말·저장 반응을 만들거나 고칠 때 아래 역할에 맞는 접점에서 기존 자산을 재사용한다. 캐릭터를 배치하는 목적은 사용자가 상황을 이해하고 다음 행동을 고르게 하는 것이다.

## 세 캐릭터의 역할

| 캐릭터 | 맡는 일 | 표현 |
|---|---|---|
| 불씨 정령 (`flame`) | 필앤노트의 대표 얼굴, 감상의 시작과 기록 성공 | 청동 등잔에 깃든 불꽃. 호기심과 작은 기쁨을 불꽃의 기울기·밝기로 표현한다. |
| 책날개 부엉이 (`owl`) | 탐색, 관계·분류의 이해, 사용자가 연 도움말 | 아이보리 몸과 청동 부리, 책장처럼 겹친 날개. 시선·고개·날개로 살펴보고 설명한다. |
| 석상 사자 (`lion`) | 개인 기록의 보관, 편안한 머무름과 휴식 | 아이보리 석재 몸과 청동 갈기. 기록 곁에 앉거나 앞발에 턱을 얹고 쉰다. |

불씨가 대표 캐릭터이며 셋을 같은 비중의 로고로 쓰지 않는다. 책·영상·게임·음악은 같은 캐릭터의 행동과 소품으로 표현한다. 기존 외형·재질을 유지하고 다른 종이나 매체별 캐릭터를 관성적으로 늘리지 않는다.

## 화면에서 쓰는 자리

- **홈·서비스 소개**: 불씨가 방문자를 맞는다. 제목·정의·주요 행동을 먼저 읽을 수 있는 비중으로 배치한다.
- **작품 추가·감상 저장**: 불씨가 실제 성공을 짧게 확인한다. 작품을 목록에 담은 것과 감상을 저장한 것을 문구로 구분한다. 실패·대기·이미 저장된 상태를 새 성공처럼 표현하지 않는다. 긍정·부정 감상과 별점에 같은 온도로 반응한다.
- **검색**: 검색 시작·결과 없음에는 부엉이를 쓴다. 검색 조건을 바꾸거나 초기화할 수 있는 기존 조작과 함께 안내한다. 정상 결과가 있으면 대상 목록이 중심이다.
- **분류·도표·사용법**: 설명이 필요한 지점에서 부엉이가 돕는다. 책장 분류처럼 반복해서 쓰는 도움말은 기본으로 접고, 현재 화면의 실제 분류와 설명을 읽는다. 도움말을 열기 위해 미조회 자료까지 가져오지 않는다.
- **개인 기록관**: 빈 기록에는 사자를 쓴다. 본인에게만 기록 추가를 권하고, 다른 회원의 기록을 보는 방문자에게는 공개 상태만 안내한다. 인물의 감상 목록은 개인 기록관으로 취급하지 않는다.
- **쉼터**: 쉬는 사자가 입구를 맡는다. 게임 조작·시간 제한·문제 풀이 중에는 인물과 게임판을 가리지 않는다.

캐릭터는 기본적으로 행동과 표정으로 성격을 드러낸다. 안내·저장 결과·오류의 의미는 실제 글자로 전달하고, 캐릭터의 말투로 바꾸어 뜻을 흐리지 않는다. 접속하지 않거나 기록이 적다는 이유로 실망·쇠약·소멸을 표현하지 않는다.

## 세력도감·신화

도감의 탐색과 분류 안내는 부엉이가 맡는다. 목록 검색의 빈 결과에는 기존 초기화 행동을 붙이고, 관련 도서에서는 해당 도감의 분류를 설명한다. 개별 인물 창의 참고도서도 같은 안내를 쓴다.

불씨는 도감에서 찾은 작품을 사용자가 자신의 기록으로 남기는 흐름의 성공 반응으로 이어진다. 개요를 열거나 장면을 넘긴 것만으로 감상 완료를 선언하지 않는다. 사자는 공개 도감의 자료 없음·미공개·조회 실패를 개인의 빈 기록처럼 표현하는 데 쓰지 않는다.

표지·주요 장면·인물 초상·개요 본문·대사·낭독의 주인공은 해당 이야기와 인물이다. 서비스 캐릭터를 전승 속 신·수호자·등장인물로 합성하지 않으며, 인물의 발언·감상이나 기관·공식 차트의 추천 주체를 대신하지 않는다. 장면 뷰어에서는 사용자가 요청한 조작 도움말 같은 서비스 안내가 필요한 자리만 검토한다.

## 공통 구현과 자산

- [공통 컴포넌트](../../../sw/web/src/components/shared/mascots/Mascot.tsx): `Mascot`은 장식 이미지, `MascotEmptyState`는 빈 상태, `MascotFeedback`은 저장 결과 옆의 반응이다. 저장 결과는 호출한 화면의 지속적인 상태 알림 영역 안에 넣는다.
- [책장 안내](../../../sw/web/src/components/shared/mascots/BookShelfGuide.tsx)는 실제 분류·설명을 받아 쓴다. 인물·도감 책장의 표시 판단은 [공통 책장](../../../sw/web/src/components/shared/BookShelf/BookShelf.tsx)이 맡는다.
- [자산 폴더](../../../sw/web/public/images/mascots/)에는 승인 외형의 투명 WebP를 둔다. 자산 주소·비율은 공통 컴포넌트, 크기·반응·배치는 [공통 스타일](../../../sw/web/src/components/shared/mascots/Mascot.module.css)과 각 사용처, 한영 문구는 `messages/{ko,en}/core.json`의 `mascot`이 쥔다. 문서에 수치를 복제하지 않는다.

새 접점도 공통 구현을 사용한다. 페이지마다 같은 그림을 다시 복사하거나 별도 캐릭터 컴포넌트를 만들지 않는다. 큰 소개 이미지와 작은 상태 표시는 필요한 디테일이 다르므로 실제 표시 크기로 보고 판단한다. 로고·제목 옆에 캐릭터를 둘 때는 텍스트 자체의 정렬축을 유지한다. 저장 전후에는 아이콘 자리와 결과 안내 공간을 유지해 주변 요소가 밀리지 않게 한다. 화면에 고정된 캐릭터가 메뉴·목차·음악·본문 조작을 덮지 않게 한다.

이미지는 장식으로 처리하고 필요한 설명은 옆 글자와 버튼에 둔다. 조작의 강조는 즉각 반응하고, 캐릭터 연출은 그 반응을 늦추지 않는다. 동작 줄이기 설정에서는 연출을 끄며, [UI 상호작용 규칙](../platform/platform-02-code-rules.md#상호작용)을 따른다.

새 포즈·이미지 제작은 [이미지 발주 규칙](../production/prod-01-image-generation.md)을 함께 읽는다. 사용자가 승인한 외형을 참조하고, 사용자에게 보이기 전 생성 원본을 지우지 않는다.
