# 한국 전승 네 곳의 빈 명단 처리

2026-09-23에 기존 [가야·신라 검수](gaya-silla-review.md), [고려세계·탐라 검수](goryeo-tamna-review.md)를 출발점으로 DB를 재조회했다. 네 전승의 한영 개요·명단 설명·핵심 인물 프로필·안내가 채워져 있고, 각 표시 후보에는 등록 아바타와 `appearance` 작품 관계가 있었다. 공개 후보만 계정 `active`, 인물 안내 발행, 전승 명단 표시로 전환했다. 전승 자체의 `published`는 바꾸지 않았다.

| 전승 | 표시 인원 이전 → 이후 | 처리한 인물 | 남은 제외 인물 |
|---|---:|---|---|
| 가야 | 0 → 5 | 김수로·허황옥·정견모주·이진아시·석탈해 | 구간·다섯 가야 시조 형제(집단 계정·아바타 없음) |
| 신라 | 0 → 10 | 박혁거세·알영·육촌장 여섯·김알지·석탈해 | 없음 |
| 탐라 | 0 → 3 | 고을나·양을나·부을나 | 벽랑국 세 공주(집단 계정·아바타 없음) |
| 고려세계 | 0 → 8 | 호경·강충·보육·진의·작제건·저민의·용건·왕건 | 없음 |

배정 26건은 고유 인물 25명이다. 그중 왕건은 이미 `active`이고 안내가 발행돼 있었다. 나머지 24명은 활성화·안내 발행을 마친 뒤 배정을 표시했다. [변경 전 백업](zero-batch-before-20260923.json)을 저장하고 각 행을 이전 상태 조건으로 갱신했으며, [변경 후 기록](zero-batch-after.json)과 별도 재조회에서 네 전승의 5·10·3·8명 표시, 표시 인물의 `active`·안내 발행, 집단 세 계정의 `inactive`·숨김, 네 전승의 `published=false`를 확인했다. 실행은 [배치 스크립트](apply-zero-batch.mjs)에 남겼다.

대상 25명의 전체 세력 배정을 다시 조회했을 때 네 전승 밖과 겹치는 인물은 이미 공개된 왕건 한 명뿐이며, `conquerors`의 배정은 변경하지 않았다.

네 전승은 **명단·계정·안내 배치가 끝났고 전승 공개 여부는 아직 미결정**이다. 기존 검수에서 신라 표지의 전경 바위가 인물 허리 아래를 가리는 점과 가야 표지 얼굴과 아바타의 완전한 동일성은 실화면 확인 의견으로 남았다. 가야·탐라의 집단 세 계정은 단일 얼굴 아바타를 임의로 만들지 않아 계속 제외한다. 개별 한국어·영어 책의 모든 판본 범위를 새로 전수 검증한 작업은 아니므로 작품 관계 전체에 대한 별도 내용 GO로 확대하지 않는다. 로컬 신화 화면은 미공개 전승의 `?myth=` 값을 받으면 공개된 전승 화면으로 돌아가므로 전승별 최신 렌더를 이 경로에서 확인할 수 없었다. `kim-suro` 한국어 인물 상세와 `jeominui` 영어 인물 상세는 로컬 서버 HTTP 200을 확인했다.
