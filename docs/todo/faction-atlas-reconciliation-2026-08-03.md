# 세력도감 정합화 작업 (2026-08-03)

제작(faction_*) ↔ 도감(celeb_tags/assignments) 전수 대조 결과와 단계별 정합화 계획.
진단 SQL은 편별로 제작 인물 수·미해소·대사 보유, 태그 연결, 웹 배정·대사 빈 수를 집계했다(읽기 전용).

## 배경

- 통합(26.07.25) 이전에 수동·구식 스크립트로 심은 태그·배정이 출간 기록 없이 웹에 살아 있다.
- 그 시절 경로는 대사(quote)·팩션 직함(lines[0]→short_desc)을 나르지 않았다 → "이름은 뜨는데 대사만 빈" 인물 다수.
- 현행 출간 파이프라인(web-bo `/factions` 출간 패널)은 대사를 항상 되쓰고, 사람 손질 소개문은 보호한다(멱등).
- 웹 화면은 이제 팩션 직함(short_desc) 우선 표기 + 미출간 태그 「준비 중」 노출로 정비됨(26.08.02~03).

## 단계 계획

1. **B군 재출간(텍스트 범위)** — web-bo 출간 패널에서 편별 진단→dry-run→출간. 대사·직함 채움. ✅/❌ 기록.
2. **C군 연결 키 지정 + 출간** — 편집기에서 세력별 tagSlug 지정(이름 1:1 대응이 명백한 것부터), dry-run으로 배정 충돌 확인 후 출간.
3. **C군 대응 미확인분 조사** — 웹 태그 ↔ 제작 편 대응표 완성, 대응 없는 웹 태그는 유지/폐기 결정(사람).
4. **D군 노출 결정** — 신화 9종 등 준비 중 → 노출 전환 여부(사람 결정).
5. **미해소 인물 정리** — B·C군의 celeb_id null 인물: 셀럽 등록(celeb 파이프라인) 또는 도감 제외 확정.

주의: 출간 패널은 화면 전용이지만, 이번 정합화는 유저 지시로 **데이터단(SQL) 직접 처리**로 전환했다.
백필 규칙은 출간 코드와 동일하게 맞췄다 — 대사(quote·en) 갱신, 한줄 소개(lines[0])·상세 설명(epithet 또는 lines[1..2]) 빈 칸만 채움, 같은 셀럽 중복 배치는 앞자리 채택, disabled 인물 제외. 배정 신규 생성(INSERT)은 하지 않았다(노출 확대는 별도 결정).

## P7 잔여 이중 표기의 정체와 감시 (26.08.03)

**정직한 잔여 목록** — 테마의 간판(이름·영문명·색)은 세력(faction_groups.name·color, 영상 자막 표기)과 테마(celeb_tags, 도감 한글 표기)에 각각 존재한다. 도감 한글 표기(스페이스X)는 제작에 원천이 없는 창작이라 어느 한쪽으로 합칠 수 없다 — 사본 두 벌이 아니라 **매체별 표기 두 개** 구조로 규정한다(인물 소개의 원문+손질 구조와 동일). 뉴럴링크 사건(소속 재편 후 간판이 옛 묶음 이름으로 잔존)이 이 틈의 사고 사례다. 26.08.03 정리: 「변경의 실험실」→「뉴럴링크」 개명, 보링 컴퍼니 한글명 부여, 1:1 태그 전수 대조에서 잔재성 어긋남 0 확인(나머지는 표기 다듬기).

**감시 상설화** — 훑는 행위를 시스템 몫으로: 편 진단 패널에 「테마 간판 어긋남(확인 요망)」 항목 추가(name_en 정규화 비교 기준, 오탐 방지). 신설 테마는 자동 장치가 세력명 그대로 만들므로 어긋남은 표기 다듬기·소속 재편 때만 발생하고, 재편 시 진단이 잡는다. (✅ 완료 — 진단 ⑦ 「간판 확인 요망」: 영문명(name_en)끼리 NFKC 정규화 비교, 1세력 태그는 세력명·공유 태그는 편 제목과 대조, 경고 성격으로 목록화. tsc·eslint 통과)

## P13 인간형 로봇 편 — 사진과 사람이 따로 놀던 문제 (26.08.03)

원인 두 겹.
1. 제작 편 `humanoids`는 등장이 사람이 아니라 **로봇 기종**(옵티머스·아틀라스·스팟·피겨03·NEO·유니트리 G1)이라 `celeb_id`가 없다 → 사진에 실을 인물 명단이 빈다.

- ✅ `faction-sync/publish.ts` — 제작에서 뽑은 사진 인물 명단이 비면 **도감에 이미 매달아 둔 명단을 지우지 않는다**(제작에 사람이 있으면 종전대로 제작이 이긴다). 이게 없으면 아래 수동 배정이 다음 출간에 날아간다
- ✅ 데이터 — `humanoid-robotics` 사진 5장에 회사 이름표(Tesla·Boston Dynamics·Figure AI·1X Technologies·중국 굴기)와 소속 인물 6명 배정. 캐시 갱신 후 실화면 확인
