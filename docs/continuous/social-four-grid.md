# 4분할 게시물 시리즈

같은 질문을 필앤노트 웹, 유튜브 게시물, X에서 이어서 운영한다. 웹에서는 회차에 맞춰 후보를 늘리고 선택이나 순위 경쟁을 연다. 웹에서 뽑은 네 후보로 유튜브 투표를 열 수도 있고, 먼저 올라간 유튜브·X 게시물의 질문과 후보를 웹으로 가져와 확장할 수도 있다.

세력·신화마다 투표에 쓸 후보 풀을 필요에 따라 여러 개 둔다. 회차를 만들 때 기존 풀을 고르거나 새로 만들고, 풀에서 해당 회차에 올릴 후보를 고른다. 후보 풀이 없는 도감은 기존 탐색 화면으로 연다.

X 이미지 게시물은 질문 한 줄과 선택지를 한 장에 담는다. 이미지 공용본은 유튜브 피드에 맞춰 1:1 정사각형으로 만든다. 웹 회차는 X 첫 답글과 유튜브 채널 프로필 링크로 안내하고, 관련 책은 웹 회차에서 소개한다. [유튜브 이미지 게시물](https://support.google.com/youtube/answer/7124474) · [유튜브 링크 안내](https://support.google.com/youtube/answer/13748639)
