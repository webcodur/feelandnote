# 가야·신라 공개 판단 (2026-09-23)

아래의 `hidden=true`·`inactive`·안내 미발행은 **배치 전 상태**다. 현재 명단 수와 공개 상태는 [후속 반영 결과](zero-batch-result.md)를 따른다.

`snapshot.json`(09:06 UTC)과 현재 등록 이미지를 확인했다. 두 세력은 여전히 `published=false`, 모든 명단은 `hidden=true`, 모든 인물은 `inactive`, 안내의 `published_at`도 비어 있다. 한영 프로필·명단 문구·안내와 `appearance` 관계는 전원 존재한다. 아바타 URL이 있는 고유 인물 14명은 로컬 등록본을 직접 보았고 기존 배치 검증에서 3종 변형 모두 `ok`다. CDN 원본은 HTTP 403으로 이 환경에서 직접 대조하지 못했다.

- **가야: 김수로·허황옥·정견모주·이진아시·석탈해 5명은 공개 후보.** 석탈해는 `가락국기`에서 수로와 술법을 겨루므로 양쪽 명단에 둘 근거가 있다. 아바타가 없는 집합 인물 `구간`과 `다섯 가야의 시조 형제`는 active/visible 대상에서 제외한다. 다섯 시조의 bio·안내가 특정 다섯 나라를 각자에게 배정하던 오류를 [원전](https://db.history.go.kr/id/sy_002r_0010_0230_0010)에 맞게 교정했다. 개요에서도 여섯 알에서 태어난 수로와 정견모주의 아들로 전하는 수로를 [별개 시조 전승](https://db.history.go.kr/id/sg_041r_0020_0010)으로 구분했다. 변경 전 값은 `gaya-silla-before-20260923.json`에 백업했고, 조건부 DB 갱신 뒤 3개 행을 읽어 새 값과 일치함을 확인했다. 표지는 수로와 허황옥의 바닷가 만남으로 시선과 주요 인물이 잘 보이나, 등록 아바타와 표지 얼굴의 동일성까지 확언하기는 어렵다.
- **신라: 10명 모두 데이터상 공개 후보.** 박혁거세·알영·육촌장 6명·김알지·석탈해의 배정은 [신라 건국 전승](https://db.history.go.kr/id/sy_001r_0020_0190_0010)에 맞는다. 소벌도리=정씨·지백호=최씨는 `삼국유사` 기준이고 bio는 `삼국사기`의 반대 배정도 명시한다. 표지는 성인 남녀가 숲의 흰 말을 바라보는 상징 장면이다. [원전](https://db.history.go.kr/id/sy_001r_0020_0190_0030)의 ‘말이 알을 지킨 탄생 순간’과는 시간상 다르므로, 정적 HTML 검수 화면의 설명에서 그 사건 묘사를 빼고 실제 그림에 맞췄다. 이미지 자체는 그대로 두었다. 전경 바위가 두 인물의 허리 아래를 가리는 점은 실제 서비스 화면에서 볼 필요가 있다.

공개 플래그는 바꾸지 않았다. 실제 서비스 화면 검수도 아직 하지 못했다.
