# 셀럽 명언 검수·교정·품질개선 룰북

기존 셀럽 명언(quotes/quotes_en)을 검수·교정·품질개선하는 전용 가이드.

---

## 작업 흐름

### 1. 배치 조회

```sql
SELECT p.id, p.nickname, p.profession, p.quotes, p.quotes_en, p.speech_tone
FROM profiles p
WHERE p.profile_type = 'CELEB'
ORDER BY p.nickname
LIMIT 30 OFFSET {offset};
```

- 30명씩 배치로 처리한다
- 각 배치마다 문제 있는 명언을 식별 → 교정 → UPDATE
- `speech_tone`을 반드시 참조하여 명언 어조의 일관성을 확인한다

### 2. 문제 식별

각 명언을 아래 **검수 체크리스트** 순서대로 판정한다.

### 3. 교정

- 문제가 있는 명언만 교정한다. 정상 명언은 건드리지 않는다
- 교정이 필요한 인물은 **웹 검색으로 올바른 명언을 확인**한 뒤 교체
- 검색해도 적절한 명언이 없으면 빈 문자열로 처리

### 4. 배치 UPDATE

```sql
UPDATE profiles SET
  quotes = CASE id
    WHEN '{id1}' THEN '{교정된 명언1}'
    WHEN '{id2}' THEN '{교정된 명언2}'
    ...
    ELSE quotes
  END,
  quotes_en = CASE id
    WHEN '{id1}' THEN '{교정된 영문명언1}'
    WHEN '{id2}' THEN '{교정된 영문명언2}'
    ...
    ELSE quotes_en
  END
WHERE id IN ('{id1}', '{id2}', ...);
```

- 개별 UPDATE 금지. 반드시 CASE문으로 배치 처리
- **quotes와 quotes_en을 항상 동시에 교정**한다

## 검수 체크리스트 (판정 순서)

아래 순서대로 확인하며, **하나라도 해당하면 교정 대상**이다.

### A. 즉시 탈락 (검색 불필요)

| # | 판정 기준 | 예시 | 조치 |
|---|----------|------|------|
| A1 | **빈 값** | `""` | 웹 검색으로 명언 확보, 불가 시 유지 |
| A2 | **캐릭터 대사** (영화·드라마·소설·게임) | "I'll be back", "나한테 말하는 거야?" | 본인 실제 발언으로 교체 |
| A3 | **노래 가사** | "앉아라, 케말라" | 본인 인터뷰 발언으로 교체 |
| A4 | **복수 명언 합본** (`/`로 연결) | "명언1" / "명언2" / "명언3" | 가장 상징적인 1문장만 선택 |
| A5 | **따옴표 래핑** | `'명언 내용'` | 따옴표 제거 |
| A6 | **원문 미번역** (한문·외국어 그대로) | 學問之道無他 | 한국어로 번역 |
| A7 | **50자 초과** | 장문의 명언 | 핵심만 추려 50자 이내로 축약 |
| A8 | **이스케이프 문자** (`\"` 등) | `\"교향곡은...\"` | 정상 문자열로 교정 |

### B. 검색 필요 판정

| # | 판정 기준 | 예시 | 조치 |
|---|----------|------|------|
| B1 | **타인 명언 오귀속 의심** | 벤저민 그레이엄에게 워렌 버핏 명언 | 웹 검색으로 원발화자 확인 → 교체 |
| B2 | **중복 귀속 의심** | 봉준호·마틴 스콜세지 동일 명언 | 원발화자 확인 → 비원발화자쪽 교체 |
| B3 | **AI 생성 의심** (범용적·검증 불가) | "연기는 진실을 찾는 과정이다" | 웹 검색으로 실제 발언 확인 → 교체 또는 빈 문자열 |
| B4 | **슬로건/구호** | "미국을 다시 위대하게" | 인물의 철학이 담긴 실제 발언으로 교체 |
| B5 | **풍자 대상의 말을 본인 말로** | 볼테르에게 라이프니츠 주장 등록 | 정확한 출처 확인 후 교체 |

### C. AI 생성 의심 판별법

아래 패턴 중 **2개 이상** 해당하면 AI 생성을 의심한다.

1. **"X는 Y이다"** 정의형 문장 (예: "연기는 진실을 찾는 과정이다")
2. 해당 인물만의 **고유한 맥락/사건/작품**이 전혀 없는 범용 문장
3. **같은 직군의 다른 인물**이 말해도 전혀 어색하지 않음
4. 웹 검색 시 해당 인물과 연결된 출처가 **하나도 없음**

→ 의심 시 `"{인물 영문명} famous quote"` 또는 `"{인물 한글명} 명언"`으로 웹 검색
→ 검색 결과에서 출처가 확인되면 해당 명언으로 교체
→ 확인 불가 시 빈 문자열

### D. 품질·임팩트 판정

A~C 통과 후에도 아래에 해당하면 **품질 개선 대상**이다.

| # | 판정 기준 | 예시 | 조치 |
|---|----------|------|------|
| D1 | **범용 자기계발 문구** — 인물 고유성 zero | "완벽하지 않아도 괜찮다", "성공이란 즐거움을 갖는 것이다" | 인물 고유 맥락이 담긴 발언으로 교체 |
| D2 | **기업 슬로건형** — 임원 누구나 할 수 있는 말 | "공감은 혁신의 원동력이다", "재무는 숫자가 아니라 전략이다" | 해당 인물의 구체적 경험/사건에서 나온 발언으로 교체 |
| D3 | **의미 불명확/맥락 없음** — 단독으로 읽으면 무슨 뜻인지 모름 | "이것은 모두를 위한 것이다", "왕관은 영광스러운 관이다" | 맥락이 살아있는 발언으로 교체 |
| D4 | **인물 불일치** — 내용이 해당 인물의 핵심 정체성과 안 맞음 | 아인 랜드에게 "돈은 하나의 도구일 뿐이다" (객관주의 철학과 충돌) | 인물 철학에 부합하는 발언으로 교체 |
| D5 | **밋밋한 역사 인물** — 스케일/포스가 안 느껴짐 | 정복왕에게 "평화를 사랑한다" | 업적·일화 기반 임팩트 있는 문장으로 교체 |
| D6 | **speech_tone 불일치** — 명언 어조가 인물의 톤과 안 맞음 | bold 인물이 "~이죠", humble 인물이 "~하라!" | speech_tone에 맞는 어조로 교체 |

#### speech_tone별 어조 가이드

명언의 말투는 `celeb_persona.speech_tone`과 일관되어야 한다.

| tone | 한국어 어조 | 영문 어조 | 예시 |
|------|-----------|----------|------|
| **bold** | 단언·선언·명령체 ("~하겠다", "~하라", "~이다") | assertive, commanding | 내 사전에 불가능은 없다 |
| **composed** | 절제·관조체 ("~일 뿐이다", "~할 따름이다") | measured, calm | 삶은 짧다. 우리가 낭비하기 때문에 짧은 것이다 |
| **gentle** | 부드러운 구어체 ("~이죠", "~하지 않을까요") | warm, soft-spoken | 상상력은 지식보다 중요하죠 |
| **free** | 거침없는 구어체 ("~거든", "~잖아", "~인데") | casual, informal | 나는 마약을 하지 않는다. 내가 곧 마약이다 |
| **humble** | 겸양체 ("~할 뿐입니다", "~하겠습니다") | modest, graceful | 신에게는 아직 열두 척의 배가 있습니다 |
| **loyal** | 의무·사명체 ("~해야 한다", "~하겠노라") | firm, devoted | 역사는 바로 세워야 한다 |

#### D 카테고리 교정 방법

1. **웹 검색 우선**: 해당 인물의 실제 발언 중 임팩트 있는 것을 찾는다
2. **역사 일화 기반 창작 허용**: 실제 발언이 없거나 밋밋한 경우, 인물의 핵심 업적·사건·철학을 기반으로 **그 인물이 했을 법한 멋있는 한마디**를 창작할 수 있다
3. **창작 시 필수 조건**:
   - 인물의 **고유한 업적/사건/철학**이 반드시 녹아있어야 한다
   - 같은 직군의 다른 인물이 말하면 어색해야 한다 (고유성 테스트)
   - 시대착오적 표현 금지
   - 짧고 강렬해야 한다 — 듣는 사람이 그 인물의 스케일을 느낄 수 있는 문장
4. **창작 톤 참고**: "주사위는 던져졌다"(카이사르), "길을 찾거나 길을 만들겠다"(한니발), "사방 끝이 보이거든, 거기까지가 고구려다"(광개토대왕)

## 교정 시 명언 선정 기준

### 우선순위

1. **역사적으로 가장 유명한 발언**: 해당 인물 하면 바로 떠오르는 한마디
2. **인물의 핵심 철학/신념**: 인터뷰·연설·저서에서 나온 대표 발언
3. **역사 일화 기반 창작**: 실제 발언이 부족하거나 밋밋한 경우, 업적·사건 기반으로 창작
4. **빈 문자열**: 위 3가지 모두 불가능한 경우에만

### 출처 허용/불허

| 허용 | 불허 |
|------|------|
| 인터뷰, 연설, 기자회견 | 출연작 캐릭터 대사 |
| 저서, 서한, 조서 | 타인이 해당 인물에 대해 한 말 |
| 공식 SNS 본인 발언 | 작품 속 인물 대사 |
| 역사서에 기록된 직접 발언 | 노래 가사 |
| 업적·일화 기반 창작 (D 카테고리) | 시대착오적·범용적 창작 |

### 포맷

- **50자 이내**, 한 문장
- 한국어로 작성 (외국어 원문 병기 금지)
- 따옴표(`""`, `''`)로 감싸지 않음
- 문자열 내 큰따옴표는 작은따옴표로 대체

## 검색 전략

### 확실한 인물 (검색 생략 가능)

역사적 위인, A급 유명인 등 대표 명언이 **명백하게** 알려진 인물은 검색 없이 판정 가능.
- 예: 데카르트, 링컨, 간디, 아인슈타인 등

### 불확실한 인물 (검색 필수)

B~C급 배우, 현대 기업인, 인플루엔서 등 대표 명언이 불명확한 인물.

```
"{영문 인물명} famous quote"
"{영문 인물명} best quotes"
"{한글 인물명} 명언"
```

- 검색 결과에서 **복수의 출처**가 동일 발언을 인용하면 신뢰
- 단일 출처이거나 quote aggregator 사이트만 나오면 추가 검증 필요
- Brainyquote, Goodreads Quotes 등은 참고용으로만 (오귀속 많음)

### 배치 효율화

- 30명 배치에서 즉시 탈락(A 카테고리)은 바로 처리
- B 카테고리 의심 건만 모아서 한 번에 검색
- 검색은 **배치당 최대 10건** 이내로 제한 (효율)
