# 가상독백

`celebs.virtual_monologue`는 인물이 자기 삶과 철학을 자기 목소리로 말하는 한국어 원고이고, `virtual_monologue_en`은 그 영문이다. 공개 인물 전원에게 채우는 정식 데이터다. 사용자 화면에서는 모든 방문자에게 인물 상세 읽어보기의 두 번째 모드로 보인다([`celeb-05-01-reading.md`](celeb-05-01-reading.md)). 영어 화면은 영문을 보이고, 영문이 비었으면 한국어를 보인다. 서비스 값의 원천은 DB다.

실행점은 `sw/web-bo/scripts/celeb/virtual-monologue.mjs` 하나이고, 호출 절차는 `celeb-virtual-monologue` 스킬이 쥔다.

## 작가

작가는 agy의 `gemini-3.8-flash-high`다. 가상독백은 한국어 문장이 곧 품질이라 한국어를 잘 쓰는 모델을 골랐다. 입력은 지시 한 줄과 인물 소개(bio) 한 줄뿐이다.

```text
<인물 이름>. 자신만의 말투로 자신의 삶과 철학을 독백한다. 분량은 A4 반 페이지.
인물 소개: <bio>
```

- 소개는 늘 붙인다. 이름만 주면 같은 이름의 더 유명한 대상(작품 속 인물·사물·다른 사람)으로 쓴다.
- 지시를 늘리지 않는다. 출처 등급과 주장 대조표를 요구하는 검수 계약을 붙이자 모델이 검증하기 쉬운 연보로 도망쳐 원고가 사전 항목처럼 됐다.
- 입장이 뒤집히기 쉬운 한국 전근대 인물만 같은 모델의 새 세션이 한 번 더 본다. 사실이 뒤바뀐 곳만 고치고 문장은 그대로 둔다. 대상 기준은 `needsLightReview`가 쥔다.
- 보류된 인물을 다시 쓸 때만 보류 사유에 맞는 한 줄 지시를 덧붙인다. 결함 문구를 예로 적지 않고 설명만 쓴다. 예를 적으면 모델이 그 문구 쪽으로 쓴다.

## 채우는 순서

공개 인물에 빈칸이 생기면 네 명령을 이 순서로 돌린다. 각 명령은 아직 처리하지 않은 원고만 잡으므로 멈춘 뒤 같은 명령을 다시 돌리면 이어서 처리한다.

```powershell
node --env-file=sw/web-bo/.env sw/web-bo/scripts/celeb/virtual-monologue.mjs light --apply
node --env-file=sw/web-bo/.env sw/web-bo/scripts/celeb/virtual-monologue.mjs notation --apply
node --env-file=sw/web-bo/.env sw/web-bo/scripts/celeb/virtual-monologue.mjs identity --apply
node --env-file=sw/web-bo/.env sw/web-bo/scripts/celeb/virtual-monologue.mjs translate --apply
```

1. `light`는 비어 있고 잠기지 않은 원고를 쓰고, 기계 검사를 통과한 원고만 넣는다. agy 쿼터가 소진되거나 로그인이 풀리면 바로 멈춘다. 보류·오류 인물은 빈 채로 남아 다음 실행에서 다시 대상이 된다.
2. `notation`은 음성화에 걸리는 표기를 정리한다.
3. `identity`는 영문이 빈 원고, 곧 번역 전의 원고를 판정한다. `--apply`면 other를 비우고 비운 slug 목록을 출력한다. 그 목록으로 `light --apply --slugs …`를 다시 돌린 뒤 판정을 한 번 더 거친다.
4. `translate`는 판정을 마친 원고를 영문으로 옮긴다. 판정 전에 번역하지 않는다. 번역을 마친 원고를 다시 판정할 때는 `identity --slugs …`로 지정한다.

`light`의 결과는 `data/celeb/virtual-monologue/light.jsonl`에 쌓인다. 보류 사유를 다음 실행의 한 줄 지시로 돌려주는 기록이다. 정리 규칙을 고친 뒤에는 `--reuse <이 기록>`으로 호출 없이 보류분을 다시 검사한다. 빈칸이 모두 채워지면 폴더째 지운다.

수백 명을 다시 쓸 때만 감시자 `sw/web-bo/scripts/celeb/vm-supervisor.ps1`을 떼어 띄운다. 메모리 부족으로 배치가 죽으면 여유가 돌아온 뒤 다시 띄우고, 쿼터나 로그인으로 멈추면 30분 뒤 다시 시도한다. 로그는 같은 데이터 폴더에 남는다. 멈출 때는 `virtual-monologue.mjs light`가 든 `node.exe`와 감시자 PowerShell만 PID로 끊는다.

## 기계 검사

`light`는 강조 기호, 명백한 머리 줄, 한자·로마자만 든 괄호, 긴 줄표만 기계로 걷어 낸다. 내용은 고치지 않는다. 아래 원고는 보류한다. 판별식은 `mechanicalIssues`·`styleFlags`·`opensWithOthers`가 쥔다.

- 남이 붙인 호칭이나 남의 말로 여는 첫 문장. "사람들은 나를 …라 부른다", "세상은 나를 …"과 그 틀에서 주어만 뺀 모양이 여기에 든다.
- 연도로 시작하는 이력서형 첫 문장
- 괄호 속 무대 지시와 웃음 표시
- 본문 밖 모델 해설("…독백입니다", 동명이인 되묻기), 인용 상자, 남은 제목 줄
- 거절 응답

## 인물 판정

기계 검사는 이름만 같은 다른 인물의 원고를 잡지 못한다. 모델이 해설 없이 다른 인물로 쓰거나 두 인물의 독백을 한 원고에 이어 붙이기 때문이다. `identity`는 muse에 인물 소개와 원고 전문을 주고 same·other·unsure로 가른다.

- 첫머리만 보고 판정하지 않는다. 첫 두 문단만 보고 other·unsure로 가른 원고를 전문으로 다시 보자 10편 중 4편은 same이었다.
- other는 비우고 다시 쓴다. unsure는 Claude나 사람이 전문을 읽고 정한다. 인물 단서가 없는 평범한 원고는 그대로 둔다.
- `long`으로 표시된 원고는 두 인물이 섞였는지 읽는다. 기준은 `LONG_MONOLOGUE_CHARS`가 쥔다. 섞였으면 인물 소개에 맞는 문단만 한영 모두에 남긴다.

## 고치는 기준

고치는 대상은 부서진 원고다. 앞말 잃은 지시어, 사라진 질문에 답하는 문장, 끊긴 이음새, 사실 오류, 모델 해설이 여기에 든다. 첫머리가 평이하거나 여러 원고에 비슷한 틀이 반복되는 것은 수천 명 규모에서 당연하므로 고치지 않는다. 판별식에 걸린다는 이유만으로 틀을 일괄로 바꾸지 않는다.

- 첫 문장을 고치거나 지울 때는 뒤 문장과 다음 문단 첫머리까지 함께 읽는다. 지운 말에 기대던 대비("…아니었다", "숨겨진"), 지시어("너희", "그"), 빠진 주어가 남으면 그 이음새까지 고친다.
- 이미 넣은 원고의 수정은 모델에 맡기지 않는다. agy는 지시문의 결함 설명 쪽으로 오히려 고치거나 낱말만 바꿔 검사를 비켜 갔고, Sonnet은 첫머리를 고치다 호칭 틀로 되돌아갔다. Claude나 사람이 그 자리만 직접 고친다.
- 한국어를 고치면 영문의 같은 자리도 함께 고친다.
- 한 행씩, 현재값이 읽은 값과 같고 잠기지 않았을 때만 쓴다.

## 음성화 표기

가상독백은 음성으로 읽힐 원고라 로마자·한자·괄호를 남기지 않는다. `notation --apply`는 한글 표기 뒤의 원어 병기 괄호를 기계로 뗀다. `--model`을 더하면 뜻풀이 괄호를 devin이 문장으로 풀고, 몇 편뿐이면 Claude가 직접 푼다. 남길 말은 자리가 아니라 **독자가 아는 쪽**으로 고른다. "공근(주유)"는 "공근 주유"로 쓰고, "(미소)" 같은 지문은 지운다.

기계 단계는 수정 전 원문을 남기지 않는다. 모델 단계는 작업 폴더(기본 `../_vm-notation`)의 `input/`에 원문을 남기므로, 반영을 확인하면 폴더를 지운다. 괄호 밖에 그냥 놓인 로마자(`GPS`, 영문 작품명)는 한글로 바꿀지 판단이 필요해 기계로 고치지 않는다.

## 영문

`translate`는 muse-spark 1.3 기여자 라인(OpenCode Go)으로 옮긴다. 견본 6편을 muse·devin(SWE-2)·Sonnet에 같은 지시로 맡겨 보니 muse가 Sonnet에 가까웠다. devin보다 원문에 충실했고 가장 빨랐다. devin은 직역투가 남았다.

- 3편씩 묶는다. 4편씩 묶었더니 긴 원고가 든 묶음에서 응답이 잘렸다.
- 한글 잔존, 끝 잘림, 문단 수, 분량 비율을 검사해 통과한 번역만 빈 영문 칸에 쓴다. 걸린 편은 빈 채로 남으므로 `--size 1`로 다시 돌린다.
- Go 라인이 한도로 멈추면 `--backend devin`으로 잇는다.
- muse 호출도 구독 한도를 쓰는 비용이다. 대상이 많으면 `--limit`으로 몇 편을 먼저 확인한다.

## 사람 검토와 잠금

주인장은 서비스 화면에서 읽으며 검토한다. 기계 검사와 판정이 못 잡는 흠은 앞뒤가 어긋나는 문장과 사후 시점이다. 확정한 원고는 `virtual_monologue_locked_at`을 찍어 잠근다. 잠긴 원고는 어떤 명령도 비우거나 고치지 않는다.

## 쓰지 않는 경로

아래 명령은 코드에 남아 있지만 집필과 수정에 쓰지 않는다.

- `generate`·`status`·`inspect`·`apply`: Gemini 초안, Gemini 웹 검수, Claude Opus 최종 검수를 잇는 세 호출 경로다. 검수 계약이 원고를 연보로 굳혔다.
- `devin`: 사실 정확도는 높지만 화자가 전기 작가로 미끄러진다. "~라는 가르침이 오래 남았다"처럼 자기 삶의 의미를 밖에서 요약하는 문장이 인물마다 되풀이됐고, 지시서를 고쳐도 사라지지 않았다. devin은 표기 정리와 번역 예비선에만 쓴다.
- `repair`: agy 국소 수정이다. 「고치는 기준」대로 이미 넣은 원고는 모델에 맡기지 않는다.
