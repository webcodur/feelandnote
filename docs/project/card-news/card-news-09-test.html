09 디지털저항군 — 카드 테스트

실제 faction-data.json 텍스트 + 영상용 실이미지(정사각). 팀이 한 목소리로 이어 말하는 구조가 메인 축.

읽는 법: 가로로 밀면 캐러셀(인스타 게시물 1건처럼) 넘어간다. 각 섹션 우측 라벨이 출력 비율. 같은 데이터를 비율만 바꿔 여러 플랫폼에 먹인다.
A · 팀 한 목소리 캐러셀 4:5 · 인스타·쓰레드

메인 포맷. 세력 1개 = 게시물 1건. 표지(그룹샷) → 인물 대사 카드(대사가 주인공, 직함은 한 줄만) → 팀 마무리. 한 팀의 대사들이 하나의 선언처럼 흐른다.
