# 서재탐방 한국어 문장 기준

스토리 구조와 사실이 확정된 뒤 문장을 다듬는다. 자연스러운 한국어를 만드는 것이 목적이며, 모든 문장을 같은 틀에 맞추지 않는다.

## 기본 원칙

- 좋은 문장은 그대로 둔다.
- 사람과 행동을 앞세운다.
- 뜻이 한 번에 잡히면 주어를 생략해도 된다.
- 문장 사이 관계가 분명하면 연결어를 억지로 넣지 않는다.
- 문장 길이를 숫자로 맞추지 않는다. 소리 내어 읽었을 때 한 호흡에 뜻이 잡히는지 본다.
- 같은 종결이 반복돼도 장면의 긴장이 살아 있다면 기계적으로 바꾸지 않는다.

## 우선 고칠 문장

### 번역투

> **판별과 교정 규칙은 `docs/project/writing-rules.md`가 SSoT다.** 사물 주어, 영어 분열문,
> 개념을 영어로 잡고 한국어 옷을 입히는 문제, 의미 전환 단계, 반복 수사 금지가 거기 있다.
> 문장 단위 진단표는 `ko-detranslate` 스킬. 여기서 규칙을 다시 정의하지 않는다.

이 단계에서 특히 자주 걸리는 것만 적는다.

- `~에 대한`, `~에 있어서`, `~을 통해`, `~의 일환으로`가 겹친 문장
- 사람이 할 일을 사물이 하는 문장
- 불필요한 수동태와 과거진행형
- 영어 어순을 따라 핵심 서술어가 지나치게 늦게 나오는 문장

예:

- 약함: `이 실패는 그에게 새로운 선택을 가능하게 했습니다.`
- 나음: `그는 실패한 뒤 다른 길을 골랐습니다.`

### AI식 추상어

- `운명`, `본질`, `시선`, `무게`, `구원`, `전환점`만으로 사건을 대신한 문장
- 세 개의 추상 명사를 나란히 놓고 의미를 만든 듯한 문장
- “단순한 A가 아니라 B”를 반복하는 문장
- 비유를 빼면 새 정보가 없는 문장

추상어가 필요하면 바로 앞이나 뒤에 행동·물건·장소·결과를 붙인다.

### 평론투와 과장

- 인물의 내면을 근거 없이 단정
- 작품의 가치를 “위대한”, “전무후무한” 같은 형용사로 대신
- 시청자에게 감정을 명령
- 실제 사건보다 해설자의 결론이 더 긴 문장

## 쉬운 말 기준

- 중학생과 할머니가 한 번에 알아들을 수 있는 낱말을 우선한다.
- 전문용어는 없애기보다 먼저 풀어 쓴다.
- 한 문장에 낯선 고유명사와 개념을 동시에 여러 개 넣지 않는다.
- 쉬운 말로 바꿔 정확성이 떨어지면 원어를 남기고 짧게 설명한다.

## TTS 기준

- 숫자·연도·외국어는 실제 발음을 확인한다.
- 쉼표가 많아 숨이 끊기면 문장을 나눈다.
- 인용문과 해설의 목소리가 섞이지 않게 한다.
- 짧은 문장만 연속해 자막이 토막 나지 않는지 듣는다.
- 발음 치환과 음성 시각은 텍스트 확정 뒤 처리한다.

## 보호 대상

문체 검토만 요청받았다면 다음은 바꾸지 않는다.

- 검증된 직접 인용
- 인명·연도·숫자·출처
- 화자·음성·이미지·타이밍 정보
- 이미 자연스럽고 구체적인 문장

사실이 의심되면 문체로 고치지 말고 사실검증 대상으로 표시한다.

## 작업 방식

1. Markdown 원고를 처음부터 끝까지 읽는다.
2. `유지`, `부분 수정`, `재작성`, `삭제 검토`, `사실 확인`으로 나눈다.
3. 대표 문제와 수정 방향을 먼저 보여준다. 사용자가 바로 적용하라고 했다면 곧바로 진행한다.
4. 필요한 문장만 고친다.
5. 확정 후 제작 데이터에 반영하고 구조를 검사한다.

## 최종 질문

- 이 문장을 한국어 화자가 실제로 이렇게 말할까?
- 누가 무엇을 했는지 바로 보이는가?
- 비유나 추상어를 빼도 정보가 남는가?
- 앞 문장의 뜻을 다른 말로 반복하지 않는가?
- 소리 내어 읽었을 때 한 번에 알아듣는가?
