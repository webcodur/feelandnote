# 수익화와 상품 판매

## 개요와 지향점

Feel&Note는 인물과 그들이 읽고 보고 듣고 즐긴 작품을 통해 취향을 발견하는 서비스다.
그 관심이 해당 작품의 소장·구매나 직접 관련된 상품으로 이어지도록 만들고,
**제휴 상품 판매를 사이트의 주 수입원으로 발전시킨다.**
현재 주 수입원이 되었다는 뜻은 아니며, 매출 규모와 전환 성과는 아직 이 문서에서 확인하지 않았다.

사이트 안에서 결제하는 쇼핑몰을 새로 만드는 구상은 아니다. 방문자가 인물과 작품을 탐색하는 기존 경험 안에서
살 이유가 있는 상품을 발견하고, 쿠팡·아마존 등 판매처에서 구매하면 제휴 수수료를 얻는 방향이다.
도서 중심의 현재 구성을 음반·게임 패키지·작품 관련 상품 등으로 넓힌다.
상품 수를 늘리는 일과 사용자가 납득할 자리에 놓는 일을 함께 풀어야 한다.

현재 서비스 단계에서는 박물관 같은 깊은 페이지까지 방문할 것을 기대하기 어렵다는 운영자의 판단을 따른다.
**홈·탐색·서재 메인페이지와 셀럽 페이지가 우선**이다. 접점은 여러 주요 화면으로 넓히되,
각 상품은 화면에서 보고 있는 특정 인물·작품·요소와 직접 연결되어야 한다.

AdSense는 제휴 판매와 함께 운영을 검토할 광고 수단이다. 검색 유입·광고 승인·제휴 매출을 같은 상태로 취급하지 않는다.
방문자가 늘어날 때까지 상품 판매를 뒤로 미루거나, 광고 승인만 기다리는 구조로 두지 않는다.

이 문서는 수익화 방향, 기존 구성, 화면별 배치와 필요한 UI의 기준을 쥔다.
플랫폼별 세부 운영은 아래 문서에서 관리하며 TODO는 이 문서를 가리킨다.

| 문서 | 담당 내용 |
|---|---|
| [제휴 판매 운영](affiliate-commerce.md) | 예스24·쿠팡·아마존, 언어와 판매처, 링크·판본·상품 관리, 계정 준비 |
| [AdSense 운영](adsense.md) | 광고 연결과 승인 확인, 콘텐츠 심사, 광고 배치 검토 |
| [SEO](seo.md) | 검색엔진 접근·색인·사이트맵 |
| [유입 실측](traffic-audit-2026-07-25.md) | 날짜가 명시된 과거 유입 근거. 현재 방문자 규모로 옮겨 쓰지 않는다 |

## 기존 구성

2026-09-14 코드 확인 기준이다. 실제 계정 승인·수익 실적과 화면 구현 여부는 별개다.

| 화면·구획 | 기존 판매 구성과 한계 |
|---|---|
| 홈 | 오늘의 인물과 작품, 인물 목록 등이 중심이며 하단에 한국어 제휴 도서 목록이 있다. 주요 요소 옆의 비도서 상품 연결은 아직 없다 |
| 탐색 메인 | 인물 필터와 결과 목록이 앞에 선다. 예전 문서의 ‘홈·작품·탐색 공통 추천 도서’ 설명과 달리 현재 탐색 메인 페이지에는 그 도서 모듈을 직접 넣지 않는다 |
| 서재 메인 | 인기 도서 미리보기·기관 선정·박물관·학당이 있고 하단에 제휴 도서 목록이 있다. 인기 도서의 출처 서점 링크와 수수료가 발생하는 제휴 링크는 구별해야 한다 |
| 셀럽 페이지 | 중단 연관작품과 페이지 하단 참고도서는 별도 구획이다. 참고도서는 등록된 연관 도서를 먼저 놓고 읽은 책·직군·인기 도서로 보충하므로 모든 상품을 해당 인물의 직접 추천으로 볼 수는 없다. 쿠팡 상품이 없는 한국어 ISBN 판본도 예스24로 연결한다 |
| 콘텐츠 상세 | 한국어 도서는 같은 ISBN의 예스24 판매 상품과 기존 쿠팡 링크를 함께 표시한다. 다른 콘텐츠는 등록된 판매처 링크를 화면 언어에 맞춰 표시한다 |
| 기관 선정 목록 | 한국어 도서 카드에서 예스24·쿠팡을 직접 선택한다. 쿠팡 상품이 없으면 예스24 버튼 하나를 표시하며, 미등록 작품은 비활성 자리를 유지한다 |
| 세력도감·신화 | 분야·원전·인물 관계에 맞춘 도서 연결이 있다. 세력도감 인물 소개 모달은 그 인물 관련 책·읽은 책마다 예스24·쿠팡 단추를 붙인다 |
| 광고 | AdSense 연결 코드가 있다. 코드 설치만으로 광고 승인이나 광고 수입 발생을 뜻하지 않는다 |

제휴 도서 목록은 [getAffiliateBooks.ts](../../../sw/web/src/actions/home/getAffiliateBooks.ts)가 조회·선정한다.
서점 순위 명단을 먼저 고려하고 인물의 독서 근거와 회전을 함께 쓰며,
명단과 상한은 [affiliateBookPicks.ts](../../../sw/web/src/constants/affiliateBookPicks.ts)가 쥔다.
문서에 별도 순위·건수·상한을 유지하지 않는다.

현재 전용 제휴 도서 카드의 표지·제목은 판매처로, 별도 상세 버튼은 서비스 작품 상세로 간다
([AffiliateBookList.tsx](../../../sw/web/src/components/shared/AffiliateBookList.tsx)).
일반 콘텐츠 카드의 열람 동작까지 같다고 가정하지 않는다.
기관 선정 목록의 구체적인 카드·빈자리 규칙은 [큐레이션 목록](../service/curated-lists.md)이 쥔다.

## 이번에 변경한 내용

첫 시도에서는 홈 하단에 스피커, 서재 하단에 독서용품, 쉼터 하단에 체스 상품을 붙였다.
페이지 주제와 상품을 느슨하게 연결한 배너였고 사용자가 지적한 대상 옆의 자연스러운 연결을 충족하지 못해 제거했다.
그때 만든 일반 상품 배너·데이터·전용 색상도 정리했다.

이후 박물관의 특정 콘텐츠 항목을 상품 사진·모델 또는 판본·구매 링크가 이어지는 행으로 바꿨다.
데스크톱에서는 구매 링크가 오른쪽에, 모바일에서는 항목 이름 아래에 붙는다.

| 남겨둔 항목 | 연결 상품 | 위치 |
|---|---|---|
| 듀얼센스 적응형 트리거 | 소니 PS5 듀얼센스 화이트 CFI-ZCT2G | [게임 입력 인터페이스 → 아날로그 스틱과 햅틱](http://localhost:3000/library/museum?cat=game&sub=interface#product-dualsense) |
| 비틀즈 Sgt. Pepper’s | 같은 앨범의 발매 50주년 LP | [음악 매체 → LP·바이닐](http://localhost:3000/library/museum?cat=music&sub=media#product-sgt-pepper) |
| 젤다: 야생의 숨결 | Nintendo Switch 한국어 본편 패키지 | [게임 그래픽 → 오픈월드](http://localhost:3000/library/museum?cat=game&sub=graphics#product-breath-of-the-wild) |

현재 구현은 [TargetProduct.tsx](../../../sw/web/src/components/features/commerce/TargetProduct.tsx),
연결 대상·상품은 [targetProducts.ts](../../../sw/web/src/components/features/commerce/targetProducts.ts)가 쥔다.
박물관 연표·시대·항목 이름이 모두 일치할 때만 해당 상품을 표시한다.
[getDeveloperProducts.ts](../../../sw/web/src/components/features/commerce/getDeveloperProducts.ts)가
개발 환경과 한국어 여부를 확인한 뒤 데이터를 넘기므로 운영·영문에는 표시하지 않는다.

세 상품은 실제 쿠팡 상품·옵션과 클릭 도착지를 확인했지만, **현재 시안의 링크는 일반 상품 상세 주소**다.
수수료를 추적하는 제휴 판매 연결을 완료한 것으로 세지 않는다. 고정 가격은 화면에 표시하지 않는다.
박물관 시안은 사용자의 지시에 따라 그대로 둔다.
다만 깊숙한 곳에 하나씩 놓인 이 시안은 주요 화면의 판매 개편을 대신하지 못한다.

## 주요 화면에서 연구할 배치

아래는 앞으로 검토할 방향이다. 상품 후보와 최종 위치가 확정된 상태는 아니다.

| 주요 화면 | 먼저 볼 요소 | 자연스럽게 연결할 방향 |
|---|---|---|
| 홈 | 오늘의 인물과 그 구획에서 실제로 소개하는 작품, 인물 미리보기 | 소개 중인 작품의 구매 또는 그 인물과 직접 관계가 확인된 상품을 해당 요소 옆에 둔다. 인물·작품이 바뀌면 상품도 함께 바뀐다 |
| 탐색 메인 | 필터·검색 결과에 나온 인물과 선택한 인물의 미리보기 | 관심을 보인 인물의 작품·관련 상품으로 잇는다. 직군만 보고 공통 생활용품을 붙이거나 인물 카드마다 무차별로 광고를 늘리지 않는다 |
| 서재 메인 | 인기 작품과 기관 선정 미리보기에 실제 표시된 작품 | 그 작품의 판본·실물 구매를 카드에 연결하고, 소개되는 매체에 따라 음반·게임 패키지 등도 검토한다. 출처 서점 링크를 제휴 링크로 오인하지 않는다 |
| 셀럽 페이지 | 상단 인물 소개와 대표작, 선택한 감상·창작 작품 | 해당 인물의 저작·음반·관련 작품 등과 구매를 연결한다. ‘읽은 작품’, ‘창작한 작품’, ‘등장하는 작품’, ‘관련 상품’을 사실대로 구별한다 |

사용자가 관심을 갖는 요소와 구매할 이유부터 찾는다.
유명인과 회사·브랜드가 관련되어 있다는 이유만으로 ‘그가 쓰는 제품’이나 ‘추천 제품’이라고 쓰지 않는다.
같은 작품인지, 모델·판본·플랫폼이 맞는지 확인하고 그 연결 이유가 화면에서도 드러나게 한다.

## 필요한 UI 모듈

여러 주요 화면에서 재사용할 수 있는 아래 형태를 연구한다.
이미 구현된 것은 도서 구매 UI와 박물관의 작은 상품 행이며, 아래 조합 전체가 갖춰진 것은 아니다.

| 모듈 | 사용자에게 보여줄 것 | 필요한 자리 |
|---|---|---|
| 작품 카드 안의 구매 액션 | 지금 보는 작품의 판매처와 판본·매체. 서비스 상세 보기와 외부 구매를 구별 | 홈 작품 미리보기, 서재 인기·기관 선정 카드, 셀럽 작품 목록 |
| 대상 옆의 작은 상품 행 | 상품 사진, 특정 대상과의 연결, 모델·판본, 판매처 링크 | 인물 미리보기나 대표작·감상 작품 바로 옆. 박물관의 현재 행을 그대로 모든 곳에 복사하지 않고 각 화면에 맞춘다 |
| 특정 인물·작품에 딸린 상품 묶음 | 같은 대상의 음반·관련 도서·정식 관련 상품처럼 각각 선택할 이유가 있는 상품 | 셀럽 대표작 구획이나 선택한 작품 주변. ‘인기 상품’ 같은 독립 광고 구획으로 흩어지지 않게 한다 |
| 판본·형태 선택 | 번역·완역·합본, LP·CD, 게임 기종 등 구매 전에 필요한 차이 | 같은 작품에서 선택지가 실제로 존재하는 경우. 의미 없는 상품 수 확대에 쓰지 않는다 |

판매처 표시, 대가성 안내, 링크 없음·품절 처리, 가격을 표시할 경우의 갱신 방식은 공통으로 다룬다.
기관 선정 목록의 구매 링크 없는 자리는 유지하면서 신규 모듈의 빈자리 처리는 별도로 설계한다.
새 상품 모듈은 우선 **개발자모드에서만** 실제 상품으로 확인한다.
모바일 첫 진입과 주요 요소 주변에서 찾을 수 있어야 하며, 직접 주소로 깊은 위치를 찾아가야만 보이는 시안으로 평가를 끝내지 않는다.

## 주 수입원으로 발전시키기 위한 과제

주요 화면에서 정확한 상품 연결을 먼저 만들고, 검증된 연결과 UI를 다른 인물·작품으로 넓힌다.
박물관 같은 깊은 페이지 확대는 그 뒤다. 작품 소개와 탐색이 살아 있어야 상품을 볼 이유도 유지된다.

일반 상품 주소를 검증된 제휴 링크로 연결하고, 방문자가 본 상품과 실제 구매 가능한 상품이 일치하도록 관리한다.
품절·판매자 변경·판본 변경을 점검하는 운영은 상품 수와 함께 늘어난다.
수집 자동화는 확인된 상품을 유지하는 수단으로 발전시키며 상품 선정 판단을 생략하지 않는다.

어느 화면·대상·상품에서 클릭이 발생하는지, 제휴 대시보드에서 실제 매출·수수료로 이어지는지를 함께 살핀다.
노출 수와 클릭 수를 매출처럼 보고하지 않는다. 측정 연결은 기존 분석 수단을 확인한 뒤 설계할 과제이며,
지금 상품별 전환 측정이 구현되어 있다는 뜻은 아니다.

한국어는 쿠팡을 중심으로 먼저 다듬고, 영어는 아마존의 계정·지급·제휴 링크·고지 준비와 화면 지원을 함께 갖춘다.
광고 연결·승인 업무는 [AdSense 운영](adsense.md), 제휴 계정과 상품 관리의 실제 준비는
[제휴 판매 운영](affiliate-commerce.md)에서 이어간다.
