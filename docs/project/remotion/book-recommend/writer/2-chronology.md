# 인생 순서 배치 규칙

에피소드 books 배열이 인물의 생애 연대기를 따르도록 배치하는 기준.

---

## 에피소드 파일 경로

```
sw/remotion/public/episodes/{stage}/{person}/{locale}.json
```

- `{stage}`: `pre-todo` | `todo` | `live` | `done`
- `{locale}`: `ko` | `en`

---

## 기본 원칙

**시간순이 기본값.** 인물의 생애를 따라가는 서사가 가장 자연스럽다.

단, 시간순은 **강제가 아니라 권장**이다. **핵무기(가장 강렬한 장면)가 감정 곡선의 올바른 위치(클라이맥스=후반 1/3)에 오도록** 전치를 허용한다. 배치의 목표는 시간순 준수가 아니라 도끼가 박히는 서사 구조다. → 감정 곡선 기준: `3-story-power.md` §2

---

## 시간순 배치 절차

### 1단계: 시점 추출

각 책의 context에서 시점 정보를 추출한다:

- **명시적 시점**: "기원전 334년", "1865년", "20대 초반"
- **사건 기반 시점**: "원정 출발 직후", "투옥 기간 중", "은퇴 이후"
- **생애 단계**: 유년기, 청년기, 전성기, 말년

### 2단계: 타임라인 구성

추출한 시점을 인물의 생애 타임라인에 매핑한다:

```
Book N: [시점] — [생애 단계] — [핵심 사건]
```

### 3단계: 현재 순서 대조

현재 books 배열 순서와 타임라인을 비교한다. 역행이 있으면 표시.

### 4단계: 재배치 제안 또는 확인

- 역행 없음 → 현재 순서 확인
- 역행 있음 → 전치 허용 여부 판단 후 재배치 제안

---

## 전치 허용 조건

시간순 역행이 허용되는 경우:

| 조건 | 예시 |
|------|------|
| **반전 효과** | 마지막 책이 유년기 독서 — "모든 것은 여기서 시작되었다" 여운 |
| **테마 그룹핑** | 전쟁 관련 책 2권을 연속 배치하여 테마 집중 |
| **감정 곡선 최적화** | 가장 감동적인 일화를 클라이맥스 위치(끝에서 2번째)에 배치 |
| **인과 연결 강화** | 시간순으로는 떨어진 두 책이 인과적으로 연결됨 |

### 전치 시 필수 조건

- 전치 사유를 명시한다
- context 텍스트에서 시간 역행이 혼란을 주지 않는지 확인한다
- "이후", "그 뒤로" 같은 시간 연결어가 역행과 충돌하지 않는지 확인한다

---

## 벤치마크: 알렉산더 대왕

가장 이상적인 시간순 배치 사례:

```
Book 1 일리아스      — 어린 시절 (출발 전)
Book 2 페르시아 원정기 — 아버지 시대~원정 준비
Book 3 키루스의 교육   — 정복 후 통치
Book 4 고대 그리스 서정시 — 기원전 335년
Book 5 오디세이아     — 기원전 331년
Book 6 아이스킬로스    — 기원전 330년
Book 7 소포클레스     — 기원전 328년
Book 8 에우리피데스    — 기원전 324년~죽음
```

8권의 책이 생애 연대기를 따라가며, 동시에 감정 곡선(영웅의 여정→몰락)도 자연스럽게 형성된다.

---

## 확인 사항

- shorts의 book-context 순서도 롱폼 books 순서와 일관되는지 확인
- 재배치 시 context 내부의 시간 표현("이후", "그 전에")이 새 순서와 충돌하지 않는지 확인
- 재배치 후 책 간 연결(마지막 문장→다음 책 암시)이 깨지지 않는지 확인

---

## 금지 사항

- 재배치가 필요하면 books 배열과 tts.books 배열을 즉시 수정한다
- 재배치 후 context 내부의 시간 표현이 새 순서와 충돌하면 함께 수정한다
- 시간 정보가 불분명한 책을 억지로 특정 위치에 배치하지 않는다
- 전치 사유 없이 "느낌상" 재배치하지 않는다
- 배치 분석 중 문체·사료·구성 문제가 보이면 함께 지적하고 수정한다

## 보고 형식

```
## [인물명] 시간순 분석

### 현재 배치
| # | 책 | 시점 | 생애 시기 |
|---|-----|------|-----------|
| 1 | [책제목] | 기원전 334년 | 원정 출발 |
| 2 | ... | ... | ... |

### 판정: ✅ 시간순 / ⚠️ 부분 전치 / 🔄 재배치 제안

### 재배치 제안 (해당 시)
- Book 3 ↔ Book 4: [사유]

### 의도적 전치 (허용)
- Book 5를 Book 6 앞에 배치: [스토리 효용 설명]
```

- 재배치가 필요하면 books + tts.books를 **즉시 수정**한다. 제안만 하지 않는다.
- 재배치 후 context 내부의 시간 표현이 새 순서와 충돌하면 함께 수정한다.
