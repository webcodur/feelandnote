# 지속 과제

완료로 닫히지 않고 대상을 바꾸어 반복하는 작업은 현재 도달점만 여기에 둔다. 끝이 정해진 후속 작업과 막힌 실행 큐는 [`todo/`](../todo/README.md)로 보낸다.

반복 작업은 서비스·대상별로 마지막 실행 묶음의 실제 종료 일시와 시간대를 하나씩 남긴다. 다음 실행이 끝나면 기존 값을 교체하고, 이전 일시·결과를 누적하지 않는다. 실패·한도 확인으로 끝난 실행도 마지막 작업에 포함한다. 다음 실행 가능 시점은 마지막 일시와 확인된 초기화·대기 규칙으로 판단하며, 규칙이 확인되지 않았으면 그 사실을 남긴다.
